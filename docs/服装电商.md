## 一、七维基础参数体系（固定不变）

所有视频生成，必须基于以下七维参数：

1. **性别品类**：男装 / 女装 / 裙装
2. **款式品类**：T恤、衬衫、卫衣、针织衫、毛衣、背心、吊带、打底内搭、夹克、风衣、大衣、防晒衣、冲锋衣、西裤、休闲裤、牛仔裤、阔腿裤、半身裙、吊带裙、西装裙、针织裙、连衣裙、两件套、运动套装、西装套装
3. **风格属性**：职场办公 / 日常休闲 / 潮流街头 / 户外机能 / 极简高级 / 温柔气质
4. **档次定位**：平价刚需 / 中端质感 / 高端轻奢
5. **自定义场景**：用户自由输入
6. **发布平台**：淘宝 / 京东 / 拼多多 / 抖音 / 小红书 / 亚马逊 / TikTok Shop / Shopee / Lazada / 速卖通
7. **输出语言**：中文 / 英文 / 西班牙语 / 葡萄牙语 / 阿拉伯语

**强制约束**：
- 所有内容必须严格适配七维参数，禁止通用模板输出。
- **输出语言强制规则**：输出语言选定后，口播文案、字幕、标题、封面词、标签**全部强制同步翻译**为该语言，禁止只翻译口播不翻译运营素材。


## 二、商品卖点双模式生产体系

### 2.1 卖点两种获取模式

**模式1：用户手动输入**

用户可输入零散卖点、短句、关键词。AI自动完成：清洗、去重、归类、润色、精炼、结构化，并自动编号为S01–S0N。

**模式2：AI智能自动生成**

用户指令「AI自动生成」，AI根据：款式 + 风格 + 档次 + 场景，自动生成5–8条专属精准卖点，并自动编号为S01–S0N。

**极端情况兜底规则**：当用户输入卖点少于3条时，AI自动触发补充追问：「您提供的卖点较少，我将基于当前品类自动补充3条通用卖点，请确认是否采纳。」用户确认后方可进入下一环节。

### 2.2 卖点分层规则（强制）

**核心卖点（2–3条）**

必须写进口播台词，用户听觉强种草。

**视觉卖点（3–4条）**

不啰嗦口述，全部通过镜头特写、面料、工艺、版型镜头视觉落地。

**辅助卖点（剩余）**

放置于：小红书正文、详情、标签、字幕点缀。

### 2.3 卖点全局强制约束

1. 后续所有口播、分镜、画面、封面、文案必须围绕**定稿卖点**生成
2. 禁止无卖点、通用套话、同质化脚本
3. 每条卖点必须落地，不能只陈列不应用
4. **卖点落地验收机制**：分镜表中必须增设「承载卖点ID」字段（必填），每镜至少绑定1条卖点ID，全片6镜须覆盖全部核心卖点+视觉卖点。最终交付须附带「卖点覆盖率验收清单」，逐镜核对，缺失即判为不合格。


## 三、口播文案生产规范（6套固定结构）

固定配比：2套固定 + 4套动态场景智能生成

**固定两套**

1. **痛点救场型**：解决穿搭麻烦、身材短板、场景不适配
2. **质感种草型**：突出面料、做工、细节、品质

**动态四套（AI自动适配场景）**

3. 场景价值塑造型
4. 氛围审美种草型
5. 实用百搭多穿型
6. 情绪体验穿搭型

**口播强制格式**

每套必须包含：方案名称 + 一句话核心叙事 + 完整口播文案。


## 四、六镜分镜全局硬性规则（不变刚性标准）

1. 固定6镜结构
2. 总时长严格**≤30秒**
3. 单镜时长：**3–7秒**，精度0.5秒
4. 短镜≤5.5s：单景别固定，禁止内部变焦
5. 长镜≥6s：允许平缓推拉景别过渡，禁止跳跃变焦
6. **景别顺滑曲线强制执行（6节点，与镜1–镜6完整映射）** ：

| 镜号 | 景别 |
|------|------|
| 镜1 | 全景 / 中全景 |
| 镜2 | 中全景 / 中景 |
| 镜3 | 中近景 / 近景 |
| 镜4 | 近景 / 特写 |
| 镜5 | 中景 |
| 镜6 | 中全景 |

**景别过渡原则**：由远及近再回中，形成视觉呼吸曲线，禁止跳跃式景别切换。

|------|----------|

| 模特动作 | 10–22字 |

| 画面色调与质感 | 12–25字 |


## 六、五套分镜固定版本体系（必须同时产出）

- **A版**：上身主导动态流量版
- **B版**：细节均衡全能版
- **C版**：场景氛围极致版（AI动态场景生成，禁止模板）
- **D版**：真实日常实拍版（AI动态生活化）
- **E版**：质感细节强化版（主打卖点可视化）


## 七、运镜规范（固定枚举，禁止自创）

**固定可用运镜**：固定静帧、缓慢推近、轻微拉远、左右微摇、跟随平移、慢速环绕、轻微俯拍、轻微仰拍、局部放大聚焦、平稳定格

**场景适配原则**：
- 正式场景（职场/高端）：稳、静、慢推、定格
- 日常场景（休闲/街头）：轻摇、平移、松弛
- 户外场景（机能/运动）：灵动、环绕、跟随


## 八、色调质感自适应体系

三层自动匹配：**场景色调 + 档次色调 + 风格色调**。禁止固定滤镜，必须智能自适应。

| 维度 | 取值方向示例 |
|------|-------------|
| 场景色调 | 室内暖光 / 户外冷白 / 街头霓虹 / 自然日光 |
| 档次色调 | 平价（明快高调）/ 中端（柔和中性）/ 高端（低饱和哑光） |
| 风格色调 | 极简（黑白灰）/ 温柔（奶油色）/ 机能（金属感）/ 街头（高饱和） |

## 十、全套运营素材产出规范

必须全套生成（所有文本类素材须同步输出为选定语言）：

1. **10个分层爆款标题**——必须按顺序产出，并在标题后标注类型：【痛点型】3条 + 【卖点型】3条 + 【场景型】2条 + 【价格型】2条，缺一不可

5. **逐镜剪辑节奏 + BGM + 音效方案**
6. **完整发布正文模板**（含@官方账号、话题标签）


## 十一、全局最终禁令

1. 禁止通用无卖点脚本
2. 禁止镜头跳切、违规变焦
3. 禁止字数超标、空字段
4. 禁止CDE模板固化（C/D/E版必须AI动态生成，禁止复用固定模板）
5. 禁止无视七维参数
6. 禁止一次性全部输出，必须分步确认
7. 禁止卖点陈列不落地（须通过卖点ID逐镜验收）

# AI交互式短视频Skill工作流 V4.4


## 一、界面固定架构（永久不变）

1. **右侧：AI交互对话区**——负责：分步提问、参数采集、卖点交互、用户选择、确认节点、流程引导
2. **左侧：可视化展示区**——负责：实时预览、参数面板、卖点清单、口播展示、分镜表格（含卖点ID绑定栏）、运营素材展示

**核心交互铁律**：所有提问、选择、修改、确认 → 全部在右侧；所有内容、成品、预览、表格 → 全部在左侧。


## 二、完整标准化工作流

### 阶段1：分步采集七维基础参数（AI单步提问）
一次只问一个参数，用户确认一步、推进下一步。全部采集完成后，左侧生成「产品参数档案面板」。

### 阶段2：卖点交互采集环节（核心升级）
AI右侧固定话术：
> 「产品基础参数已全部采集完成。接下来我们确定商品核心卖点。你可以：
> 1. 手动输入这款衣服的卖点（可以零散、可以短句）
> 2. 回复：AI自动生成，我将根据这款产品定位自动生成全套卖点清单」

**分支A：用户手动输入卖点**
AI自动：清洗、去重、归类、润色、结构化。左侧输出定稿卖点清单（编号S01–S0N）。用户可自由增删、修改、确认。

**分支B：用户回复「AI自动生成」**
AI自动根据：款式 + 风格 + 档次 + 场景，生成5–8条精准专属卖点，自动编号S01–S0N。左侧展示，用户可修改、删减、确认。

**兜底机制**：若用户输入卖点少于3条，AI在清洗后自动触发补充追问，确认后方可继续。

### 阶段3：卖点确认后强制锁定
AI锁定卖点为全局核心生产依据。后续口播、镜头、特写、封面全部强制植入卖点。分镜表中每镜须标注承载卖点ID，作为验收凭证。

### 阶段4：生成6套差异化口播文案
右侧提示进度，左侧实时展示全套6套文案。右侧引导用户：选择一套口播主干进入分镜生成。

### 阶段5：根据选定口播主干 + 定稿卖点，生成5套六镜分镜
AI全自动产出A/B/C/D/E五套合规分镜。全部卖点自动分配：核心卖点进台词、视觉卖点进镜头特写。

**口播与画面绑定规则**：五套分镜以选定口播为主干文案，允许**E版（质感细节强化版）和C版（场景氛围极致版）** 在固定主干基础上**微调±15%台词**（仅限语气词、场景呼应句），以适应极致特写或氛围长镜。A/B/D版须100%忠实于主干口播。

左侧展示完整分镜表格（按第十二章格式，含卖点ID绑定栏）。

### 阶段6：用户选定最终分镜版本
支持微调：场景、色调、动作、时长、质感强化。

### 阶段7：全自动生成全套运营素材包
标题、封面词、标签、字幕、剪辑节奏、BGM、发布文案。左侧完整展示。

### 阶段8：输出最终完整交付物
整合：参数档案 + 定稿卖点（含编号） + 口播 + 分镜表格（按第十二章格式） + 卖点验收清单（12.3格式） + 全套运营素材。

## 四、Skill强制执行顺序（不可打乱）

1. 七维参数分步采集
2. 卖点采集/AI生成 & 用户确认（含兜底与编号锁定）
3. 6套口播生成 & 用户选稿
4. 5套分镜全自动生成（按第十二章表格格式，卖点ID逐镜绑定）
5. 用户定稿分镜
6. 全套运营素材生成
7. 最终成品打包交付（含参数档案 + 卖点清单 + 口播 + 分镜表 + 验收清单 + 运营素材）


## 五、Skill核心执行规则

1. 必须分步交互，禁止一次性输出所有内容
2. 卖点为**强制前置环节**，跳过禁止进入口播
3. 所有内容必须绑定「参数 + 卖点」双驱动
4. 五套分镜以同一口播为主干，E版/C版允许±15%微调，其余版本100%忠实
5. 全程左展示、右交互、完全隔离
6. 支持任意环节回退、修改、重选、重生成
7. 最终交付物须附带「卖点验收清单」（按12.3格式），逐镜核对卖点ID是否全部覆盖
