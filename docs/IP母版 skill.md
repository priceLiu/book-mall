# Skill：IP 母版模板生成（ip-master-template）

> 本 Skill 用于从「角色基准图」或「文字描述」生成标准化的 IP 母版模板，固定角色识别骨架（刚性锚点）、标注可变更项（柔性可变项）与特例放行规则。模板可独立交付，也可被手办 SOP、品牌 VI+表情包 SOP 读取复用。
> 触发口令：`生成IP母版模板` / `IP模板` / `提取角色模板`

---

## 一、触发条件

### 1.1 触发场景
用户出现以下需求时启动本 Skill：
- “基于这张图提取 IP 模板 / 角色结构”
- “把这个角色的形象规范固定下来”
- “生成 IP 母版模板，后面手办和 VI 都用它”
- “把我的角色描述整理成结构化的固定模板”
- “做一个角色骨架规范”

### 1.2 必要输入（二选一）
| 输入方式 | 要求 |
|---|---|
| A. 图片输入 | 上传 1 张角色基准图（线稿 / 立绘 / 头像 / 已有手办或 VI 产物图） |
| B. 文字输入 | 输入角色文字描述（自然语言即可，AI 负责结构化） |

### 1.3 输入不足时的追问
若用户只说“生成 IP 模板”但未提供图片或描述，按以下话术追问，禁止凭空编造：
> 生成 IP 母版模板需要两项中的任一项：请上传角色基准图（线稿/立绘/头像均可），或输入角色文字描述（如：Q版潮玩、包子脸、3头身、星星发饰、科技感穿搭）。也可以两者都提供。

---

## 二、核心执行原则

1. **先锚点后细节**：优先锁定刚性锚点（识别骨架），柔性项只做标注，不做硬性固定；
2. **锁骨架，放皮肤**：脸型、头身比、标志性轮廓 = 不可改；发色、肤色、服饰、表情 = 允许变体；
3. **优先级明确**：每个刚性锚点标注最高/次优先级，AI 翻车时优先保高优先级特征；
4. **轻量校对**：自动提取后用户可快速编辑确认，不设计复杂人工审核；
5. **不编造**：图片或文字中无法确认的信息，标记「待补充」，不臆造默认值；
6. **版本管理**：每次保存生成新版本号，下游默认读取最新版。

## 三、前置开场白（用户提交输入后第一句发送）

> 你好，我将为你的角色生成一份 IP 母版模板：锁定不可改动的识别骨架（刚性锚点），标注允许变体的部分（柔性可变项），并记录特例放行规则。模板生成后，手办、VI、表情包等所有延展都以此为准。请上传基准图或输入角色描述，分步确认推进即可。

---

## 四、路径 A：图生模板（分步话术）

### 第 1 步｜接收图片并解析
> 话术：已收到你的基准图。我将解析角色特征，自动提取刚性锚点（脸型轮廓、头身比、标志性轮廓特征、五官相对排布）与柔性可变项（发色、肤色、服饰、表情动作）。
> 解析完成后，会先展示给你校对，确认后再保存为模板。是否开始解析？

- 用户确认 → 输出解析结果（模板草稿）

### 第 2 步｜展示模板草稿 + 快速校对
> 话术：解析完成，以下是提取的 IP 模板草稿。请检查刚性锚点是否准确、优先级是否合理；如有识别误差，直接告诉我修改（例如“脸型应该是方圆脸，不是圆脸”），确认无误后我保存为正式模板。

**模板草稿展示格式（直接输出以下结构）**
```
【IP角色结构化模板·草稿】
版本：V0.1（待确认）｜来源：图生模板
▌刚性锚点（不可改动，带优先级）
1.【最高优先级】标志性轮廓特征：<AI解析结果>
2.【最高优先级】脸型轮廓：<AI解析结果>
3.【次优先级】五官相对排布：<AI解析结果>
4.【次优先级】头身比：<AI解析结果>
▌柔性可变项（允许修改，用于系列变体）
1. 头发：发色、发型细节可更换
2. 肤色：可调整，支持异色限定款
3. 服饰、配饰：可更换款式、颜色、花纹
4. 表情、肢体动作：可自由变化
▌待补充项：<图片中无法确认的信息>
```

- 用户确认 → 保存为 V1.0 正式模板
- 用户提出修改 → 仅调整对应锚点/优先级，重新展示确认

### 第 3 步｜确认特例放行规则（可选）
> 话术：模板即将定稿。最后确认：是否有特殊场景需要临时突破刚性锚点？例如“超大摆件可临时改头身比”“迷你挂件可简化五官细节”。没有可以直接跳过，默认空白。

- 用户提供 → 写入【特例放行规则】
- 用户跳过 → 保持空白

### 第 4 步｜保存并交付
> 话术：IP 母版模板已生成并保存（版本 V1.0）。后续跑手办或品牌 VI 时，可直接读取此模板作为角色约束。需要我现在输出模板全文供你复制吗？

## 八、下游读取规则（手办 SOP / VI 表情包 SOP 集成）

1. 手办 SOP、VI 表情包 SOP 在「基准形象确认」步骤增加读取逻辑：
   - **已有模板**：读取选中的模板（默认最新版），将刚性锚点、柔性项、特例放行规则追加为本次生成约束；柔性项按本次需求覆盖（如盲盒新服装、表情包新表情）；
   - **无模板**：提示「可先生成 IP 母版模板（可选）」，或按原流程直接以参考图生成，不阻断；
   - **模板只读引用**：不修改下游 SOP 本身流程。
2. 冲突检测：用户同时上传新参考图并选择旧模板时，若刚性锚点明显冲突，弹出三选一：
   ① 以模板为准；② 以新图为准并覆盖更新模板；③ 重新生成模板。

## 九、纠错与异常处理

| 情况 | 处理 |
|---|---|
| AI 识别锚点有误 | 用户在草稿阶段直接提出修改，仅调整对应项，不重跑全流程 |
| 用户要改刚性锚点 | 允许，但保存为**新版本**（V1.1），旧版本保留可回溯 |
| 文字描述信息缺失 | 标记「待补充」，不编造默认值；用户可跳过留空 |
| 用户想换基准图 | 以新图重新解析生成新模板，不覆盖旧模板（并存） |
| 柔性项被误判为刚性 | 校对阶段用户可直接移动该项到柔性区 |
| 用户要求模板用于手办/VI | 输出模板全文 + 提示下游读取方式，不直接篡改下游流程 |
