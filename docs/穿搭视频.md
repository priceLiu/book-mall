AI穿搭视频动作迁移功能 产品设计文档（可直接编码落地版）
一、功能整体概述
1.1 业务背景
平台已具备成熟模特素材库、服装商品库，原有一键式AI视频生成属于黑盒全自动模式：用户提交素材后无任何干预权限，成片不可控、废片率高、无法自定义镜头节奏，无法满足精细化商业穿搭内容生产需求。
本次升级 【可视化分镜可控版穿搭视频动作迁移功能】：基于参考视频真实镜头结构拆解分镜、生成分镜预览图，开放用户分镜级编辑干预权限，用户确认镜头后再批量生成视频片段，最终无缝合并成片。兼顾AI自动化效率与人工精细化可控度，属于商业级成熟工作流。
1.2 核心设计原则（硬性技术规范）
- 禁止文本驱动动作：动作、镜头、时序全部由视频解析结构化数据控制，不由Prompt文字描述控制
- 全链路JSON结构化：所有AI入参、分镜数据、AI返回结果100%标准化JSON，无自由文本
- 三层条件驱动生成：骨骼动作时序 + 模特身份特征 + 服装版型特征，Prompt仅做画质/风格/兜底约束
- 可干预、可编辑、可回溯：打破黑盒生成，分镜可视化、支持单镜重绘、删除、调整、重生成
- 前后端解耦：AI只输出标准JSON结构，前端根据JSON字段解析渲染分镜、参数、视频信息
1.3 能力边界（明确可做/不可做）
✅ 可实现：参考视频真实镜头拆解、结构化分镜提取、分镜预览图生成、用户分镜编辑、单镜重生成、分段视频合成、动作复刻、模特服装锁定
❌ 不实现：不通过大模型虚构文字分镜脚本（精度过低、废弃方案），所有分镜源自原视频真实时序结构

二、全新升级用户操作流程（可视化可控版）
新增分镜预览编辑环节，用户拥有完整干预权，不再是无脑一键生成：
1. 步骤1：进入【穿搭视频迁移】功能模块
2. 步骤2：选择模特 —— 从平台模特库选择/上传模特图
3. 步骤3：选择服装 —— 从平台服装库选择对应穿搭服装
4. 步骤4：上传参考视频 —— 上传9:16竖屏爆款穿搭参考视频
5. 步骤5：后端自动解析拆镜 —— 拆解N段真实物理分镜、输出结构化分镜JSON + 每段分镜预览图
6. 步骤6：用户可视化编辑干预（核心新增） —— 查看所有分镜、删除劣质镜头、单独重生成某一分镜、调整镜头顺序
7. 步骤7：确认分镜队列，提交批量生成视频片段
8. 步骤8：后端无缝合并所有片段，输出完整10-15秒成片
9. 步骤9：前端解析JSON返回结果，展示成片、参数、状态

三、全新升级核心技术链路（可控制、可编辑版）
用户素材输入 → 参考视频真实镜头拆解（非文本AI脑补） → 结构化分镜时序数据 + 分镜预览图 → 用户编辑确认 → 逐镜骨骼迁移生成视频片段 → 帧对齐合并 → 成片输出
1. 视频分镜解析模块（核心新增）：对参考视频做镜头检测、场景切割、动作分段，拆分出真实物理分镜（每段2-4s）；逐段提取骨骼关键点、机位、动作、光影参数；输出分镜预览关键帧图片。
2. 分镜结构化存储模块：每一段镜头独立JSON对象，支持前端单独渲染、单独操作、单独重跑任务。
3. 特征绑定模块：锁定模特身份特征、锁定服装版型/色彩/面料特征，全部分镜统一特征参数，杜绝前后不一致。
4. AI生成模块（千万3.8 Max）：支持全局批量生成与单分镜单独重生成，基于每段镜头骨骼时序精准迁移。
5. 视频合并后处理模块：自动对齐所有分段首尾帧、消除拼接断层、全局统一光影色调、防抖降噪，合成完整成片。
6. 结果封装模块：强制输出分镜级+成片级双层标准JSON，前端完全可视化渲染。

四、AI模型选型 & 全链路JSON结构
4.1 固定模型选型
本功能统一使用 千万3.8 Max 大模型，适配视频镜头解析、分镜结构化、图像预览生成、视频时序迁移、强JSON格式约束，完美支撑可视化可控穿搭迁移流程。
4.2 核心逻辑最终对齐（完全匹配你的理解）
1、不是大模型脑补分镜：分镜全部来自原视频真实镜头切割，是物理存在的动作片段，不是文字虚构脚本。
2、精细化动作迁移：把原本整段15秒的黑盒迁移，拆成多段短镜头精细化迁移，画质、稳定性、一致性大幅提升。
3、彻底解决无干预问题：先出分镜预览图，用户审图、改镜、删镜、重镜后，再出视频，用户拥有完整控制权。
4、最终成片由可控片段拼接而成：质量远高于一次性盲生成。

五、用户分镜编辑权限（核心产品亮点）
前端完全基于JSON渲染分镜操作台，用户拥有以下所有干预能力：
- 查看所有分镜预览图：提前看每一段镜头效果，规避废片
- 删除单条分镜：删掉不好看、多余、动作怪异的镜头
- 单独重生成某一个分镜：某一段衣服崩坏/人脸异常，只重跑这一段，不用整体重跑
- 调整分镜顺序：微调视频节奏
- 批量生成：确认队列后一键生成所有片段
