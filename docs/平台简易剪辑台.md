# 平台简易剪辑台

> 状态：**平台层 + 电商试点（卡点成片）已全量对齐 Media Render**（2026-10-04）。

## 1. 产品定位

- **线上用户**：无需安装客户端或 npm 包；功能随 **e-commerce-toolkit / canvas-web** 容器发布，与 Gateway TTS、Media Render 等同域 API 配合使用。
- **名称**：平台简易剪辑台（Platform Simple Compose Workbench）
- **归属**：Book（book-mall）平台能力 + **`@private/platform-compose-ui`**（`book-mall/platform-compose-ui`）唯一 UI 维护点；电商 / 画布为薄壳 + adapter
- **目标**：多段视频顺序、入出点、分割、预览、导出合成；与画布「自动成片」共用 **Timeline v1 + RenderProfile**
- **非目标**：多轨专业混音、关键帧、特效库

## 2. SSOT 与 API

| 层级 | 路径 |
|------|------|
| 类型与转换 | `book-mall/lib/media/platform-compose-workbench.ts` |
| 剪辑纯函数 | `book-mall/lib/media/compose-workbench-editing.ts` · `@private/platform-compose-ui/editing` |
| 画布 adapter | `book-mall/lib/media/jianying-compose-adapter.ts` · `platform-compose-ui/jianying-adapter.ts` |
| 共享 UI 包 | `book-mall/platform-compose-ui` → `@private/platform-compose-ui` |
| HTTP 契约 | `book-mall/doc/tech/platform-compose-workbench-api.md` |
| 平台 TTS | `POST /api/sso/tools/media/tts/generate` |
| 通用合成 | `POST /api/sso/tools/media/compose/render` |
| SFV 段配音 | `POST .../compose/clips/:clipId/tts` · `POST/DELETE .../compose/clips/:clipId/audio` |
| SFV 业务 | `PATCH/POST .../simple-fusion-video/projects/:id`（meta + render） |
| 电商薄壳 | `e-commerce-toolkit/.../simple-fusion-compose-workbench.tsx` |
| 画布 Dock | `canvas-web/.../jianying-compose-dock-panel.tsx` + 节点 `composeWorkbench` |
