# 平台简易剪辑台

> 状态：**平台层 + 电商试点（卡点成片）已全量对齐 Media Render**（2026-10-04）。

## 1. 产品定位

- **名称**：平台简易剪辑台（Platform Simple Compose Workbench）
- **归属**：Book（book-mall）平台能力 + 共享前端（电商 `e-commerce-toolkit` 试点 UI）
- **目标**：多段视频顺序、入出点、分割、预览、导出合成；与画布「自动成片」共用 **Timeline v1 + RenderProfile**
- **非目标**：多轨专业混音、关键帧、特效库

## 2. SSOT 与 API

| 层级 | 路径 |
|------|------|
| 类型与转换 | `book-mall/lib/media/platform-compose-workbench.ts` |
| HTTP 契约 | `book-mall/doc/tech/platform-compose-workbench-api.md` |
| 通用合成 | `POST /api/sso/tools/media/compose/render` |
| 低阶合成 | `POST /api/sso/tools/media/render` |
| SFV 业务 | `PATCH/POST .../simple-fusion-video/projects/:id`（meta + render） |
| 前端 API 封装 | `e-commerce-toolkit/lib/platform-compose-render-api.ts` |
| 试点 UI | `e-commerce-toolkit/components/simple-fusion-video/simple-fusion-compose-workbench.tsx` |
