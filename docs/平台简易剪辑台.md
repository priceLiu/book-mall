# 平台简易剪辑台

> 状态：需求定稿 + **电商试点已落地部分能力**（卡点成片 · 简易剪辑）。目标形态为 Book 平台可复用组件与合成 API，供电商、画布、Story 等子应用接入。

## 1. 产品定位

- **名称**：平台简易剪辑台（Platform Simple Compose Workbench）
- **归属**：Book（book-mall）平台能力 + 共享前端包（当前试点 UI 在 `e-commerce-toolkit`）
- **目标**：在不做完整 NLE 的前提下，提供「多段视频顺序、入出点、分割、预览、导出合成」的剪映式轻量时间线，并与画布「自动成片 / 剪映导出」能力 **对齐数据模型与渲染选项**（字幕、TTS、BGM 等逐步补齐）
- **非目标（当前阶段）**：多轨音频专业混音、关键帧、特效库、协作审片

## 2. 用户场景

| 场景 | 说明 |
|------|------|
| 电商卡点成片 | 多段 i2v 按 BGM 节拍拼接；用户微调顺序、裁剪、分割后重新云端合成 |
| 画布 / Story（规划） | 分镜视频条目的顺序与粗剪，导出走统一 `media/render` |
| 任意子应用（规划） | 通过 Platform API 读写 `composeWorkbench` 快照 + 调用合成 |

## 3. 能力矩阵

### 3.1 时间线与交互（对齐 Dreamina / 剪映轻量习惯）

| 能力 | 说明 | 试点（SFV） | 平台目标 |
|------|------|-------------|----------|
| 迷你浮窗 | 页面内浮动，非通栏嵌入；可拖标题栏移动 | ✅ | ✅ |
| 全屏编辑 | 与迷你能力一致，更大预览与时间线 | ✅ | ✅ |
| 片段顺序 | 胶片条拖拽排序 | ✅ | ✅ |
| 入出点 | 拖 trim 手柄或快捷定界 | ✅ | ✅ |
| 播放头 vs 选中 | 解耦；分割仅当播放头落在**选中段**节目时间内 | ✅ | ✅ |
| 分割 | 播放头处拆分为两段 | ✅ | ✅ |
| 删除段 | 至少保留 1 段 | ✅ | ✅ |
| 导入片段 | 上传视频追加轨道 | ✅ | ✅ |
| 刻度缩放 | 迷你/全屏时间线 zoom | ✅ | ✅ |
| 竖屏缩略图 | 9:16 胶片条（卡点竖屏） | ✅（迷你） | 可配置 |

### 3.2 合成与持久化

| 能力 | 说明 | 试点（SFV） | 平台目标 |
|------|------|-------------|----------|
| 工作台快照 | `meta.composeWorkbench`（顺序、入出点、profile） | ✅ | 通用 schema |
| 专用合成 API | 按工作台导出，非仅默认顺序全长拼接 | ✅（SFV compose） | `POST /api/sso/tools/media/render` 通用化 |
| 成片展示 | 工作区占位格 + 悬停预览/下载 | ✅ | 各业务自选 UI |
| 字幕 / 烧录 | 样式包 `@private/media-render-subtitle-style` | ❌ 服务端仍 `none` | 与画布 auto-compose 一致 |
| ASR / TTS / mixTts | 画布已有字段 | ❌ | 接入 render profile |
| BGM | 模板级 preset | ✅（模板默认） | 工作台可选 / 替换 |
| 生成历史 | 全步骤落生成记录 | ✅（SFV 链路） | 各业务统一规范 |

## 4. 试点范围（电商 · 简易融合短视频）

**入口**：电商工具箱 → 短视频 → **卡点跳舞换装**（及同 compose 工作台的其他 SFV preset）→ ③ 卡点成片 →「简易剪辑」。

**前端（主要文件）**

- `e-commerce-toolkit/components/simple-fusion-video/simple-fusion-compose-workbench.tsx`
- `e-commerce-toolkit/lib/simple-fusion-compose-workbench.ts`
- `book-mall/lib/ecom/simple-fusion-video/compose-workbench.ts`

**已完成（截至 2026-10）**

1. 迷你剪辑浮窗：`ModalPortal`、宽约 `66.666vw`、默认底边距视口高度 1/3；**标题栏拖动**（fixed 定位 + 视口坐标 clamp）
2. `ComposeSequenceTrack`：节目时间映射、胶片条 reorder、trim commit、竖屏 `h-24` 轨道
3. 播放头全高；分割与播放头/选中段一致性修复（`programSecFromTrackPx` / `resolveClipAtProgramSec`）
4. 全屏编辑器与迷你能力对齐；导出/自动合成调用 SFV compose 渲染
5. ③ 区：成片 `EcomVideoSlot` + 悬停预览/下载（移除独立预览/下载按钮）

**已知缺口（下一阶段）**

- 合成 profile 未透传字幕烧录、段级 `subtitle` / `audioUrl`
- 未抽成独立 npm 包 / Book 文档化 HTTP 契约（仍绑 SFV 项目 API）
- 全站架构图未单独登记「简易剪辑台」服务（无新端口，随 book + ecom 前端）

## 5. 技术原则

- 厂商 AI / 重渲染经 **Gateway + Book**；剪辑台导出走 **Media Render**（云端 FFmpeg 类管线）
- 刷新可恢复：工作台写项目 meta；导出后更新成片 URL 与生成记录
- UI：电商内遵循 `ecom-workspace-media-standard.mdc`；禁止原生 `alert/confirm`
- 破坏性删除/清空轨道须二次确认（若产品提供「清空全部段」）

## 6. 验收要点（试点）

- [ ] 打开迷你剪辑 → 拖标题栏 → 浮窗仍在视口内；关闭后再开位置重置
- [ ] 播放头在选中段内时可分割；否则分割禁用或提示
- [ ] 改顺序/入出点后导出，成片时长与预览一致（允许编码误差）
- [ ] 重新生成某段 i2v 后，须再次导出成片
