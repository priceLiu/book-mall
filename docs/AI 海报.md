# AI 海报生成平台 V2.0（简化单人完整版 PRD）

> 
> 重要变更：**砍掉团队、子账号、管理员 / 成员权限体系**。全部为独立个人账号，一个账号拥有全部能力；品牌 VI、批量功能、AI 文案、多尺寸全部开放给当前登录人自主操作，没有角色隔离。适配 OPC 从业者、中小商家、运营个体，一人搞定全部海报生产，降低开发复杂度，优先把核心商业能力跑通。

## 1 产品总览

### 1.1 产品定位

面向 OPC 从业者、中小微商家、企业运营、商业自媒体的**单人商用 AI 海报生产力工具**。
主打：一个账号全部能力，无需团队权限，用户自己维护品牌信息、自己批量生成、自己管理全部作品，专注商业海报产出（日签、战报、招商、促销、产品海报、节日商业海报）。

> 
> 去掉：团队空间、成员管理、管理员权限、子账号体系。

### 1.2 目标用户

1. OPC 个人从业者 / 项目负责人（高频输出招商海报、喜报、战报、项目宣传）
2. 中小实体商家（门店促销、节日海报）
3. 中小企业市场 / 运营单人岗（没有设计，自己做全部物料）
4. 商业自媒体、电商商家

> 
> 全部是**单人作业**，不需要多人协同，自己账号全部自己说了算。

### 1.3 核心痛点

1. 没有设计师，外包成本高、改稿慢
2. 做出来海报品牌调性不统一
3. 需要多平台尺寸，手动改图麻烦
4. 想批量产出多套海报，缺少工具
5. 自己不会写营销海报文案
6. 担心商用版权、水印、画质问题

### 1.4 本版本保留 / 裁剪清单

✅ **保留功能**

- 个人品牌 VI 配置库（logo、品牌色、字体、slogan、联系方式）
- 文生海报 / 图生海报 / AI 模板重构
- AI 自动生成商业营销文案
- 一键多平台尺寸自动适配重排
- 高级编辑器、局部重绘
- 批量生成、批量替换文案、批量打包下载
- 作品云端库、参数记忆复刻
- 会员 / 付费、高清无水印、商用授权

❌ **彻底砍掉，不做**

- 团队、子账号、管理员 / 普通成员角色
- 团队共享素材库、团队空间
- 成员权限管控、品牌参数锁死

> 
> 逻辑：品牌 VI 属于当前账号，用户可以随意修改、删除、重置，没有审批、没有其他人干涉。

## 2 核心业务主流程（单人全链路）

> 
> 所有操作全部归属于当前登录账号，没有其他角色参与

1. **登录进入工作台**
首页工作台：快速创作入口、我的品牌配置、商业模板库、我的作品。
2. **（可选）设置我的品牌 VI**
用户自行上传 logo、设置品牌主色 / 辅助色、默认字体、slogan、二维码联系方式；保存后，后续生成海报可以选择「应用我的品牌」。

> 
> 用户随时可以改、清空、重置，没有权限限制。

3. **选择创作模式三选一**

- AI 文生商业海报
- 参考图图生海报
- 商业模板 AI 重构

4. **设置生成参数**

- 是否开启【应用我的品牌】（开启则自动带入 logo、品牌色、slogan）
- 选择业务场景、行业
- 选择输出尺寸（朋友圈 1:1 / 小红书 3:4 / 短视频 9:16 / 公众号封面 / 电商主图 / 展板）
- 填写主题需求；可开启【AI 自动生成营销文案】
- 设置生成张数，批量参数（如需批量模式）

5. **提交 AI 生成任务**
后端调用模型，同时生成画面 +（可选）AI 营销文案；返回多张候选海报。
6. **挑选海报，进入编辑器**
不满意直接重新生成；选中一张进入编辑页。
编辑器能力：修改文案、换字体颜色、全局换品牌色、局部重绘、增删装饰元素；**也可以一键切换其他尺寸，AI 自动重排构图文字**。
7. **单张导出 / 批量打包导出**

- 单张：导出 JPG/PNG/PDF，会员解锁高清无水印商用
- 批量模式：批量替换多组文案，批量生成多版本，打包下载 zip

8. **自动存入【我的作品】**
作品连同生成 prompt、品牌参数全部保存；支持再次编辑、复刻同款参数、删除。

**分支流程**

1. 从「我的作品」打开历史作品 → 再次编辑 / 复刻生成
2. 创作中途退出自动保存草稿，下次进入继续编辑
3. 内容命中安全审核拦截，提示修改需求

### 后端简易逻辑

前端交互 → 业务服务层（账号鉴权、次数扣减、草稿 & 作品存储、内容安全）→ AI 调度层（prompt 组装、文生 / 图生调用、文案大模型调用）→ 素材服务（模板、商用字体贴纸）→ DB（账号、个人品牌配置、作品、草稿）

> 
> 没有团队表、成员表，数据库只存**账号维度的品牌配置**。

## 3 详细功能模块

### 模块 1：个人品牌 VI 库（单人完全自主）

> 
> 属于当前账号，全部由用户自由增删改，无锁、无审批

1. Logo 上传：支持多套 logo 保存，制作海报时选择使用哪一个；设置 logo 默认摆放位置，AI 自动避让画面主体
2. 品牌色彩组：保存多组主色、辅助色；一键全局应用到整张海报
3. 默认文字配置：预设 slogan、底部联系文案、二维码，生成时一键带入
4. 默认商用字体集：选择账号偏好字体
5. 重置按钮：一键清空全部品牌配置

### 模块 2：三大海报生成引擎

#### 2.1 文生商业海报 + AI 营销文案生成

- 用户输入业务主题、行业、简单需求
- 开关：开启「AI 生成商业文案」，自动输出主标题、副标题、卖点、底部标语；用户可以直接选用或者二次修改
- 正向 / 反向提示词，风格选择，生成数量设置

#### 2.2 图生海报（参考图重绘）

上传参考海报，可选保留构图 / 保留风格，叠加业务主题，可开启应用个人品牌，AI 重绘出新商用海报。

#### 2.3 商业 AI 模板重构库

分类：OPC 战报喜报、招商海报、门店促销、节日商业、产品宣传、品牌日签。
选择模板后，AI 重构画面，可一键带入自己账号的品牌 VI。

### 模块 3：多尺寸智能适配

已经做好一张海报，一键切换目标尺寸，AI 自动重排图文，避免文字裁切、元素溢出。
预设全部商业常用尺寸，也支持自定义宽高。

### 模块 4：高级海报编辑器

1. 文本编辑：增删改文案，商用字体、字重、字间距、对齐、底色阴影
2. 全局配色：一键应用账号保存的品牌色
3. 局部 AI 重绘：框选区域，输入指令修改局部画面瑕疵、替换元素
4. 商用贴纸、线条、边框素材库
5. 撤回重做

### 模块 5：批量生成能力（单人可用）

> 
> 不需要团队，就是个人高效做大量物料

1. 批量文案导入：粘贴多组标题 / 卖点文案列表
2. 在当前海报模板基础上，批量替换文案，批量生成多张不同版本海报
3. 批量打包 ZIP 下载

> 
> 使用场景：OPC 一天产出十几张喜报、多版本活动宣传物料。

### 模块 6：我的作品 & 草稿管理

1. 作品库：所有生成 / 编辑完成海报，带生成参数，支持复刻同款
2. 草稿：未完成的创作自动保存
3. 操作：预览、再次编辑、复制参数生成、删除

### 模块 7：会员 & 导出 & 版权

1. 免费额度：有限生成次数，导出带平台水印，标准分辨率
2. 付费会员：无限 / 高额度生成，高清 2K‑4K，无水印，全部功能（批量、品牌库、AI 文案全部解锁）
3. 版权说明：账号生成的海报，账号持有人获得商用授权；内置字体素材全部商用合规。

## 4 交互与验收标准

1. 操作链路：登录 → 创作 → 生成 → 编辑 → 导出，最多 5 步完成一张海报。
2. 品牌 VI 开关清晰：每次生成时明确「是否应用我的品牌配置」，避免用户莫名其妙多出 logo。
3. AI 文案输出是营销向商业文案，不是文艺文案，允许用户一键全部重写。
4. 尺寸切换后图文自动适配，不出现文字截断。
5. 批量功能单人操作稳定，打包下载可用。
6. 生成失败、审核拦截给出清晰提示。

## 5 风险点

1. 用户随意上传 logo / 图片，内容安全需要对上传图片做审核。
2. 用户批量大量生成，需要做接口限流，防止资源被刷爆。
3. 品牌配置误修改：提供重置确认弹窗，防止手滑清空全部品牌配置。
