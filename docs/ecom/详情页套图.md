## 2. 用户步骤

1. **产品图**：多张上传（非强制）
2. **七维**：选项卡逐步选择（与故事版同一套选项）
3. **卖点**：手填 / 多图识图 / AI 润色 / 确认清单
4. **模板**：按平台 + 类目加载该平台系统副本（或「我的模板」）
5. **大模块**：开关、张数 N、可新增自定义模块
6. **子维度**：手选 / 随机 / 自增
7. **提示词**：每开启模块一次 LLM；可改单条或 AI 重写
8. **出图**：`StoryboardModelPickerDialog`（尺码数据总表图除外）；单张 / 按模块 / 全部（≤49）；长任务进 BackgroundGenerationDock

## 3. 平台复制规则

种子：3 份类目 JSON × 12 个 `platformCode` = **36** 条 `type=system` 模板。  
复制时只覆盖该平台出图规格（比例、`widthPx`、风格 note）。模块与候选池第一期相同。  
之后改京东/亚马逊只改该平台行，不回写淘宝。

平台清单：淘宝/天猫、京东、拼多多、抖音电商、快手小店、小红书商城、视频号小店、1688、唯品会、亚马逊、Shopee/Lazada、独立站。

## 4.1 尺码参考模块（`mod7_size_table`）

### 参数

| 字段 | 值 |
| --- | --- |
| `module_id` | `mod7_size_table`（第 7 大模块，不变更编号） |
| `max_num` | 6（含系统子项 + 用户「+ 新增点位」） |
| `default_count` | 1（默认只勾选 **尺码数据总表图**） |

### 系统子维度（`candidate_pool`）

1. **尺码数据总表图** — **程序化出图**（SVG→PNG，不经大模型、不经 Gateway 文生图）
2. **服装测量部位线稿示意图** — 走 LLM 提示词 + 文生图
3. **多身高模特上身试穿参考图** — 走 LLM 提示词 + 文生图

### 两层设计

| 层级 | 内容 |
| --- | --- |
| **模板固定** | 表头字段、表格版式（黑表头 / 白底网格）、渲染宽度 750px；户外类默认演示表「女款外套尺码」 |
| **单品变量** | 存于 `project.brief.sizeChart.tables[]`；用户在中栏点击点位编辑尺码数据；**禁止**用演示数据直接上架（UI 强提示） |

### 用户流程（与现有 Studio 一致）

1. 勾选尺码模块子维度（默认 1 张总表图）
2. **撰写提示词**：「尺码数据总表图」不调用 LLM，自动标记就绪；其余子项仍走 LLM
3. **生图**：总表图由 `book-mall/lib/ecom/detail-page-suite/size-chart-render.ts` 渲染并上传 OSS；其余子项仍走 `StoryboardModelPickerDialog` + Gateway

### 校验

- 无有效 `brief.sizeChart` 行数据时，**不允许**生成「尺码数据总表图」
- 线稿 / 模特对比子项不依赖尺码录入

### 实现入口

- 常量：`size-chart-constants.ts`
- 默认演示数据：`size-chart-defaults.ts`
- 渲染：`size-chart-render.ts` · `size-chart-image.ts`
- 提示词占位：`DETAIL_PAGE_SUITE_SIZE_CHART_PROMPT_MARKER`

全局负面词（系统拼接，不交给模型）：

```
水印，文字，乱码，变形，肢体畸形，手指残缺，人脸扭曲，画面闪烁，模糊，噪点过高，曝光过度，死黑，色差严重，多余杂物，背景杂乱，3D卡通，手绘，插画，油画，畸形服装，衣服褶皱崩坏
```

## 5. LLM 围栏

围栏名：`` ```detail-page-suite ``  
`schemaVersion`: `detail-page-suite/v1`

```json
{
  "schemaVersion": "detail-page-suite/v1",
  "module_id": "mod4_detail",
  "items": [
    {
      "item_key": "zipper",
      "item_label": "防风拉链特写，展示拉链质感与防风结构",
      "positive_prompt": "……"
    }
  ]
}
```

校验：合法 JSON；`items.length === N`；每条 `item_label` 对上 `selected_item_list`；失败重试最多 3 次。  
模型只做摄影润色，禁止发明列表外主体；每条须按子维度区分景别/光位，禁止复制粘贴。
