### 使用说明（并入前面产品设计文档）

1. 当用户选择【户外外套 / 羽绒服模板】，UI 加载上面整套候选池；
2. 用户开启模块后，可以手动勾选池内条目，或者输入数量随机抽取；
3. 抽取出来的条目组成`selected_item_list`传入大模型；
4. 大模型**不能新增上面清单以外的拍摄内容**，仅针对每一条做摄影、光影、构图润色，输出 JSON 数组正向 prompt。
