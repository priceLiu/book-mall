# 与 AI 详情页工作台的关系

- 本文档可作为侧栏 **「策划 Prompt（写词规则）」** 的默认参考：粘贴全文或上传 `.md` / `.txt` 后，平台会在末尾 **强制追加 JSON 输出契约**（围栏 + `module_id` + `items[]`），用户不可删除该尾段。
- 工作台主按钮 **「生成模块 Prompt」** 会：按 **产品品类** 自动匹配子维度 → 创建点位 → 调用 LLM 写入各 slot 的 `positive_prompt`（**不出图**）。审词阶段可手改、上传本格参考图、AI 重写单条 Prompt。
- 尺码/参数 **数据总表** 由系统程序化出图，不参与上述 LLM 写词。

---

# 任务说明

我会一次性提供三类输入：

1. 【产品参考图】
2. 【商品卖点与基础信息】
3. 【16个详情模块各自需要生成的图片数量】

请你基于产品参考图，为每个模块生成可直接用于文生图模型的电商详情页 Prompt。所有 Prompt 必须保持同一产品的外观结构、材质、颜色、比例、品牌识别和整体视觉风格，不得把产品重绘成另一个品类。

模块数量为 0 时，直接跳过该模块，不输出任何内容。

---

# 统一视觉风格要求

所有详情图请默认遵循以下通用电商风格，除非模块本身需要明显不同的信息表达：

- 整体风格：现代商业摄影、干净高级、真实产品摄影、电商详情页商用图
- 色彩方向：保持产品原图色彩，整体色调干净统一，避免过度花哨
- 光影：柔和棚拍光、自然侧光或干净柔光，突出材质和轮廓
- 背景：浅色纯净背景、灰白渐变、简洁室内环境或同色系场景，避免杂乱
- 质感：清晰锐利、真实材质、合理景深、产品边缘干净
- 构图：产品始终是第一视觉，信息层级清楚，适合详情页阅读
- 负面约束：低分辨率、模糊、过曝、欠曝、噪点、产品变形、比例错误、多余物体、杂乱背景、水印、乱码文字、手指畸形、结构崩坏

如果我后续指定具体风格，例如“极简风 / 高级ins风 / 科技感 / 温馨家居风 / 复古质感风”，请将该风格作为所有模块的统一视觉锚点。

# 16个详情模块定义与 Prompt 生成要求

## 1. 首屏主视觉

模块定位：详情页第一张图，用于快速建立产品价值感和吸引力。

生成要求：
- 产品为绝对主体，完整展示
- 画面有较强视觉冲击力
- 可结合简洁背景、光影、烟雾、投影、局部材质放大等视觉元素
- 适合详情页首屏，不塞入过多信息
- 文字类首屏可预留标题区，但不要生成乱码文字

Prompt 结构建议：
主体 + 高级商业摄影构图 + 干净背景 + 柔和棚拍光 + 产品质感突出 + 负面约束

---

## 2. 核心卖点图

模块定位：突出产品差异点和核心优势。

生成要求：
- 每张图只讲一个卖点
- 产品清晰展示，卖点文字区域整洁
- 可使用局部放大、对比、图标、标签、箭头等视觉辅助
- 避免一图塞入多个卖点
- 文字内容必须用中文双引号标注，例如“核心卖点：XXX”

Prompt 结构建议：
产品主体 + 卖点视觉锚点 + 简洁信息排版 + 白底或浅色背景 + 商业详情页风格 + 负面约束

---

## 3. 使用场景图

模块定位：展示产品在真实生活或工作环境中的使用状态。

生成要求：
- 必须有人使用产品，或明确展示使用动作
- 场景要合理，符合产品真实用途
- 产品不能被遮挡太多，仍需清晰识别
- 重点是“正在使用”，不是单纯摆拍

Prompt 结构建议：
人物使用产品的动作 + 真实环境 + 自然光线 + 生活化商业摄影 + 产品清晰可见 + 负面约束

---

## 4. 多角度图

模块定位：从不同角度展示产品外观。

生成要求：
- 每张图一个角度，例如正面、侧面、背面、顶部、45度斜角
- 背景统一，通常使用白底或浅灰棚拍背景
- 产品大小、比例、颜色保持一致
- 适合做详情页外观展示组图
- 不要把不同角度混成一张复杂拼图

Prompt 结构建议：
固定产品主体 + 指定角度 + 白底棚拍 + 柔和阴影 + 完整轮廓展示 + 负面约束

---

## 5. 场景氛围图

模块定位：营造使用环境和情绪价值。

生成要求：
- 侧重环境美学和氛围，不强调复杂使用动作
- 产品自然融入场景
- 可突出季节、空间、生活方式、情绪、质感
- 适合提升详情页格调，但不能喧宾夺主

Prompt 结构建议：
产品置于氛围场景中 + 统一色调 + 柔和光线 + 浅景深 + 生活方式商业摄影 + 负面约束

---

## 6. 商品细节图

模块定位：放大展示材质、工艺、纹理、接缝、边缘、按钮、内衬、表面处理等。

生成要求：
- 使用微距或局部特写
- 聚焦产品局部，不做复杂场景
- 材质纹理要清楚
- 可加入箭头、放大框、标注线，但不要生成乱码文字
- 适合展示做工和品质感

Prompt 结构建议：
产品局部微距特写 + 材质纹理清晰 + 柔和棚拍光 + 浅景深 + 高品质商业摄影 + 负面约束

---

## 7. 品牌故事图

模块定位：传达品牌理念、品质感、审美取向或品牌态度。

生成要求：
- 不一定以产品为最大主体
- 可使用抽象场景、手工感、自然元素、空间质感、光影氛围
- 整体要有品牌感，避免廉价促销感
- 可搭配简短品牌态度文字，如“专注品质”“简约生活”等，但不要生成乱码文字

Prompt 结构建议：
品牌情绪场景 + 统一视觉语言 + 柔和光影 + 高级留白 + 品牌摄影质感 + 负面约束

---

## 8. 尺寸/容量/尺码图

模块定位：清晰展示产品规格、尺寸、容量、重量、尺码等信息。

生成要求：
- 白底或浅色背景
- 产品旁边有尺寸线、箭头、标尺、容量示意或对比参照物
- 信息排版干净，数字和单位清楚
- 适合详情页参数说明，不做复杂场景
- 如果我未提供具体数值，Prompt 中使用“尺寸标注区域”“容量标注区域”等占位表达，不虚构数据

Prompt 结构建议：
产品主体 + 尺寸标注线 + 浅色信息图背景 + 清晰排版 + 商业说明图风格 + 负面约束

---

## 9. 效果对比图

模块定位：直观展示使用前后、安装前后、清洁前后、修复前后、性能前后等差异。

生成要求：
- 左右分栏或上下分栏布局
- 同一产品、同一背景、同一光线
- 一侧为“前”，一侧为“后”
- 对比结果要合理，不能夸张失真
- 文字标签可使用“使用前”“使用后”，不要生成额外乱码文字

Prompt 结构建议：
左右对比构图 + 同一背景 + 同一产品 + 清晰前后差异 + 商业说明图 + 负面约束

---

## 10. 详细规格/参数表

模块定位：展示详细商品数据。

生成要求：
- 以信息卡片或表格为主
- 白底、浅色、简洁排版
- 产品小图与参数表结合
- 适合承载参数、型号、材质、尺寸、重量、包装清单等信息
- 如果我未提供具体参数，不要虚构数据，只生成参数表版式，并用“参数项”“参数值”作为占位

Prompt 结构建议：
产品小图 + 参数表版式 + 白底信息卡片 + 清晰对齐 + 电商详情页说明图 + 负面约束

---

## 11. 工艺制作图

模块定位：展示产品制作过程、工艺步骤、匠心细节或生产环节。

生成要求：
- 每张图突出一个工艺环节
- 可以是手工制作、机器加工、组装、打磨、裁剪、缝制、浇筑、包装等
- 画面要真实、干净、有流程感
- 适合详情页“工艺说明”部分
- 不要生成工厂脏乱画面

Prompt 结构建议：
工艺动作或制作环节 + 干净工作台 + 柔和光线 + 纪实商业摄影 + 流程感清晰 + 负面约束

---

## 12. 配件/赠品图

模块定位：明确展示产品本体和所有配件、赠品、包装内容。

生成要求：
- 俯拍平铺或整齐陈列
- 产品本体、配件、赠品、说明书、包装盒等分区清楚
- 适合详情页“开箱清单”“包装内容”展示
- 可使用编号或标签说明，但不要生成乱码文字
- 不要遗漏主要配件，也不要虚构不存在的赠品

Prompt 结构建议：
产品与配件整齐陈列 + 俯拍平铺 + 浅色背景 + 清晰分区 + 电商开箱图 + 负面约束

---

## 13. 系列展示图

模块定位：展示同系列不同颜色、款式、型号、容量、配置等 SKU。

生成要求：
- 同一产品结构，不同颜色或款式
- 整齐排列，统一大小和角度
- 背景干净，适合对比选择
- 每张图可展示多个 SKU，但产品外形必须一致
- 可加颜色标签，如“曜石黑”“月光白”“深海蓝”，不要生成乱码文字

Prompt 结构建议：
同系列产品阵列 + 统一角度 + 白底棚拍 + 清晰配色展示 + SKU对比图 + 负面约束

---

## 14. 商品成分图

模块定位：展示产品成分、材质、原料、配方、面料类型等信息。

生成要求：
- 产品与原料、材质切片、成分图标并列展示
- 信息图风格，背景干净
- 适合说明面料、材质、配方、成分、环保材料等
- 如果我未提供具体成分，不要编造内容，使用“成分A”“成分B”“天然材质”等占位表达

Prompt 结构建议：
产品 + 材质或成分元素 + 信息图排版 + 浅色背景 + 清晰标注区域 + 负面约束

---

## 15. 售后保障图

模块定位：展示服务承诺、售后政策、品质保障、物流说明等。

生成要求：
- 电商信息海报风格
- 产品小图 + 服务权益卡片
- 背景简洁，文字区域充足
- 不要使用夸张促销词，除非我明确提供
- 常见文案可用“品质保障”“售后无忧”“快速发货”等，不要生成乱码文字

Prompt 结构建议：
产品小图 + 服务权益卡片 + 浅色商业海报 + 清晰信息层级 + 电商详情页风格 + 负面约束

---

## 16. 使用建议图

模块定位：说明产品使用方法、操作步骤、注意事项、保养建议等。

生成要求：
- 图文说明风格
- 每张图突出一个操作动作或注意点
- 使用简洁编号、箭头、图示和短句
- 适合详情页“使用指南”“保养说明”部分
- 文字必须清晰，如“使用步骤”“注意事项”“请勿暴晒”，不要生成乱码文字

Prompt 结构建议：
操作动作或注意场景 + 简洁图示 + 信息排版 + 浅色背景 + 说明图风格 + 负面约束

# 附录：平台 JSON 输出规范（工作台强制追加，不可删）

写词 LLM **实际调用**时，平台会在你自定义正文之后自动追加与本节一致的契约；**不要**在可变段里要求「分段纯文本 / 【模块名称】需要生成 N 张」等旧格式。

1. 只输出一个 Markdown 围栏（名为 `detail-page-suite`），围栏内为 JSON，不要解释。
2. JSON 形状（单次调用对应 **一个** 模块）：

```json
{
  "schemaVersion": "detail-page-suite-v1",
  "module_id": "当前模块 id",
  "items": [
    {
      "item_key": "短英文 key",
      "item_label": "必须与当次 selected_item_list 原文完全一致",
      "positive_prompt": "摄影/场景润色正文，8 字以上"
    }
  ]
}
```

3. `items` 条数必须等于 user 消息中的 N；`item_label` 不得使用列表外的子维度。
4. 子维度为 **尺码/参数数据总表**（由系统程序化出图）：勿在 items 中输出文生图 Prompt。
5. 禁止编造未提供的规格参数；禁止水印、乱码、低清晰度。

模块 8（尺码/容量/尺码图）、模块 10（详细规格/参数表）中的 **数据总表** 行：由系统根据 brief 表格程序化出图，**不要**在 LLM items 里生成对应 Prompt。

# 最终约束

1. 所有 Prompt 必须基于我提供的产品参考图，保持产品外观、颜色、材质、比例和品类一致。
2. 所有 Prompt 必须可直接复制给文生图模型使用。
3. 每个模块的 Prompt 必须符合该模块定义，不得把细节图写成场景图，也不得把场景氛围图写成使用场景图。
4. 涉及参数、尺寸、成分、赠品、售后承诺等信息时，只使用我提供的真实信息；未提供时不虚构具体数据。
5. 在工作台内：遵守上文 **JSON 附录**；在站外手工使用时，可按各模块「Prompt 结构建议」撰写单条中文生图描述。
6. 如果某个模块数量为 0，该模块不参与当次 LLM 调用。
