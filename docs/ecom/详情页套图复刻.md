> **状态**：已落地（DPR-101～DPR-110）  
> **管理入口**：Book [`/admin/pending-features`](http://localhost:3000/admin/pending-features) → **待处理**  
> **用户入口**：电商工具箱 `/ecom/detail-page-suite-replica`（侧栏位于「详情页套图」正下方）  
> **关联产线**：[详情页套图.md](./详情页套图.md)（模板 + 七维路径）· [拆详情页套图提示词.md](./拆详情页套图提示词.md) · 样例长图 `10196bb8ca5f0427b05a7bf7a6712148.jpg` · 目标粒度示例 [羽绒服拆解.md](./羽绒服拆解.md)

面向服装电商：上传 **参考详情长图** + **产品实拍**（+ 可选模特），AI **尽可能完整拆解**参考版式并归入 **12 大模块框架**，再按 **自家卖点** 润色生图 Prompt，在套图格子中批量出图。**非像素级复刻**；无七维逐步采集、无平台模板子维度手选、无助手区（第一期）。

## 2. 用户流程

1. **上传**：参考套图长图（**拆解必填**）、产品实拍（出图/识图卖点建议有，**拆解不强制**）、模特图（可选）
2. **卖点**：手填 / 多图识图（需产品图）；可在拆解前或拆解后填写
3. **拆解**：A0 清单（Vision，自上而下 `segments[]`）→ A1 归类（文本 LLM，高置信自动写入模块）；中区展示清单 + 按模块汇总（`replicaStatus: decomposed`）
4. **生成 Prompt**：用户勾选模块（可全选 12）→ **单次** 文本 LLM 批量润色（不内部分批）→ 写入下区 `slots`
5. **核对 / 编辑**：下区 12 模块格子内可改单条 Prompt、编辑尺码表（mod7）
6. **出图**：`StoryboardModelPickerDialog`；长任务进 BackgroundGenerationDock

| --- | --- | --- |
| `reference_suite` | 拆解必填 | 整页/长条参考详情，Vision 拆解 **唯一** 输入 |

## 6. LLM 围栏与 JSON

### 6.1 阶段 A · 先清单、再归类

**观察粒度 SSOT**：[羽绒服拆解.md](./羽绒服拆解.md)；写入 `visualDetail` / `layoutHint` / `referenceCopyHints`（不写 positive/negative Prompt）。

**A0 · 视觉清单**（单次 Vision，**不**输出 12 模块）

- 库：`runDetailPageVisionInventory`
- 围栏：`` ```detail-page-suite-replica-inventory ``  
- `schemaVersion`: **`detail-page-suite-replica-inventory/v1`**
- 持久化：`meta.replicaInventory.segments[]`（按 `segmentIndex` 自上而下）

**A1 · 自动归类**（单次文本 LLM）

- 库：`runDetailPageVisionClassify`
- 围栏：`` ```detail-page-suite-replica-classify ``  
- `schemaVersion`: **`detail-page-suite-replica-classify/v1`**
- `confidence: high` 且 `module_id` 有效 → 写入 `meta.replicaSegmentMapping` 并归入模块
- `confidence: low` → **待归类**，用户在 Studio 下拉选择模块（`POST …/replica/inventory/assign`）后重算 `meta.replicaPhaseA`

**衍生 Phase A（润色输入）**：`buildPhaseAFromInventoryAndMapping` → 12 模块 JSON（与下表结构一致，供阶段 B 与旧 UI 复用）。仍保留可复用 `runDetailPageVisionDecompose`（一步 12 模块）供其它入口。

围栏名（衍生 / 一步拆解）：`` ```detail-page-suite-replica ``  
`schemaVersion`: **`detail-page-suite-replica/v1`**

```json
{
  "schemaVersion": "detail-page-suite-replica/v1",
  "categoryKey": "outdoor_jacket",
  "referenceSummary": "一句话：参考详情整体版式/风格（不含品牌名）",
  "sharedVisualBrief": "整套共享：色调、版式节奏、摄影风格、典型景别",
  "modules": [
    {
      "module_id": "mod1_banner",
      "detected": true,
      "coverageNote": "首屏大 banner，模特全身雪山背景",
      "sizeChartHint": "",
      "items": [
        {
          "item_key": "banner_main",
          "item_label": "首屏主视觉",
          "layoutHint": "竖版 9:16，人物居中",
          "referenceCopyHints": ["参考图上的系列名仅作版式 hint，禁止输出"],
          "visualDetail": {
            "model": "…",
            "garment": "…",
            "background": "…",
            "scene": "…",
            "lighting": "…",
            "pose": "…",
            "props": "…",
            "onImageText": "与 referenceCopyHints 一致；其余字段为高密度观察句（见羽绒服拆解样例）"
          }
        }
      ]
    }
  ]
}
```

规则：

- **`modules` 长度必须为 12**，且 `module_id` 与种子一致、顺序一致
- `detected: false` 时 `items: []`；`mod7_size_table` 可仅填 `sizeChartHint` 文本
- 阶段 A **须列全**参考页上该模块的独立画面，**不得**在 Prompt 里写「按 max_num 只保留 N 条」；`max_num` 仅表示 **首批润色/出图格子预算**（12 模块合计约 **49**，参考页若更多条仍保存在 `meta.replicaPhaseA`，用户可 **+** 增点位）
- 超出 `max_num` 时：阶段 B 与 `suite.slots` 只取首批；`meta.replicaWarning` 提示剩余条数在拆解结果中
- 禁止输出参考图上的品牌名、具体 SKU 文案到 `positive_prompt`（A 阶段不写 final prompt）

### 6.2 阶段 B · 润色生图 Prompt（批量 · 单次调用）

围栏名：`` ```detail-page-suite-replica-polish-batch ``  
`schemaVersion`: **`detail-page-suite-replica-polish-batch/v1`**

```json
{
  "schemaVersion": "detail-page-suite-replica-polish-batch/v1",
  "modules": [
    {
      "module_id": "mod4_detail",
      "items": [
        {
          "item_key": "zipper",
          "item_label": "防风拉链特写",
          "positive_prompt": "……摄影润色正文，商品须与产品实拍一致……",
          "negative_prompt": "文字，logo，水印，……"
        }
      ]
    }
  ]
}
```

规则：

- 用户请求体 `moduleIds` 为 1～12 个子集；**一次 Gateway 调用** 须返回 **相同顺序、相同 id 集合** 的 `modules`（全选 12 亦单次，**禁止**服务端内部分批）
- 须注入 **已确认卖点** 与产品简述；改写可售表述，不照抄参考
- `mod7` 中「尺码数据总表图」项 `positive_prompt` 使用 `[detail-page-suite:size-chart-render]` 占位
- 每条 `positive_prompt` 长度 ≥ 8 字；失败重试最多 3 次（整批）

旧单模块围栏 `` ```detail-page-suite-replica-polish `` 仅作历史参考，新实现以 batch 为准。

### 6.3 meta 字段

| 字段 | 说明 |
| --- | --- |
| `replicaInventory` | A0 清单 JSON |
| `replicaSegmentMapping` | A1 + 手动：`item_key` → `module_id` |
| `replicaPhaseA` | 由清单+映射衍生的 12 模块 JSON |
| `replicaStatus` | `idle` · `decomposing` · `decomposed` · `polishing` · `ready` · `error` |
| `replicaError` | 最近一次失败摘要 |
| `phase` | 复刻项目固定 `prompts` / `images`（无七维阶段） |
