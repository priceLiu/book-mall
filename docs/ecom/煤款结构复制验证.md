# AI电商详情页范式拆解与智能生成系统｜验收标准
> 文档说明：用于开发完成后的功能验收，分为**基础功能验收、AI拆解能力验收、文案模块验收、视觉场景模块验收、编辑交互验收、渲染输出验收、合规&边界验收、异常容错验收**，每个条目给出「通过标准」，可直接作为测试用例。

## 一、基础功能验收
|测试项|通过标准|
|---|---|
|上传竞品详情长截图|支持上传本地长截图，图片正常加载；不限制图片高度，支持淘宝完整滚动详情长图|
|解析触发|上传完成后触发AI解析，不阻塞界面；解析状态有加载提示|
|解析结果输出|输出结构化模板JSON，包含：模板名称、画布宽度750、品类标签、全局视觉风格、全局文案风格、component_list组件列表|
|模板保存|解析完成的模板可以保存到模板库，支持后续加载复用|
|用户素材录入|支持上传自有新品产品图、模特图；支持文本输入新品核心卖点|

## 二、AI结构范式拆解验收（核心）
> 输入：淘宝详情长截图；禁止输出像素坐标、原图素材、原文文案。

|测试项|通过标准|
|---|---|
|组件识别|能够识别枚举内组件：`full_banner/main_product/feature_card/spec_table/detail_closeup/scene_image/contrast/after_sale/other`；识别从上到下顺序，和原图页面顺序保持一致|
|排版识别|正确识别排版类型：`full_image/image_text_top_bottom/image_text_left_right/text_only/table`|
|重复卡位识别|对于可重复模块（卖点卡片、细节特写、场景图），识别出`repeat_count`默认数量；同时标记`user_editable_count:true`，代表允许用户修改数量|
|动态模块处理|遇到模块数量可变的详情页，不输出固定数组；可以识别连续重复的同类组件，正确统计重复次数|
|插槽字段输出|每个组件输出`text_slot`（最大字符数、文案类型）、`image_slot`（构图、是否需要场景背景）|
|全局风格输出|输出`global_style` 七维：场景环境、光影、色调、构图方式、画面氛围、道具风格、清晰度质感；以及 `global_copy_style`|
|爆款洞察输出|输出 `market_insight`：`hot_selling_dimensions`、`user_pain_points`、`narrative_sequence`、`copy_style`、`module_copy_functions`；**不包含竞品原文句子**|
|不输出违禁内容|解析结果**不包含竞品原图base64、不输出竞品原始文案、不输出像素坐标框**|

## 三、AI文案范式拆解 + 文案融合重写验收
|测试项|通过标准|
|---|---|
|拆解阶段|AI 输出 `market_insight`（卖点维度+痛点+叙事+口吻+模块文案功能抽象描述）；**绝不输出竞品详情原文句子**|
|洞察可编辑|工作台可编辑 `market_insight` 与 `global_style`，保存后参与后续重写|
|融合重写输入|接收「market_insight + global_style + 用户新品卖点」；**新品卖点优先**，不匹配的爆款维度丢弃|
|文案分配逻辑|重写后的文案自动分配到对应组件插槽：banner钩子、主图短标题、卖点卡片、细节说明、参数说明；严格遵守`text_slot`的最大字符限制|
|原创性|文案为全新生成，不复制竞品原句；内容以**用户提供的新品卖点为主体**，不强行套用竞品不匹配的痛点|
|模块适配校验|banner模块输出短钩子；卖点卡片输出单条利益点；参数模块输出规格说明；不会出现长文本塞到banner插槽的错误|
|可编辑|生成后的文案支持用户手动修改、替换|

## 四、AI视觉场景范式拆解 + 场景图生成验收
|测试项|通过标准|
|---|---|
|场景拆解|只提取七维氛围参数；**剥离原图模特、服装、产品主体**|
|场景 Prompt 重写|「生成原创文案与 Prompt」时，LLM 依据 `global_style` + 新品重写各卡位 `positive_prompt` 场景段，不复刻竞品画面|
|全局视觉一致性|输出的`global_style`会作为整套详情所有模块的统一参考；所有生成场景继承该套氛围，避免整套详情画风割裂|
|组件构图匹配|每个`image_slot`输出对应构图约束：全身/半身/特写/大远景，匹配组件用途（banner大远景、细节特写近景）|
|生图输出|基于拆解得到的氛围参数 + 用户新品，生成全新背景场景图；不复用竞品原图素材|
|素材合成逻辑|支持把用户上传的产品/模特素材，叠加到AI生成的场景背景之上；可区分：产品主体（用户上传）、背景（AI生成）|

## 五、可视化编辑交互验收（解决卡位灵活调整）
> 这是关键验收点：AI解析结果只是初始参考，必须允许用户手动干预。

|测试项|通过标准|
|---|---|
|模块增删|支持新增组件、删除任意组件；支持把组件从列表移除|
|模块排序|支持拖拽调整组件上下顺序，修改详情叙事流|
|修改重复数量|对标记`user_editable_count:true`模块（卖点、细节、场景），支持手动修改`repeat_count`；例如：AI识别3个卖点，用户可改成2个或者5个|
|单模块编辑|可单独修改某一个组件：组件类型、排版方式、文案插槽、图片插槽配置|
|重置能力|支持一键回退到AI原始解析的模板结构|
|预览|编辑过程中可以实时预览页面结构，看到模块排布效果|

## 六、渲染输出验收
|测试项|通过标准|
|---|---|
|画布规范|输出图片统一宽度750px，淘宝详情标准尺寸；高度随模块内容自适应|
|素材拼接|把：用户自有产品/模特图 + AI生成场景背景 + AI生成文案，按照模板组件顺序拼接成详情套图|
|输出产物|1.分段详情套图；2.完整模板JSON文件；3.全套文案文本；4.独立AI场景背景素材|
|排版对齐|图文按照组件layout排版规则渲染：上图下文、左图右文、全屏大图等，布局无错乱|
|字体样式|文案渲染清晰，文字不溢出图片边界|

## 七、合规边界验收（硬性红线，不通过则不可上线）
|测试项|通过标准|
|---|---|
|禁止复用竞品素材|系统不存储、不返回、不直接使用竞品截图里的原图、原模特、原文案；所有最终输出素材来源：用户上传素材、AI全新生成|
|提示文案|界面展示合规提示：「本工具仅提取版式叙事逻辑，不复制竞品图文素材；上架商品图文需由用户保证版权合规」|
|禁止抄袭提示|文案生成不允许直接搬运竞品原文；AI输出结果不提供竞品原文摘抄|
|场景生成约束|不复刻竞品独有的原创美术布景；只提取通用场景氛围参数|

## 八、异常与容错验收
|测试项|通过标准|
|---|---|
|解析失败处理|遇到排版极度混乱、异形创意详情截图，AI解析失败，给出友好提示，不崩溃；提示建议使用排版规整的详情截图|
|素材缺失处理|用户未上传部分素材时，给出提示，不强制渲染；允许先保存模板，后续补素材再渲染|
|AI输出格式校验|AI返回的JSON必须符合Schema；出现格式错误时，做容错，提示解析异常，不导致程序崩溃|
|空输入处理|用户没有填写新品卖点，文案模块给出提示，不输出无意义垃圾文案|

## 九、验收分级定义
1. **P0（必须通过，不通过不能上线）**
    - 截图解析输出符合Schema
    - 不输出竞品原图、原文
    - 支持模块增删、修改重复卡位数量
    - 渲染输出750px标准详情套图
    - 异常不崩溃

2. **P1（重要，建议上线前完成）**
    - 文案可以正确分配到对应插槽，遵守字符限制
    - 视觉场景拆解剥离原有产品模特
    - 编辑预览可用
    - 模板保存加载正常

3. **P2（优化项，可迭代）**
    - AI拆解识别准确率优化；
    - 场景图风格一致性进一步提升；
    - 更多组件类型扩展；
    - 批量导出、批量模板管理。
