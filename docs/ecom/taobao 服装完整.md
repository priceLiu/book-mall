## 1 文档概述
### 1.1 目标
本工具面向电商服装商家，录入商品基础信息、上传产品参考图，选择品类模板，完成配置后生成淘宝/京东等平台服装详情页全套AI生图提示词集合；
大模型输出强制限定JSON格式，AI仅做摄影描述润色，**不能自行创造业务子维度**，业务拍摄对象严格来源于选中的品类模板候选池。

### 1.2 范围
✅ 包含：用户输入信息、基础参数配置、品类模板选择、12大模块开关与数量配置、模块子维度选择（手动勾选 / 池内随机抽样）、大模型请求入参定义、大模型JSON输出约束、数据输出结构、模板管理后台、异常校验规则。
❌ 不包含：后端业务代码、文生图接口对接、图片后期排版合成、PSD文件导出。

### 1.3 核心架构说明
固定**12个顶层详情模块骨架**，不可新增/删除顶层模块；
模板分为【系统预置模板】和【用户自定义模板】，一套模板包含全部12个模块；每个模块内配置`max_num`（最大生成图片数量）、`candidate_pool`子维度候选池（每张图片对应的拍摄对象）。

## 2 术语定义
|名词|说明|
| ---- | ---- |
|顶层12大模块|详情页固定章节骨架；必选模块不可关闭，可选模块支持开关；每个模块拥有`module_id`唯一标识|
|品类模板|分为**系统预置模板**、**用户自定义模板**；一套模板包含全部12个模块，每个模块存储：模块最大阈值`max_num`、子维度候选池`candidate_pool`；模板可复制、编辑、另存为新模板|
|子维度|模块池内每一项拍摄对象/姿势/场景；AI禁止生成候选池以外子维度|
|selected_item_list|用户手动勾选/随机抽样后筛选出来的子维度子集，作为传给大模型的输入，大模型只能基于该列表生成提示词|
|全局负面Prompt|统一固定负面提示词，不交由大模型生成，每张生图请求拼接该负面词|

## 3 用户端完整业务流程
### 3.1 步骤1：基础信息录入【全局基础配置】
用户操作界面，填写全局商品信息，全部为生成详情页的基础上下文。
1. 上传产品参考图（支持多张，用于AI参考产品版型、颜色、面料；可选上传，非强制）
2. 基础属性选择
    - 服装品类：下拉选择（户外羽绒服 / 商务衬衫 / 自定义模板）
    - 性别：男 / 女 / 中性
    - 目标电商平台：淘宝(750px) / 京东(790px) / 亚马逊 / TikTok跨境（决定图片输出尺寸参数）
    - 输出语言：中文 / 英文（控制生成提示词描述语言）
3. 商品基础卖点输入（文本框，多条卖点换行分隔）
>示例：防风防水、90白鸭绒填充、抗皱免烫、透气亲肤
4. 商品简要描述：简短文本，例如「红色男士户外加厚羽绒服」

>完成本步骤后，系统根据选中的【服装品类】自动加载对应**系统预置品类模板**；用户也可以手动切换到自己保存的【用户自定义模板】。

### 3.2 步骤2：12个顶层大模块配置
系统加载选中品类模板，读取模板内部每个模块：`module_id`、模块名称、`max_num`最大图片阈值、`candidate_pool`子维度候选池。

UI展示全部12个模块列表：
- 属性标记：`必选` / `可选`
- 开关：必选模块开关置灰不可关闭；可选模块用户可关闭（关闭=生成数量置0）
- 输入框：填写本模块希望生成图片张数N
    >校验规则：
    >1. 必选模块 N 取值范围：`1 ≤ N ≤ max_num`，禁止填0
    >2. 可选模块 N 取值范围：`0 ≤ N ≤ max_num`，0代表关闭该模块
    >3. N大于max_num，前端直接拦截提示：`该模块最大允许生成{max_num}张，请修改数量`

### 3.3 步骤3：模块内部子维度选择（针对已经开启的模块）
针对每一个N>0的模块，提供两种模式，用户二选一：
#### 模式A：手动勾选子维度
UI展示当前模板该模块下完整`candidate_pool`候选列表，用户手动勾选N个子维度，生成`selected_item_list`子集。
>勾选数量不足/超过N时前端提示校验。

#### 模式B：池内随机抽样
用户不手动勾选，点击随机选取；系统在本模块`candidate_pool`池子内随机抽取N项，生成`selected_item_list`。

>每一个开启的模块都会产出独立的`selected_item_list`。

### 3.4 步骤4：确认配置，提交任务
用户确认全部模块的：开关状态、生成张数N、选中子维度集合`selected_item_list`。
系统收集全部全局入参，准备批量调用大模型。
>注意：**每个开启的模块独立发起一次大模型请求**，例如开启模块3、模块4，则调用2次大模型，分别生成各自模块的Prompt数组。

### 3.5 步骤5：调用大模型，强制返回JSON格式
>重点约束：不允许返回markdown、解释文字、自然语言；输出必须严格JSON数组。

### 3.6 步骤6 组装完整详情页提示词集合
多个模块调用完成后，每个模块得到一组正向Prompt数组。
系统把所有模块结果做结构化组装，输出完整详情页Prompt集合文档。
每条正向Prompt统一拼接**全局固定负面Prompt**，用于后续调用文生图API。

>全局固定负面Prompt
```
水印，文字，乱码，变形，肢体畸形，手指残缺，人脸扭曲，画面闪烁，模糊，噪点过高，曝光过度，死黑，色差严重，多余杂物，背景杂乱，3D卡通，手绘，插画，油画，畸形服装，衣服褶皱崩坏
```

### 3.7 步骤7 下游输出
输出两类产物：
1. 结构化JSON：完整详情页生成任务包，包含全部模块信息、每条图片正向prompt、全局负面prompt、平台尺寸参数；可供后端直接遍历调用文生图API。
2. 可读预览文档：给商家预览，分模块展示每张图的提示词内容。

## 4 大模型调用规范
### 4.1 大模型System系统提示词（固定不变）
```
你的任务：根据传入参数生成N条电商服装生图正向提示词。
硬性规则：
1. 只允许使用入参传入的【selected_item_list】里面的项目，严禁自行创造列表以外的拍摄部位、姿势、场景。每一条prompt对应列表中的其中一项。
2. 你的工作只做摄影层面润色：优化构图、光影、微距、景深、画面质感描述，不修改核心拍摄主体。
3. 强制统一画面风格约束：电商商业摄影，写实照片，8K超清，影棚柔和布光，主体清晰对焦，简洁纯色背景，无水印，画面内不出现任何文字。
4. 禁止输出3D渲染、插画、手绘、卡通、二次元风格描述。
5. 输出格式：严格返回JSON字符串数组，数组每一项为完整正向生图提示词。
6. 禁止输出任何解释、说明、markdown、代码块标记、注释，只输出JSON数组。

入参变量：
商品描述：{{product_desc}}
商品卖点：{{sell_points}}
目标平台：{{platform}}
输出语言：{{lang}}
当前模块名称：{{module_name}}
需要生成条数N：{{N}}
选中子维度列表selected_item_list：{{selected_item_list}}
```

### 4.2 请求入参示例（mod4_detail细节特写模块）
```json
{
  "product_desc":"红色男士户外加厚羽绒服",
  "sell_points":"防风防水，90白鸭绒，耐磨抗撕裂",
  "platform":"taobao",
  "lang":"zh-CN",
  "module_name":"细节特写模块",
  "N":5,
  "selected_item_list":["防风拉链","口袋结构","面料肌理","内衬材质","帽檐细节"]
}
```

### 4.3 大模型正确返回示例

### 4.4 返回结果校验逻辑
1. 判断是否合法JSON；解析失败 → 触发重试机制。
2. 判断数组长度是否等于入参N；不相等 → 触发重试。
3. 简单内容校验：每一条prompt必须包含selected_item_list内对应子维度关键词，防止AI篡改主体。
>校验失败则重新请求大模型；重试最大3次，超过返回任务异常。

## 6 模板管理后台设计
>定位：独立后台模块，用于**管理多套品类模板**，维护12个顶层模块、各模块内部子维度候选池；支持新增/复制/编辑/删除模板、增删改子维度，供前端生成详情页任务时调用。
>底层约束：**12个顶层module_id固定不可增删**，后台仅允许修改模板内每个模块的：`max_num`、`candidate_pool`子维度列表，不允许新增/删除顶层12个板块。

### 6.1 后台核心能力清单
1. 模板列表管理：查看全部系统预置模板 + 用户自定义模板
2. 模板新增：两种方式
    - 方式A：空白新建（极少用，推荐复制）
    - 方式B：**复制现有模板**（主推，复制一份已有模板，再修改内容，降低配置成本）
3. 模板编辑：
    - 修改模板基础信息：模板名称、所属品类、备注
    - 进入12大模块配置页：对每一个模块，修改`max_num`最大阈值、编辑`candidate_pool`子维度候选池（新增、删除、修改子维度文本、拖拽排序子维度顺序）
4. 模板启用/禁用：禁用后的模板，前端下拉选择框不再展示，不可用于生成任务
5. 模板删除：仅**用户自定义模板**可删除；系统预置模板禁止删除，仅支持查看，不可直接编辑（想要修改系统模板，必须先复制成自定义模板再修改）
6. 模板预览：在后台可预览当前这套模板的12模块、每个模块子维度清单，快速核对
7. 模板导入/导出：导出整套模板JSON备份；支持导入JSON文件新增模板（方便跨环境迁移模板配置）

>权限规则：
> - 系统预置模板：type=`system`，只读，不可编辑、不可删除，可复制
> - 用户自定义模板：type=`user`，完全可编辑、可删除、可复制、可启用禁用

### 6.2 后台页面结构
#### 页面1：模板列表页（首页）
|字段|说明|
| ---- | ---- |
|模板ID|template_id，唯一标识，自动生成，不可修改|
|模板名称|例如：户外外套/羽绒服、商务正装衬衫|
|品类标签|服装品类：户外服饰 / 商务衬衫 / T恤休闲等|
|模板类型|系统预置 / 用户自定义|
|状态|启用 / 禁用|
|创建时间| |
|操作按钮|【复制模板】【编辑】【预览】【导出JSON】【删除】（系统模板删除按钮灰化）|

顶部操作按钮：【新建空白模板】【导入模板JSON】

#### 页面2：模板编辑页
分为两大标签页：
>标签1：模板基础信息
- 模板名称
- 品类名称
- 备注（可选，记录用途，如“男装商务衬衫，淘宝平台”）
- 模板状态：启用 / 禁用

>标签2：12模块配置（核心页面）
一次性加载固定12个顶层模块（module_id固定，顺序固定，不能删减）
每一行对应1个顶层模块，展示：
1. 模块ID（只读，例如mod4_detail）
2. 模块名称（只读，例如细节特写模块）
3. 是否必选（只读，必选标记由系统固定，不能修改）
4. 最大生成数量 max_num：数字输入框
    - 校验：正整数；max_num ≥1
5. 子维度候选池【candidate_pool】编辑区域
    - 列表展示所有子维度条目
    - 单行条目：文本框 + 【上移】【下移】【删除】按钮
    - 按钮【+ 添加子维度】，新增一行空白文本用于录入新子维度
    - 支持拖拽排序子维度（影响前端下拉/勾选框展示顺序）

>保存校验规则（保存模板时自动校验）
1. 必选模块：max_num ≥ 1
2. candidate_pool不能为空，至少包含1条子维度
3. candidate_pool里面不能出现空字符串
4. 同一模块内子维度不允许完全重复文本

#### 页面3：模板预览页面
只读展示，结构化展示整套模板：
模板基础信息 + 12模块列表，每个模块展示：模块名称、必选/可选、max_num、完整子维度清单。用于快速核对配置，不支持编辑。

### 6.3 后台操作业务流程
#### 场景1：复制系统预置模板，修改成自定义模板
1. 在模板列表，找到系统预置模板，点击【复制模板】
2. 系统生成一条全新template_id，type自动改为`user`
3. 进入编辑页，修改模板名称
4. 进入12模块配置，修改对应模块max_num、增删子维度、调整排序
5. 保存，校验通过后模板生效，前端生成页面下拉框可以选择该模板

#### 场景2：新建空白模板
1. 点击【新建空白模板】
2. 填写模板名称、品类
3. 依次对固定12个模块，逐个填写max_num，录入子维度候选池
> 不推荐，工作量大，优先复制模板方式

#### 场景3：导出/导入模板
1. 导出：点击导出JSON，下载完整模板JSON文件，用于备份或者迁移到其他环境
2. 导入：上传JSON文件，系统校验JSON结构合法性；校验成功，新增一条用户自定义模板

### 6.4 后台操作校验提示文案
1. 子维度为空：`子维度文本不能为空，请输入内容或者删除该行`
2. 模块候选池为空：`该模块子维度列表不能为空，至少保留1条`
3. max_num输入0：`必选模块最大数量不能小于1`
4. 导入JSON结构异常：`JSON解析失败，模板结构不符合规范，请检查文件`
5. 删除被任务引用的模板：`该模板已经被历史生成任务引用，确认删除？删除后历史任务不受影响，但无法再新建任务选用该模板`

### 6.5 和详情生成主流程联动关系
1. 用户进入【详情生成页面】，下拉选择模板，前端请求后台接口，读取该模板完整JSON
2. 前端渲染12个模块、每个模块max_num、子维度候选池，给到用户勾选/随机抽样
3. 用户配置完成提交任务，把模板ID、选中子维度列表传给大模型生成prompt
4. 修改模板，**不会影响已经生成完成的历史任务**（历史任务会缓存当时选中的子维度快照，和模板解耦，模板后续修改不改动旧任务结果）

## 8 校验与异常处理规则
1. 模块数量校验：必选模块`enable`不允许false；开启模块`generate_count`不能大于模板内该模块`max_num`。
2. 子维度校验：`selected_item_list`内所有元素必须来源于该模块模板`candidate_pool`，前端拦截非法值。
3. 大模型返回校验：JSON合法性、数组长度匹配N、关键词主体校验；失败最多重试3次，超过返回任务失败。
4. 全局总张数校验：所有开启模块generate_count总和设置全局上限（例如44张），防止一次性任务过大。

## 9 非功能约束
1. 大模型永远不允许自行创造子维度拍摄对象，拍摄主体严格来自传入`selected_item_list`；AI只做摄影文案润色。
2. 负面提示词全局固定，不交给大模型生成。
3. 大模型输出强制JSON数组，禁止附带多余文本。
