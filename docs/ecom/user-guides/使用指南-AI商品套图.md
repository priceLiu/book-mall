# 使用指南 · AI 商品套图

**Tagline：白底/卖点/场景套图 + 可选上架文案**

面向 **上架前要一组商品图** 的卖家：左侧上传 **商品原图（最多 6 张）**，右侧 **配置套图结构**（白底、卖点、场景、细节），一键 **AI 规划各槽位 Prompt**，在中栏 **勾选批量出图**；可选 **卖点图版式库**、**爆款风格** 与 **上架文案**。无 Step0–3 助手，路径更短。

**入口**：电商工具箱 → **电商** → **主图与套图** → **AI 商品套图**（`/ecom/product-image-set`）

---

## 适合谁

- 需要 **白底图 + 卖点图 + 场景/模特场景 + 细节辅助** 组合，张数自己配（有上限）。
- 已有 **多角度的产品实拍**，希望 **锁定同款** 批量出图。
- 想复用平台 **卖点图版式预置** 或 **爆款视觉风格** 卡片，而不是从零写每条主图文案。

**不太适合**

- 要强 **营销方案三选一、购买理由矩阵、主图分层叙事** → [电商产品主图创作](./使用指南-电商产品主图创作.md)。
- 要 **详情长图 / A+ 模块 / 服装 12 模块** → [详情页工具怎么选](./详情页工具怎么选.md)。

对比见 [主图与套图工具怎么选.md](./主图与套图工具怎么选.md)。

---

## 界面怎么分

| 区域 | 作用 |
| --- | --- |
| **中栏（左区）** | 上传 **商品原图**（≤6）、套图 **槽位网格**、勾选出图、预览/改 Prompt |
| **右侧配置侧栏** | 平台/国家/语种、出图比例、卖点文档、套图结构、版式与风格、模型、**生成套图占位** |
| **顶栏** | 新建、项目列表、保存工作流、导出 ZIP、分享、**去做视频**（需已有成图入库） |

**没有** 右侧对话助手；全流程在 **配置 + 中栏槽位** 完成。

---

## 套图结构（可配张数）

在侧栏 **套图结构配置** 用步进器设定（各类型有上限）：

| 类型 | 含义 | 数量范围（界面） |
| --- | --- | --- |
| **白底图** | 纯白/干净底商品图 | 0～5 |
| **卖点图** | 带卖点信息的主图类画面 | 0～9 |
| **场景 / 模特场景** | 生活/穿搭/环境 | 0～12 |
| **细节 / 辅助图** | 细节特写等；标 **AI 智能匹配** | 0～5 |

**至少上传 1 张原图**，且 **结构合计 > 0 张** 才能点生成占位。

**卖点图 > 0** 时，需 **选择卖点图版式参考**（从预置 `sellpoint_layout` 库按品类挑选，数量不超过卖点图张数）。也可上传 **自定义版式参考图**（在版式选择流程中，以界面为准）。

## 推荐流程

### 1. 上传商品原图

- 中栏 **商品原图** 区：本地上传（可多张，**最多 6 张**）。
- 用于 **AI 识卖点** 与出图时锁定商品外观。

### 2. 生成设置与卖点

- **生成设置**：目标 **平台、国家/市场、语种**（影响文案与风格倾向）。
- **出图比例**：1:1、3:4、4:5、16:9、9:16 等；与 **生图模型参数** 联动（侧栏 **模型与参数** 打开统一 **StoryboardModelPickerDialog**）。
- **商品卖点 & 要求**：建议填 **五段式卖点** 模板；可点 **AI 帮写**（分析原图生成卖点文档，需先有原图）。

### 3. 可选增强

- **爆款风格分析**：勾选后展示 **trending_visual** 风格卡片（按推断品类刷新），可多选；可 **换一批风格**。
- **商品上架文案生成**：勾选后，规划/出图流程可附带 **listing 文案**（成图后在槽位区或导出中查看，以界面为准）。

### 4. 生成套图占位（AI 规划 Prompt）

侧栏底部 **「生成套图占位（N 张）」**：

1. 先保存当前卖点文本到项目。
2. 调用 **AI 规划套图 Prompt**，按结构创建 **N 个槽位**，每条写入 **title + 生图 prompt**（卖点图会结合所选版式）。
3. 成功后中栏出现分组网格：**白底图 / 卖点图 / 场景图 / 其他**。

若 LLM 规划失败，系统可能走 **fallback** 占位 Prompt，界面会提示；你可 **改 Prompt 后重试规划**（中栏 **重新规划**，以顶栏/槽区按钮为准）。

### 5. 中栏出图

- **勾选** 要生成的槽位 → **生成选中**；或对单槽 **生成 / 重新生成**。
- 可 **编辑 Prompt**（编辑过的条目会标记，避免被误覆盖）。
- 出图进行中侧栏与中栏显示 **槽位出图中** 状态；长任务请留在页面或稍后刷新项目（异常中断可能提示 **任务状态超时**，需重新点生成）。

### 6. 导出与后续

- **导出 ZIP**：打包套图与相关文案。
- **保存工作流**：把当前配置与占位存为 **项目镜像**（新建前会询问是否先保存）。
- **分享工作流**：10 位码/链接，好友领取 **副本** 继续编辑出图。
- **去做视频**：至少一槽 **已出图并入库** 后，可带资产跳转 **电商口播故事版** 做短视频（自动建故事版项目）。

## 与「电商产品主图创作」差在哪

| | 电商产品主图创作 | AI 商品套图 |
| --- | --- | --- |
| 交互 | 助手 Step + Prompt 计划 | **侧栏结构配置 + 槽位网格** |
| 产出形态 | 主图 **分层策略 + 若干主图** | **白底/卖点/场景/细节** 套图 |
| 版式库 | 无统一卖点版式 picker | **卖点图版式预置 + 爆款风格** |
| 上架文案 | 非核心 | 可选 **上架文案生成** |
| 详情衔接 | 可 **导入策略** 到详情长图 | 无 Step 导入；可 **去做视频** |

## 使用要点

1. **先占位、再出图**：未规划前中栏无槽位；规划完务必 **看一眼每条 Prompt** 再批量生成。
2. **卖点图张数 = 版式选择数**：减少卖点张数时，已选版式会自动截断。
3. **细节/辅助图** 由 AI 按卖点 **智能匹配** 意图，仍建议在出图前扫一眼 Prompt。
4. **品类推断**：系统会根据原图/配置推断 vertical（如服装、包袋、3C、通用），影响 **版式库与风格卡片** 推荐。
5. **计费**：AI 帮写、规划 Prompt、出图均经 Gateway；`toolKey: ecom-toolkit__product-image-set`，rollup 至电商工具箱月费。

## 常见问题

**最多几张原图？**  
**6 张** product 参考。

**一次必须出满 N 张吗？**  
不必；占位 N 张后 **勾选哪张出哪张**。

**和 AI 商品套图并排的「主图创作」能合并吗？**  
不能共项目；同一商品可 **各建一个项目**，分别走策略主图与套图批量。

**刷新后还在吗？**  
项目、槽位、Prompt、已出图 **持久化**；记住在顶栏用 **项目列表** 切换。

**删除/新建？**  
新建若已有未保存改动，会提示 **先保存工作流**；删除项目遵循工作台 **二次确认**（若入口提供）。
