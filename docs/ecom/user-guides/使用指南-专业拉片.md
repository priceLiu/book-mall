# 使用指南 · 专业拉片

**Tagline：工业化逐镜拉片 · 换角 · 合成成片**

面向 **进阶视频创作**：上传一条 **不超过 90 秒** 的参考视频，AI 做 **逐镜专业拉片**（约 **25 维** 字段，结果 **只读**）；再用 **自己的模特图 + 产品图** 走 **一键复刻 → 参考图匹配 → 制作脚本 → 制作成片 → 合成**，按原片镜头语言复刻出一条新视频。

**入口**：电商工具箱 → **电商** → **拆解与拉片** → **专业拉片**（`/ecom/film-pull`）

---

## 适合谁

- 带货短片、品牌 TVC 切片、竞品视频：**要镜级运镜、布光、叙事功能**，而不只要一张简表。
- 计划在 **同一页面内** 完成：拉片 → 换模特/换产品 → 逐镜 **生图 / 生视频** → **合成完整 MP4**。
- 能接受 **单条视频 ≤90 秒**（更长需自行剪段，当前不支持自动分段拉片）。

**不太适合**

- 只有 **一张静态图**、或只想快速出分镜表 → [拆图拆视频](./使用指南-拆图拆视频.md) 更合适。
- 只要脚本策划、不要拉片表 → 种草视频等入口。

对比说明见 [拆解与拉片工具怎么选](./拆解与拉片工具怎么选.md)。

---

## 和「拆图拆视频」差在哪（一句话）

| | 拆图拆视频 | 专业拉片 |
| --- | --- | --- |
| 素材 | 图 **或** 视频 | **仅视频**（≤90s） |
| 分析表 | 视频分镜表 + 叙事/卡点/拍摄脚本 | **25 维逐镜表** + 元信息 + 拍摄准备 + 叙事/卡点/脚本摘要 |
| 成片工作区 | 复刻区叫 **方案② / 拆图复刻 · 精细成片** | 专用 **制作成片**（制作脚本表 + 分镜卡片 + **合成成片**） |
| 时间轴 | 复刻时继承拆解镜序 | **镜数与时长继承拉片结果，制作阶段不可改时间轴** |

## 界面概览

| 区域 | 作用 |
| --- | --- |
| **顶栏** | 新建、项目列表、**保存**、**我的资产**、分享、**导出 ZIP** |
| **视频上传** | 本地 / HTTPS 链接 / 我的资产；拉片进行中 **锁定** 源视频不可换 |
| **拉片指令 + 模型** | 默认拉片 Prompt，可编辑；选 **支持视频理解** 的模型 |
| **拉片结果** | **只读**：元信息、拍摄准备、**逐镜大表**、叙事逻辑 / 卡点 / 可复刻脚本等 |
| **复刻后续区** | 参考素材 →（自动）制作脚本 → **制作成片** 工作区 |
| **底栏** | 阶段提示 + **一键复刻** 等主操作 |

页内 **步骤条** 常见四段：**拉片 → 审校 → 换角 → 成片**（与底栏状态联动，拉片进行中会显示「拉片中…」）。

## 推荐流程

### 步骤 1 · 拉片

1. 上传 **≤90 秒** 视频（界面会提示时长上限）。
2. 确认 **拉片 Prompt** 与 **视觉/视频理解模型**（默认常用 `qwen3.8-max` 一类，以你账户 Gateway 列表为准）。
3. 点 **「拉片」**（分析可能较久，可留意 **后台任务** 与页内进度；进行中可 **中止** 拉片任务）。
4. 成功后查看 **拉片结果**（不可直接改表内字段——这是 **审校阅读**；要改叙事请换 Prompt 重新拉片）：
   - 全片时长、叙事主线、剪辑节奏、风格、音频设计、镜头序列与运镜总结
   - **拍摄准备**：场地、服装、道具、设备
   - **逐镜表**：镜号、起止时间、景别、角度、运镜、焦距透视、构图、调度、视线、场景、层次、道具、布光、影调、叙事功能、音频（字幕/情绪/环境音/特效 BGM）、节奏权重、视觉隐喻、AI 视觉描述等
   - **叙事逻辑**、**卡点**、**可复刻拍摄脚本** 文字块

5. 可选：**保存** 项目、**导出 ZIP**、**分享工作流副本**。

### 步骤 2 · 一键复刻 + 参考素材

1. 拉片完成后，点 **「一键复刻」**（结果区或底栏）。
2. 在 **参考素材** 面板上传 **模特图**、**产品图**（可多张：拖放、粘贴、我的资产、模特库；@图片1 起为模特，其后为产品）。
3. **AI 识产品** 或手动填写 **产品描述/卖点**。
4. 素材齐后，系统在后台 **自动生成制作脚本**（底栏会分步提示，例如：读取拉片结构 → 分配参考图 → 组装画布/光影/运镜 → 写生图/生视频 Prompt → 保存脚本表）。

### 步骤 3 · 参考图匹配（系统自动 + 可改）

- 平台 **自动** 为每一镜匹配使用哪些模特/产品参考（@图片N）。
- 若提供 **参考图匹配表** 编辑能力，可在确认前进制作脚本前 **改任意镜的 ref 组合**（以当前界面为准）。
- 确认后进入 **制作脚本** 阶段。

### 步骤 4 · 制作脚本

- 打开 **制作脚本表**（在拉片结构之上扩展 **生图 Prompt、生视频 Prompt** 等列）。
- **可编辑** 各镜 Prompt 与描述；改完需 **保存 / 确认制作脚本**（确认后底栏模式会进入制作）。
- 脚本确认后，**镜数与时间码仍来自拉片**，不要在制作阶段指望改切片数量。

### 步骤 5 · 制作成片

进入 **制作成片** 工作区（**不是** 种草视频的「精细成片」表）：

- **上方**：已确认的制作脚本（可再编辑保存）。
- **下方**：分镜卡片——每镜可 **只生视频**（参考图 + 生视频 Prompt → 常见 R2V 类模型），或 **先生图再生视频**，或 **改 Prompt 多次重试**。
- 支持 **勾选多镜批量** 生图/生视频；任务进 **后台生成 Dock**。
- 在 **StoryboardModelPickerDialog** 中选择 **出图 / 出视频模型** 与参数。

### 步骤 6 · 合成

- 当 **每一镜都有分镜视频** 后，点 **「合成成片」**。
- 预览 **整条视频**，可保存到 **我的资产** 或通过 **导出 ZIP** 取回。

## 使用要点

1. **90 秒硬上限**：超长素材请先剪辑；不支持 V2 里的「分段拉片」。
2. **拉片只读**：专业字段是分析产物；要改分析请 **重新拉片** 或改 Prompt，不要在结果表里找编辑入口。
3. **先脚本、后生成**：未 **确认制作脚本** 时不要跳过直接批量出片，否则 Prompt 与 ref 可能未对齐。
4. **换角只用自有图**：出图/出视频 **仅使用你上传的模特与产品**，不会把参考原片当生图输入。
5. **与影视专业版画布**：同一套 **制作档 / pro2 拉片结构** 可在画布 Hub 做更重度剪辑；电商本页是 **独立项目**，专注「拉片 + 电商复刻成片」闭环。

## 常见问题

**拉片失败或 JSON 报错？**  
与拆图拆视频类似：_fence JSON 校验失败会提示错误，请 **重试或换模型**，不会展示半成品为成功。

**必须走完全部步骤吗？**  
若你 **只要拉片报告**，到步骤 1 导出即可；复刻与合成是可选。

**和拆图拆视频的一键复刻一样吗？**  
壳层类似（上传 → 分析 → 一键复刻 → 素材），但拉片用 **25 维表 + 制作脚本 + 合成**，不是种草 7 列表。

**制作阶段能删镜吗？**  
**不能** 改拉片定下的镜数与时间轴；只能在该结构下换 Prompt、换参考、重生成。

**Mock 拉片按钮？**  
仅 **本地开发** 环境可能出现，用于无模型调试；正式环境请用 **拉片**。

**计费**  
拉片、识产品、生图、生视频、合成都走 Gateway；归属电商工具箱 **e-commerce-toolkit** 月费体系。
