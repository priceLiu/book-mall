# 使用指南 · 服装详情套图（模板）

**Tagline：无参考图 · 七维 + 平台模板 · 12 模块最多 49 张**

面向 **服装电商**：不依赖参考详情长图，通过 **七维参数 + 平台模板 + 12 个大模块** 批量生成摄影向详情套图（模特上身、面料、版型、场景等）。交互壳与「电商口播故事版」类似：步骤轨 + 三栏，但是 **独立项目**，与口播分镜不混用。

**入口**：电商工具箱 → **服装详情套图（模板）**（`/ecom/detail-page-suite`）

---

## 适合谁

- 卖 **服装/外套/衬衫/T 恤** 等，希望按 **淘宝/京东/抖音…** 不同平台比例与风格 note 出图。
- 愿意花几分钟做 **七维选择**（性别品类、款式、风格、档次、场景、平台、语言），让候选子维度更贴类目。
- 需要 **子维度手选 / 池内随机 / 自己新增**，并可选保存为「我的模板」。
- **不需要** 上传竞品或参考详情长图（与复刻、爆款结构工具不同）。

---

## 不适合谁

- 必须 **照着某张详情长图** 拆版式 → [参考详情 → 标准套图](./使用指南-参考详情转标准套图.md)。
- 学 **竞品叙事卡位**、卡位数量可变 → [学竞品结构 · 原创详情](./使用指南-学竞品结构原创详情.md)。
- 非服装多品类 A+ 16 模块 → [A+ 详情模块出图](./使用指南-A+详情模块出图.md)。

---

## 推荐流程（8 步）

1. **产品图**：多张上传（非强制）；无图则关闭 AI 识图。
2. **七维**：逐步点选，与口播故事版同一套选项。
3. **卖点**：手填 / 多图识图 / AI 润色 → 确认清单。
4. **模板**：按 **平台 + 类目** 加载系统模板或「我的模板」（12 平台各有副本，改京东不会同步淘宝）。
5. **大模块**：12 模块均可 **开关**；每模块设张数 N（全局硬顶 **49 张**）。至少开启 1 个模块且 N≥1 才能继续。
6. **子维度**：在每个已开模块里选手选、随机或新增候选。
7. **提示词**：每个已开模块调用一次 LLM 润色（JSON 围栏）；可改单条或 AI 重写。  
   - **尺码数据总表图**：填好 `brief` 尺码表后 **程序渲染**，不走文生图；线稿/模特对比类仍走模型。
8. **出图**：用统一 **模型选择器** 单张 / 按模块 / 全部（≤49）；长任务进后台 Dock。

## 12 模块一览（户外外套种子示例）

| 模块 | 含义 | 上限张数（示例） |
| --- | --- | --- |
| 首屏主视觉海报 | 详情第一张 | 1 |
| 产品核心亮点汇总 | 卖点汇总（须对齐产品参考图） | 2 |
| 模特上身整体穿搭 | 穿搭展示 | 6 |
| 细节特写 | 拉链、帽檐等 | 10 |
| 面料材质说明 | 材质近景 | 3 |
| 版型剪裁讲解 | 版型示意 | 3 |
| 尺码参考 | 含 **尺码总表（程序化）** | 6（默认开 1 张总表） |
| 场景穿搭场景图 | 户外/街景等 | 5 |
| 颜色多色对比 | 色号对比 | 4 |
| 工艺/功能说明 | 科技点 | 5 |
| 买家痛点对比 | 前后对比 | 2 |
| 售后保障+品牌收尾 | 留白底图，画面内避免文字 | 2 |

不同类目种子（衬衫、T 恤）结构相同，后台模板可再调 `max_num`。

## 尺码模块特别提醒

- **尺码数据总表图** 必须用你在中栏编辑的 **真实尺码行**；不要用演示数据直接上架（界面有强提示）。
- 未录入有效尺码时， **不允许** 生成总表图；线稿/多身高试穿类不依赖尺码表。

---

## 平台与比例

- 侧栏/ brief 选定平台后，出图比例、像素宽等跟该平台模板走（如 3:4、750 宽等）。
- 中栏可切换 **展示比例** 预览，不影响已出 OSS 图的像素（以生成时设定为准）。

---

## 项目与导出

- **新建 / 打开 / 删除** 项目在中栏顶栏；删除需二次确认。
- 成图进 **我的资产**（来源：**服装详情套图（模板）**）。
- 本工具产出 **多张独立模块图**，不自动拼长图；你可自行在 PS/稿定里拼接。

## 常见问题

**必须开满 12 模块吗？**  
不必，全部可关；只要至少 1 个模块 N≥1。

**和口播故事版能共用一个项目吗？**  
不能，各自独立项目表与入口。

**44 张还是 49 张？**  
户外外套等种子合计 **49**；界面「已开模块」计数以当前模板 `max_num` 与勾选为准，以工作台顶栏提示为准。

**LLM 会瞎编拍摄主体吗？**  
系统 Prompt 约束禁止发明未提供的主体；仍建议上传产品图并在卖点里写清款号/颜色。
