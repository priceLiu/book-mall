# 详情页相关工具怎么选

面向淘宝、京东、抖音等平台的卖家与运营。电商工具箱里与「详情页」相关的入口有 **五个**，产出形态不同，**不要混用**：一个项目建好后属于哪个工具就固定了，不能中途改成另一种。

---

## 一句话对照（看 tagline 选）

| 工具名称 | Tagline | 你手上有… | 你更想要… |
| --- | --- | --- | --- |
| **[A+ 详情模块出图](./使用指南-A+详情模块出图.md)** | 无参考图 · 16 模块 · 9 品类 · 自动子维度 | 产品实拍 + 卖点文案 | 按 A+ 模块批量写 Prompt、出图（含尺码/参数表程序化图） |
| **[详情长图分屏创作](./使用指南-详情长图分屏创作.md)** | 架构 + 分屏文案 · 助手 Step · 可接主图策略 | 产品图；可选详情长图参考 | 助手带 Step、分屏文案 + **每条 Prompt 对应一屏** 的详情长图 |
| **[服装详情套图（模板）](./使用指南-服装详情套图（模板）.md)** | 无参考图 · 七维 + 平台模板 · 12 模块最多 49 张 | 服装产品图 + 七维偏好 | 按平台模板勾选 12 大模块/子维度，批量摄影套图 |
| **[参考详情 → 标准套图](./使用指南-参考详情转标准套图.md)** | 上传参考长图 · 拆入固定 12 模块 · 自家卖点出图 | **自家**参考详情长图 + 产品图 | 学参考版式节奏，拆进标准 12 模块再出图（非像素级抄图） |
| **[学竞品结构 · 原创详情](./使用指南-学竞品结构原创详情.md)** | 竞品只学结构/氛围 · 卡位可调 · 文案原创、只用自家图 | 竞品详情长截图 + **自有**新品图 | 学爆款叙事与卡位，文案重写，出图只用自家商品/模特 |

主图策略与详情长图的关系：若已用 **[电商产品主图创作](../../../book-mall/doc/product/ecom-product-creation-workflow.md)** 做完 Step0–3，可在详情长图分屏创作里 **从主图项目导入**，不必重填策略。

## 容易混淆的两对

### 「参考详情 → 标准套图」 vs 「学竞品结构 · 原创详情」

两者都可以上传 **一张很长的详情截图**，但目的不同：

| | 参考详情 → 标准套图 | 学竞品结构 · 原创详情 |
| --- | --- | --- |
| 框架 | 固定 **12 大模块**（与服装模板套图同一套 id） | **卡位数量不固定**，可增删、排序、改重复张数 |
| 参考图角色 | 最好是 **你或同行可借鉴的详情版式**（自家/已授权参考） | 明确为 **竞品**，只学结构/氛围，**禁止**照抄原文原图 |
| 文案 | 卖点须来自 **你填的 sellPoints** | AI **原创重写**，界面有合规提示 |
| 典型用户 | 「我就照着这张参考详情模块节奏做自家款」 | 「这张淘宝爆款结构好，我要用自家新品做一套类似叙事」 |

### 「A+ 详情模块出图」 vs 「服装详情套图（模板）」

| | A+ 详情模块出图 | 服装详情套图（模板） |
| --- | --- | --- |
| 模块体系 | **16 个 A+ 模块**（首屏、卖点、场景、规格表…） | **12 个服装大模块**（模特上身、面料、版型…） |
| 品类 | **9 品类**（含母婴、鞋靴、户外等），自动匹配子维度 | 首期以 **服装七维 + 平台模板** 为主（户外外套等类目种子） |
| 参考详情长图 | **不需要** | **不需要** |
| 七维逐步采集 | 无（选品类 + 卖点即可） | **有**（与口播故事版同一套七维选项） |

## 入口路径（侧栏 · **详情页** 分组）

在电商工具箱侧栏 **电商 → 详情页** 下，自上而下：

1. A+ 详情模块出图 → `/ecom/ai-detail-page`
2. 详情长图分屏创作 → `/ecom/detail-page-creation`
3. 服装详情套图（模板） → `/ecom/detail-page-suite`
4. 参考详情 → 标准套图 → `/ecom/detail-page-suite-replica`
5. 学竞品结构 · 原创详情 → `/ecom/detail-page-suite-hit`

**主图与套图** 分组含主图创作与 AI 商品套图；**详情长图分屏创作** 与 A+ / 服装套图并列在 **详情页** 分组，便于按场景选型。

套图三条（3～5）共用相似的中栏「模块格子 + 模型出图」，但 **新建项目、上传区、拆解按钮** 各不相同；请按上表先选对入口再开工。

---

## 计费与保存

- 上述工具均归属电商工具箱 **同一套月费**（`e-commerce-toolkit`），具体扣费以生成时 Gateway 模型调用为准。
- 项目保存在云端，刷新页面可继续；出图结果写入 **我的资产 / 生成历史**（按来源模块筛选）。
- 破坏性删除项目须在工作台内二次确认；导出 ZIP（部分套图工具顶栏）仅打包 **你方** 出图与文案，不含竞品原图。
