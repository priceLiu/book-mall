# 拆解与拉片工具怎么选

电商侧栏 **拆解与拉片** 分组里有两个工具，都涉及「上传素材 → AI 分析」，但 **深度与后续成片能力不同**。

| 工具 | Tagline | 上传 | 分析产出 | 后续 |
| --- | --- | --- | --- | --- |
| **[拆图拆视频](./使用指南-拆图拆视频.md)** | 图片/视频反推拆解 · 分镜与生图提示词 | **1 张图** 或 **1 段视频** | 视频：分镜表 + 台词/卡点/拍摄脚本；图：要素 + Prompt + 实拍方案 | 可选 **一键复刻** → 方案② / 拆图复刻 · 精细成片 |
| **[专业拉片](./使用指南-专业拉片.md)** | 工业化逐镜拉片 · 换角 · 合成成片 | **仅视频 ≤90s** | **25 维逐镜表**（只读）+ 叙事/卡点/脚本摘要 | **一键复刻** → 制作脚本 → **逐镜出片 → 合成整条视频** |

---

## 怎么选（30 秒）

- **只有图片**，或只想 **快速反推** 分镜/生图词 → **拆图拆视频**。
- **短视频复刻成片**，需要 **镜级运镜布光** 和 **最后一键合成 MP4** → **专业拉片**。
- 两个都可以 **导出 ZIP**、**分享工作流副本**（好友领取后可继续编辑/复刻）。

---

## 和「详情页」「种草视频」的关系

- **详情页** 五个入口：出 **详情模块图/长图**，不做视频拉片 → 见 [详情页工具怎么选](./详情页工具怎么选.md)。
- **种草视频**：从策划到 30s 成片的 **产品向助手**；拆图拆视频 **不做** 那套多步助手，但 **视频复刻** 会借用其分镜成片能力。
- **专业拉片** **不走** 种草「精细成片」表，用 **拉片专用制作脚本 + 合成**。
