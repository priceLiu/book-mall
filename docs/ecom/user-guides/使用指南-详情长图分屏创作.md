# 使用指南 · 详情长图分屏创作

**Tagline：架构 + 分屏文案 · 助手 Step · 可接主图策略**

面向希望 **自己掌控详情叙事结构**、按 **一屏一图** 产出详情长图素材的卖家。与「电商产品主图创作」共用同一套产品创作壳：**中间工作区出图 + 右侧助手逐步推进**。

**入口**：电商工具箱 → **详情长图分屏创作**（`/ecom/detail-page-creation`）

---

## 适合谁

- 需要 **Step0–3 策略层**（Brief、拆解、营销方案、购买理由），再落到 **详情架构 + 分屏文案**。
- 已在 **主图创作** 里定好策略，想 **拷贝到详情项目** 继续做，而不重填一遍。
- 习惯 **Prompt 计划**：每条生图 Prompt 对应一张详情屏，确认后再出图，避免「一句描述 × N 张雷同图」。
- 可选：上传 **detail-style 详情长图参考**，或自写生图意图，走 **产品图 + 参考图 + Prompt** 快捷路径。

**不太适合**：按 12/16 固定模块批量摄影、无分屏助手 → 请用 A+ 或服装套图系列（见 [详情页工具怎么选.md](./详情页工具怎么选.md)）。

---

## 与主图创作的关系

| 项目类型 | 产出 |
| --- | --- |
| 电商产品主图创作 | 卖点策略 + 主图分层文案 + 主图 |
| 详情长图分屏创作 | 策略（可导入）+ 详情架构 + 分屏文案 + 详情屏 |

- **一个项目只属于一种入口**，建成后不能改成主图项目。
- **不必先做主图**：可直接进详情入口从零开始。
- **从主图带入策略**（两种方式）：
  1. 主图全部出齐后，中栏卡片 **「主图已出齐，继续做详情页？」**
  2. 详情入口顶部 **「从主图项目导入」**，勾选是否带产品图、是否用主图成品作风格参考  

导入是 **快照拷贝**，之后两个项目互不影响。

## 界面怎么分

| 区域 | 作用 |
| --- | --- |
| **中间工作区** | 上传参考图、选平台、产品信息、制作方式、**Prompt 计划**、生成、预览、导出 ZIP |
| **右侧助手** | 流式文案；**下一步 / 修改当前步**；不代替中栏出图 |

---

## 两种制作方式（出图前汇合）

上传产品图后选一次：

| 方式 | 说明 |
| --- | --- |
| **助手流程（Step by step）** | 助手带 Step0–3 → **Step7 详情架构** → **Step8 分屏文案** → Prompt 计划 → 出图 |
| **产品图 + 参考图 + Prompt** | 自写意图（参考图可选）→ **识别并拆解** 成 N 条 Prompt → 确认 → 出图 |

**无论哪种，出图前都必须在中栏完成 Prompt 计划并点「确认计划并开始出图」。** 助手只产出文案，不以聊天记录为准出图。

### 助手路径要点

- **Step0** 可选 **AI 拆解产品图** 或 **手动输入**（手动不产生模型调用）。
- 营销方案 **选定后不可换方案**，但方案内容仍可在中栏铅笔修改。
- 若从主图导入了策略，助手会问 **沿用已有策略** 或 **先去中栏改策略**，再进 Step7。

### 参考图角色

| 角色 | 用途 |
| --- | --- |
| **product** | 商品实拍，出图锁定款式/颜色 |
| **detail-style** | 详情版式/模块节奏参考（常为长图） |

详情路径下：**detail-style 长图参考** 与 **自写 Prompt** 至少有一个；产品实拍建议上传。

---

## Prompt 计划

1. **产品理解**：名称、品类、卖点等（可改）。
2. **生图 Prompt 列表**：每条 = 一屏的职责与构图。
3. **识别并拆解 / 从文案生成草稿** 会回到草稿态；你 **手动改过的条目** 在重新拆解时 **默认保留**。
4. **确认计划并开始出图** 后，才创建对应数量的出图槽位。

单张「生成」与「生成全部」都使用列表里 **当前** 的 Prompt 文本。

---

## 导出与后续

- **导出交付包（ZIP）**：文案 + 详情图 + 参考图分类。
- 全部完成后可跳转 **去做视频**（若你方已开通种草视频等入口）。

## 常见问题

**为什么要先确认 Prompt？**  
保证每一屏有独立构图与卖点分工，而不是同一句描述重复出多张。

**和 A+ 详情模块出图的区别？**  
分屏创作是 **自由屏数 + 助手架构**；A+ 是 **固定 16 模块 + 9 品类**，无 Step7/Step8。

**和「参考详情 → 标准套图」的区别？**  
分屏创作 **不强制** 12 模块框架，也不做 Vision 长图拆解；参考套图工具专吃 **一张参考长图 → 12 模块格子**。

**导入策略会扣费吗？**  
不会，导入是纯数据拷贝。

**哪些操作会调用 AI？**  
Step0 AI 识图、各步文案、Prompt 拆解、出图；选手动 Step0 则跳过识图调用。
