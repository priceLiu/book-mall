# 使用指南 · 参考详情 → 标准套图

**Tagline：上传参考长图 · 拆入固定 12 模块 · 自家卖点出图**

面向：**已经有一张想借鉴的详情长图**（自家旧款、供应商样稿、已获授权的同行版式等），希望 AI **按画面顺序拆解**，再 **归入与服装模板相同的 12 大模块**，用 **你家的产品图 + 卖点** 重新出图。  
**不是** 像素级复刻，也 **不要** 指望 OCR 原样还原参考图上的品牌与 SKU 文案。

**入口**：电商工具箱 → **参考详情 → 标准套图**（`/ecom/detail-page-suite-replica`）

---

## 适合谁

- 手上有 **整页/长条参考详情图**，想要 **模块节奏对齐** 服装标准套图（首屏、模特、细节、尺码…）。
- 已有 **产品实拍** 和 **可上架卖点**，愿意在拆解后 **核对 Prompt** 再批量出图。
- **不需要** 七维问卷、不需要手选平台子维度池（与「服装详情套图（模板）」相反）。

**不太适合**

- 参考图是 **竞品爆款**、主要想抄叙事与卡位 → 请用 [学竞品结构 · 原创详情](./使用指南-学竞品结构原创详情.md)（合规与卡位编辑更匹配）。
- 没有参考长图、只想按模板从 0 搭 → [服装详情套图（模板）](./使用指南-服装详情套图（模板）.md)。

---

## 上传什么

| 类型 | 是否必填 | 说明 |
| --- | --- | --- |
| **参考详情长图** | 拆解必填 | 整页截图；Vision **只读这一张** 做拆解 |
| **产品实拍** | 出图/识图强烈建议 | 锁定款式颜色；**不参与** 拆解阶段 A |
| **模特图** | 可选 | 出图时可学模特气质 |

参考长图经上传后会在服务端缩放以控制识别成本；请尽量清晰、完整、自上而下可读。

---

## 界面结构（上下分区）

1. **上区**：上传 + 卖点 + **拆解 / 生成 Prompt** 按钮  
2. **中区**：拆解结果只读（视觉片段清单 + 按模块汇总）；未识别到的模块显示 **「无」**  
3. **下区**：与模板套图相同的 **12 模块格子**，编辑 Prompt、出图  

顶栏可 **素材打包导出**（ZIP 含你方出图与说明，不含参考图二次传播用途——请自行合规使用参考素材）。

## 推荐流程

### 1. 上传与卖点

- 先传 **参考长图**；产品图、模特图可在拆解前或后补。
- **卖点**：手填或 **多图识图**（需产品图）；卖点会进入阶段 B 润色，**禁止** 模型照抄参考图上的促销句。

### 2. 拆解（两阶段）

- **阶段 A0**：视觉清单，自上而下切分 `segments`（布局、元素描述，不写最终 Prompt）。
- **阶段 A1**：自动归类到 12 模块；置信度高的写入对应模块，其余可在 UI **手动改模块归属**。
- 完成后状态为 **已拆解**；中区可核对「这张参考里哪一段归到了哪个模块」。

### 3. 生成 Prompt

- 勾选要处理的模块（可全选 12）→ **单次** 批量文本润色 → 写入下区各 slot。
- **尺码模块 mod7**：参考图里的表格 **不会** 被抠成尺码数据；与模板套图一样，**尺码总表** 需你在编辑器里填 **自家尺码** 后 **程序化出图**。

### 4. 核对与出图

- 下区可 **改单条 Prompt**、编辑尺码表。
- 出图走 **StoryboardModelPickerDialog**；长任务进后台 Dock。
- 出图参考 **仅 product / model**，**不会** 把参考长图当作生图输入（避免抄竞品画面）。

## 与「学竞品结构 · 原创详情」怎么选

| | 参考详情 → 标准套图 | 学竞品结构 · 原创详情 |
| --- | --- | --- |
| 输出框架 | 固定 **12 模块** | **可变卡位** `component_list` |
| 参考图定位 | 版式/模块 **对齐标准套图** | **竞品** 结构/氛围，界面合规提示 |
| 文案 | 来自 **你的 sellPoints** 润色 | **原创重写** + 可编辑 `slot_copy` |
| 典型心智 | 「这张详情模块划分我想沿用」 | 「这张卖得好，我要类似叙事但全新文案」 |

## 常见问题

**拆解后某模块是「无」？**  
说明 AI 没在参考里找到对应该模块的段落；可手动调整归类，或接受该模块不出图。

**可以不上传产品图就拆解吗？**  
拆解可以；但 **识图卖点与出图质量** 会明显受影响。

**会保存参考长图吗？**  
项目会关联上传记录用于拆解；请勿上传无版权素材。删除项目需 **二次确认**。

**和详情长图分屏创作的区别？**  
分屏创作是 **助手 + 自由屏数 Prompt 计划**；本工具 **必须** 有参考长图且 **落 12 模块**。
