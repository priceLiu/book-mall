# 使用指南 · A+ 详情模块出图

**Tagline：无参考图 · 16 模块 · 9 品类 · 自动子维度**

面向需要按 **亚马逊 A+ / 模块化详情** 节奏批量出图的卖家：不用先找一张参考长图，只要 **产品实拍 + 卖点信息**，系统按 16 个大模块帮你写生图 Prompt 并出图。

**入口**：电商工具箱 → **A+ 详情模块出图**（`/ecom/ai-detail-page`）

---

## 适合谁

- 做 **多品类**（服装、鞋靴、母婴、厨房、户外、珠宝等）详情模块图，希望 **按品类自动匹配子维度**（例如卖点图、场景图该拆几条）。
- 需要 **尺码表 / 参数规格表** 等「数据图」与摄影图混排，且尺码总表希望 **程序生成、不走 AI 瞎编数字**。
- 已有清晰卖点清单，想 **先审 Prompt、再批量出图**，而不是助手一步步聊长图文案。

**不太适合**：必须严格复刻某张淘宝长图版式 → 请用 [参考详情 → 标准套图](./使用指南-参考详情转标准套图.md) 或 [学竞品结构 · 原创详情](./使用指南-学竞品结构原创详情.md)。需要助手带 Step、分屏长图文案 → 请用 [详情长图分屏创作](./使用指南-详情长图分屏创作.md)。

---

## 界面怎么分

| 区域 | 作用 |
| --- | --- |
| **中栏** | 按已开启模块展示出图格子；可预览、单张/批量生成、编辑单条 Prompt |
| **右侧配置** | 产品图、卖点、**产品品类（9 选 1）**、16 模块开关与各模块张数、策划 Prompt 规则、文本/出图模型 |

新建或打开项目后，**只有右侧勾选的模块** 且 **张数大于 0** 的，才会在中栏出现格子（取消勾选后中栏会同步变少）。

## 推荐流程

### 1. 准备素材

- **产品参考图**：建议上传，保证款式、颜色、材质在全套图里一致。
- **卖点与基础信息**：产品名、核心卖点、可选规格说明；可用 **AI 识图** 从多图里抽卖点草稿，再人工确认。
- **选品类**：在右侧选择与你商品最接近的 **9 大品类之一**，影响子维度自动匹配规则（旧项目若显示「通用/服装」别名，以侧栏当前选项为准）。

### 2. 勾选模块与张数

- 系统提供 **16 个 A+ 模块**（首屏主视觉、核心卖点图、使用场景图、多角度图、场景氛围图、商品细节图、尺码/容量图、参数表等）。
- **新建项目默认开启前 6 个模块**（首屏、核心卖点、使用场景、多角度、场景氛围、商品细节），其余可按需打开。
- 某模块张数填 **0** 等同于跳过，不会参与写 Prompt / 出图。

### 3. 生成模块 Prompt（不出图）

- 点击 **「生成模块 Prompt」**：系统按品类匹配子维度、创建点位，调用文本模型写入各格的 `positive_prompt`。
- 此步骤 **只写词，不出图**，方便你先通读、手改，或给单格上传 **本格参考/场景图** 后再 **AI 重写单条 Prompt**。
- 侧栏可粘贴或上传 **策划 Prompt（写词规则）** 文档；平台会在末尾强制追加 JSON 输出格式，请勿删掉尾段契约。

### 4. 尺码表 / 参数表（特殊模块）

- **尺码数据总表图**：在中栏编辑 **真实尺码数据** 后，由系统 **程序化渲染** 成表图（不经文生图模型），避免 AI 编造尺码。
- **详细规格/参数表**：同样支持程序化参数表 + 其余子项走 LLM/出图；无有效数据时，总表类点位会提示先补数据再生成。

### 5. 出图

- 在 **StoryboardModelPickerDialog** 中选择 **出图模型** 与参数（与分镜工作台同一套选择器）。
- 支持单张、按模块、全部已就绪点位；长任务可在 **后台生成 Dock** 里查看进度。
- 项目、模型选择与 Prompt 修改 **会保存**；刷新页面可继续未完成批次。

### 6. 导出与资产

- 成图进入 **我的资产**，来源模块显示为 **A+ 详情模块出图**。
- 自行在平台详情后台按模块上传拼接；本工具 **不** 自动拼一张淘宝长图。

## 使用要点

1. **先 Prompt、后出图**：批量出图前建议至少扫一遍首屏与卖点模块的用词，避免中文乱码进画面（可在 Prompt 里用引号标注允许出现的文案）。
2. **模块开关与张数**：右侧一改，中栏格子数跟着变；避免「以为关了模块还在占屏」的困惑。
3. **与服装 12 模块套图的区别**：A+ 是 16 模块 + 9 品类，无七维逐步问卷；服装模板套图见 [使用指南-服装详情套图（模板）.md](./使用指南-服装详情套图（模板）.md)。

## 常见问题

**必须上传参考详情长图吗？**  
不需要。本工具 tagline 即 **无参考图** 路径。

**和「详情长图分屏创作」差在哪？**  
分屏创作是 **助手 Step + 分屏文案 + Prompt 计划** 出 **一屏一图** 的长图节奏；A+ 是 **固定 16 模块摄影批量化**，无 Step7/Step8 架构助手。

**刷新后项目还在吗？**  
在。未完成的出图任务会继续在后台轮询更新。

**删除项目？**  
在工作台项目菜单中删除，需 **二次确认**；仅删记录与关联配置，已进资产库的图是否另删取决于你在资产库的操作。
