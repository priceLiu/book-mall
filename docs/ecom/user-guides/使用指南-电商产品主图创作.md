# 使用指南 · 电商产品主图创作

**Tagline：卖点策略 + 主图文案与配图**

面向淘宝、京东、抖音等平台的卖家：用 **产品实拍 +（可选）店铺风格参考**，在 **助手 Step** 或 **Prompt 拆解** 两条路径下，先定 **卖点策略与主图分层文案**，再经 **Prompt 计划确认** 逐张出 **商品主图**。做完主图后，可 **一键把策略快照** 带到 [详情长图分屏创作](./使用指南-详情长图分屏创作.md)。

**入口**：电商工具箱 → **电商** → **主图与套图** → **电商产品主图创作**（`/ecom/product-creation`）

---

## 适合谁

- 需要 **主图点击率**：先想清楚人群、痛点、方案，再出 **多张职责不同的主图**（不是一条 Prompt 连出 N 张雷同图）。
- 有 **产品实拍**，希望 AI 帮写 **营销文案层**，但 **生图仍以你确认的 Prompt 列表为准**。
- 计划 **主图 + 详情** 都做：主图项目里填一次 Step0–3，详情入口 **导入快照** 即可。

**不太适合**

- 要 **白底 + 卖点 + 场景** 一套上架图、偏 **套图批量占位** → [AI 商品套图](./使用指南-AI商品套图.md)（见 [主图与套图工具怎么选](./主图与套图工具怎么选.md)）。
- 要 **详情模块 / 长图分屏 / 服装 12 模块** → [详情页工具怎么选](./详情页工具怎么选.md)。

---

## 界面怎么分

| 区域 | 作用 |
| --- | --- |
| **中间工作区** | 上传参考图、选平台、产品信息、选制作方式、**Prompt 计划**、生成、预览、**导出 ZIP** |
| **右侧助手** | 流式文案；**下一步 / 修改当前步**；**不能代替** 中间区直接出图 |

一个项目 **只属于主图入口**，建成后 **不能** 改成详情项目；详情需另建项目并导入策略。

---

## 两种制作方式（出图前汇合）

上传 **产品实拍** 后选一次：

| 方式 | 说明 |
| --- | --- |
| **助手流程（Step by step）** | 助手带 Step0–3 策略 → Step4 **主图分层文案** → Prompt 计划 → 出主图 |
| **产品图 + 参考图 + Prompt** | 自写意图（**main-style 风格参考可选**）→ **识别并拆解** 成 N 条 Prompt → 确认 → 出图 |

**无论哪种，出图前都必须** 在中栏完成 **Prompt 计划** 并点 **「确认计划并开始出图」**。  
走 Prompt 方式时 **不必先选张数**——张数 = 列表里 Prompt 条数。

---

## 推荐流程 · 助手路径

### 1. 策略层 Step0–3

| 步骤 | 内容 |
| --- | --- |
| **Step0 Brief** | 产品名、人群、痛点、优势 |
| **Step1 产品拆解** | 视觉调性、合规红线等 |
| **Step2 营销方案** | 3 个方案选 1 个（**选定后不可换方案**，内容仍可铅笔修改） |
| **Step3 购买理由** | 购买理由矩阵 |

**Step0** 二选一：**AI 拆解产品图**（点选确认）或 **手动输入**（零模型调用）。系统 **不会** 未授权自动读图。

### 2. Step4 · 主图分层文案（主图专属）

助手产出主图各层的文案结构；详情入口 **没有** Step4。

### 3. Prompt 计划

1. 中栏打开 **「主图 · Prompt 计划」**，点 **从文案生成草稿**（或 Prompt 路径的 **识别并拆解**）。
2. 检查每条 **标题 + 完整中文生图指令**；可 **保存修改**。
3. 点 **确认计划并开始出图** → 创建对应数量出图槽位。

**你手改过的 Prompt** 在重新生成草稿时 **默认保留**（按钮旁会提示条数）。

### 4. Step5 · 出主图

- 单张 **生成** / **生成全部** 均使用列表里 **当前** Prompt。
- 缩略图可 **画廊预览**；完成后 **导出交付包（ZIP）**。

### 5. 继续做详情（可选）

主图 **全部出齐** 后，中栏会出现 **「主图已出齐，继续做详情页？」**  
点 **去做详情页** → 新建详情项目并 **快照拷贝** Step0–3、产品图、主图成品（可作 detail-style 参考，≤3 张）→ 跳转详情长图分屏创作。

导入 **不扣费**、**不自动同步** 后续修改；两项目之后各改各的。

---

## 推荐流程 · Prompt 快捷路径

1. 选平台，上传 **product 产品实拍**（必传）；可选 **main-style** 店铺主图风格参考。
2. 填写生图意图 Prompt → **识别并拆解** → 编辑 Prompt 计划 → **确认** → 出图。

---

## 参考图角色（主图）

| 角色 | 用途 |
| --- | --- |
| **product** | 商品实拍，锁定款式/颜色/材质 |
| **main-style** | 主图店铺风格（模特、场景、光线），**可选** |

---

## 使用要点

1. **助手只出文案**；真正出图以 **已确认 Prompt 计划** 为准，未确认就生成会提示先回计划区。
2. **一条 Prompt 一张图**：避免笼统描述 × N 张导致画面雷同。
3. **与 AI 商品套图**：主图偏 **策略 + 分层主图**；套图偏 **结构配置 + 白底/卖点/场景批量**（无 Step 助手）。
4. **计费**：Step0 AI 识图、文案、Prompt 拆解、出图走 Gateway；归属电商工具箱 **e-commerce-toolkit** 月费。

## 常见问题

**必须先做主图才能做详情吗？**  
不必。详情可从零开始；主图只是 **省一次策略填写** 的捷径。

**能在一个项目里又做主图又做详情吗？**  
不能。各建一个项目，用 **导入** 带策略。

**导出包里有什么？**  
文案 + 主图成品 + 参考图分类（以实际 ZIP 内容为准）。

**和「AI 商品套图」区别？**  
见 [主图与套图工具怎么选.md](./主图与套图工具怎么选.md)。
