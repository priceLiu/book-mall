# 使用指南 · 拆图拆视频

**Tagline：图片/视频反推拆解 · 分镜与生图提示词**

面向想 **「看懂别人怎么拍」** 的卖家与内容团队：上传 **一张图** 或 **一段视频**，AI 输出结构化拆解表（不是聊天式多轮助手）。可 **导出交付包**、**分享工作流副本**；视频/图片拆解成功后，还可走 **一键复刻** 用自家模特与产品做 **精细成片**。

**入口**：电商工具箱 → **电商** → **拆解与拉片** → **拆图拆视频**（`/ecom/media-decompose`）

---

## 适合谁

- 看到竞品 **种草短视频 / 带货切片**，想拆成 **分镜表 + 台词 + 卡点 + 可复刻拍摄脚本**。
- 看到一张 **高转化静态图**，想要 **画面要素、中英文生图 Prompt、实拍复刻清单**。
- 拆解结果满意后，希望 **换自家模特图、产品图** 按原片节奏 **重新出分镜图或短视频**（进阶，见下文「一键复刻」）。

**不太适合**

- 需要 **90 秒内专业级 25 维拉片 + 按镜合成整条复刻片** → 请用 [专业拉片](./使用指南-专业拉片.md)（见 [拆解与拉片工具怎么选](./拆解与拉片工具怎么选.md)）。
- 只想写脚本、不做反推 → 种草视频等其它入口。

---

## 和「专业拉片」差在哪（一句话）

| | 拆图拆视频 | 专业拉片 |
| --- | --- | --- |
| 输入 | **图片或视频** 二选一 | **仅视频**（≤90 秒） |
| 分析深度 | 视频：**分镜表 + 叙事/卡点/拍摄脚本**；图片：**要素 + Prompt + 实拍方案** | **逐镜约 25 维**专业字段 + 制作脚本表 |
| 典型用户 | 快速反推、学结构、轻量复刻 | 进阶复刻、按镜生图/生视频、**合成成片** |

## 界面概览

| 区域 | 作用 |
| --- | --- |
| **顶栏** | 新建项目、项目列表、分享工作流、导出 ZIP |
| **素材区** | 上传 / 粘贴 HTTPS 链接 / 从 **我的资产** 选 **1 条** 素材 |
| **指令与模型** | 编辑拆解 Prompt（随图片/视频自动切换默认模板）、选择 **视觉理解模型** |
| **拆解结果** | 结构化表格/卡片（成功时）；失败时显示 **解析错误**，需重试 |
| **底栏引导** | 拆解完成后提示 **一键复刻** |

一个项目 **同时只绑定 1 条素材**（图或视频，不能混绑）。

## 推荐流程 · 只做拆解

### 1. 准备素材

- **本地**：拖拽或选择 jpg/png/webp 等图片，或 mp4 等视频。
- **链接**：粘贴 **公网 HTTPS** 图片/视频地址（须可访问；平台会做安全校验，必要时转存到你的 OSS）。
- **我的资产**：从资产库挑选已有成图/成片。

上传后系统自动识别 **image / video**。

### 2. 检查 Prompt 与模型

- 默认指令已针对 **图片** 或 **视频** 写好（分镜 JSON / 画面要素 JSON）；可按需修改，但请保留模型需要的 **JSON 围栏** 输出格式。
- **图片拆解**：选支持 **看图** 的文本/视觉模型。
- **视频拆解**：必须选带 **视频理解** 能力的模型；平台会对视频做 **语音识别（ASR）** 辅助台词，**全片台词与各镜口播以 ASR 为准回填**，避免模型瞎编对白。

### 3. 点击「拆解」

- 流式返回结果；完成后界面渲染为 **可读表格/区块**（不再是一坨纯 Markdown）。
- 若 JSON 校验失败，会显示 **parseError**，**不会** 把半拉子结构当成功；请调整 Prompt 或换模型后 **重新拆解**。

### 4. 使用结果

**视频成功时**，你通常能看到（以界面为准）：

- 全片风格、色调、运镜摘要，场景/道具准备
- **开场 0–3 秒** 钩子、**完整台词**、模特与服装分析（全片）
- **分镜表**：镜号、时长、景别、运镜、构图、布光、画面内容、动作表情、字幕、口播、音效、BGM、转场等
- **叙事逻辑**、**卡点要点**、**可复刻拍摄脚本**（偏执行层）
- 若模型输出了 **复刻资产清单**（人物/产品/道具/场景），会单独展示，供后续复刻对照

**图片成功时**，你通常能看到：

- **画面要素**（主体、场景、构图、布光、色彩、氛围等）
- **正向 / 负向生图 Prompt**
- **实拍复刻方案**（场地、走位、机位、灯光、道具、参数、分步清单等）

### 5. 保存与导出

- 项目 **自动落库**，刷新后可继续打开（顶栏 **项目列表**）。
- **导出 ZIP**：打包拆解结果与项目信息，便于归档或发给同事。
- **分享工作流**：生成 10 位码或链接；对方领取 **副本** 后可继续看拆解结果、做一键复刻（不含你的 Gateway 密钥）。

## 推荐流程 · 一键复刻（可选）

拆解 **成功且结构化解析通过** 后，结果区或底栏会出现 **「一键复刻」**。

### 阶段 A · 素材采集

1. 点 **一键复刻**，系统按拆解结果生成 **复刻资产方案**（常见为人物 / 产品 / 道具 / 场景等槽位）。
2. 按提示 **上传模特图**、**产品图**（可多张，从本地上传、粘贴、我的资产或模特库导入）；原片无产品也可在复刻阶段 **新增产品槽**。
3. 未上传的槽位可 **沿用原片文字描述**（inherit）；上传的图在脚本里用 **@图片1、@图片2…** 引用（先模特编号，再产品编号）。
4. 填写 **产品卖点/描述**，或使用 **AI 识产品**；必要时 **AI 写模特提示词 / 生成模特参考图**。
5. 点 **「生成复刻脚本」**，系统把拆解分镜与资产方案匹配成可执行的替换脚本。

### 阶段 B · 精细成片

- **视频拆解复刻**：工作区标题为 **「方案② · 精细成片」**，按分镜 **生图 / 生视频**，可改 Prompt 后多次生成，长任务在 **后台生成 Dock** 查看。
- **图片拆解复刻**：工作区为 **「拆图复刻 · 精细成片」**，偏 **分镜静帧 + 出图** 路径（无原视频时间轴）。

复刻过程会关联一个 **种草视频格式的子项目** 用于存储分镜与成片；你在拆图拆视频页内即可完成，无需先单独去开种草项目。

## 使用要点

1. **先拆解、再复刻**：复刻依赖成功 JSON；解析报错时请先解决拆解，不要强行点复刻。
2. **视频模型别选错**：视频素材请选 **支持 video 理解** 的模型，否则无法提交或会失败。
3. **台词可信度**：视频口播以 **ASR + 模型分镜分配** 为准；若 ASR 失败，检查视频是否有人声、是否过吵。
4. **合规**：拆解用于学习结构与脚本；复刻请只用 **有权使用的素材** 与 **自有商品图**。
5. **计费**：拆解与复刻出图/出视频经 **Gateway** 调用，归属电商工具箱月费体系；具体以生成时选择的模型为准。

## 常见问题

**能一次上传多张图吗？**  
不能，一个项目 **一条素材**。多张请分项目或先拼成视频/长图再拆（长图按 **静态图** 路径）。

**拆解会生成成片吗？**  
默认 **只出分析报告**；成片需走 **一键复刻 → 精细成片**。

**和种草视频的关系？**  
交付都用 **围栏 JSON + 表格渲染**，但拆图拆视频 **没有** 种草那套「脚本模式 / 30s 策划助手」；复刻阶段才借用种草项目的 **分镜成片** 能力。

**删除项目？**  
在项目列表或新建流程中删除，需 **二次确认**；已进资产库的成片是否删除在资产库另行操作。

**分享副本对方能看我的原视频吗？**  
副本带项目结构与拆解/复刻进度；媒体 URL 权限以平台复制规则为准，分享前请确认素材可对外协作。
