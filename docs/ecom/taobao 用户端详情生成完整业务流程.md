# AI 服装电商详情页生成工具‑产品功能设计文档

> **已并入 SSOT**：[`docs/ecom/详情页套图.md`](./详情页套图.md)。本文仅作历史底稿。

文档版本：V1.0
编写日期：2026‑09‑13

## 文档概述

### 1.1 目标

本工具面向电商商家，输入产品基础信息、产品参考图，选择品类模板，完成配置后生成淘宝 / 京东等平台服装详情页全套 AI 生图提示词集合；大模型输出强制限定 JSON 格式，AI 仅做摄影描述润色，**不能自行创造业务子维度**，业务拍摄对象严格来源于选中的品类模板候选池。

> 
> 核心架构：固定 12 个顶层详情模块骨架 + 多套品类模板（系统预置 + 用户自定义），模块内子维度由模板管控，大模型只负责 Prompt 润色，输出结构化 JSON 数组，后端再基于数组调用文生图 API 完成图片生成。

### 1.2 范围

- 包含：用户输入信息、基础参数配置、品类模板选择、12 大模块开关与数量配置、模块子维度选择（手动勾选 / 池内随机抽样）、大模型请求入参定义、大模型 JSON 输出约束、数据输出结构、异常校验规则。
- 不包含：后端 API 代码、文生图接口对接、图片后期排版合成、PSD 导出。

### 1.3 术语定义

表格

| 名词 | 说明 |
| --- | --- |
| 顶层 12 大模块 | 详情页固定章节骨架，例如首屏主视觉、细节特写模块；必选模块不可关闭，可选模块支持开关；每个模块拥有`module_id`唯一标识 |
| 品类模板 | 分为**系统预置模板**、**用户自定义模板**；一套模板包含全部 12 个模块，每个模块存储：模块最大阈值`max_num`、子维度候选池`candidate_pool`；模板可复制、编辑、另存为新模板 |
| 子维度 | 模块池内每一项拍摄对象 / 姿势 / 场景；例如细节模块：防风拉链、袖口做工；AI 禁止生成候选池以外子维度 |
| selected_item_list | 用户手动勾选 / 随机抽样后筛选出来的子维度子集，作为传给大模型的输入，大模型只能基于该列表生成提示词 |
| 全局负面 Prompt | 统一固定负面提示词，不交由大模型生成，每张生图请求拼接该负面词 |

## 2 用户完整业务流程

### 2.1 步骤 1：基础信息录入【全局基础配置】

用户操作界面，填写全局商品信息，全部为生成详情页的基础上下文。

1. 上传产品参考图（支持多张，用于后续 AI 参考产品版型、颜色、面料；可选上传，非强制）
2. 基础属性选择
   - 服装品类：下拉选择（户外羽绒服 / 商务衬衫 / 基础休闲 T 恤 / 连衣裙等）
   - 性别：男 / 女 / 中性
   - 目标电商平台：淘宝 (750px) / 京东 (790px) / 亚马逊 / TikTok 跨境（决定后续图片输出尺寸参数）
   - 输出语言：中文 / 英文（控制生成提示词描述语言）
3. 商品基础卖点输入（文本框）
> 
> 示例：防风防水、90 白鸭绒填充、抗皱免烫、透气亲肤等；多条卖点可用换行分隔。
4. 商品简要描述：简短文本，例如「红色男士户外加厚羽绒服」

> 
> 完成本步骤之后，系统根据用户选择的【服装品类】自动加载对应**系统预置品类模板**；用户也可以手动切换到自己保存的【用户自定义模板】。

### 2.2 步骤 2：12 个顶层大模块配置

系统加载选中品类模板，读取模板内部每个模块：`module_id`、模块名称、`max_num`最大图片阈值、`candidate_pool`子维度候选池。

UI 展示全部 12 个模块列表：

- 属性标记：`必选` / `可选`
- 开关：必选模块开关置灰不可关闭；可选模块用户可关闭（关闭 = 生成数量置 0）
- 输入框：填写本模块希望生成图片张数 N
> 
> 校验规则：
> 
> 
> 1. 必选模块 N 取值范围：`1 ≤ N ≤ max_num`，禁止填 0
> 2. 可选模块 N 取值范围：`0 ≤ N ≤ max_num`，0 代表关闭该模块
> 3. N 大于 max_num，前端直接拦截提示：`该模块最大允许生成{max_num}张，请修改数量`

### 2.3 步骤 3：模块内部子维度选择（针对已经开启的模块）

针对每一个 N>0 的模块，提供两种模式，用户二选一：

#### 模式 A：手动勾选子维度

UI 展示当前模板该模块下完整`candidate_pool`候选列表，用户手动勾选 N 个子维度，生成`selected_item_list`子集。

> 
> 勾选数量不足 / 超过 N 时前端提示校验。

#### 模式 B：池内随机抽样

用户不手动勾选，点击随机选取；系统在本模块`candidate_pool`池子内随机抽取 N 项，生成`selected_item_list`。

> 
> 每一个开启的模块都会产出独立的`selected_item_list`。

### 2.4 步骤 4：确认配置，提交任务

用户确认全部模块的：开关状态、生成张数 N、选中子维度集合`selected_item_list`。
系统收集全部全局入参，准备批量调用大模型。

> 
> 注意：**每个开启的模块独立发起一次大模型请求**，例如开启模块 3、模块 4，则调用 2 次大模型，分别生成各自模块的 Prompt 数组。

### 2.5 步骤 5：调用大模型，强制要求返回 JSON 格式

> 
> 重点约束：不允许返回 markdown、解释文字、自然语言；输出必须严格 JSON 数组。

#### 大模型 System 系统提示词（固定不变）

```
你的任务：根据传入参数生成N条电商服装生图正向提示词。
硬性规则：
1. 只允许使用入参传入的【selected_item_list】里面的项目，严禁自行创造列表以外的拍摄部位、姿势、场景。每一条prompt对应列表中的其中一项。
2. 你的工作只做摄影层面润色：优化构图、光影、微距、景深、画面质感描述，不修改核心拍摄主体。
3. 强制统一画面风格约束：电商商业摄影，写实照片，8K超清，影棚柔和布光，主体清晰对焦，简洁纯色背景，无水印，画面不生成任何文字。
4. 禁止输出3D渲染、插画、手绘、卡通、二次元风格描述。
5. 输出格式：严格返回JSON字符串数组，数组每一项为完整正向生图提示词。
6. 禁止输出任何解释、说明、markdown、注释，只输出JSON数组。

入参变量：
商品描述：{{product_desc}}
商品卖点：{{sell_points}}
目标平台：{{platform}}
输出语言：{{lang}}
当前模块名称：{{module_name}}
需要生成条数N：{{N}}
选中子维度列表selected_item_list：{{selected_item_list}}
```

##### ❌禁止行为

1. 返回文字说明、markdown、```json 代码块标记；
2. 新增 selected_item_list 以外拍摄主体；
3. 返回条数不等于 N。

#### 返回结果校验逻辑

1. 判断是否合法 JSON；解析失败 → 触发重试机制。
2. 判断数组长度是否等于入参 N；不相等 → 触发重试。
3. 简单内容校验：每一条 prompt 必须包含 selected_item_list 内对应子维度关键词，防止 AI 篡改主体。

> 
> 校验失败则重新请求大模型；重试最大 3 次，超过返回任务异常。

### 2.6 步骤 6 组装完整详情页提示词集合

当多个模块分别调用完成，每个模块得到一组正向 Prompt 数组。
系统把所有模块结果做结构化组装，输出完整详情页 Prompt 集合文档。

每条正向 Prompt 统一拼接**全局固定负面 Prompt**，用于后续调用文生图 API。

> 
> 全局固定负面 Prompt

```
水印，文字，乱码，变形，肢体畸形，手指残缺，人脸扭曲，画面闪烁，模糊，噪点过高，曝光过度，死黑，色差严重，多余杂物，背景杂乱，3D卡通，手绘，插画，油画，畸形服装，衣服褶皱崩坏
```

### 2.7 步骤 7 下游输出

输出两类产物：

1. 结构化 JSON：完整详情页生成任务包，包含全部模块信息、每条图片正向 prompt、全局负面 prompt、平台尺寸参数；可供后端直接遍历调用文生图 API。
2. 可读预览文档：给商家预览，分模块展示每张图的提示词内容。

## 4 校验与异常处理规则

1. 模块数量校验：必选模块`enable`不允许 false；开启模块`generate_count`不能大于模板内该模块`max_num`。
2. 子维度校验：`selected_item_list`内所有元素必须来源于该模块模板`candidate_pool`，前端拦截非法值。
3. 大模型返回校验：JSON 合法性、数组长度匹配 N、关键词主体校验；失败最多重试 3 次，超过返回任务失败。
4. 全局总张数校验：所有开启模块 generate_count 总和设置全局上限（例如 44 张），防止一次性任务过大。

## 5 模板扩展能力说明

1. 系统预置至少 3 套模板：户外外套羽绒服模板、商务衬衫模板、基础休闲 T 恤模板。
2. 用户操作：复制任意模板 → 编辑每个模块的`candidate_pool`增删子维度、修改`max_num` → 保存为用户私有自定义模板。
3. 底层 12 个`module_id`固定，**不允许新增、删除顶层模块**，模板仅修改模块内部池子数据。

## 6 非功能约束

1. 大模型永远不允许自行创造子维度拍摄对象，拍摄主体严格来自传入`selected_item_list`；AI 只做摄影文案润色。
2. 负面提示词全局固定，不交给大模型生成。
3. 大模型输出强制 JSON 数组，禁止附带多余文本。
