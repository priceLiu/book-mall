# 附加使用说明（适配你的 AI 分层海报 / 详情模板项目）

1. 生成策略：**图片和文字分开生成**，所有 prompt 都不带文字，图片生成完成后，用图层编辑 API 叠加文案，避免 AI 生成文字乱码；完美适配 Seedream 图层拆分能力
2. 可替换项：如果你要换成亚洲模特版本，直接在 prompt 里把「白人男模」替换成「东亚男性模特」即可，其余画面描述不变
3. 格式适配：全部为竖版 9:16，淘宝移动端详情原生比例
4. 调用方式：可以把单条 prompt 直接丢进 API，批量循环生成整套详情素材
