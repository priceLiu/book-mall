统一积分 v2：现网扣分以渠道净成本 C 为起点，经系数 M 得到人民币挂牌价 P，再按锚定 ¥0.03 换成人人相同的积分 U₀。套餐档位只影响购分单价 ppc，不改变扣多少分。厂商挂牌价与渠道折扣由财务在模型成本页自行填写。

> **版本**：2026-09-30  
> **范围**：平台代付（会员积分）生图 / 生视频扣分与毛利测算  
> **代码**：`book-mall/lib/pricing/credit-pricing-formulas.ts`、`credit-pricing-engine.ts`、`model-margin-policy.ts`、`gateway-credit-settlement.ts`  
> **后台**：模型成本 `/admin/model-cost`（主站跳转 finance-web）；毛利测算 `/admin/finance/margin-projection`

---

## 1. 一句话

**C 是净成本，不是积分。** 厂商官网挂牌价减去你们填的渠道折扣，得到 C；系统用 M 加成得到 P（元）；再 `P ÷ 0.03` 得到积分 U₀。用户生成时扣 `U₀ × 张数或秒数`。

---

## 2. 公式（现网实际扣分）

```
挂牌 listCost     = 厂商官网价（财务录入 ModelCostProfile.listCostYuan）
折扣 discountRate = 渠道折 0～1（财务自行填写，如 0.05 = 5 折省 / 九五折）
C                 = listCost × (1 − discountRate)     // 净成本
M                 = 加价系数（图/视频默认 1.5；文本默认 1.0；单模型可改）
P                 = C × M                             // 对用户人民币挂牌价
U₀                = round2(P ÷ 0.03)                  // 积分/单位，人人相同
扣分              = U₀ × units                        // 张数，或视频秒数（默认封顶 15s）
```

套餐实收与积分的关系：

```
ppc        = 套餐实收 ÷ 月积分池
月积分池   = 含席位数 × 月积分     // 个人席位=1；团队月积分=每席积分
用户实收   = 扣分 × ppc            // 档位差只在这里
厂商成本   = 用量 × C              // 核算用净成本
整月毛利   = 套餐实收 − 厂商成本   // 剩余未消耗积分仍算已收款
```

### 2.1 容易混淆的两点

1. **P 不是积分。** P 是加成后的人民币价。积分是 U₀。
2. **现网不是直接拿官网挂牌价换积分。** 换算起点是 C。折扣为 0 时，C 才等于挂牌价。

### 2.2 用量 units

| 类型 | units | 说明 |
|---|---|---|
| 生图 `PER_IMAGE` | 张数，至少 1 | GPT Image 2.0 等 |
| 视频 `PER_SEC` | 实际秒数，缺省或超长按封顶（默认 15s） | Wan 3.0 / HappyHorse 1.1 |
| 万相 3.0 | 输入秒 + 输出秒；都缺则按 15 | 带参考视频时条数会变少 |

同一模型、同一用量，标准档和至尊档 **扣分相同**。

## 3. 符号对照

| 符号 | 含义 | 谁定 |
|---|---|---|
| 挂牌 listCost | 厂商官网价 | 财务录入 |
| 折扣 discountRate | 渠道折 | 财务自行填写 |
| **C** | 净成本 | 算出来 |
| **M** | 加价系数 | 系统默认，可改 |
| **P** | 对用户挂牌价（元） | 算出来 |
| **U₀** | 积分/单位 | 算出来 |
| 锚定 0.03 | 1 积分对应 ¥0.03 | 全站配置，很少改 |
| ppc | 该档买分单价 | 套餐价 ÷ 积分池 |

## 4. 哪些可以改

日常调价主要是两处：

1. **厂商折扣**（模型成本页，自己填）
2. **M**（图/视频默认 1.5，文本默认 1.0；单模型成本档的 `marginM` 也可改）

另外两个一般少动：

- **厂商挂牌价**：也是你们填的，厂商调价时要改
- **锚定 0.03**：积分报价配置里的全站汇率

套餐四档价格和月积分 **不改变 U₀**，只改变 ppc 和「同样积分能买到的毛利空间」。

---

## 5. C 在哪里看

后台文案写的是 **「净成本」**，就是 C。

| 入口 | 看到什么 |
|---|---|
| 财务后台 **定价与模型 → 模型成本**（主站菜单「模型成本与折扣」） | 挂牌成本、折扣、**净成本 C**；编辑时有净成本预览 |
| **模型运营中心** | 候选列「净成本」 |
| 路径 | finance-web `/admin/model-cost`；主站 `/admin/finance/model-cost` 会跳转 |

公式：`C = 挂牌 × (1 − 折扣)`。例如挂牌 ¥0.25、折扣 5%，C = ¥0.2375。

## 6. 数值例子（按现网：先折后加成）

假设 M=1.5、锚定 ¥0.03。

| 模型 | 挂牌 | 折扣 | C | P | U₀ | 15s / 1 张扣分 |
|---|---:|---:|---:|---:|---:|---:|
| GPT Image 2.0 | 0.25 元/张 | 5% | 0.2375 | 0.3563 | 11.87 | 11.87 分/张 |
| Wan 3.0 720P | 0.60 元/秒 | 10% | 0.54 | 0.81 | 27 | 405 分/15s |
| HappyHorse 1.1 720P | 0.90 元/秒 | 10% | 0.81 | 1.215 | 40.5 | 607.5 分/15s |

若某模型折扣填 0，则 C=挂牌，U₀ 会高于上表。

## 7. 毛利测算页（与现网的差别）

主站 **管理后台 → 财务控制台 → 毛利测算**：`/admin/finance/margin-projection`

该页与现网 **同一口径**（公式 v4）：挂牌、折扣、净成本 C、M 取模型成本页生效中的成本档；一次扣分 U₀ 优先取积分报价页 **已发布** 的值（= 现网实扣）。若改了折扣或 M 但未重新发布，U₀ 列会提示「按当前成本档应为 …，待重新发布」。

读表：

1. 先看套餐实收：用户这个月付给平台多少钱。
2. 再看「能生成」：月积分 **只打这一个模型** 时最多多少张/条。三种模型是三套互斥情景，不要加总。
3. 厂商成本 = 条数 × C × units。
4. 整月毛利 = 套餐实收 − 厂商成本。一定有数字；剩积分没打完也算钱已收。

举例（现网折扣均为 0 时）：个人标准档 ¥69、860 分，只打 Wan 3.0 15 秒。C = ¥0.60/秒，一条净成本 ¥9、扣 450 分，能打 1 条，厂商成本 ¥9，整月毛利 ¥60。若折扣填 10%，则 C = ¥0.54，一条扣 405 分、净成本 ¥8.1。

此前聊天里宽表把「档位」和「实收」合成一格，列对错了，最后一列毛利看起来是空的。那不是没毛利，是表头错位。测算页已改成每个模型一张表。

## 8. 订阅档位与积分包

豪华下架。月付四档每分单价：**0.08 / 0.072 / 0.058 / 0.04**。

个人月付：¥69 / 860，¥269 / 3730，¥699 / 12050，¥1199 / 30000。

个人年付：价 = 月价 × 10；积分 = 月积分 × 12。

年付发放：套餐表 `monthlyCredits` 填全年总额；会员服务 365 天内每 31 天发一期 = 全年 ÷ 12（共 12 期）。同档在服务期内续费只顺延服务期，不立即重发，下一期仍按原 31 天周期发放；首购、过期后续费、换档立即发放。

团队每席与个人同档 ppc，席位价不跟个人同倍率涨。每席月积分：2490 / 9570 / 20670 / 50000。三席月付总价仍是 597 / 2067 / 3597 / 5997。

积分购买包：¥80 / 1000，¥163 / 2500，¥300 / 6000（ppc 约 0.08 / 0.065 / 0.05，不低于至尊 0.04）。
