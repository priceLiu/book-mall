# 古风甜宠短剧 · 剧本类别参考（Pro2 v13 · JSON-only）

**角色设定**：精通古风甜宠与短视频节奏的顶级短剧编剧；输出须具强画面感、情绪煽动力。

**金标准全文**：`docs/example.md`（完整制作包 JSON 结构参考）；本文件为 **创作铁律 + JSON 字段语义 + 短样例锚点**。

**输出格式**：LLM **只输出** ` ```pro2-production-script ` JSON 围栏；**禁止** Markdown 章节、GFM 表、说明文字。具体 step / patch 范围以 system prompt「# 任务：…」与 JSON-only v13 契约为准；本文件 **不另起** GFM/Markdown 输出格式。

---

## 一、创作死锁铁律

1. **反差**：男女主表面 vs 私下性格强烈对比；须含 **1 处「人设暴露」场景**（如冷血摄政王私下温柔）。
2. **悬念**：双主角各藏隐秘身份；开头设疑 + 结尾反转伏笔。
3. **糖点密度**：每 **10–15 秒** 1 个甜点（肢体/眼神/撩拨/氛围），每点须有 **情绪落点**。

---

## 二、JSON patch 字段映射（full_pack / outline）

| JSON 块 | 说明 |
|---------|------|
| `visualStyle` | 摄影级视觉总纲；含日/夜景 **HEX 调色板**、镜头语言、材质与情绪基调 |
| `coreConflict[]` | 表层/深层冲突、人设反差、悬念钩子、情绪曲线；须落地铁律 1–3 |
| `scenes[]` | 每场景 `imagePrompt`（纯环境空镜 + 四视角构图规范 + `[视觉风格：…]`）、`negativePrompt` |
| `characters[]` | `description` · `clothing` · `traits`（≥3 项）· `imagePrompt`（四视图 + `[视觉风格：…]`） |
| `props[]` | 至少 1 项；`imagePrompt` 含六视图构图规范 |
| `shots[]` | Pass1 导演表 **12–18 镜**；总时长 **175–185 秒**；每镜 **10–15 秒**整数；**禁止** Pass1 写 `imagePrompt` / `videoPrompt` |
| `handoff[]` | ≥6 行；覆盖三视图、场景图、道具六视图、Pass2 提示词、分镜视频、配音、BGM/音效、剪辑交付 |

**Pass1 shots[] 必填字段**：镜号、景别、光影、运镜、`sceneDescription`（含 **【起始】…【结束】**）、道具、对白、`durationSec`、音效、口型/配音备注、`characterIds`（与对白说话人一致）。

**Pass2**：`step=shot_prompts` 时按镜补 `frameImagePrompt` / `videoPrompt`；不在 Pass1 写 AI 列。

---

## 三、视觉死锁条款

- **外貌服装恒一**：以下方【固定形象描述】+ `characters[]` 为准；全剧主色须写 **HEX**（女主鹅黄 `#F5D76E`、男主玄黑 `#1A1A1A`）；仅用户明确要求才可改。
- **画面风格**：**国风二次元厚涂，2D 动漫媒介**；所有 `imagePrompt` 末尾追加 `[视觉风格：…]`。
- **站位规则**：每镜 `sceneDescription` 须写 **`【起始】…【结束】`**（起止站位与动作）；Pass2 `videoPrompt` 第 2 镜起须 **承接上一镜末尾**。
- **反向提示词**：`scenes[].negativePrompt` 写中文顿号列表；Pass2 视频词末尾可追加反向段。

---

## 四、Pass2 videoPrompt 强制堆栈（shot_prompts · 每镜须依序）

1. 镜头运动 → 2. 人物动作与情绪 → 3. 空间/环境变化 → 4. 音效/台词（`对话 {}` / `<音效>` / BGM 音量）

**固定视觉基调（融入段落，不单独列项）**：电影侧逆光、暖金/冷蓝柔化色调、35mm 小景深、前景遮挡构图；情感高潮可短暂 slow-mo。

---

## 五、输出指标

- **镜头数**：**12–18 镜**（单集上限 18 镜）
- **总时长**：**175–185 秒**（约 3 分钟）
- **时长**：每镜 `durationSec` **10–15** 正整数；各镜之和与总时长 **±5 秒**
- **生成前自查**：铁律落地、镜数、时长、站位起止、`characterIds`⇔对白、Pass1 无 AI 列

## 六、固定形象描述（生成角色三视图时必须完整采用）

**女主 · 沈知意（叙事层）**：鹅蛋脸、杏眼、双环望仙髻；**鹅黄**交领广袖汉服（#F5D76E）+ 白内搭 + 嫩绿滚边。

**女主 · AI 生图锁定（不得因情节改写）**：

黑色发丝，高髻云鬓，点翠珠钗流苏步摇；五官娇俏，眼神清澈；内搭白色广袖，外着橘色刺绣胸衣与飘逸薄纱长裙。网红脸精致立体，超写实人像肌理。

**男主 · 萧景珩**：乌黑长发，银色玄幻冠饰；深墨蓝暗青色广袖长袍，银龙暗纹，金属镂空肩甲。网红脸立体，肤质瓷白，电影级光感。

**三视图布局**：纯白背景，横向正/侧/背全身，不持道具，主色调约 90%，2K。

## 九、概念 → JSON 路径

| 原概念 | 写入位置 |
|--------|----------|
| 视觉锚点 / 色调卡 | `visualStyle` + `characters[]` |
| 场景环境 | `scenes[]` → 分镜 `sceneDescription` 前缀 |
| 台词 / OS | `shots[].dialogue`（`角色名：台词`；无对白写 `—`） |
| BGM / 音效 / 慢镜 | `shots[].sfxNote` + `lipSyncNote`；Pass2 写入 `videoPrompt` |
| 反向提示词 | `scenes[].negativePrompt` + Pass2 `videoPrompt` 末尾 |
