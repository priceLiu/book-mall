> **关联**：[Pro2剧本结构化.md](./Pro2剧本结构化.md) · [25-canvas-pro2-script-structured-output.md](../book-mall/doc/product/25-canvas-pro2-script-structured-output.md)

## 1. 产品目标

将「资产出图 → 分镜图 → 分镜视频 → 音画同步」从分散的 Hub 顶栏按钮，收敛为 **全屏两步向导**：

1. **Step 1 · 资产制作**：角色 / 场景 / 道具 **只做出图**（参考图 + 提示词 + 模型 + 生成挂位）。
2. **Step 2 · 分镜制作**：分镜脚本 + `@` 资产 → 分镜图 prompt → 生图 → 视频 prompt → 生视频 → **此时**再挂对白 / TTS / 口型（音画同步）。

**Step 2 · 实体关联（Pass1 reconcile）**

| 机制 | 说明 |
|------|------|
| 结构化字段 | 每镜 `sceneId` / `characterIds` / `propIds` 与资产辞典 ID 对齐 |
| Pass1 落库 | LLM JSON apply 后自动 `reconcileProductionScriptEntityLinks`（正文 / 对白 / `@` 推断补全） |
| 向导分镜表 | 展示 **场景** 列；画面描述 / 光影 / 运镜 / 对白按 **本镜** 关联实体绿色高亮（道具列不高亮） |
| 编辑保存 | `@` 引用与场景下拉 / 道具 `@` 保存时回写 ID；打开向导时对历史数据 reconcile 一次 |
| Pass2 | `expandWizardMentionsForPrompt` 将 `@<wiz-*>` 展开为资产辞典摘要 |

旧流程（`pro2-script-hub-toolbar` 三按钮 + 分散 picker）在 Hub 已有结构化制作包后 **停用**（代码保留，Hub 级门控）。

## 3. 音画策略（已定）

**前期专注出图；音频在做视频时再加入，由用户调整；数据结构先行预留。**

| 来源 | 字段 / 槽位 | Step 1 UI | Step 2 UI |
|------|-------------|-----------|-----------|
| `productionScript.shots[]` | `dialogue`, `audioNote`, `sfxNote` | 不展示 | 镜卡片可改 + 按镜 TTS |
| `productionScript.characters[]` | 可选 `voiceRefNote` | 可选小字段 | 首次 TTS 可绑定声线 |
| `productionScript.audios[]` | SFX 元数据 | 不展示 | 视频阶段引用 |
| 视频列 row | `ttsRuntime`, `videoRuntime` | 空槽预建（`idle`） | 生成与调整 |

对白方案 **A**：对白留在分镜表；Step 1 **不做**按句配音；Step 2 按镜 TTS（`PRO2_TTS_MODEL_KEYS` + Gateway）。

## 5. 拓扑预搭建 · sync vs mount

| 阶段 | 时机 | 行为 |
|------|------|------|
| **sync** | Pass1 写入 `productionScript` 后 | 仅 Hub 内嵌 rows、`scriptStudioVideoRows`（含 `ttsRuntime` 空槽）、`productionWizardMode`；**不** spawn 画布节点 |
| **mount** | 向导内用户点 **「放入画布」** | spawn 角色/分镜/视频/道具/音效列；**不** spawn 旧「场景设计」列（`story-pro2-scene`）；`sceneRows` 挂 Hub |

若画布上已有遗留「场景设计」列，mount 时会迁移行到 Hub 并移除该节点（`migratePro2SceneColumnOffCanvas`）。

## 9. 验收（首步 · PW-101/104）

1. 新建 **影视专业版 2.0** 项目，添加/使用脚本 Hub，生成分镜制作包（`productionScript.shots`）。
2. Hub 顶栏出现 **「剧本制作」**，旧三按钮（三视图/场景图/生成分镜）隐藏。
3. Pass1 后 Hub 内已有 rows（含 `ttsRuntime` 空槽），**画布不自动**出现分镜/视频等列。
4. 向导内点 **「放入画布」** 后才 spawn 列节点；**不出现**旧「场景设计」列。
5. 向导 Step 1/2 可预览资产与分镜列表。
