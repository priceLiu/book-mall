## 1. 需求

在电商工具箱 **微剧故事版** 内，按 [3C数码.md](./3C数码.md) 接入 **3C数码专业版** 全流程：

| 能力 | 说明 |
|------|------|
| 入口 | 新建电商专业版项目 → 上传产品图 → 选「3C 数码」 |
| 七维 | 产品大类 + 产品细项（可搜索级联）+ 设计语言 + 档次 + 使用场景 + 平台 + 语言 |
| 卖点 | 手动输入或 AI 自动生成，S01–S0N 分层锁定 |
| 口播 | 6 套（痛点爆破/硬核参数/场景种草/颜值种草/性价比说服/使用体验），用户选 1 套 |
| 分镜 | A–E 五版六镜（开箱惊艳/功能演示/场景沉浸/实测挑战/设计美学），每镜绑定卖点 ID + 12.3 验收清单 |
| 运营包 | 标题/封面词/标签/正文等 |
| 成片 | 路径 B：分镜图 → 单镜视频 → 云端合并 |
| 交互 | 右侧分步对话、左侧实时预览（与服装/包包专业版一致） |
| 角色图 | **可选**（不强制；产品演示为主） |

## 2. 方案 · Pro Vertical 插件

### 2.1 架构

- **引擎（共享）**：阶段机、JSON 解析/合并、Markdown 渲染、助手 Chat 分轨、分镜表同步、生图/生视频
- **配置（按品类）**：`VerticalConfig` — 七维枚举、六镜职能、A–E 版标题、LLM 规则片段、生图 category

已注册 vertical：

| vertical | schema | 状态 |
|----------|--------|------|
| `fashion_apparel` | `fashion-v4`（legacy）/ `pro-v1` | 现网不变 |
| `bags` | `pro-v1` | 已上线 |
| `digital_3c` | `pro-v1` | **已接入** |

### 2.2 交付物

- **JSON 真源**：`meta.deliverable`，`schemaVersion: "pro-v1"`, `vertical: "digital_3c"`
- **Panel 字段**：统一 `productFocus`（UI 显示「产品展示重点」）
- **Workflow**：`proPhase`（与包包相同）

### 2.3 七维 UI

- 产品大类 / 产品细项：**可搜索下拉**（细项随大类自动筛选）
- 其余维度：chip 或 freeText

## 6. 验收清单（3C-110）
