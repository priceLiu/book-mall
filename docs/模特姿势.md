## 内置姿势知识库（全部内嵌，生成时随机抽取组合）
以下所有姿势动作元素均已内置。生成时需从不同类别中随机抽取基础架构，并进行风格化微调，确保每次输出不重复且覆盖多种类型。

### 姿势库 A：基础站姿类
- 正面直立，双腿微微分开，重心居中，双手自然下垂或拎包。
- 正面直立，双腿并拢，双手插兜（裙兜/裤兜），肩部放松。
- 正面站立，双腿一前一后错开，单手拎包，另一手抬起触碰头发/额头。
- 站立，重心落在后腿，前腿向前交叉伸出，单臂向外张开，手掌朝上。
- 笔直站立，双腿微微分开，双手置于身前（拎包或自然交叠）。
- 正面全身站立，双腿并拢直立，双手插在裙兜/裤兜里，双肩放松，头部微低。

### 姿势库 B：行走与动态类
- 向前行走，右腿迈出左腿在后，左手搭衣襟，右手拎包下垂，头微低，长发遮挡部分脸部。
- 侧身行走，身体朝向左前方，左脚前迈，右手放身后包位，低头看斜下方。
- 行走姿态，右腿迈出左腿在后，双臂向身体两侧舒展张开，手掌朝下，低头看地面。
- 侧身向前行走，身体朝左，左腿前迈，双手环抱胸前小包，侧脸回眸看向镜头。
- 模特向画面左前方行走，右腿向前迈出，左腿在后，左手随意搭在衣襟处，右手自然下垂拎包，身体微微侧转。

### 姿势库 C：侧身与扭转类

- 三分之二侧面，双手插兜或自然垂放，头部转回看向镜头，目光自信。
- 侧身站立，身体朝向左侧，脸回转向镜头，单腿前迈，单手插兜，另一手拎包垂于身后。
- 身体旋转 40° 左转为三分之二侧面，右手放腰部，左臂放松，头部转回看向镜头，目光自信。
- 侧身站立，双腿一前一后错开，右手拎包垂于身侧，左臂抬起弯曲，手抬到额头/头发位置。

当用户提出“生成姿势”或类似需求时，按以下 6 个步骤执行：

### 第一步：收集模特信息（三种模式，三选一）
以自然对话方式询问用户，如何确定模特（人物）形象：
- **模式 A（上传参考图）**：用户上传一张模特参考图，后续将严格沿用该图中的人物身份和服装细节。
- **模式 B（AI 推荐）**：根据用户的行业和风格，AI 主动生成 2~3 种虚拟模特描述供用户选择（例如：高挑冷艳御姐风 / 甜美邻家少女风 / 中性干练职场风等，需附带面部特征和身形描述）。
- **模式 C（用户手写描述）**：用户直接输入文字描述模特的外貌、身材、着装风格等。

### 第二步：收集场景/背景信息（三种模式，三选一）

- **模式 A（上传参考图）**：用户上传一张背景参考图，后续将严格沿用该背景。

#### 平台动态倾向：
- **小红书 / Instagram**：生活感强，动作适中，加入抓拍感（低头、撩发、互动感）。

### 第六步：随机组合、去重并输出
- 从内置姿势库（A~L）中随机抽取 N 个不同的基础架构（N = 用户指定数量，默认 6）。
- **必须覆盖至少 4 种不同的大类**（如：A站姿 + B行走 + D蹲姿 + E背面 / H户外 + J商务 + K红毯等），确保呈现丰富性。
- 依据风格映射表和平台倾向，对每个姿势进行个性化微调，确保 N 个姿势在动作上有明显区分（不重复、不雷同）。
- 结合模特、场景、道具三种信息，最终形成完整的姿势描述。
