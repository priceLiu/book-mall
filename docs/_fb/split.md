# 详情长图分屏创作 · 使用指南（助手带 Step，一屏一图出详情长图）

> 这篇是写给**已经注册好、登录进去就能用**的你看的。不讲技术，只讲「点哪里、传什么、会出什么」。

---

## 这个功能是干嘛的？

一句话：你想**自己掌控详情叙事结构**、按**一屏一图**产出详情长图素材，就用它。它和「电商产品主图创作」共用同一套壳：中间工作区出图 + 右侧助手逐步推进。

> 侧栏名字叫「**详情长图分屏创作**」，在「电商工具箱」下，认这个名字就能找到。

---

## 开工前：准备这两样

1. **进对地方**：电商工具箱 → **详情长图分屏创作**。
2. **给素材**：上传**产品图**；可选上传 **detail-style 详情长图参考**，或自写生图意图。

## 第一步：选制作方式（出图前汇合）

上传产品图后选一次：

- **助手流程（Step by step）**：助手带 Step0–3 → **Step7 详情架构** → **Step8 分屏文案** → Prompt 计划 → 出图。
- **产品图 + 参考图 + Prompt**：自写意图（参考图可选）→ **识别并拆解**成 N 条 Prompt → 确认 → 出图。

> 无论哪种，**出图前都必须在中栏完成 Prompt 计划并点「确认计划并开始出图」**。助手只产出文案，不以聊天记录为准出图。

---

## 第二步：把策略定下来

- 若已用「电商产品主图创作」出齐主图，中栏卡片会问「主图已出齐，继续做详情页？」；或在详情入口顶部点 **「从主图项目导入」**（勾选是否带产品图、是否用主图成品作风格参考）。导入是**快照拷贝**，之后两项目互不影响。
- Step0 可选 **AI 拆解产品图**或**手动输入**（手动不产生模型调用）；营销方案选定后不可换方案，但内容仍可在中栏铅笔改。

---

## 第三步：写 Prompt 计划（核心）

1. **产品理解**：名称、品类、卖点等（可改）。
2. **生图 Prompt 列表**：每条 = 一屏的职责与构图。
3. **识别并拆解 / 从文案生成草稿**会回到草稿态；你**手动改过的条目**重拆时**默认保留**。
4. **确认计划并开始出图**后，才创建对应数量的出图槽位。

---

## 第四步：出图 + 导出

- 单张「生成」与「生成全部」都用列表里**当前**的 Prompt 文本。
- **导出交付包（ZIP）**：文案 + 详情图 + 参考图分类；全部完成可跳转**去做视频**（若已开通种草视频等入口）。

---

## 几个贴心小贴士

- 先确认 Prompt 是为保证每一屏有独立构图与卖点分工，而不是同一句描述重复出多张。
- 和 A+ 不同：分屏创作是**自由屏数 + 助手架构**；A+ 是固定 16 模块。
- 和「参考详情 → 标准套图」不同：分屏创作**不强制** 12 模块，也不做 Vision 长图拆解。
- 导入策略**不扣费**；会调 AI 的环节：Step0 识图、各步文案、Prompt 拆解、出图（选手动 Step0 可跳过识图）。
