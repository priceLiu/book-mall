# 使用指南 · 电商口播故事版

**侧栏名称：电商口播故事版**（`/ecom/storyboard/micro-drama`）  
**新建项目**：默认 **电商专业版**（`proMode`）。工作台 **顶栏标题** 统一为「电商口播故事版」，不按品类显示「××专业版」。

面向抖音 / 小红书 / 淘宝等：**上传产品图 → 选大类品类 → 逐步填参数 → 选产出线 → 卖点与脚本 → 分镜出图 / 成片**。

**入口**：左侧 **营销** → **电商口播故事版**

---

## 整体顺序（不要跳步）

![流程图](@./story.png)

1. **必须先有产品图**，助手才会出现 **大类品类** 卡片（未传图只会提示先上传）。  
2. **品类选定后** 再进入该品类的 **参数采集**（步数见下表）。  
3. **参数采集完成** 后选 **产出模式**（标准口播线 / 故事剧场线）。  
4. 两条线 **共用卖点步骤**，之后 **完全不同**（见下文分支）。

---

## 第一步：九大类品类怎么选

上传产品图后，助手会出现 **9 张品类卡片**（文案形如「选择品类·服装」）。**只能选一次**；选错请 **新建项目** 重选。

| 助手显示名称 | 说明（卡片副文案摘要） | 角色/模特参考图 |
| --- | --- | --- |
| **服装** | 七维参数 · 卖点口播 · 六镜分镜 · 服装展示 | **必填**（可 AI 生成或上传） |
| **包包** | 七维参数 · 卖点口播 · 六镜分镜 · 包袋背携 | **必填** |
| **3C 数码** | 七维参数 · 卖点口播 · 六镜分镜 · 功能演示 | **可选**（产品演示为主时可跳过模特步） |
| **鞋子** | 上脚走步 · 鞋底工艺 · 六镜分镜 | **必填** |
| **珠宝** | 佩戴微距 · 工艺细节 · 六镜分镜 | **可选** |
| **户外用品** | 功能实操 · 户外场景 · 六镜分镜 | **可选** |
| **家居服** | 居家亲肤 · 上身治愈 · 六镜分镜 | **必填** |
| **厨房用品** | 厨具实操 · 居家厨房 · 六镜分镜 | **可选** |
| **母婴用品** | 安全材质 · 实操演示 · 六镜分镜 | **可选** |

九类均已 **available: true**（无「即将上线」灰显项）。故事剧场选题与 Prompt 也按这 **9 大品类** 对齐。

## 第二步：品类参数采集（「七维 / 八维」）

选定大类后，助手 **逐步出卡片**（或搜索框），一维一维确认。不同品类 **第一步字段名不同**；多数品类末尾共享：

- **风格属性**（职场办公 / 日常休闲 / 潮流街头 / 户外机能 / 极简高级 / 温柔气质 等）  
- **档次定位**（平价刚需 / 中端质感 / 高端轻奢）  
- **使用场景**（自由填写）  
- **发布平台**（淘宝、京东、拼多多、抖音、小红书、亚马逊、TikTok Shop、Shopee、Lazada、速卖通 等）  
- **输出语言**（中文、英文、西/葡/阿拉伯语 等）

各品类 **前几维**（实现为准，跟助手卡片走）：

| 大类 | 参数步要点 |
| --- | --- |
| **服装** | 性别品类 → 款式品类（T 恤、连衣裙、冲锋衣等，选项较多）→ 共享后五维 |
| **包包** | 性别定位（男包/女包/中性）→ 包型品类 → 共享后五维 |
| **3C 数码** | **产品大类 + 产品细项**（**可搜索级联**，先选大类再选细项）→ 设计语言 → 核心功能属性（多选 chips）→ 档次 → 使用场景 → 平台 → 语言（共 **8 步**） |
| **鞋子** | 鞋类品类（运动/休闲/靴等）→ 共享后五维 |
| **珠宝** | 珠宝品类 → 共享后五维 |
| **户外用品** | 户外品类 → 共享后五维 |
| **家居服** | 家居服品类 → 共享后五维 |
| **厨房用品** | 厨房产品子类 → 产品功能风格 → 共享后五维 |
| **母婴用品** | 母婴产品子类 → 核心功能属性（chips）→ 风格定位 → 档次/场景/平台/语言 |

某维列表里没有合适项时，卡片上可选 **「自定义填写」**，在下方输入框发送。

**3C 数码** 的「产品大类 / 产品细项」为 **搜索下拉**，不必在长列表里硬翻。

## 第三步：产出模式（两条策划线）

参数采集完成后，出现 **两张产出模式卡片**（二选一）：

| 卡片标题 | 适合 | 之后的主线 |
| --- | --- | --- |
| **选择产出：分镜脚本标准线** | 口播带货、讲参数、讲卖点 | 6 口播 → A–E 分镜 → 运营包 → 交付/成片 |
| **选择产出：故事剧场线** | 微型剧情、情绪、避坑故事 | 5 故事主题 → T1–T5 → 编辑确认 → 成片 |

**不要** 在故事线里找「6 套口播 / A–E 五版」；**不要** 在标准线里找「T1–T5 故事版」。

---

## 标准线 · 分镜脚本（口播带货）

1. **卖点**：AI 生成或手动输入 → **锁定卖点**。  
2. **口播**：生成 **6 套** 口播，选 1 套。各品类 **6 套名称不同**，例如：  
   - 服装：痛点救场 / 质感种草 / 场景价值 / 氛围审美 / 实用百搭 / 情绪体验 等  
   - 3C：痛点爆破 / 硬核参数 / 场景种草 / 颜值种草 / 性价比 / 使用体验 等  
   - 其它品类以助手卡片为准  
3. **分镜**：生成 **A–E 五版** 六镜分镜，选 1 版。每版有标题摘要（如 3C 的「开箱惊艳 / 功能演示 / 场景沉浸…」，服装的「上身动效 / 细节均衡…」）。  
4. **六镜职能**（各品类镜头文案不同，结构均为 6 镜）：如服装为场景氛围 → 轮廓 → 面料 → 卖点特写 → 穿搭场景 → 收尾种草；3C 偏亮相 → 工业设计 → 细节 → 功能演示 → 真实使用 → 品牌落版。  
5. **运营包**：标题、封面词、标签、详情要点等。  
6. **成片方式**（助手二选一）：  
   - **分镜脚本交付**：偏脚本 + 分镜图导出  
   - **故事版一键成片**：进 **成片工作区** → 批量分镜图 → 单镜/整片视频 → 可 **合并镜级视频**

---

## 故事剧场线（剧情向）

1. **卖点**：同样须 **锁定卖点**（无 6 套口播步骤）。  
2. **故事主题**：系统给出 **5 个候选主题** 选 1；你可在 **我的资产 → 剧情故事** 自建主题，参与抽取。  
3. **剧情分镜**：生成并选择 **T1–T5** 之一（全品类通用类型名）：  
   - T1 · 痛点治愈剧情  
   - T2 · 场景适配剧情  
   - T3 · 前后反差剧情  
   - T4 · 经验避坑剧情  
   - T5 · 情绪共鸣剧情  
4. **编辑**：中栏 **故事剧场分镜表** 可改字段并保存。  
5. **确认**：须点 **「确认故事版，开始成片」** 后才会进入成片工作区（未确认不算定稿）。  
6. **出图出片**：与标准线共用 **分镜图 / 单镜视频 / 合成** 能力，但 **没有** A–E 商业分镜与 6 口播环节。

---

## 中栏、进度与设置

- **进度轨**：上传 → 维度 → 卖点 → 成片等阶段。  
- **预览**：标准线可见 **分镜表 / 卖点验收清单**；故事线可见 **故事剧场分镜表**。  
- **影片参数**（助手区设置）：对话模型、生图/生视频模型、画幅（如 9:16）、时长等。  
- **保存工作流 / 分享**：副本链接或 10 位码；好友可继续编辑（不含你的 API 密钥）。  
- **导出 ZIP**：卖点、脚本、分镜、运营包等（以实际包内容为准）。

## 旧版项目

早期 **通用分镜**（11 项参数采集、方案三选一那套）打开后 **只读**，助手不能继续推进。请 **新建** 电商专业版项目，按本文 **九类 + 两线** 流程操作。

## 常见问题

**没传图为什么没有品类卡片？**  
大类选择依赖 **已上传产品图**；请先在中栏上传。

**选错品类怎么办？**  
建议 **新建项目**；已 deep 推进的项目不宜强行改 vertical。

**服装和 3C 口播名字不一样？**  
正常，各品类配置了不同的 **6 套口播类型** 与 **A–E 分镜标题**。

**故事剧场和标准线能互换吗？**  
产出模式在 **卖点流程前** 选定；中途改线请 **新建项目**。

**和种草视频的区别？**  
种草视频是 **素材 + 3 套脚本 + 约 30s 成片** 的独立入口；故事版是 **Pro 分镜表 + 九品类规则 + 两线策划**。

**从 AI 商品套图跳过来？**  
套图页 **去做视频** 可带成图资产创建故事版项目，但 **品类与策划仍须在本页** 按助手走完。
