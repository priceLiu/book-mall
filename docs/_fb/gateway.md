## 1. Gateway 是什么（用户语言）

Gateway 是平台的 **「AI 模型中转站」**：

- 你在 **Gateway 控制台** 绑定 **云厂商账号的 API 凭证**（如百炼、灵积、KIE、火山、DeepSeek 等，以控制台可选为准）。
- 你创建一把 **Gateway API Key（形如 `sk-gw-...`）**，并把它与 **Book 主站账号关联**。
- 之后，**各创作应用** 在你点击「生成」时，会通过 Gateway **安全地** 去调用对应厂商模型，而不是把厂商 Key 散落在每个网页里。

对普通创作者：Gateway 是 **「让生成能跑起来 + 可查记录」** 的后台。  
对开发者：Gateway 还提供 **统一的 HTTP API**，用同一把 Key 在 **自建服务、脚本、后端** 里调模型。

## 2. 和主站（Book）的关系

| 项目 | 说明 |
|------|------|
| 账号 | 推荐 **只用 Book 注册邮箱**；Gateway 侧用 **「使用 Book 账号登录」** 或主站 **「用 Book 账号打开 Gateway」**，不要同一邮箱在 Gateway 再注册一套密码。 |
| 关联 Key | Book **个人中心 → Gateway API Key** 粘贴 `sk-gw-...` 验证；主站只存 **关联关系**，不长期展示明文 Key。 |
| 生成入口 | Canvas、Story、工具站等 **不在网页里填厂商 Key**；它们经主站代理 + 你的 Gateway Key 身份去调用。 |

**订阅会员（平台代付）** 用户：主站可能为你 **自动托管** Gateway 身份，个人中心 **看不到** 完整 Key 也属正常；用量可在主站 **财务/用量** 与（若有权限）Gateway 只读页查看。  
**需要自己绑厂商 Key 的用户**：须完成下文 **凭证 → Key → 关联** 三步。

## 3. 怎么进入 Gateway

| 入口 | 操作 |
|------|------|
| **推荐** | 主站已登录 → **个人中心 → Gateway API Key** → **用 Book 账号打开 Gateway** |
| 备选 | Gateway 登录页 → **使用 Book 账号登录** |
| 本地开发 | 主站 `localhost:3000` 个人中心；Gateway 一般为 `localhost:3005` |

进入后左侧为导航菜单；不同身份看到的菜单 **多少不同**（见 §5）。

## 4. 首次配置（自带厂商凭证的用户）

按顺序完成即可在创作应用里生成：

| 步骤 | 菜单位置 | 做什么 |
|------|----------|--------|
| ① 厂商凭证 | **厂商凭证** | 新增一条凭证，选择厂商类型，粘贴厂商控制台颁发的 Key |
| ② API 密钥 | **API 密钥** | 创建 `sk-gw-...`，勾选要绑定的厂商凭证；**明文只显示一次**，请立即复制保存 |
| ③ 关联主站 | Book **个人中心 → Gateway API Key** | 粘贴 sk-gw 验证成功 |
| ④ 回创作应用 | 刷新 Canvas 等 | 再试生成 |

若生成仍提示未关联：确认 sk-gw 是在 **当前 Book 邮箱对应的 Gateway 用户** 下创建的，且至少绑定了一种凭证。

## 5. 控制台菜单说明

### 5.1 所有用户常见

| 菜单 | 用途 |
|------|------|
| **操作指引** | 控制台内嵌的 Gateway 使用说明 |
| **用量** | 近一段时间 **请求次数、Token 汇总、按模型排行、按日趋势**；先看这里了解「用多了谁」 |
| **日志** | **逐条请求**：时间、来源应用（如 Canvas）、状态、模型、耗时、失败原因等 |
| **状态 / 轮询池** | 查看 **长时间异步任务**（视频等）在后台排队与轮询情况 |
| **模型市场** | 浏览平台登记的 **模型能力说明**（便于选对模型） |

### 5.2 具备管理权限的用户额外可见

（例如 BYOK 用户、被授权管理平台凭证池的管理员）

| 菜单 | 用途 |
|------|------|
| **模型管理** | 查看/维护模型路由与凭证绑定（偏运维） |
| **API 密钥** | 创建、撤销、轮换 sk-gw |
| **API 调试** | 在浏览器里试发一条 API 请求 |
| **调用示例** | 常见语言的示例代码片段 |
| **接入文档** | HTTP 路径、鉴权头、请求体格式说明 |

若你看不到 **API 密钥 / 接入文档**，但仍能在 App 里生成，说明当前是 **平台托管 Key** 模式，API 自助以主站 **API 会员 / 平台 API Key** 产品说明为准。

## 6. 在哪里看「我用掉了多少」

| 想看什么 | 去哪里 |
|----------|--------|
| **按请求、按模型、按 App 来源** | Gateway → **用量** + **日志** |
| **主站积分扣减、按工具汇总** | 主站个人中心 → **财务控制台**（见《财务管理 · 使用指南》） |
| **Book 个人中心 Gateway 卡片** | 仅显示 **是否已关联、Key 前缀、绑了哪些厂商类型**，**不含** Token 明细 |

Canvas / 电商等走 Gateway 的生成，都会在 Gateway **日志** 里留下 **来源标签**，便于你对照某次操作。

## 7. API 应用：谁需要、能做什么

### 7.1 适合用 API 的场景

- 你有 **自己的网站、小程序、后台任务**，要在服务端调 **同一套** 平台模型。
- 你想用 **脚本批量** 生图、生视频、对话，而不想手动点网页。
- 你采用 **API 会员** 身份注册，主站发放 **平台 API Key**，专门走 HTTP 接口（与纯 App 订阅是不同产品路径，注册时选定）。

### 7.2 典型用法（概念层）

1. 在主站完成 **API 身份注册 / 充值 / 创建平台 API Key**（以主站「API 价格 / API 账单」页为准）。
2. 在 HTTP 请求头携带：`Authorization: Bearer sk-gw-...`（或主站文档规定的平台 Key 形式）。
3. 调用主站暴露的 **Gateway 兼容路径**（如对话、图像、视频、任务查询等），请求体指定 `modelKey` 与参数。
4. 异步任务（视频）返回 taskId，再 **轮询任务状态** 直到成功或失败。
5. 在 Gateway **日志** 或主站 **用量** 里核对调用记录。

### 7.3 控制台里与 API 相关的工具

| 工具 | 作用 |
|------|------|
| **API 调试（Playground）** | 不用写代码，先测通鉴权与模型 |
| **调用示例** | 复制 curl / 常见语言示例 |
| **接入文档** | 字段说明、错误码、限流提示 |

**注意**：请勿把 `sk-gw` 写进公开前端网页；API 应在 **服务器** 调用。

### 7.4 API 与创作 App 的关系

- **同一套模型登记**：App 里选的模型与 API 的 `modelKey` 对应同一能力池（以平台模型市场/管理页为准）。
- **同一身份约束**：一个账号通常 **一种计费身份**（订阅 App vs API）；两种都要时，产品策略是 **分账号（分身）**，以注册页说明为准。
- **日志统一**：经 Gateway 的请求都会进 **日志**，方便你排查「脚本哪次调用了哪个模型」。

## 8. 密钥与安全习惯

| 做法 | 原因 |
|------|------|
| sk-gw **只创建时复制一次** | 之后控制台只显示前缀 |
| 在 Book **解除关联** | 仅断开主站与该 Key 的关系，Key 在 Gateway 仍可能存在 |
| 在 Gateway **撤销 Key** | 所有使用该 Key 的 App/API **立即失效** |
| 厂商 Key **只放在 Gateway 凭证** | 不要发到聊天、不要写进公开仓库 |

## 9. 常见问题

**Q：Book 邮箱密码能否直接登 Gateway？**  
A：**不能**，除非你在 Gateway 单独设过密码。请用 **Book SSO**。

**Q：Canvas 提示要关联 Key，但我已关联？**  
A：刷新页面；若 Key 已在 Gateway 撤销，需新建 Key 并重新关联。

**Q：日志里「预估成本」和主站积分不一致？**  
A：Gateway 成本多为 **厂商挂牌估算**；主站积分在 **财务控制台** 查看，两者口径不同，本文不展开计费。

**Q：SSO 打开 Gateway 失败？**  
A：确认主站仍登录、换浏览器重试；持续失败请联系支持（勿使用 VPN 作为官方解决方案）。
