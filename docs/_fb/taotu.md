# AI 商品套图·使用指南

> 一句话：上架前要一组商品图就用它。左边传商品原图（最多 6 张），右边配套图结构（白底 / 卖点 / 场景 / 细节），一键 AI 规划各槽位 Prompt，中栏勾选批量出图；可选卖点图版式库、爆款风格与上架文案。没有 Step 助手，路径更短。

**入口**：电商工具箱 → 电商 → 主图与套图 → AI 商品套图

## 适合谁

- 需要白底图 + 卖点图 + 场景 / 模特场景 + 细节辅助组合，张数自己配（有上限）。
- 已有多角度产品实拍，希望锁定同款批量出图。
- 想复用平台卖点图版式预置或爆款视觉风格卡片，而不是从零写每条主图文案。

**不太适合**

- 要强营销方案三选一、购买理由矩阵、主图分层叙事 → 看「电商产品主图创作」。
- 要详情长图 / A+ 模块 / 服装 12 模块 → 看「详情页工具怎么选」。

## 界面怎么分

| 区域 | 作用 |
| --- | --- |
| **中栏（左区）** | 上传商品原图（≤6）、套图槽位网格、勾选出图、预览 / 改 Prompt |
| **右侧配置侧栏** | 平台 / 国家 / 语种、出图比例、卖点文档、套图结构、版式与风格、模型、生成套图占位 |
| **顶栏** | 新建、项目列表、保存工作流、导出 ZIP、分享、去做视频（需已成图入库） |

没有右侧对话助手；全流程在配置 + 中栏槽位完成。

## 套图结构（可配张数）

在侧栏套图结构配置用步进器设定（各类型有上限）：

| 类型 | 含义 | 数量范围 |
| --- | --- | --- |
| **白底图** | 纯白 / 干净底商品图 | 0～5 |
| **卖点图** | 带卖点信息的主图类画面 | 0～9 |
| **场景 / 模特场景** | 生活 / 穿搭 / 环境 | 0～12 |
| **细节 / 辅助图** | 细节特写，标 AI 智能匹配 | 0～5 |

至少上传 1 张原图，且结构合计 > 0 张才能点生成占位。卖点图 > 0 时需选卖点图版式参考（从预置库按品类挑，数量不超过卖点图张数），也可上传自定义版式参考图。

## 推荐流程

**第一步：上传商品原图**——中栏商品原图区本地上传（可多张，最多 6 张），用于 AI 识卖点并锁定商品外观。

**第二步：生成设置与卖点**——设目标平台、国家 / 市场、语种（影响文案与风格）；选 1:1 / 3:4 / 4:5 / 16:9 / 9:16 等出图比例；填五段式卖点模板，可点「AI 帮写」（需先有原图）。

**第三步：可选增强**——勾选爆款风格分析看 trending_visual 卡片（可换一批）；勾选商品上架文案生成，成图后附带 listing 文案。

**第四步：生成套图占位**——侧栏底部「生成套图占位（N 张）」：先保存卖点文本，调 AI 规划套图 Prompt，按结构创建 N 个槽位，每条写入 title + 生图 prompt（卖点图结合所选版式）；成功后中栏出现分组网格（白底 / 卖点 / 场景 / 其他）。LLM 规划失败会走 fallback 占位 Prompt，可改 Prompt 后重试。

**第五步：中栏出图**——勾选要生成的槽位 → 生成选中；或单槽生成 / 重新生成；编辑过的条目会标记避免误覆盖。

**第六步：导出与后续**——导出 ZIP 打包套图与文案；保存工作流存为项目镜像；分享工作流给好友领副本；至少一槽已出图入库后可「去做视频」带资产跳电商口播故事版。

## 使用要点

1. **先占位、再出图**：未规划前中栏无槽位；规划完务必看一眼每条 Prompt 再批量生成。
2. 卖点图张数 = 版式选择数；减少卖点张数时，已选版式会自动截断。
3. 细节 / 辅助图由 AI 按卖点智能匹配意图，出图前仍建议扫一眼 Prompt。
4. 系统按原图 / 配置推断品类（服装、包袋、3C、通用），影响版式库与风格卡片推荐。

## 常见问题

**最多几张原图？** 6 张。

**一次必须出满 N 张吗？** 不必；占位 N 张后勾选哪张出哪张。

**和主图创作能合并吗？** 不能共项目；同一商品可各建一个项目分别做。

**刷新后还在吗？** 项目、槽位、Prompt、已出图持久化，用顶栏项目列表切换。
