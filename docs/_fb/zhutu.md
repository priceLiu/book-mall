# 电商产品主图创作·使用指南

> 一句话：面向淘宝、京东、抖音的卖家。用产品实拍（+ 可选店铺风格参考），先定卖点策略与主图分层文案，再逐张出商品主图；主图出齐后还能一键把策略带到详情页。

**入口**：电商工具箱 → 电商 → 主图与套图 → 电商产品主图创作

## 适合谁

- 想要**主图点击率**：先想清楚人群、痛点、方案，再出多张职责不同的主图（不是一条 Prompt 连出 N 张雷同图）。
- 有产品实拍，希望 AI 帮写营销文案层，但**生图仍以你确认的 Prompt 列表为准**。
- 计划主图 + 详情都做：主图项目里填一次 Step0–3，详情入口**导入快照**即可。

**不太适合**

- 要白底 + 卖点 + 场景一套上架图、偏套图批量占位 → 看「AI 商品套图」。
- 要详情模块 / 长图分屏 / 服装 12 模块 → 看「详情页工具怎么选」。

## 界面怎么分

| 区域 | 作用 |
| --- | --- |
| **中间工作区** | 上传参考图、选平台、填产品信息、选制作方式、Prompt 计划、生成、预览、导出 ZIP |
| **右侧助手** | 流式文案；下一步 / 修改当前步；**不能代替**中间区直接出图 |

一个项目只属于主图入口，建好后**不能**改成详情项目；详情需另建项目并导入策略。

## 两种制作方式（出图前汇合）

| 方式 | 说明 |
| --- | --- |
| **助手流程（Step by step）** | 助手带 Step0–3 策略 → Step4 主图分层文案 → Prompt 计划 → 出主图 |
| **产品图 + 参考图 + Prompt** | 自写意图（main-style 风格参考可选）→ 识别并拆解成 N 条 Prompt → 确认 → 出图 |

无论哪种，出图前都必须在中栏完成 **Prompt 计划** 并点「确认计划并开始出图」。走 Prompt 方式时不必先选张数——张数 = 列表里 Prompt 条数。

## 推荐流程（助手路径）

**第一步：策略层 Step0–3**

- Step0 Brief：产品名、人群、痛点、优势（二选一：AI 拆解产品图 或 手动输入，不会未授权自动读图）。
- Step1 产品拆解：视觉调性、合规红线等。
- Step2 营销方案：3 个方案选 1 个（选定后不可换方案，内容仍可改）。
- Step3 购买理由：购买理由矩阵。

**第二步：Step4 主图分层文案**——助手产出主图各层的文案结构（详情入口没有这步）。

**第三步：Prompt 计划**——中栏打开「主图 · Prompt 计划」，点从文案生成草稿（或 Prompt 路径的识别并拆解）；检查每条标题 + 完整中文生图指令，可保存修改；点「确认计划并开始出图」。

**第四步：Step5 出主图**——单张生成 / 生成全部均用列表里当前 Prompt；缩略图可画廊预览；完成后导出交付包（ZIP）。

**第五步（可选）：继续做详情**——主图全部出齐后中栏出现「主图已出齐，继续做详情页？」，点去做详情页 → 新建详情项目并快照拷贝 Step0–3、产品图、主图成品（≤3 张）→ 跳转详情长图分屏创作。导入不扣费、不自动同步。

## 使用要点

1. **助手只出文案**；真正出图以已确认 Prompt 计划为准，未确认就生成会提示先回计划区。
2. **一条 Prompt 一张图**：避免笼统描述 × N 张导致画面雷同。
3. 与 AI 商品套图：主图偏策略 + 分层主图；套图偏结构配置 + 白底/卖点/场景批量（无 Step 助手）。
4. 计费：Step0 识图、文案、Prompt 拆解、出图走 Gateway，归属电商工具箱月费。

## 常见问题

**必须先做主图才能做详情吗？** 不必。详情可从零开始；主图只是省一次策略填写的捷径。

**能一个项目又做主图又做详情吗？** 不能。各建一个项目，用导入带策略。

**导出包里有什么？** 文案 + 主图成品 + 参考图分类（以实际 ZIP 内容为准）。
