# AI 画布 · 使用指南

> **产品名**：ZH 无限画布（门户）· **影视专业版 2.0** 为当前主推创作线。  
> **更新日期**：2026-10-04  
> **读者**：设计师、影视创作者、需要可复用 AI 工作流的用户。

## 流程总览

![流程图](@./canvas.png)

## 1. 画布能帮你做什么

AI 画布是一块 **可以无限平移、缩放的创作桌面**。你在上面放置 **节点**（文本、图片、脚本、生图/生视频引擎等），用 **连线** 把上一步的结果传给下一步，从而搭建：

- **海报与商业视觉**：产品图 + 文案 + 风格参考 → 多版海报方案。
- **影视专业版 2.0（Pro2）**：故事与剧本 → 风格定调 → 角色/场景 → 分镜静帧 → 分镜视频 → 导出剪映包或自动剪辑成片。
- **分镜视频 1.0（sbv1）**：更偏「单条分镜视频合成」工作流，与 Pro2 **不能混在同一张画布**（系统按项目版本隔离）。
- **社区工作流**：复制他人公开的模板/精选/案例，在自己账户里改参数继续用。

---

## 2. 从哪里进入

- 打开 **AI 画布** 独立站点（生产环境一般为 `canvas.ai-code8.com`）。
- 从主站 **应用入口 / 个人中心** 跳转时，会使用与主站相同的登录态。
- 首次生成前，若账号未完成 **Gateway 关联**（视你的会员类型而定），顶栏可能出现提示；按指引到主站个人中心或 Gateway 完成即可。

## 3. 首页与门户

### 3.1 开始创作

- 点击 **「开始我的创作」** 会直接新建并打开 **影视专业版 2.0** 空白画布（无需再选旧版入口）。
- Hero 下方会随机展示若干 **精选工作流**（均为 2.0 项目），可一键复制到你的账户。

### 3.2 最近项目

展示你最近编辑过的画布；**查看全部** 进入 **我的画布** 列表。

### 3.3 发现区（全部 / 精选 / 模板 / 案例）

| Tab | 内容 | 点击行为 |
|-----|------|----------|
| 全部 | 精选 + 模板 + 案例合并 | 见下 |
| 精选 | 管理员设为首页推荐的 2.0 作品 | 他人作品 → **预览** → **复制到我的画布** |
| 模板 | 用户公开到社区的 2.0 模板 | 同上 |
| 案例 | 审核通过的案例 | 同上 |

**说明**：发现区 **只展示影视专业版 2.0**；旧版「影视专业版 1.0」「分镜视频 1.0」项目仍可在「我的画布」里打开，但不会出现在发现列表。

- **自己的** 精选/案例/模板：可直接进入编辑（模板通过「复制到画布」再编辑）。
- **他人的** 内容：先预览，再复制。

## 4. 我的画布

- 新建项目默认走 **Pro2** 主入口。
- 列表中可管理历史项目（含旧版 1.0、sbv1 项目）。
- 卡片上可进行 **投稿**（精选/案例）、**分享到社区**（模板）、**保存为我的模板** 等（见 §6）。

## 5. 影视专业版 2.0：怎么用（用户视角）

Pro2 采用 **「画布薄卡片 + 右侧检视面板」**：

- 画布上的节点只显示 **阶段、进度、缩略图** 等摘要。
- **选中节点** 后，在 **右侧面板** 里编辑完整表单、表格、生成按钮。
- 生成时，面板底部有 **Composer**；画布卡片上显示进度状态。

### 5.1 推荐阶段顺序（五段流水线）

| 阶段 | 你在做什么 | 典型节点（用户可见名） |
|------|------------|------------------------|
| 故事 | 定主题、上传或生成剧本 | 故事起点、分镜脚本中心 |
| 风格 | 定视觉锚点、参考图 | 风格 |
| 设计 | 角色三视图、场景参考 | 角色、场景 |
| 分镜 | 按镜号出静帧 | 分镜 |
| 视频 | 按镜出分镜视频、配音等 | 分镜视频 |
| 导出 | 剪映工程包或平台自动剪辑 | 剪映导出 / 自动剪辑 |

**定稿习惯**（重要）：

1. 在 **分镜脚本中心** 审阅大纲、角色、分镜表，确认后 **定稿**，下游才按你的剧本结构展开。
2. **风格定稿** 前，系统会限制下游媒体乱生成。
3. 定稿 **不会自动** 替你把所有图/视频跑完；你需要在对应阶段 **单镜或批量** 点击生成。

### 5.2 画布上的通用操作

- **拖动**：在节点空白区域拖动移动位置（按钮、输入框区域除外）。
- **连线**：从节点侧面的 **「+」** 拖线到另一节点，或从菜单 spawn 下游节点。
- **选模型**：通过 **模型 / 参数** 两个入口（浮动 Dock 或工具条），从平台已登记的 **文本 / 图片 / 视频** 模型里选择；不要指望固定写死某一个模型名，以你账户可见列表为准。
- **有图的图片节点**：顶部会出现 **工具条**（预览、重绘、保存为资产、截帧/裁剪视频等，视节点类型而定）。
- **打组**：框选多个节点可 **打组**，组上有 **批量下载、重排、解组** 等操作。
- **3D 导演台**：特定节点可 **内嵌打开 3D 导演台**，摆好机位后 **截图回传** 到画布，再连到生图节点。

### 5.3 分镜视频 1.0（sbv1）项目

若你打开的是 **分镜视频 1.0** 画布（青色系节点）：

- 核心是 **分镜图片节点 + 视频合成节点**，底部有 **视频合成 Dock**。
- 交互规则与 Pro2 **共用同一套** 拖动、预览、模型选择规范，但 **节点种类与菜单不同**。
- 新建 sbv1 项目请从对应入口创建，**不要** 在 Pro2 项目里手动拼 sbv1 节点。

### 5.4 旧版「影视专业版 1.0 / 基础快手版」

- 仅 **维护**，新功能在 Pro2 与 sbv1。
- 旧项目可继续编辑，但不建议新开工单再用旧轨。

## 6. 分享、投稿与模板

### 6.1 普通用户

| 方式 | 入口 | 对外可见性 |
|------|------|------------|
| 社区模板 | 画布工具栏 → **分享到社区** | **立即** 出现在发现「模板」 |
| 精选投稿 | 我的画布 → 卡片 **投稿** → 选「精选」 | 需 **管理员审核** |
| 案例投稿 | 同上 → 选「案例」 | 需 **管理员审核** |
| 私有模板 | 工具栏 → **保存为我的模板** | 仅自己可见 |

### 6.2 团队用户（可选）

- 顶栏 **「关联剧本包」** 仅 **团队空间用户** 与 **平台管理员** 可见。
- 个人用户不显示该入口；个人创作 **无需** 关联剧本包即可使用 Pro2。
- 团队可通过剧本包 + 公告栏 + 制作任务协同（与影视工业化流程相关）。

### 6.3 管理员

- 顶栏 **「管理中心」**：工作流审核、模板管理、Pro2 剧本 LLM 模板与节点资产模板等（详见站内 `docs/画布管理中心.md`）。

## 7. 生成、排队与结果

- 提交生成后，节点会显示 **排队 / 进行中 / 成功 / 失败**；失败时可查看原因并 **重试**（视节点类型）。
- 长时间视频任务可能在后台继续；画布会 **自动刷新状态**（进行中时会周期性更新）。
- 成功结果以 **图片或视频** 显示在节点上，可 **下载、spawn 下游节点、保存为项目资产**。
- **视频节点** 支持：截帧（首/尾/时间点）、裁剪片段 spawn 新节点、提取字幕 spawn 文本节点等（以节点顶栏实际按钮为准）。

---

## 8. 项目资产与历史

- **保存为资产**：把当前图/视频/角色等纳入 **项目资产库**，在同项目其他节点 **@ 引用** 或插入。
- **生成记录**：与任务状态联动，便于找回某次模型与参数下的结果（具体入口在画布项目菜单/侧栏，以线上一致为准）。
- **自动保存**：编辑画布会自动保存；请勿在大量上传进行中强行关页，等待上传队列完成更稳妥。

## 9. 与漫剧空间、电商、导演台的关系

| 关系 | 说明 |
|------|------|
| 漫剧空间 | 门户侧重 **漫剧项目（故事设定→分镜设定）** 的线性体验；深度节点工作流在 **AI 画布 Pro2**。账号数据互通，按任务选择入口。 |

| 3D 导演台 | 独立站点，也可在画布 **iframe 内嵌** 使用。 |

## 10. 常见问题（使用向）

**Q：发现区怎么没有我的项目？**  
A：仅 **Pro2** 且满足公开/审核规则的内容会进入对应 Tab；旧版项目不会出现在发现区。

**Q：为什么点生成没反应？**  
A：检查是否未完成 **脚本/风格定稿**、是否未选模型、或 Gateway/积分门禁提示；按页面文案完成前置步骤。

**Q：能否把 Pro2 项目转成 sbv1？**  
A：**不支持** 自动迁移；请新建对应版本项目，手动复制素材。

**Q：AI 小智能答画布吗？**  
A：可以问流程与入口；复杂节点以本指南与画布内提示为准。
