# 快速复制 · 使用指南

> **产品名**：快速复制（QuickReplica）  
> **更新日期**：2026-10-04  
> **读者**：希望「照着官方/他人示例，换自己的素材快速出同款」的创作者。

## 流程总览

```mermaid
flowchart LR
  A[选大类] --> B[点 kind 子类型]
  B --> C[右栏模板 · 预览]
  C --> D[复制到工作区]
  D --> E[换素材/改 Prompt/选模型]
  E --> F[产生]
  F --> G[我的作品 · 顶部]
```

---

## 1. 快速复制是什么

快速复制是一个 **「发现示例 → 载入工作区 → 改 Prompt/素材/模型 → 生成」** 的独立应用。你不需要自己搭画布节点，只要：

1. 在左侧选好 **大类**（视频、图像、角色、场景、声音等）；
2. 在中间看清 **子类型（kind）** 与 **分类示例**；
3. 在右侧 **模板墙** 里点一张卡片，预览后 **复制** 到中间工作区；
4. 替换参考图/视频/音频、改提示词、选 AI 模型，点 **产生**；
5. 新结果会进入 **我的作品**，并 **优先出现在右侧模板区顶部**（你的历史模板）。

对标体验：类似「模板市场 + 单页工作区」，强调 **快** 与 **可复用**。

---

## 2. 界面三栏（记住这三块）

| 区域 | 作用 |
|------|------|
| **左栏** | 主导航：首页、创造五大类、**我的作品**、置顶工具（如运动同步、唇语同步、编辑图像/视频等） |
| **中栏** | **浏览态**：子类型列表 + 官方分类示例缩略图；**工作区态**：复制后的表单、素材槽、模型与 **产生** 按钮 |
| **右栏** | **模板网格**：随当前分类/kind 过滤；点卡片 → **预览弹层** → **复制**（右栏不切换，中栏进入工作区） |

底部还有 **分类 Tab**，与左栏「创造」分类 **同步**，方便宽屏时快速切换。

## 3. 推荐使用流程

### 第一步：选分类

- **视频**：图生视频、文生视频、动作迁移、改背景、重打光、特效、HD、换角色、延长视频等（以界面子类型为准）。
- **图像**：文生图、变体、编辑、扩图、超分、多视角、机位、换脸等。
- **角色**：创建角色、角色图、角色视频、带声视频等。
- **场景**：创建场景、场景机位、场景演员等。
- **声音**：分类已预留，以实际上线子类型为准。

### 第二步：点 kind，看右栏模板

- 在中栏点某一 **子类型（kind）**，右栏只显示该 kind 下的模板。
- 不点 kind 时，右栏展示 **当前大类下的全部模板**（官方 + 符合条件的公开模板）。

### 第三步：预览 → 复制

- 右栏点模板 → **预览弹层** 看参考素材、Prompt、示例成片。
- 点 **复制** → 中栏进入 **工作区**，自动填入该模板的 **参考槽位、Prompt、默认模型与参数**。

### 第四步：改素材与文案

工作区常见槽位（视 kind 而定）：

- 目标图、参考视频、参考音频；
- 多张场景图、角色参考；
- 正向 / 负向 Prompt（中英文均可，以模板为准）。

请 **替换为你有权使用的素材**；不要用他人未授权肖像或品牌素材。

### 第五步：选模型（可选调整）

- 点击 **模型选择**，从平台登记的 **IMAGE / VIDEO / LLM / AUDIO** 模型中选（列表随 Gateway 配置变化）。
- 可调参数（比例、时长、种子等）以弹层中 **「N 项可调参数」** 为准。

### 第六步：产生

- 点 **产生** → 等待任务完成（界面会轮询状态）。
- 完成后可在预览中确认，结果 **写入你的模板库**，并出现在 **我的作品** 与右栏顶部。

---

## 4. 「我的作品」

- 左栏进入 **我的作品** → 右栏 `scope=my`，只看你生成的模板/结果。
- 中栏可能是空态，引导你先回某一分类 **复制官方示例** 再产生。
- 适合回顾 **最近同款实验**，或把满意结果当作下次复制的起点（在预览里再复制一次即可）。

---

## 5. 置顶工具（快捷入口）

左栏或导航上的 **置顶工具** 会 **跳过 browse**，直接进入工作区并带上固定 `toolKey/kind`，例如：

- **运动同步**（motion-sync）
- **唇语同步**（lip-sync）
- **编辑图像 / 编辑视频**

适合老用户 **重复同一类任务**，不必每次从分类点进。

---

## 6. 官方示例 vs 用户模板

| 来源 | 谁维护 | 你怎么用 |
|------|--------|----------|
| 官方模板 / 分类示例 | 平台在后台模板管理维护 | 右栏浏览、复制、改参产生 |
| 用户模板 | 你自己产生后入库 | 在「我的作品」或右栏顶部找 |
| 公开模板 | 其他用户设为 public（若有） | 与官方同样 **预览 → 复制** |

预览弹层 **不提供写操作**；要改只能 **复制到工作区** 后再编辑。

---

## 7. 登录与权限

- 使用 **与主站相同的账号** 登录快速复制站点。
- 需已开通该应用的 **使用权限**（与主站工具准入一致；具体以个人中心/提示为准）。
- 生成走平台 **Gateway** 能力；若页面提示关联 Key 或积分不足，请回主站个人中心处理。

---

## 8. 与 AI 画布、工具站的区别

| 对比 | 快速复制 | AI 画布 |
|------|----------|---------|
| 交互 | 三栏 + 单工作区 | 无限画布 + 多节点连线 |
| 适合 | 快速同款、单任务 | 复杂流水线、Pro2 影视 |
| 模板 | 右栏网格为核心 | 发现区「工作流」复制 |

| 对比 | 快速复制 | 工具站 |
|------|----------|--------|
| 结构 | 示例驱动 | 试衣、文生图等独立页 |
| 目标 | 复刻示例效果 | 单点工具 |

---

## 9. 使用技巧

1. **先复制官方示例，再只改一项**（例如只换目标图），便于对比效果。
2. **kind 选对了**，右栏模板才精准；若结果不对，先确认 kind 是否匹配任务（如「图生视频」vs「文生视频」）。
3. **保存 Prompt**：满意的工作区可复制 Prompt 到提示词优化器或画布文本节点复用。
4. 生成失败时，看弹层/Toast **失败原因**（素材尺寸、时长、模型不支持等），再改参重试。
