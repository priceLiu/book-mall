# 海报制作 · 使用指南（一句话出电商营销海报）

> 这篇是写给**已经注册好、登录进去就能用**的你看的。不讲技术，只讲「点哪里、传什么、会出什么」。

---

## 这个功能是干嘛的？

一句话：你给简单的素材或一句话需求，系统帮你出**电商营销海报**——促销、上新、节日、直播预告、主图氛围都行。可以傻瓜式最少输入，也能专业式全参数调。

文字和图默认分开处理（先出**无字底图**，再用程序排版加字），好处是：你后面只想改句文案，不用重新生一张图，省时又省钱。

---

## 开工前：准备素材（最少可什么都不传）

1. **进对地方**：左边菜单点「营销」→「海报制作」。
2. **按你要走的路准备**（四种路径，详见第一步）：
   - 模特图 + 服装图 + 场景图（路径 A 需要）；
   - 或只传服装图（路径 B，系统补模特 / 场景）；
   - 或一句话活动需求（路径 C，可不出参考图）；
   - 或节日 + 至少一项 VI / 品牌资产（路径 D，偏创意品牌向）。
   - 素材来源：我的资产库、本地上传、剪贴板粘贴都行。

## 第一步：选模式

- **傻瓜出图**（默认）：最少输入，系统补全策划、文案、无字底图、默认排版。
- **专业创作**：文生营销海报 / 图生海报（参考构图风格 + 新文案）/ 模板重构（电商模板库）。

---

## 第二步：傻瓜式四选一（给最少素材）

| 路径 | 你给最少 | 系统补全 |
|------|----------|----------|
| **A** | 模特 + 服装 + 场景（+ 节日） | 融合场景、节日包、营销文案、无字底图、默认排版 |
| **B** | 仅服装（+ 可选节日） | 默认补模特 / 场景、文案、无字底图 |
| **C** | 一句话活动需求（+ 可选节日 / 尺寸） | 文生营销海报，极简 |
| **D** | 节日 + 至少 1 项 VI / 品牌资产 | 偏创意 / 品牌向海报 |

---

## 第三步：出无字底图

左侧「一键策划并出图」或专业模式出图，先出一张摄影级**无字底图**（推荐「字后加」，重要活动主图更稳）。

---

## 第四步：排版加字

右侧看候选底图 → 点「排版与出图」全屏弹层：

- 左侧画布拖拽文案块；右侧调**对齐、字号、颜色、字体预设**；
- **字效**：投影 / 外发光 / 描边 / 字底衬底；
- 多块文案各自独立，块内回车可换行。

改字 / 改样式后点 **「生成预览」** 核对，再 **「保存并关闭」**。

> 小提示：只改字再合成**不会重新生图**（除非你改了无字提示词或重出底图），省钱省时。

---

## 第五步（高级）：批量出图

展开「批量出图」，每行写一条文案，批量出无字底图（仍需逐张排版合成）。

---

## 做完之后：保存与资产

- 保存进作品库；项目自动存，刷新页面会回到上次项目。
- **品牌素材**：参考位可放 Logo / 服装 / 场景 / 风格 / 品牌 VI；开关「本次使用品牌参考」关掉就不参与。
- **上游导入**：从我的资产选品牌 VI / IP 母版 / 手办分组带入（路径 D 偏品牌向）。

---

## 几个贴心小贴士

- 重要活动主 KV 建议「字后加」（无字底图 + 程序排版），别用字图同出。
- 改字后一定先「生成预览」再保存，否则预览和成图可能不一致。
- 尺寸：1:1 / 3:4 / 9:16 各尺寸**分别生成**，想要多尺寸就分别选。
- 想有品牌感？走路径 D（节日 + 品牌资产）或专业模式导入 VI。
