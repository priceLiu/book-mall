# 主图与套图工具怎么选·使用指南

> 一句话：电商侧栏「主图与套图」分组里有两个入口——**电商产品主图创作** 和 **AI 商品套图**。都出商品图，但工作流深度不同。这篇帮你 30 秒选对。

## 这俩有啥不一样

| 工具 | 干啥的 | 典型场景 |
| --- | --- | --- |
| **电商产品主图创作** | 卖点策略 + 主图文案与配图 | 先定 Brief / 方案 / 购买理由，再出主图；可导入详情 |
| **AI 商品套图** | 白底 / 卖点 / 场景套图 + 可选上架文案 | 结构配张数 → AI 规划槽位 → 白底 + 卖点 + 场景批量出图 |

## 30 秒怎么选

- 想要**营销助手带着走**、主图**每张 Prompt 职责清晰**、做完主图**顺带做详情** → 选 **电商产品主图创作**。
- 想要**上架一套图**（白底 / 卖点 / 场景 / 细节）、用**版式库 / 爆款风格**、可选**上架文案** → 选 **AI 商品套图**。

两个入口**各建各的项目**，不能合并；同一 SKU 可以两个都做。

## 和详情页的关系

- 详情长图分屏可从主图项目**导入 Step0–3**（策略快照）；与 AI 商品套图无直接导入。
- 模块化详情（A+、服装套图等）见「详情页工具怎么选」。
