# 户外对镜自拍 OOTD · 使用指南（小红书风格，落地镜前转身展示穿搭）

> 这篇是写给**已经注册好、登录进去就能用**的你看的。不讲技术，只讲「点哪里、传什么、会出什么」。

---

## 这个功能是干嘛的？

一句话：你给「模特 + 镜前场景 + 服装」，AI 自动生成**小红书风格户外对镜自拍穿搭视频**——模特站在户外落地镜前，自然转身、侧身、整理穿搭，生活化种草质感。

> 侧栏名字叫「**户外对镜自拍**」，认这个名字就能找到。

---

## 开工前：先备好这几样

1. **模特**：三选一 —— 文字创建 / 模特库挑 / 上传模特图。
2. **场景**：三选一，且**必须是镜前类场景**：
   - 文字自定义（如「街边落地镜、午后自然光」）；
   - 场景库挑（街边落地镜 / 商场落地镜 / 小区户外镜 / 咖啡店门口镜）；
   - 上传一张自定义镜子场景图。
3. **服装平铺图**：必填，上传一张。

## 第一步：进对地方

左边菜单点「电商工具箱」→「电商」→「短视频」→「户外对镜自拍」。

---

## 第二步：填好表单

- 选模特（文字创建 / 模特库 / 上传图）。
- 选镜前场景（文字 / 场景库 / 上传图），**记得必须是带镜子的场景**。
- 上传一张服装平铺图。

---

## 第三步：点生成，等出片

点「生成」后系统先做换装融合（强调镜子透视结构正常），再生成一段「镜前自然转身、侧身展示、轻微整理头发 / 衣角」的 OOTD 视频。

---

## 第四步：预览与保存

出片是 **6 秒、9:16** 的户外镜前 OOTD 短视频，预览满意就「保存作品」或导出。

---

## 几个贴心小贴士

- **镜子要正常**：系统会强约束「镜子透视正确、镜像反射逻辑正确」，生成后还会自动校验，异常自动重试——如果还是看到镜子里的脸歪了，重生成一次即可。
- **动作克制**：固定规则是镜前站立、小幅转身、侧身展示，**禁止跑跳、禁止大动作**。
- **户外自然光**：场景选「户外」类镜前场景，成片会更像小红书真实自拍。
- **想改默认文案**：静态融合 / 视频 / 负面提示词都预填好了，可在工作台改，改坏点「恢复系统默认」。
- **贴图感？** 若人物和户外光影不融合显得像贴上去，静态融合词已强调光影匹配，可微调场景描述再生成。
