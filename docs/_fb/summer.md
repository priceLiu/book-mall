Prompt 结构统一：**人物资产 + 环境资产 + [夏日午后缘侧… halation… 35mm 胶片] + 【多分镜时间轴】**（空镜/特写/风扇/指缝阳光/玻璃杯折射/风铃等 **0–18s** 硬切分镜）。

**未接** 单一 `jianying-auto-render-pro2`：成片以 **多节点分别导出** 或在画布外剪辑拼接。

## 4. 复现要点

1. 先做好 **场景 knolling** 与 **服装拆解**，再 **试穿板**（qwen/wan 二选一对比）。  
2. 视频 **每条只写 1～2 个分镜段落**，避免单 Prompt 过长失败。  
3. 保持 **冷调逆光、不发黄** 等负面约束在各镜重复。  
4. 复制后检查 **每个视频 3～4 路 ref** 是否仍指向当前节点 id。
