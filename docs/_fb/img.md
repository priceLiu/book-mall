# 图片处理 · 使用指南（抠图、换底、擦除、重绘、拆层）

> 这篇是写给**已经注册好、登录进去就能用**的你看的。不讲技术，只讲「点哪里、传什么、会出什么」。

---

## 这个功能是干嘛的？

一句话：一个**项目制图台**——你上传主图，换背景、擦掉不要的东西、局部重绘、一键把图拆成图层、框选拆区域，对比预览后导出 PNG 或存进资产库。

做海报、做视频前的修图，都先用它。

---

## 开工前：准备一张主图

1. **进对地方**：左边菜单点「营销」→「图片处理」。
2. **准备主图**：上传 / 从资产库带入 / 剪贴板粘贴都行。

## 第一步：新建项目 + 上传主图

新建或打开项目，上传主图（或从资产库带、粘贴自动带入）。

---

## 第二步：选工具干活

顶栏五个按钮，挑要用的：

| 按钮 | 干什么 |
|------|--------|
| **背景与主体** | 一键抠图换背景（独立进度） |
| **擦除** | 框选 / 笔刷选区，擦掉不要的部分 |
| **局部重绘** | 在蒙版范围内重画（最多 2 框） |
| **AI 图层分离** | 一键把整图自动拆成多个图层 |
| **框选拆分区域** | 框选某块，拆成独立子图层 |
| **图层编辑** | 有图层栈时排序、开关可见、导出合成 |

---

## 第三步：对比预览

处理完左右对比看效果；历史对话框能回看每一步、恢复参数（刷新不丢）。

---

## 第四步：导出 / 存资产

保存弹层写入我的图片库；或直接导出 PNG。

---

## 几个贴心小贴士

- 重绘 / 擦除要**先选区域**（笔刷或框选）再提交；万相 2.7 用框选，Qwen / 万相 painting 用笔刷蒙版，规则不同，看顶栏提示。
- 想做海报？处理完去「海报制作」；做视频去「口播故事版 / 种草视频」。
- 这里就是营销日常修图入口；专门的「AI 海报生成器」已并入海报制作，不用另找。
