## 2. 差异处理记录

### 2.1 HappyHorse 1080P +32s → +47s（抽样完成）

- 厂商 **204s** = 平台按时间排序前 **32 条** 1080P 任务累计秒数。
- 超出部分为 **8/30** 批次新生成（样例 logId）：
  - `cmtf8j03r00lqif0d546kio9n` · `cmtf952zy00vqif0dx7y3vmnk` · `cmtf9531400vsif0den20s88n` · `cmtf9533200vuif0dqldyoebc`（各 8s）
  - 后续又有 `cmtfmr0o6000difo8qmln94fr` 等 3×5s → 平台升至 251s
- 各条均有独立 `externalTaskId`，非平台重复计费；**疑厂商月汇总滞后或未入账**。

### 2.2 wan2.2-s2v

- **代码**：AI Space 合成失败终态写入 `usage.duration`（音频秒）；aggregator 纳入 FAILED + 按 `audio_url` 去重取 max。
- **回填**：`backfill-s2v-video-duration.ts --apply --since=2026-08-01`
- **结果**：23s → **50s**（3 个唯一音频：15+15+20）；厂商 59.3s，差 **9.3s**。

### 2.3 ASR −281s

- aggregator 已按 **fileUrl 去重**（保留 billable 最大秒）。
- 68 唯一 URL · 1,073s；厂商 1,354s。
- ffprobe 回填后 119 条为 16s 档；与 transcription `original_duration` 一致处仍不足。
- **结论**：~281s 暂无 Gateway 日志可映射；后续 ASR 已走 `/api/gw/v1/dashscope/asr/transcribe` 写 `sourceAudioDurationSec`。

### 2.4 text-embedding-v3（已 OK）

- 历史 `assistant:index` 无 Gateway 日志；多次全量重建导致阿里累计 ~258K TOKEN、库内仅 367 chunk（~48.5K）。
- **回填**：`backfill-embedding-gateway-logs-from-chunks.ts --scale=5.334` → 37 批 · **258.676 KTOKEN**。
- **聚合修复**：`billable-units` 识别 embedding 为 KTOKEN；joinKey `tokenDirection=none` 与 CSV 对齐。
