# 平台分享功能 · 使用指南

> **更新日期**：2026-10-04  
> **读者**：所有希望 **邀请好友、分享工作流、公开作品、团队协同或发到社交平台** 的用户。  
> **说明**：平台有多套「分享」，用途不同，不要混用。本文按 **用户操作** 编写；奖励数字与门禁以主站 **「分享与领取说明」** 弹层及 `/account/referral` 为准。

---

## 1. 先搞清：平台里的「分享」有哪几类

| 类型 | 你分享的是什么 | 好友/公众得到什么 | 典型入口 |
|------|----------------|-------------------|----------|
| **邀请好友** | 你的 **8 位邀请码** / 主站链接 / 微信二维码 | 新用户 **注册** 并关联邀请关系 | 主站个人中心「分享得积分」 |
| **工作流分享** | **10 位工作流码** / 主站链接 / 二维码 | 登录后 **领取项目副本**，跳转到画布或电商等 | 画布 / 电商 / 快速复制 内「分享工作流」 |
| **画布门户公开** | 整份 **画布项目** 的展示权限 | 他人在 **发现区** 预览或 **复制到我的画布** | 画布「分享到社区」或「投稿」 |
| **快速复制模板** | **我的作品** 模板（若允许） | 他人在模板墙 **预览 → 复制** | 快速复制工作区/预览弹层 |
| **团队内共享** | 画布 **项目资产** 可见性 | 同团队成员在资产库中 **共用** | 画布项目资产「共享/收回」 |
| **团队加人** | **团队邀请链接**（手机号邀请）或主账号 **「邀请成员体验」** 工作流码 | 好友 **加入团队**，不是拉注册奖励 | 主站团队中心 |
| **一键发布** | 图文/视频 **成品** | 内容发到 **小红书、抖音、微博** 等 | 一键发布门户 / 电商资产库入口 |

下面分章说明每一类 **怎么发、怎么领、谁能用**。

## 2. 邀请好友（8 位邀请码）

### 2.1 适合什么时候用

- 你想让 **还没注册** 的朋友来用平台。
- 你关心的是 **拉新注册**，而不是复制某一份具体项目。

### 2.2 在哪里找到你的邀请码

| 入口 | 操作 |
|------|------|
| **个人中心 · 概览** | 账户卡片上 **「分享得积分」**（团队主账号文案为 **「分享邀请」**）→ 弹层 |
| **个人中心 · 侧栏** | 「订阅与积分」区域的同一分享 action |
| **邀请明细页** | `/account/referral`：8 位码大号展示、复制、统计、邀请列表 |
| **订阅页** | 「去分享」→ **「分享与领取说明」**（规则说明，不跳转） |

弹层与明细页通常提供：

- **8 位邀请码**（口述、复制均可）
- **主站链接**（形如 `https://主站域名/code/xxxxxxxx`）
- **微信二维码**（扫码即打开同一链接）
- 兼容旧链接 **`/r/xxxxxxxx`** 仍可用

### 2.3 你怎么发给好友

- 微信私聊/群：发 **二维码图片** 或 **链接** 或 **直接报 8 位码**。
- 好友也可打开主站 **「兑换分享码」** 页（`/code`），手动输入 8 位码。

### 2.4 好友侧会发生什么

1. 打开链接 / 扫码 / 在 `/code` 输入码。
2. 系统识别为 **邀请码** → 进入 **注册页**（邀请关系自动带上）。
3. 好友完成注册后，按平台规则使用即可。

### 2.5 积分奖励（分享者）

- 好友 **首次订阅或首次充值**（满足平台定义的「首笔付费」）后，邀请人可获得 **邀请奖励积分**（默认 **20 积分/人**，以页面展示为准）。
- 在 **邀请明细** 可查看：已注册人数、待完成（已注册但未付费）、已获积分。
- 奖励为 **积分**，不是现金；到账后可在财务控制台查看流水。

### 2.6 谁可以发邀请码

| 身份 | 能否分享 8 位码 |
|------|-----------------|
| **个人用户**（有效订阅） | ✅ |
| **团队主账号（OWNER）** + 有效团队套餐 | ✅（拉 **团队外** 好友，规则同个人） |
| **团队 ADMIN / 普通成员** | ❌ 不可对外分享 |

团队成员即使有个人订阅，也 **不能** 使用对外邀请码（产品规则）。

## 3. 工作流分享（10 位工作流码）

### 3.1 适合什么时候用

- 你已经做好 **一份可复用的项目**（画布、电商分镜、种草项目等），希望好友 **一键拿到副本** 接着改。
- 你想让同事 **同款工作流** 开干，而不是只看教程。

### 3.2 支持工作流分享的应用

| 应用 | 分享的是什么 | 常见入口位置 |
|------|--------------|--------------|
| **AI 画布** | 整个 **画布项目**（clone 为新项目） | 画布顶栏/工具栏 **分享工作流** |
| **电商工具箱** | 各类 **项目**（见下表） | 项目顶栏 **分享** 图标 |
| **快速复制** | **我的作品** 中的模板 | 预览/工作区 **分享**（须为「我的作品」；运营账号可分享更多） |

**电商工具箱** 当前可分享的项目类型包括（名称以界面为准）：

- 电商口播故事版（分镜项目）
- 电商产品主图 / 详情长图（产品创作项目）
- AI 商品套图
- 服装模特图
- 手办盲盒 SOP、品牌 VI 表情包 SOP
- 种草视频
- 拆图拆视频、专业拉片  
- 资产库中对支持的项目也可发起分享

领取后，好友会进入 **带「分享副本」后缀的新项目**，**不会覆盖** 你的原件。

### 3.3 怎么生成分享码

1. 打开对应 **项目**（已保存）。
2. 点击 **「分享工作流」**（团队主账号可能显示 **「邀请成员体验」**，见 §5）。
3. 在弹层点 **创建链接**（若首次）。
4. 复制 **10 位码**、**主站链接**，或保存 **二维码**。
5. 仍可使用 **兼容长链接** `{子站}/share/w/{token}`，但推荐 **主站 `/code/{10位码}`** 统一兑换。

### 3.4 好友如何领取

1. 扫码或打开 **主站链接** `/code/xxxxxxxxxx`（10 位）。
2. 若 **未登录**：先登录或注册，再自动回到兑换页。
3. 若 **已登录**：系统 **自动 claim**，复制项目并 **跳转到对应应用** 打开副本。
4. 也可在主站 **`/code`** 页手动输入 10 位码。

领取失败时，页面会提示 **「分享码无效或已失效」**（过期、停用、次数上限等）。

### 3.5 积分奖励（工作流 · 个人用户）

对 **个人用户**（非团队主账号的「加成员」模式）：

- 好友领取副本后，需 **首次成功完成一次扣积分的生成**，且 **首笔订阅或充值**，分享者可获 **工作流分享奖励**（默认 **40 积分**，以页面为准）。

### 3.6 邀请 vs 工作流：好友只算一笔奖励

同一好友 **终身只触发一笔** 分享奖励给某一位分享者：

- 若 **先领取工作流** 再注册邀请关系 → 按 **工作流链路**（40 分档）。
- 若 **先通过邀请码注册** 再领工作流 → 按 **邀请链路**（20 分档）。

**先到先得**，不会两笔都发。详情见主站 **「分享与领取说明」**。

## 4. 统一兑换页：主站 `/code`

无论 8 位还是 10 位，**推荐** 都走主站兑换：

| 路径 | 作用 |
|------|------|
| `/code` | 手动输入分享码 |
| `/code/{码}` | 扫码或点链接直达 |

系统会自动判断：

- **8 位** → 去 **注册**（邀请）
- **10 位** → 已登录则 **领取工作流**；未登录则 **登录后回来领取**

无效码统一提示，避免泄露码类型。

## 5. 团队场景：和「分享得积分」不一样

### 5.1 团队主账号 · 工作流 =「邀请成员体验」

若你是 **团队 OWNER**，在工作流分享弹层可能看到 **「邀请成员体验」**：

- 仍是 **10 位码 + 主站链接 + 二维码**。
- 好友领取副本后，系统会尝试将其 **加入你的团队**。
- **不发** 工作流分享积分奖励（目的是 **加成员**，不是对外拉新）。

**团队外** 拉新请仍用 **8 位邀请码**。

### 5.2 团队邀请链接（手机号）

- 入口：**主站团队中心** 按手机号邀请。
- 链接形如 **`/invite/t/{token}?code=...`**，与 8/10 位分享码 **不是同一体系**。
- 用途：**加成员**，不发分享积分。

### 5.3 团队成员（非 OWNER）

- **不能** 使用 8 位邀请码对外分享。
- **不能** 创建工作流分享码。
- 需要使用团队资源时，由 **主账号** 分享或管理员分配。

## 6. AI 画布 · 门户公开（社区 / 精选 / 案例）

这与 **10 位工作流码** 不同：门户公开是让 **陌生人** 在画布 **首页发现区** 看到作品，而不是只发给指定好友。

### 6.1 几种公开方式

| 方式 | 入口 | 是否立刻对外 | 他人怎么用 |
|------|------|--------------|------------|
| **社区模板** | 画布内 **分享到社区** | **是**，立刻出现在「模板」Tab | 预览 → **复制到我的画布** |
| **精选工作流** | 我的画布 → **投稿** → 精选 | **否**，管理员审核 | 通过后出现在「精选」 |
| **案例** | 我的画布 → **投稿** → 案例 | **否**，管理员审核 | 通过后出现在「案例」 |
| **私有模板** | **保存为我的模板** | 否，仅自己 | 自己复用 |

**分镜视频 1.0（sbv1）** 项目还可投稿 **「视频作品」** 等（以投稿弹层选项为准）。

### 6.2 投稿时注意

- 公开内容请 **勿含未授权肖像、商标、私密客户资料**。
- 社区模板 **立即公开**；精选/案例被拒可修改后再次投稿。
- **管理员** 投稿可 **立即生效** 上架（无需审核）。

### 6.3 与工作流分享的区别

| | 门户公开 | 工作流 10 位码 |
|--|----------|----------------|
| 受众 | 发现区 **所有访客/用户** | **知道码的人** |
| 副本 | 他人 **复制** 到新项目 | 好友 **claim 副本** |
| 奖励 | 无分享积分体系 | 可能有 40 分奖励 |

## 7. 快速复制 · 分享模板

- 在 **我的作品** 中，对 **你自己生成** 的模板可 **分享工作流**（10 位码），好友领取后在快速复制 **打开副本**。
- **普通用户** 一般 **不能** 把官方内置示例当作自己的去分享；**运营/管理员** 可分享更多可见模板。
- 领取流程同 §3.4（主站 `/code`）。

---

## 8. 画布 · 团队内共享项目资产

在 **项目资产** 视图中，可将资产设为 **团队共享** 或 **收回为私有**：

- **共享** 后，同团队成员可在团队上下文中 **引用** 该资产（如角色、场景图）。
- 这是 **团队内部协作**，不是对外链接，也不产生邀请/工作流奖励。

## 9. 一键发布（发到社交平台）

**一键发布** 解决的是：把 **做好的一张图、一条视频** 发到 **小红书、抖音、微博、B 站、公众号** 等，属于 **站外分发**，与 **8/10 位分享码** 无关。

### 9.1 你需要准备

- **一键发布** 门户账号（与主站同一用户）。
- **浏览器扩展** 或 **桌面客户端**（多账号矩阵用桌面端）。
- 各平台 **已在浏览器/客户端中登录** 的发布账号。

### 9.2 典型流程

1. 在 **一键发布** 门户或 **电商资产库** 等入口编辑 **标题、正文、话题、封面**。
2. 选择要发的 **平台**。
3. 系统向 Book 申请 **发布任务凭证**，扩展/桌面端 **接管** 在各平台页面完成发布。
4. 发布动作 **不扣创作积分**（与创作生成不同）；使用权限以 **一键发布** 套件准入为准。

### 9.3 注意

- 扩展与桌面端的 **平台登录态不互通**（各装各的）。
- 网页发起的任务以 **网页登录用户** 为准；扩展里若用户不一致会 **拒绝** 并提示。

更多见 `docs/一键发布平台.md`。

## 10. 领取方速查（我是被分享的人）

| 收到的是 | 我该怎么做 |
|----------|------------|
| **8 位邀请码** | 打开主站链接/扫码/`/code` → **注册** → 正常使用；需要时再订阅/充值 |
| **10 位工作流码** | 打开主站链接/扫码/`/code` → **登录**（无号先注册）→ 自动 **打开副本项目** |
| **画布发现区链接** | 打开画布门户 → 预览 → **复制到我的画布**（需登录） |
| **快速复制模板** | 在快速复制里 **预览 → 复制** 到工作区 |
| **团队邀请** | 打开团队邀请链接，按页完成 **加入团队** |

领取工作流后，你的副本 **独立保存**；修改 **不会影响** 分享者的原件。

## 11. 权限与常见报错

| 现象 | 可能原因 | 建议 |
|------|----------|------|
| 找不到「分享得积分」 | 非有效订阅 / 团队成员 | 查看个人中心提示；成员请联系 OWNER |
| 工作流分享创建失败 | 未登录、无权限、项目不存在 | 刷新登录态，确认项目已保存 |
| 「分享码无效或已失效」 | 码错误、过期、停用、领取上限 | 让分享者 **重新生成** |
| 领取后跳错应用 | 资源类型与 app 不匹配 | 重新从主站 `/code` 领取；仍失败联系支持 |
| 没收到奖励积分 | 好友未 **首笔付费** 或未 **首次成功生成**（工作流） | 看邀请明细「待完成」；规则见说明弹层 |
| 团队主账号工作流没积分 | 正常，**邀请成员体验** 不发奖 | 团队外用 8 位码 |

## 12. 内容与合规建议

- 分享的工作流、公开模板、发布到社交平台的内容，须 **拥有版权或使用权**。
- 含 **人脸、品牌 Logo、客户 SKU** 的素材，对外分享前请 **脱敏或取得授权**。
- 不要分享 **账号密码、Gateway Key、厂商 Key**；只分享平台提供的 **邀请码 / 工作流码 / 公开链接**。
