# 三视图提示词方案

> 真源代码：`canvas-web/lib/canvas/three-view-prompt-rules.ts`（book-mall 镜像同步）  
> 全片视觉块：`canvas-web/lib/canvas/story-pro-visual-style-pack.ts` · `formatThreeViewVisualStyleSection`

## 1. 设计原则

| 块 | 来源 | 是否可变 |
|---|---|---|
| 【任务】 | 系统常量 | 否 |
| 【硬性约束 - 必须遵守】 | 系统常量 | 否 |
| 【角色设定：{名} - {身份}】 | 剧本角色表 · `appearance` / `aiImagePrompt` | **是（唯一变量块）** |
| 【全局视觉风格 - {摘要}】 | 大纲 `## 视觉风格总纲` · `StoryProVisualStylePack` | 项目级，非每角色单独写 |
| 英文 turnaround 一行 | 系统常量 | 否 |

**组装顺序（约束先行 → 角色 → 画风 → 英文补强）：**

```
【任务】
【硬性约束】
【角色设定】     ← 剧本生成，可替换
【全局视觉风格】 ← 视觉风格总纲
White-bg turnaround: …
```

**刻意不包含：**

- `性格：` — 对 turnaround 无意义，易引入表情/气质干扰
- `【输出参数】` — 2K / 16:9 / PNG 由三视图节点 **Gateway 参数** 与 `libtv-media-aspect-preset`（profile=`three-view`）控制，不写进 prompt，避免与 API 参数冲突

## 2. 角色设定 · LLM 输出规范

写入角色表 **「外貌/服装」**（及必要时 **「AI生图提示词」**）列：

- 采用 **bullet 列表**（`- 字段：描述`）
- 推荐字段：年龄与身份、发型、面容、服饰、肩甲/配饰、整体材质
- **只写造型**（是什么），不写摄影/画风/场景/道具
- 禁止：性格、情节氛围、背包/手持/挡脸动作
- 与 `THREE_VIEW_APPEARANCE_LLM_RULE_ZH` · `PRO2_GU_FENG_CHARACTER_IMAGE_RULES` 一致

示例见本文 §5。

## 3. 全局视觉风格 · 字段映射

从 `StoryProVisualStylePack`（大纲视觉风格总纲）映射：

| Pack 字段 | 全局块 bullet |
|---|---|
| `visualStyle` | 风格定位；并作为标题摘要 `【全局视觉风格 - …】` |
| `lighting` | 光线设定（缺省则用摄影棚侧逆光模板） |
| `styleAnchorZh` / 摄影相关 | 镜头效果（缺省 35mm f/2.8 浅景深） |
| `colorPalette` | 色调方向 |
| `era` + `worldBackground` | 时代气氛 |
| （固定） | 环境光适配 · 白底摄影棚反射 |

服务端 `prependStoryProStyleAnchor`：若 prompt 已含 `【全局视觉风格】` 或 `【全片视觉` 则 **不再重复 prepend**。

## 4. 运行时链路

1. 剧本 hub 生成角色表 → `appearance` bullet
2. `buildPro2ThreeViewDockPrompt(row, visualPack)` 组装完整 prompt → 写入列 `row.prompt` / Dock
3. 用户 Dock 编辑 → `commitPro2ThreeViewRowPromptFromDock` 写回 `row.prompt`
4. 后端 `runStoryProCharacterRow` 读 `row.prompt`，**不拼** hub 大纲/分镜 markdown
5. Gateway 生图 · aspect 16:9 · 模型参数控制分辨率

## 5. 完整事例（萧景珩 · 摄政王）

以下为 `buildPro2ThreeViewDockPrompt` 组装结果（角色 bullet 来自剧本表，全局视觉来自大纲视觉风格总纲）：

```markdown
【任务】
生成主角的标准三视图设计稿。

【硬性约束 - 必须遵守】
- 仅生成一张图，横向构图，从左到右依次排列 **恰好三个** 全身视角：正面、侧面、背面。
- 三个视角的角色比例、服饰、发型、配色必须完全一致。
- 禁止重复视角；禁止出现分格线、边框、文字标注或网格。
- 背景为纯白色（纯白底，无渐变，无场景，无道具）。
- 角色直立站姿，双臂自然下垂于身体两侧。
- 双手不得触碰面部、遮挡面部，也不得手持或夹带任何物品。
- 只允许穿戴服饰和饰品，不得出现包袋或随身物件。
- 面部表情保持中立（无表情、无笑容），以符合标准三视图的设计规范。

【角色设定：萧景珩 - 摄政王】
- 年龄与身份：24 岁，中国古代王爷，架空唐代风格。
- 发型：乌黑长发，佩戴银色尖刺造型的玄幻冠饰。
- 面容：眉眼深邃冷冽，瓷白冷调肤质，哑光质感。表情中立。
- 服饰：深墨蓝暗青色广袖长袍，绣有银龙暗纹刺绣（正面、侧面、背面的龙纹位置可略有不同，以符合服装裁剪逻辑）。
- 肩甲：金属镂空肩甲，呈现真实金属质感与反光。
- 整体材质：长袍呈现丝绸自然垂坠感，肩甲呈现金属光泽，皮肤呈现真实哑光质感。

【全局视觉风格 - 照片级写实，电影感真人拍摄风格，拒绝二维插画或动漫风格】
- 风格定位：照片级写实，电影感真人拍摄风格，拒绝二维插画或动漫风格
- 光线设定：自然日光感，主光源来自右后方的侧逆光，辅光来自左前方柔和补光，以清晰呈现面部细节。拒绝平光。
- 镜头效果：模拟 35mm 焦距，光圈 f/2.8 的浅景深，带有轻微电影颗粒感
- 色调方向：肤色与织物高光呈现暖金色，金属与阴影区域呈现冷蓝灰色
- 时代气氛：参考架空唐代，唐代美学，春夏之交的温暖感美学，但背景为纯白，因此通过光影和色调传递氛围，不绘制实际场景。
- 环境光适配：由于背景纯白，所有材质（丝绸、金属、皮肤）应反射柔和的白色环境光，呈现摄影棚质感，高光自然不溢出。

White-bg turnaround: front, side, back full-body only; no props in hands, no labels or panel borders.
```

> 分辨率 2K、宽高比 16:9、输出 PNG 由三视图节点 Gateway 参数控制，**不写入 prompt**。
