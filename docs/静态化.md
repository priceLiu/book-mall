## 1. 背景与目标

高流量门户页（主站首页、画布首页等）若每次访问实时查 Prisma / 聚合 Gateway 模型，会占用数据库连接与 API 延迟。目标：

| 目标 | 说明 |
|------|------|
| **预生成** | Cron / 管理后台 / CLI 在业务日（CST）开始前写入当日快照 |
| **读路径轻量** | 用户访问只读 `StaticPageSnapshot` 或 ISR/SSR 缓存，不实时查库 |
| **可运维** | 生成流水 `StaticSnapshotGenerationRun`、管理页手动补生成、公开读 API 供子站 SSR |
| **保留实时例外** | 登录态、个人列表（如画布「最近项目」）仍走实时 API |

---

## 2. 数据模型

| 表 | 说明 |
|----|------|
| `StaticPageSnapshot` | `pageKey` + `dateKey`(CST) 唯一；`payload` Json；`status` READY/FAILED |
| `StaticSnapshotGenerationRun` | 每次生成一条（CRON / ADMIN / CLI） |

**保留策略**：每 `pageKey` 快照保留 **14 天**；流水保留最近 **50 条**。

## 3. 已实施 pageKey

### 3.1 `site-home`（主站首页）

| 区块 | payload 来源 |
|------|----------------|
| Hero 背景 + clips | `dateKey` 确定性 seed + story 视频池 |
| 平台应用 showcase | 静态 gallery + SSO href |
| Gateway 模型市场 | Cron 时 `listPublicMarketShowcaseModels()` |

- **读**：`getSiteHomeSnapshotForRender()` → 当日 READY → 昨日 → fallback  
- **写**：`pnpm --dir book-mall site-home:snapshot-generate`  
- **ISR**：`app/(site)/page.tsx` · `revalidate = 86400`  
- **客户端**：平台卡片 **18s** 视口内轮换；视频 hover 播放  

### 3.2 `canvas-home`（画布门户首页）

| 区块 | payload 来源 |
|------|----------------|
| 精选 / 模板 / 案例 | 门户 Prisma 聚合（与旧 portal API 同源） |
| 分镜视频作品墙 | `listPortalFilmShowcaseMedia()` |

- **读**：canvas-web SSR `fetchCanvasHomeSnapshotServer()` → book-mall `GET /api/public/static-snapshots/canvas-home`  
- **写**：`pnpm --dir book-mall canvas-home:snapshot-generate`  
- **ISR**：`canvas-web/app/page.tsx` · `revalidate = 3600`  

**画布首页例外（仍实时）**：

- `viewer-session`（登录态）
- **最近项目** · `GET /api/canvas/projects`（登录用户）
- 分享成功后 `markRecentProjectsStale()` 主动刷新；提交审核 bump `updatedAt`

**已删除的客户端拉数**（静态化后）：`portal-featured` / `portal-cases` / `public templates` / `portal-film-showcase` 在首页不再请求；发现/视频墙只读快照 context。

## 4. 写路径（生成）

| 入口 | 命令 / 路径 |
|------|-------------|
| Cron | `POST /api/internal/static-snapshots/generate?pageKey=all`（`CRON_SECRET`） |
| 管理后台 | `/admin/static-snapshots` → 主站 / 画布 Tab → 立即生成 |
| CLI | `site-home:snapshot-generate` · `canvas-home:snapshot-generate` |

**Cron 时间**：CST **05:30**（`vercel.json` / CloudBase 定时 HTTP，见 deploy 文档）。

成功后：`revalidatePath('/')`（主站）、公开 API Cache-Control。
