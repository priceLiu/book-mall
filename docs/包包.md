## 前言

本文档为**箱包/包袋类AI电商短视频唯一生产标准规范**，所有口播、分镜、画面、运镜、色调、字幕、运营素材、成片逻辑，均严格遵照本文档执行。

本手册为《服装AI短视频生产规则手册V4.4》的同级独立版本，针对包袋品类完成了全链路专属改造——包括七维参数、六镜职能、五套分镜体系、卖点词库、运镜特写、运营素材方向等，所有规则均已做品类适配。

配套交互流程参照《Skill交互式工作流文档》，本文件为底层生产刚性约束库。


## 一、七维基础参数体系（固定不变）

所有视频生成，必须基于以下七维参数：

1. **性别定位**：男包 / 女包 / 中性
2. **包型品类**：托特包 / 斜挎包 / 单肩包 / 双肩包 / 手提包 / 手拿包 / 腰包 / 水桶包 / 马鞍包 / 波士顿包 / 信封包 / 箱型包 / 饺子包 / 托特购物袋 / 旅行袋 / 电脑包
3. **风格属性**：职场办公 / 日常休闲 / 潮流街头 / 户外机能 / 极简高级 / 温柔气质
4. **档次定位**：平价刚需 / 中端质感 / 高端轻奢
5. **使用场景**：用户自由输入（如：通勤 / 约会 / 出差 / 旅行 / 逛街 / 上学）
6. **发布平台**：淘宝 / 京东 / 拼多多 / 抖音 / 小红书 / 亚马逊 / TikTok Shop / Shopee / Lazada / 速卖通
7. **输出语言**：中文 / 英文 / 西班牙语 / 葡萄牙语 / 阿拉伯语

**强制约束**：
- 所有内容必须严格适配七维参数，禁止通用模板输出。
- **输出语言强制规则**：输出语言选定后，口播文案、字幕、标题、封面词、标签**全部强制同步翻译**为该语言，禁止只翻译口播不翻译运营素材。


## 二、商品卖点双模式生产体系

### 2.1 卖点两种获取模式

**模式1：用户手动输入**

用户可输入零散卖点、短句、关键词。AI自动完成：清洗、去重、归类、润色、精炼、结构化，并自动编号为S01–S0N。

**模式2：AI智能自动生成**

用户指令「AI自动生成」，AI根据：包型 + 风格 + 档次 + 使用场景，自动生成5–8条专属精准卖点，并自动编号为S01–S0N。

**AI自动生成卖点词库参考**（按维度抽取组合）：

| 卖点维度 | 关键词示例 |
|----------|-----------|
| 皮质/面料 | 头层牛皮 / 羊皮 / 帆布 / 尼龙 / 涂层帆布 / PVC / 超纤 / 麂皮 / 鳄鱼纹压花 / 粒面皮 / 荔枝纹 |
| 五金件 | 金色 / 银色 / 枪色 / 做旧 / 抛光 / 拉链顺滑 / 磁扣吸力 / 刻字logo / 定制五金 |
| 容量/结构 | 大容量 / 分层收纳 / 独立电脑仓 / 拉链暗袋 / 钥匙扣位 / 水杯位 / 手机位 / 主仓大开口 |
| 背携方式 | 可斜挎 / 可单肩 / 可手提 / 可双肩 / 可拆卸肩带 / 可调节长度 / 手提肩带两用 |
| 尺寸/重量 | 轻量化 / 小体积 / 大号 / 迷你号 / 刚好装下iPad / 可放13寸电脑 / 自重轻 |
| 耐用性 | 耐磨 / 防水 / 防刮 / 抗污 / 不易变形 / 植鞣革会养色 / 边油加固 |

**极端情况兜底规则**：当用户输入卖点少于3条时，AI自动触发补充追问：「您提供的卖点较少，我将基于当前包型自动补充3条通用卖点，请确认是否采纳。」用户确认后方可进入下一环节。

### 2.2 卖点分层规则（强制）

**核心卖点（2–3条）**

必须写进口播台词，用户听觉强种草。例：可装下13寸电脑 / 整包仅重300g / 头层牛皮

**视觉卖点（3–4条）**

不啰嗦口述，全部通过镜头特写展示：皮质肌理 / 五金logo / 缝线工艺 / 内衬结构 / 容量实测

**辅助卖点（剩余）**

放置于：小红书正文、详情、标签、字幕点缀。

### 2.3 卖点全局强制约束

1. 后续所有口播、分镜、画面、封面、文案必须围绕**定稿卖点**生成
2. 禁止无卖点、通用套话、同质化脚本
3. 每条卖点必须落地，不能只陈列不应用
4. **卖点落地验收机制**：分镜表中必须增设「承载卖点ID」字段（必填），每镜至少绑定1条卖点ID，全片6镜须覆盖全部核心卖点+视觉卖点。最终交付须附带「卖点覆盖率验收清单」，逐镜核对，缺失即判为不合格。


## 三、口播文案生产规范（6套固定结构）

固定配比：2套固定 + 4套动态场景智能生成

**固定两套**

1. **痛点救场型**：解决包包装不下/肩带勒肩/不耐磨/不好搭衣服等日常痛点
2. **质感种草型**：突出皮质、五金、做工、细节、品质感

**动态四套（AI自动适配场景）**

3. 场景价值塑造型（通勤/出差/旅行等场景的价值输出）
4. 氛围审美种草型（颜值即正义，好看就完事了）
5. 实用百搭多穿型（一包多背、一包多搭）
6. 情绪体验穿搭型（背上它心情变好、自信满满）

**口播强制格式**

每套必须包含：方案名称 + 一句话核心叙事 + 完整口播文案。


## 四、六镜分镜全局硬性规则（不变刚性标准）

1. 固定6镜结构
2. 总时长严格**≤30秒**
3. 单镜时长：**3–7秒**，精度0.5秒
4. 短镜≤5.5s：单景别固定，禁止内部变焦
5. 长镜≥6s：允许平缓推拉景别过渡，禁止跳跃变焦
6. **景别顺滑曲线强制执行（6节点，与镜1–镜6完整映射）** ：

| 镜号 | 景别 |
|------|------|
| 镜1 | 全景 / 中全景 |
| 镜2 | 中全景 / 中景 |
| 镜3 | 中近景 / 近景 |
| 镜4 | 近景 / 特写 |
| 镜5 | 中景 |
| 镜6 | 中全景 |

**景别过渡原则**：由远及近再回中，形成视觉呼吸曲线，禁止跳跃式景别切换。

## 六、五套分镜固定版本体系（必须同时产出）

- **A版**：上身携带动感版（模特背着包走路/转身/上下楼梯，展示动态背携效果）
- **B版**：细节均衡全能版（外观 + 上身 + 特写全覆盖，最均衡）
- **C版**：场景氛围极致版（包包融入咖啡馆/办公室/街头/旅行场景，AI动态生成，禁止模板）
- **D版**：真实日常实拍版（生活化使用场景，如取物/放物/开合/收纳展示）
- **E版**：质感细节强化版（皮质肌理 + 五金刻字 + 缝线边油极致特写）


## 七、运镜规范（固定枚举，禁止自创）

**固定可用运镜**：固定静帧、缓慢推近、轻微拉远、左右微摇、跟随平移、慢速环绕、轻微俯拍、轻微仰拍、局部放大聚焦、平稳定格

**场景适配原则**：
- 正式场景（职场/商务）：稳、静、慢推、定格
- 日常场景（休闲/逛街）：轻摇、平移、松弛
- 户外场景（旅行/机能）：灵动、环绕、跟随

**包包专属运镜推荐清单**：

| 运镜 | 适用展示内容 |
|------|-------------|
| 局部放大聚焦 | 五金logo刻字、皮质肌理、缝线细节、内衬标签 |
| 慢速环绕（30°–60°） | 展示包型360度立体感、整体轮廓 |
| 跟随平移 | 模特背着包走路/转身，展示动态效果 |
| 轻微俯拍（15°–30°） | 展示包内结构、分层收纳、开合状态 |
| 平稳定格 | 包 + 手 + 身体完整展示，收尾定妆 |

# AI交互式短视频Skill工作流 V1.0（包包版）


## 一、界面固定架构（永久不变）

1. **右侧：AI交互对话区**——负责：分步提问、参数采集、卖点交互、用户选择、确认节点、流程引导
2. **左侧：可视化展示区**——负责：实时预览、参数面板、卖点清单、口播展示、分镜表格（含卖点ID绑定栏）、运营素材展示

**核心交互铁律**：所有提问、选择、修改、确认 → 全部在右侧；所有内容、成品、预览、表格 → 全部在左侧。


## 二、完整标准化工作流

### 阶段1：分步采集七维基础参数（AI单步提问）
一次只问一个参数，用户确认一步、推进下一步。全部采集完成后，左侧生成「产品参数档案面板」。

### 阶段2：卖点交互采集环节（核心升级）
AI右侧固定话术：
> 「产品基础参数已全部采集完成。接下来我们确定商品核心卖点。你可以：
> 1. 手动输入这款包的卖点（可以零散、可以短句）
> 2. 回复：AI自动生成，我将根据这款包的定位自动生成全套卖点清单」

**分支A：用户手动输入卖点**
AI自动：清洗、去重、归类、润色、结构化。左侧输出定稿卖点清单（编号S01–S0N）。用户可自由增删、修改、确认。

**分支B：用户回复「AI自动生成」**
AI自动根据：包型 + 风格 + 档次 + 使用场景，按卖点词库抽取组合，生成5–8条精准专属卖点，自动编号S01–S0N。左侧展示，用户可修改、删减、确认。

**兜底机制**：若用户输入卖点少于3条，AI在清洗后自动触发补充追问，确认后方可继续。

### 阶段3：卖点确认后强制锁定
AI锁定卖点为全局核心生产依据。后续口播、镜头、特写、封面全部强制植入卖点。分镜表中每镜须标注承载卖点ID，作为验收凭证。

### 阶段4：生成6套差异化口播文案
右侧提示进度，左侧实时展示全套6套文案。右侧引导用户：选择一套口播主干进入分镜生成。

### 阶段5：根据选定口播主干 + 定稿卖点，生成5套六镜分镜
AI全自动产出A/B/C/D/E五套合规分镜。全部卖点自动分配：核心卖点进台词、视觉卖点进镜头特写。

**口播与画面绑定规则**：五套分镜以选定口播为主干文案，允许**E版（质感细节强化版）和C版（场景氛围极致版）** 在固定主干基础上**微调±15%台词**（仅限语气词、场景呼应句），以适应极致特写或氛围长镜。A/B/D版须100%忠实于主干口播。

左侧展示完整分镜表格（按第十二章格式，含卖点ID绑定栏）。

### 阶段6：用户选定最终分镜版本
支持微调：场景、色调、动作、时长、质感强化。

### 阶段7：全自动生成全套运营素材包
标题、封面词、标签、字幕、剪辑节奏、BGM、发布文案。左侧完整展示。

### 阶段8：输出最终完整交付物
整合：参数档案 + 定稿卖点（含编号） + 口播 + 分镜表格（按第十二章格式） + 卖点验收清单（12.3格式） + 全套运营素材。
