# 户外对镜自拍 OOTD 视频

## 1. 产品定位

自动生成**小红书风格户外对镜自拍穿搭视频**：模特站在户外落地镜前，自然转身、侧身、整理穿搭，生活化种草质感。

## 2. 用户输入（极简表单）

1. **模特**（三选一）：文字创建 / 模特库选择 / 上传模特图
2. **场景**（三选一，需为镜前类场景）：
   - 文字自定义（如 "街边落地镜、午后自然光"）
   - 场景库选择（街边落地镜 / 商场落地镜 / 小区户外镜 / 咖啡店门口镜）
   - 上传自定义镜子场景图
3. **服装平铺图**（必填，用户上传）

## 3. 技术链路

```
确定模特 + 确定镜前场景 + 服装图
        ↓
千问Image3.0 / Wan2.7 多图融合：
模特换装 + 镜前场景融合 → 全身静态参考图
（强调镜子透视结构正常）
        ↓
图生视频接口 → 镜前自拍OOTD视频
```

## 4. 视频生成规则（固定）

- 画面比例：9:16；时长：6 秒
- 动作：镜前站立、小幅转身、侧身展示穿搭、轻微整理头发 / 衣角
- 约束：**禁止跑跳、禁止大幅度动作**
- 关键：镜子透视正常、镜像反射逻辑正确、户外自然光氛围

## 5. 提示词（系统默认预填，用户可改）

工作台提供 **静态融合 / 图生视频 / 负面** 三个输入框，初始值为下方默认文案；用户可编辑，支持「恢复系统默认」。

## 5.1 系统默认提示词

**静态融合 Prompt**

```
模特正面全身站立在户外落地镜前，精准还原服装版型与面料细节，保留模特原始五官样貌，完美融合户外场景光影，镜子透视结构正常，高清手机自拍质感。
```

**视频生成 Prompt**

```
9:16竖屏，小红书OOTD对镜自拍，模特在落地镜前自然转身、侧身展示全身穿搭，动作松弛自然，轻微整理头发，户外柔和自然光，画面稳定流畅，生活种草氛围。
```

**负面 Prompt**

```
镜子透视错误，镜像人脸崩坏，镜像人物重复，肢体畸形，大幅度跳动，画面闪烁，脸部变形，多余肢体
```

## 6. 入口与持久化

- **入口**：电商工具箱 → **电商** → **短视频** → **户外对镜自拍**（`/ecom/video/mirror-selfie`）。
- **项目 / 生成记录 / 保存作品**：同简易融合短视频统一规范（deliverable 快照 + 生成记录）。

## 7. 输出结果

- 6 秒 9:16 户外镜前 OOTD 穿搭短视频

## 8. 主要风险与兜底

- 风险（最高）：AI 镜子透视崩坏、镜像人物五官错乱 → 负面词强约束 + 生成后画面校验，异常自动重试
- 风险：人物与户外光影不融合出现 "贴图感" → 静态融合词强调光影匹配
- 降级：同 PRD 一，多图融合失败切 VTON 兜底
