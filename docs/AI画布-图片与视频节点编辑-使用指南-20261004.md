# AI 画布 · 图片节点与视频节点编辑 · 使用指南

> **更新日期**：2026-10-04  
> **读者**：在 **影视专业版 2.0（Pro2）** 或 **分镜视频 1.0（sbv1）** 画布里，用 **图片节点**、**视频合成节点** 做生图、改图、生视频、截帧剪辑的用户。  
> **配套**：[AI画布-使用指南-20261004](./AI画布-使用指南-20261004.md)（门户与 Pro2 阶段）、项目 [使用案例](./canvas/) 系列。

本文只讲 **节点上的可见操作**（顶栏、底部浮动 Dock、局部编辑态）；不涉及计费与 Gateway 配置。

---

## 1. 先认清两类节点

| 用户可见 | 节点类型（系统名） | 典型场景 |
|----------|-------------------|----------|
| **图片节点** | Pro2：`story-pro2-image`；sbv1：`sbv1-image` | 上传/生图、参考融图、分镜静帧 |
| **视频合成节点** | `sbv1-video-engine` | 文/图生视频、参考生视频、动作参考、Pro2 里的分镜成片 |

**共用一套 LibTV 交互**：卡片预览、底部 **浮动输入 Dock**、有结果时 **顶部工具条**。  
Pro2 与 sbv1 的 **图片节点** 外观几乎相同；差异主要是 **Pro2 多「魔术」「宫格切分」**，sbv1 图片顶栏 **没有** 这两项。

**何时出现顶栏？**

- **图片**：节点里 **已有图片**（生成成功或上传完成），且该节点为 **当前唯一选中**（多选时不显示单节点顶栏）。
- **视频**：节点里 **已有视频**（或部分布局下为精简顶栏），同样以 **唯一选中** 为准。

**底部 Dock 何时出现？**

- 选中 **图片节点** 或 **视频合成节点** 时，画布下方会出现 **560×240 左右** 的浮动输入区（拖动节点时 Dock 会暂时隐藏，松手后恢复）。
- 节点在 **媒体打组** 里时，组内小格可能用 **嵌套 Dock**，不占整屏底部。

---

## 2. 图片节点 · 从无到有

### 2.1 空节点（还没有图）

- 卡片中央：**「添加或生成图片」**。
- 可操作：**双击/点击上传**、从本机 **拖入**、在 Dock **粘贴** 图片（多图粘贴会按规则处理）。
- 左侧 **连线入口** `in_image`：上游图片节点的结果会进入 Dock **参考区**，参与编辑或融图。

### 2.2 底部 Dock（生图 / 改图指令）

选中图片节点后，Dock 大致分为：

| 区域 | 作用 |
|------|------|
| **正文输入** | 写提示词；输入 **`@`** 可引用同项目上游 **文本、图片、风格** 等（选中后会出现 **内联小缩略图**） |
| **上游 chip / 参考图条** | 已连线或手动加入的参考图缩略；可悬停看大图，可移除 |
| **风格**（若启用） | 从风格库带入视觉锚点 |
| **模型 · 参数** | **两个按钮** 分开选：**Gateway 图片模型** + **比例 / 清晰度 / 张数** 等（以当前模型支持项为准） |
| **发送** | 无图时一般为 **「生成图片」**；已有结果时为 **「重新生成」**；生成中可 **停止** |

**习惯建议**

- 改图、融图时，先 **连好参考图** 或在正文 **`@` 点选**，再写清楚「保留什么、改什么」。
- 切换选中 **另一个图片节点** 时，Dock 会 **切换为该节点自己的草稿**（不会串台）。

### 2.3 节点标题

- 点击卡片标题可 **内联改名**（如「巴鲁」「场景 A」），便于在 `@` 列表里辨认。

### 2.4 侧面「+」菜单

- 节点左右 **「+」** 可 **生成邻接节点**（下一张图、视频合成、风格库等），并 **自动连线**；具体菜单随 Pro2 / sbv1 版别略有不同。

## 3. 图片节点 · 有图后的顶栏

顶栏浮在卡片 **上方居中**（缩放画布时工具条会随比例调整，便于点击）。

### 3.1 Pro2 与 sbv1 共有

| 按钮 | 作用 |
|------|------|
| **反推提示词** | 用 **Qwen3.8 Max** 读当前图，**新建文本节点** 并写入反推结果（需已有图片） |
| **保存 ▼** | **保存为资产**（写入 **本项目资产库**，供其他节点 `@`）；部分节点还有 **保存到库**（全局姿势/服装等目录）、**私域人像入库**（真人肖像走火山人像库，供合规生视频） |
| **下载** | 下载当前 OSS 图片 |
| **放大预览** | 全屏缩放查看 |
| **复制节点** | 复制 **配置 + 当前结果**，便于做 A/B |

sbv1 图片节点顶栏 **仅上述能力**（无下面 Pro2 专有项）。

### 3.2 仅 Pro2 图片节点

| 按钮 | 作用 |
|------|------|
| **全景** / **多角度** | 当前为 **「即将推出」** 提示，尚未接入 |
| **魔术 ▼** | 见 §4 |
| **宫格切分 ▼** | 见 §5 |
| **智能编辑**（魔杖图标） | **「即将推出」** |

---

## 4. 魔术菜单（Pro2 图片 · 有图）

路径：**顶栏 → 魔术 ▼**。分两类行为：

### 4.1 在 **当前节点上** 进入编辑态（不新建节点）

| 菜单项 | 你怎么做 | 结果 |
|--------|----------|------|
| **重绘** | 进入 **局部重绘**：笔刷 / 橡皮 / **框选**、撤销重做；涂好或框选后在 **底部 Dock 发送** | 按蒙版区域重生成 |
| **擦除** | 同上工具条，固定 **擦除** 语义 | 去掉涂抹区域内容并补背景 |
| **裁剪** | 进入 **裁剪画布**，选比例后确认 | 更新为裁剪后图片 |
| **扩图** | 进入 **扩图画布**，拖外框扩大画幅，Dock 里设张数/分辨率后生成 | 向外补全画面 |

重绘/擦除时，卡片上会出现 **半透明工具条**（笔刷粗细滑条等）；点 **×** 退出编辑态。

### 4.2 在 **右侧新建** 图片节点并连线

| 菜单项 | 行为 |
|--------|------|
| **高清** | 新建节点，Dock 预填超分指令，参考当前图 |
| **去全图水印** | 新建节点并 **自动发起一次生成**（万相类编辑模型） |
| **抠图** | 新建节点，预填抠主体 Prompt |
| **扩图**（菜单项） | 也可走 **spawn 邻节点** 路线；与 §4.1「原位扩图」二选一按习惯使用 |

新节点会自动 **连 `in_image`**，参考图出现在 Dock 上游区。

---

## 5. 宫格切分（Pro2 图片 · 有图）

路径：**顶栏 → 宫格切分 ▼** → 选预设（如 2×2、3×3）或 **自定义列×行**。

进入 **宫格选择态** 后：

- 在图上 **点选格子**（顶栏显示 **已选 N**）。
- **Esc** 或顶栏 **返回** 图标：退出宫格模式。

| 按钮 | 作用 |
|------|------|
| **扩图** | 对 **已选格子** 批量扩图 |
| **创建分镜组** | 把选中格 **打成媒体组**，便于分镜流水线 |
| **生成高清图片 ▼** | 对已选格做 **2倍 / 4倍** 等超分（以下拉为准） |

适合：**一张多宫格分镜大图** 拆成多镜、或选中几格单独高清/扩图。

## 6. 视频合成节点 · 连线与 Dock

### 6.1 节点上的连接点

| 入口 | 连什么 | 典型用途 |
|------|--------|----------|
| **文本** `in_text` | 文本 / 脚本节点 | 分镜描述、对白、拆解后的段落 |
| **参考** `in_ref` | 图片节点（部分模型也接 **动作视频**） | 角色脸、服装、场景；**全能参考** 多图 |
| **动作视频** `in_motion_video` | 其它 **视频** 节点 | **动作迁移 / Motion Control**：保留运镜与节奏，换人物或换装 |

连线后，Dock **参考条** 会显示缩略；Prompt 里也可 **`@`** 点名上游。

### 6.2 底部 Dock

| 区域 | 作用 |
|------|------|
| **Prompt** | 描述镜头、运动、对白氛围；**`@`** 引用上游图/文/视频 |
| **模式 chip 栏** | 随模型变化：**文生视频**、**图生视频**、**首尾帧** 等快捷模式 |
| **参考模式**（参数里） | 常见：**全能参考**（多图身份/场景）、**首尾帧**（起止画面过渡）、部分模型有 **智能多帧** |
| **模型 · 参数** | **视频模型** + **比例、分辨率、时长、有声/无声、水印** 等（以 Gateway 登记为准） |
| **发送** | 无片：**生成视频**；已有片：**重新生成视频**（有时允许空 Prompt 仅重跑） |

**空节点快捷标签**（视配置）：如 **图参考生视频**、**参考音频生视频** 等，点选会预填模式。

**真人 / 肖像**：若模型要求人像库，可能弹出 **活体校验** 或提示 **私域人像入库**（先在图片节点顶栏入库）。

## 7. 视频节点 · 有片后的顶栏

| 按钮 | 作用 | 前提 |
|------|------|------|
| **裁剪** | 打开 **时间轴裁剪 Dock**，选入出点，确认后得到 **新片段**（可 spawn 新节点） | 已有成片 URL |
| **截帧 ▼** | **首帧** / **尾帧** / **自定义帧…**（自定义打开裁剪 Dock 的选帧模式） | 同上 |
| **高清** | **即将推出** | — |
| **反推提示词** | 同图片，建文本节点写视频描述 | 有预览 |
| **提取字幕** | ASR 生成 **带时间轴 SRT**，并 spawn **文本节点** | 有音频的成片 |
| **智能去字幕** | 按钮 **灰色禁用**（尚未上线） | — |
| **音频分离 ▼** | **去原音**（静音轨）或 **音频分离**（抽出音轨供下游） | 有片 |
| **保存为资产** | 写入项目资产库 | 有预览 |
| **下载 / 放大预览 / 复制节点** | 同图片逻辑 | — |

卡片上 **播放** 钮：在节点内预览；**放大预览** 走全屏播放器。

---

## 8. 视频裁剪 / 截帧 Dock（时间轴）

从顶栏 **裁剪** 或 **截帧 → 自定义帧** 进入：

- 底部出现 **片段编辑器**：拖动 **入点 / 出点**，或移动播放头。
- **确认** 后：裁剪 → 新视频结果；截帧 → 新建 **图片节点** 承载该帧（便于再进生图/生视频链）。

生成中请勿重复点顶栏，等待当前任务结束。

---

## 9. 打组与批量（多图 / 多视频）

框选多个媒体节点 **打组** 后，组顶栏常见：

- **批量重新生成**、**重排顺序**、**组名/颜色**、**批量下载**、**保存为资产**、**解组**。

组内 **单个格子** 仍可选中，使用 §2～§7 的单节点能力；批量操作只影响组顶栏勾选的范围。

---

## 10. 画布级：历史与生成记录

与「节点内多版本切换」不同，整项目级找回方式：

| 入口 | 作用 |
|------|------|
| **我的历史** | 恢复 **画布快照**（自动保存 / 手动保存） |
| **生成记录** | 按 **节点** 查看每次 AI 任务成功/失败、模型与参数；节点删了也可从这里找线索 |

若节点提示链接过期，可尝试 **重新生成**，或从 **生成记录 / 历史** 找当时版本。

## 11. Pro2 分镜格 / 特殊布局说明

- Pro2 **分镜板组** 内的 **视频格** 可能挂载 **精简顶栏**（预览、下载、复制等），**裁剪/截帧/反推** 等以界面实际按钮为准。
- **三视图、角色、场景** 等专用节点：Dock 文案与占位符不同，但 **模型+参数双钮、@ 引用、发送** 逻辑与图片节点一致。

## 13. 常见问题

**Q：点了顶栏没反应？**  
A：确认 **已选中且仅选中一个节点**、**已有图/片**；裁剪截帧类需 **生成已完成** 且有有效 URL。

**Q：`@` 和连线参考有什么区别？**  
A：**连线** 决定模型实际收到的参考素材列表；**`@`** 主要在 Prompt 里 **点名**（全能参考模式下，多图仍通常 **全部提交**，以当前模型规则为准）。

**Q：魔术「扩图」有两种？**  
A：**原位扩图**（当前节点上拖框）与 **魔术菜单 spawn 新节点** 两种入口，效果都是向外补画，按是否想保留原节点分支选择。

**Q：sbv1 项目里能用 Pro2 魔术吗？**  
A：**不能**；魔术 / 宫格仅 **Pro2 的 story-pro2-image**。

**Q：为什么智能编辑、全景、视频高清是灰的？**  
A：尚未上线或 **即将推出**，以弹窗提示为准。
