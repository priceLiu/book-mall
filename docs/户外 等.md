# 鞋子 / 珠宝 / 户外用品 / 家居服 · AI 短视频生产规则（合订 MVP）

> 四个 **独立品类**，界面分入口；本文档仅作产品与 config 对齐参考。  
> 硬性约束：总时长 ≤30 秒，固定 6 镜；单镜 3–7s（0.5s 精度）。

---

## 一、鞋子（footwear）

**子类**：运动鞋、休闲鞋、板鞋、靴、凉鞋、拖鞋、童鞋、功能鞋（防滑/劳保）。

**六镜**：镜1 场景痛点（磨脚/不跟脚/显矮）→ 镜2 全貌 → 镜3 材质/鞋底/缝线 → 镜4 **上脚走步/弯折** 核心演示 → 镜5 穿搭场景 → 镜6 定格种草。

**口播 6 型**：痛点救场、缓震舒适、场景百搭、质感做工、功能防护、情绪自信。

**五版**：A 上脚动感 / B 均衡 / C 街头场景 / D 日常实拍 / E 鞋底工艺特写。

**铁律**：必须上脚或手捏弯折演示，禁止纯静物摆拍。

---

## 二、珠宝（jewelry）

**子类**：戒指、项链、耳饰、手链、吊坠、胸针、手表（饰品向）。

**六镜**：镜1 送礼/穿搭痛点 → 镜2 全貌/礼盒 → 镜3 微距材质/镶嵌/刻字 → 镜4 **佩戴展示**（手/颈/耳）→ 镜5 场景氛围 → 镜6 定格。

**口播 6 型**：痛点救场、设计美学、场景仪式、工艺细节、百搭叠戴、情绪表达。

**五版**：A 佩戴特写 / B 均衡 / C 氛围光影 / D 日常实拍 / E 工艺微距。

**铁律**：禁止夸大保值、疗效、医疗功效；禁止虚假证书表述。

---

## 三、户外用品（outdoor_gear）

**子类**：帐篷、睡袋、登山杖、户外炉具、露营灯、背包（户外）、户外穿戴、水具。

**六镜**：镜1 户外痛点（负重/难搭/不防风）→ 镜2 全貌 → 镜3 材质/结构细节 → 镜4 **功能实操**（搭建/收纳/点火/挂载）→ 镜5 真实户外场景 → 镜6 定格。

**口播 6 型**：痛点救场、硬核功能、轻量便携、场景沉浸、耐用实测、情绪自由。

**五版**：A 实操演示 / B 均衡 / C 山野氛围 / D 真实露营实拍 / E 结构工艺。

**铁律**：必须功能演示，禁止仅风景无产品。

---

## 四、家居服（loungewear）

**子类**：睡衣套装、家居套装、浴袍、睡裙、居家开衫、软家居裤。

**六镜**：镜1 居家痛点（不服帖/不透气/丑睡衣）→ 镜2 全貌平铺/挂拍 → 镜3 面料/走线特写 → 镜4 **上身居家状态**（坐/伸展/走动）→ 镜5 卧室/客厅场景 → 镜6 治愈定格。

**口播 6 型**：痛点救场、亲肤舒适、场景居家、质感种草、百搭外穿、情绪放松。

**五版**：A 上身治愈 / B 均衡 / C 暖光氛围 / D 居家实拍 / E 面料特写。

**铁律**：与「服装专业版」分入口；强调居家软感，非正式通勤穿搭。
