# ⑥鞋子品类｜AI 短视频生产规则手册 V1.0

> 
> 独立品类，禁止套用服装上身、包包挎背、厨具、3C、母婴逻辑；总时长≤30s，固定 6 镜；单镜 3‑7s，精度 0.5s

## 一、适用范围

运动鞋、老爹鞋、板鞋、皮鞋、乐福鞋、马丁靴、凉鞋、拖鞋、老爹鞋、小白鞋、登山鞋、女鞋男鞋童鞋；鞋类配件鞋垫鞋套。
核心特质：**上脚脚感、版型鞋楦、鞋底回弹、耐磨、透气、重量、搭配、舒适度**。

## 二、鞋子专属六维参数体系

1. 鞋子子类：板鞋、运动鞋、老爹鞋、皮鞋、马丁靴、凉鞋、拖鞋、登山鞋、小白鞋、帆布鞋、童鞋
2. 核心功能属性：轻便软底、回弹缓震、透气不闷脚、防滑耐磨、显脚小、不磨脚、久走不累、增高、防水
3. 外观风格：休闲简约、潮流街头、商务通勤、甜酷机车、复古风、户外机能、轻奢高级
4. 档次定位：平价刚需 / 中端质感 / 高端精品
5. 使用场景：日常通勤、逛街走路、运动健身、户外出行、上班商务、居家、约会穿搭、学生校园
6. 销售平台 & 语言：淘宝 / 京东 / 拼多多 / 抖音 / 小红书 / TikTok Shop/Shopee；中文、英文、西语、葡语、阿拉伯语

## 三、卖点双模式体系

模式 A 用户手动输入；模式 B AI 自动生成 5‑8 条卖点
- 核心卖点 2‑3 条（进口播）：轻便软底、缓震回弹、防滑耐磨、透气不闷脚、久走不累、显脚型
- 视觉卖点 3‑4 条（镜头必须演示）：鞋底弯折测试、上脚效果、按压鞋底回弹、鞋面材质特写、防滑摩擦演示
- 辅助卖点（字幕 / 标签 / 文案）：多配色、尺码齐全、百搭好搭、送礼

> 
> 禁令：不能医疗夸大，不说矫正脚型、治疗扁平足等医疗话术

## 四、6 套口播文案

1. 痛点救场型：磨脚、走路脚疼、闷脚臭脚、鞋子笨重、显脚大
2. 脚感体验型：主打软底回弹，久走不累，聚焦上脚感受
3. 版型穿搭型：显脚小，百搭各种裤子裙子，日常好搭配
4. 材质工艺型：鞋面做工、鞋底耐磨防滑，用料质感
5. 场景价值型：通勤、逛街、运动，多场景适配
6. 情绪种草型：舒服又好看，出门不用纠结穿鞋

## 五、鞋子六镜固定职能

镜 1｜痛点引入镜：走路脚累、旧鞋磨脚、穿鞋臃肿显脚大场景
镜 2｜产品全貌镜：鞋子完整外观，多角度展示鞋型配色
镜 3｜材质工艺特写镜：鞋面纹理、鞋口、鞋底纹路、鞋楦细节
镜 4｜核心功能演示镜【核心镜头】：弯折鞋底、按压回弹、防滑测试；**真人上脚局部，禁止只静物摆拍**
镜 5｜场景上脚实穿镜：走路、站立，搭配裤子裙子，真实场景行走
镜 6｜收尾定格镜：鞋子摆放 / 上脚定格，干净高级画面

## 六、5 套分镜版本

A 版｜脚感测试流量版：重点弯折、回弹、防滑测试，强短视频流量
B 版｜细节均衡全能版：鞋型 + 材质 + 测试 + 上脚，绝大多数鞋子通用
C 版｜潮流穿搭氛围感版：侧重搭配、街景，潮流板鞋老爹鞋适用
D 版｜生活化实拍版：普通人随手实拍，弱化广告，通勤休闲鞋拖鞋
E 版｜质感工艺强化版：皮质皮鞋、高端鞋款，微距做工质感

## 七、运镜 & 色调

推荐运镜：固定机位，缓慢推近，俯拍鞋型，侧拍上脚，局部放大鞋底，小幅度环绕；禁止剧烈晃动
色调：
休闲潮流：干净明亮，低饱和；商务皮鞋：冷调高级；户外鞋：自然环境写实

## 八、字段字数约束

画面场景 12‑25｜人物动作 10‑22｜产品重点 10‑22｜口播 15‑40｜色调质感 12‑25

## 九、运营素材包

10 个爆款标题；3 套封面提示词（上脚效果、鞋底测试、鞋型颜值）；标签 #鞋子推荐 #好穿的鞋子 #软底鞋；字幕圆润无衬线，高亮：软底、回弹、防滑、透气；BGM：轻快流行、街头轻节奏；发布正文模板。

## 十、鞋子专属禁令

1. 禁止复用其他品类脚本逻辑；2. 禁止只静物摆拍，必须有上脚或者鞋底功能演示；3. 严禁医疗功效宣传，不做矫正、治病描述；4. 卖点要区分 “脚感” 而不是只讲外观好看。

# ⑦珠宝品类｜AI 短视频生产规则手册 V1.0

## 二、珠宝六维参数体系

1. 珠宝子类：耳饰、项链、手链手镯、戒指、吊坠、首饰套组、玉石配饰
2. 核心功能属性：不易掉色、不易过敏、精致小巧、显气质、可叠戴、简约百搭、送礼佳品

4. 档次定位：平价配饰 / 中端轻奢 / 高端贵重珠宝
5. 使用场景：日常通勤、约会聚会、宴会礼服、节日送礼、国风穿搭、通勤职场

## 三、卖点分层

## 四、6 套口播文案

1. 痛点救场型：戴首饰过敏、款式浮夸日常戴不了、容易掉色
2. 质感光泽型：主打金属光泽，做工细节
3. 佩戴氛围感型：戴上提升气质，简单穿搭点睛
4. 叠戴搭配型：单戴好看，叠戴更出彩

6. 情绪审美型：小小首饰提升一整天好心情

## 五、珠宝六镜

镜 1｜痛点引入：普通首饰掉色、款式太夸张不适合日常
镜 2｜产品全貌：首饰完整形态，礼盒 / 本体展示
镜 3｜微距工艺特写【核心镜头】：金属反光、纹理、刻字、宝石切面微距
镜 4｜佩戴实操镜头：手部 / 耳部 / 颈部佩戴，上手操作，拿取佩戴
镜 5｜真人佩戴场景镜：通勤、约会穿搭，搭配衣服佩戴效果
镜 6｜柔光定格：首饰柔和光影下静态高级定格

## 六、五套分镜

A 版｜光泽微距流量版：大量特写反光，突出质感；短视频高点击率
B 版｜细节均衡全能版：全貌 + 微距 + 佩戴，大部分配饰通用
C 版｜氛围感穿搭版：侧重搭配穿搭，适合项链耳饰
D 版｜生活化实拍版：居家随手拍，平价配饰弱化广告
E 版｜高端贵重质感版：柔和柔光、礼盒、高级布景，黄金 K 金玉石

运镜：慢推、微距聚焦、缓慢小环绕、固定静帧；禁止大幅度晃动
色调：轻奢冷银调；黄金暖柔光；新中式低饱和国风；背景简洁干净，杜绝杂乱背景。
