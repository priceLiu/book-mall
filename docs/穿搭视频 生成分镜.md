# 完整业务流程：拉片结束后 → 上传模特服装图 → 识别服装 → 分镜自适应改写 → 视频生成

前置前提：
爆款样片已经完成拉片拆解，输出一组**4 秒单段原始分镜模板数组**；模板内固化：机位、运镜、背景、色调、总走位、镜头起止大体姿态、单段时长固定 4s；**模板只作为骨架，不直接用于生成视频**。

## 整体完整链路（含「用户填写卖点 / 用户不填写卖点」双分支逻辑）

1. 用户端操作：上传模特上身服装参考图 +【卖点输入框（选填）】
   - 情况 A：用户主动填写服装卖点（例如：垂感面料、收腰显高、抗皱、显瘦）
   - 情况 B：用户**不填卖点、留空**，由 AI 根据图片识别服装特征自动推导最优展示卖点
2. 视觉识别模块：对上传图片做服装结构化解析，输出固定结构化文本
3. LLM 分镜改写模块输入三样数据：**原始 4s 分镜模板 + 视觉识别服装结构化结果 + 用户卖点字段**
   - 分支 A（有用户卖点）：**优先以用户指定卖点为第一目标**微调动作，识别信息作为版型约束底线，避免动作和衣服冲突
   - 分支 B（无用户卖点）：完全基于视觉识别出的版型、面料、剪裁、结构亮点自动推导展示重点，设计适配动作
4. LLM 按照强约束规则改写分镜：**镜头骨架 100% 保留，仅微调细节动作、身体角度、手部姿态、画面焦点**，输出标准化 JSON 最终分镜
5. 最终分镜 JSON + 用户上传模特参考图，送入 AI 视频生成模型
6. 分段生成每一段 4s 视频片段，拼接成片、导出

---

## 步骤详细拆解（每一步输入、处理逻辑、输出、双分支判断）

### 步骤 1｜用户输入层

输入：

- 素材：模特上身服装图片（1 张或多张）
- 选填字段：`user_sell_point`
  - A：用户填写内容：`user_sell_point="高腰剪裁，显腿长，垂感好"`
  - B：用户未填写：`user_sell_point=""`
  业务规则：前端空值统一传给后端字符串**无**，方便大模型判断分支。

> 
> 输入不直接传给 LLM；图片先走独立视觉识别模型。

### 步骤 2｜视觉识别：服装结构化解析（图→文字）

视觉模型输出固定 5 类结构化信息，字段固定，下游 LLM 读取这一段文本，**不再读图**
输出字段：

1. 品类：连衣裙 / 西装外套 / 阔腿牛仔裤 / 针织上衣等
2. 版型：宽松 / 修身 / 直筒 / A 字 / 收腰 / 微喇 / Oversize
3. 面料 & 物理特性：硬挺西装料、软糯针织、垂感雪纺、耐磨牛仔、易皱等
4. 外观细节：颜色、花色、特殊结构（翻领、开叉、腰带、泡泡袖、荷叶边）
5. 动作约束（自动推导禁忌）：

> 
> 示例识别输出

```
品类：长款A字西装连衣裙
版型：腰部微收、下摆A字宽松、中长款
面料：哑光西装面料，偏硬挺、不易大面积飘动
外观细节：黑色、翻领设计、腰带收腰、后侧开叉
动作禁忌：避免剧烈转圈、大幅度跳跃、深度下蹲；动作舒缓，展示腰线和裙摆自然垂感
自动推导天然卖点：收腰显瘦、版型利落通勤、垂坠下摆
```

👉 这里的**自动推导天然卖点**就是【用户不填卖点】时 AI 使用的展示重点。

### 步骤 3｜LLM 分镜改写核心逻辑（双分支判断，最重要）

#### LLM 三份输入：

① 原始单段 4s 拉片分镜模板（镜头、运镜、背景、光影、原始动作、4s 时长、起止姿态）
② 步骤 2 完整服装结构化识别结果
③ `user_sell_point` 用户卖点（值：用户文字 / "无"）

#### 内置判断逻辑

- **分支 A：user_sell_point ≠ 无（用户提供卖点）**
最高优先级：所有微调动作围绕**用户给出卖点**设计；
第二约束：必须遵守视觉识别给出的版型、面料、动作禁忌，不能出现违背服装物理的动作；
例：用户卖点是「后背蝴蝶结设计」，那微调动作就增加侧身、轻微转头展示后背；同时不能做大幅度扭身导致衣服形变崩坏。
- **分支 B：user_sell_point = 无（用户未提供卖点）**
完全使用视觉识别里【自动推导天然卖点】作为展示核心；
根据版型、面料、禁忌自主设计动作；
例：识别出垂感雪纺长裙，自动设计缓慢转身、轻轻抬手让裙摆自然晃动，突出面料垂感。

#### 全局强制不变规则（两条分支通用，绝不允许改动）

> 
> 原始分镜里以下内容**原样保留，不做任何修改**
> 镜头机位、运镜方式（推 / 拉 / 摇 / 固定）、背景环境、画面色调光线、4 秒时长、模特整体走位、镜头开始与结束的大体身体朝向。
> **只允许修改：**
> 模特细微肢体动作、身体旋转角度、手部摆放、头部转向、视线、画面对焦位置；
> 改动目的：突出卖点，规避动作禁忌，防止 AI 视频穿模、布料扭曲。

#### LLM 输出：标准化 JSON 单条 4s 最终分镜

```
{
"original_storyboard":"原始拉片4s分镜原文",
"cloth_analyse":"视觉识别服装完整总结",
"user_sell_point":"用户填写内容/用户未提供卖点，AI基于服装特征自动推导展示重点：xxx",
"mode":"A-用户指定卖点模式 / B-AI自动识别卖点模式",
"adjust_logic":"说明哪些镜头完全保留、动作哪里微调、调整原因、如何突出卖点、规避哪些版型风险",
"final_storyboard":"最终可直接给视频AI的4s画面完整描述",
"positive_prompt":"正向视频生成提示词，光影延续原片，面料真实，动作自然",
"negative_prompt":"肢体畸形、人脸漂移、服装穿模、布料诡异变形、画面闪烁、模糊、曝光异常"
}
```

### 步骤 4｜视频生成层

输入：

1. 上面 JSON 中`final_storyboard`、正向、负面提示词
2. 用户上传模特参考图（人物形象锁定）
业务二选一：

- 模式 1：模特人脸不变，更换为本套识别出的新款服装（固定模特上新）
- 模式 2：人物全部重绘，新模特 + 新款服装（批量不同模特种草）
输出：单段 4s 短视频。

### 步骤 5｜片段拼接

把所有改写后的 4s 分镜生成视频按原模板顺序拼接，得到完整成片。

# 定稿完整版【LLM 常驻系统提示词】（可以直接放进后端，生产可用）

```
#角色
你是专业电商穿搭短视频分镜优化专家，任务是基于拉片原始4秒分镜模板、服装图片识别信息、用户选填卖点，输出适配新款服装的优化后分镜脚本。
#输入说明
输入共三部分：
1.原始4s拉片分镜模板：镜头、运镜、背景、光影、原始动作、4s时长、镜头起止大体姿态；本模板为镜头骨架，镜头信息禁止修改。
2.服装视觉识别结构化信息：品类、版型、面料、外观细节、动作禁忌、AI自动推导天然卖点。
3.user_sell_point：用户选填卖点，值为【无】代表用户没有输入卖点。

#双分支业务规则
分支A：当user_sell_point != "无"【用户提供卖点】
1.优化动作的第一目标：突出用户指定卖点；
2.第二约束：严格遵守识别出的服装版型、面料、动作禁忌，动作不能违背衣服物理特性；
3.镜头骨架完全保留，仅微调手部、转身、身体倾斜、头部角度等细节动作。

分支B：当user_sell_point == "无"【用户未提供卖点】
1.以视觉识别模块给出的【AI自动推导天然卖点】作为展示核心；
2.根据版型面料自主设计合理动作，扬长避短，规避动作禁忌；
3.镜头骨架完全保留，仅微调细节动作。

#通用硬性约束（两条分支都必须遵守）
1.严禁修改：机位、运镜、背景、色调、4秒时长、模特整体移动路线、镜头首尾大体朝向；
2.只能微调局部肢体动作，不能彻底推翻原版动作逻辑；
3.动作幅度匹配面料：硬挺面料动作舒缓；垂感面料可小幅晃动展示质感；紧身款动作收敛；长款服饰避免大跨步下蹲；
4.输出严格JSON格式，不要任何解释、开场白、多余文字；
5.字段mode标记当前是A模式还是B模式；
6.正向、负面提示词适配视频生成，重点规避穿模、布料畸变、人物崩坏。

#固定输出JSON字段
{
"original_storyboard":"",
"cloth_analyse":"",
"user_sell_point":"",
"mode":"",
"adjust_logic":"",
"final_storyboard":"",
"positive_prompt":"",
"negative_prompt":""
}

#本次动态输入
原始拉片分镜：{{原始4s分镜文本}}
服装识别信息：{{视觉模型返回的结构化文字}}
用户卖点：{{user_sell_point}}
```
