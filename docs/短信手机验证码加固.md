## 1. 背景

2026-08-25 公网 IP `195.178.110.242` 对 **电商工具箱**（`ecom.ai-code8.com`）约 2 分钟内发起 198 次 GET 扫描（WordPress / `.env` 等）。排查结论：

| 项 | 结论 |
|---|---|
| 是否已被利用 | **否** — 无登录、无发短信、生图 API 仍要 token |
| 真实风险 | 门户 **短信 BFF 无图形验证码**、**密码登录无失败锁定**、短信 IP 限额按 **子站出口 IP** 共用 |

本次加固：**不阻断扫描 PV 统计**，但标明扫描路径；同时收紧登录/短信滥用面。

## 2. 已实现能力（代码）

### 2.1 门户 BFF → Book 真实客户端 IP

各子站 `/api/auth/login`、`/api/auth/sms/send` 经 `portal-auth-bff` 转发时写入请求头：

```http
x-platform-client-ip: <浏览器 IP>
```

Book 侧 `portalClientIpFromRequest()` 仅在 **Bearer `TOOLS_SSO_SERVER_SECRET`** 的门户接口信任该头（`/api/sso/portal/verify`、`/api/sso/portal/sms/send`）。

**涉及子站**：`e-commerce-toolkit`、`canvas-web`、`story-web`、`quick-replica-web`、`common-tools`、`publisher-web`；`gateway-web` 短信/登录代理同理。

### 2.2 密码登录失败限速

实现：`book-mall/lib/auth/auth-throttle.ts` · `login-with-throttle.ts`

| 维度 | 窗口 | 上限 | 触发后 |
|---|---|---|---|
| 同一 IP | 15 分钟 | 20 次失败 | 429，再封 15 分钟 |
| 同一手机号 | 15 分钟 | 8 次失败 | 429，再封 15 分钟 |

**接入点**：

- Book NextAuth `authorize`（主站 `/login`）
- `POST /api/sso/portal/verify`（各门户 BFF）
- `POST /api/sso/client/login`（扩展/桌面客户端）
- `POST /api/gateway/auth/login`（Gateway 邮箱密码，按 IP + email）

`autologin` 票据登录 **不计入** 失败窗口。

### 2.3 短信突发限速（在原有日限额之上）

原有（不变）：同号 60s 冷却、10 条/日/手机号、30 条/日/IP。

新增：**同一 IP 10 分钟内最多 8 次** `issueSmsCode`（含门户 BFF 路径）。

实现：`consumeRateLimit('sms:ip:…', SMS_BURST_IP)` in `sms-verification-service.ts`。

### 2.4 生产关闭 SSO 配置探针

`GET /api/sso-config-health` 在 `NODE_ENV=production` 返回 **404**：

- `e-commerce-toolkit`
- `story-web`

本地 dev 仍可用；`sso-error` 页文案已注明。

### 2.5 访问统计：扫描路径仍计 PV，另标「扫描」

（与短信加固同批上线，便于看清扫描流量）

| 字段 | 说明 |
|---|---|
| `SiteTrafficDaily.probeViews` | 日汇总中扫描次数（仍计入 `pageViews`） |
| `SiteTrafficIpDaily.probeHitCount` | IP 明细中扫描次数 |
| 后台 | `/admin/traffic` 类型列：**正常 / 扫描 / 混合** |

路径判定：`shared/platform-traffic/classify-traffic-path.ts`（`wp-admin`、`/.env`、`*.php` 等）。

迁移：`20260825040000_site_traffic_probe_views`。

## 3. 限速与验证码路径对照

| 入口 | 图形验证码 | IP 限速 | 说明 |
|---|---|---|---|
| Book `POST /api/auth/sms/send` | ✅ 必填 | ✅ 真实 IP | 主站注册/登录页 |
| 门户 `POST /api/auth/sms/send` → Book `/api/sso/portal/sms/send` | ❌ | ✅ 真实 IP（BFF 转发后） | 子站品牌登录页 |
| Book `POST /api/auth/login`（NextAuth） | — | ✅ | 密码/验证码登录 |
| 门户 `POST /api/auth/login` → `/api/sso/portal/verify` | — | ✅ | 各工具站登录 |

门户仍 **不** 加图形验证码（BFF 已持 server secret）；依赖 IP/手机号限速 + 日限额。

## 4. 部署清单

### 4.1 必须先部署：`book-mall`

```bash
cd book-mall
pnpm db:apply-pending    # 迁移 20260825040000_site_traffic_probe_views
pnpm db:generate
# build + 部署 book-mall
```

**无新增 env**；沿用 `TOOLS_SSO_SERVER_SECRET` / `GATEWAY_SSO_SERVER_SECRET`。

### 4.2 建议同批部署（门户 BFF）

否则短信/登录限速仍可能按 **子站容器出口 IP** 计数，多用户共用限额：

| 子应用 | 说明 |
|---|---|
| `e-commerce-toolkit` | 被扫站点；sso-config-health 生产 404 |
| `canvas-web` | 登录/短信 BFF |
| `story-web` | 登录/短信 BFF + sso-config-health |
| `quick-replica-web` | 登录/短信 BFF |
| `common-tools` | 登录/短信 BFF |
| `publisher-web` | 登录/短信 BFF |
| `gateway-web` | 短信 + 登录代理带 `x-platform-client-ip` |

### 4.3 可跟日常发版（无行为变化）

仅同步 `lib/platform-traffic/classify-traffic-path.ts` 副本（扫描打标在 book-mall 汇聚层完成）：

`tool-web` · `director-web` · `finance-web` · `prompt-optimizer-platform`

### 4.4 推荐顺序

```text
1. book-mall（迁移 + 限速 + 统计后台）
2. e-commerce-toolkit
3. canvas / story / quick-replica / common-tools / publisher
4. gateway-web
```

## 5. 生产验收

### 5.1 短信限速

- [ ] 同一 IP 10 分钟内第 9 次点「获取验证码」→ 429「请求过于频繁」
- [ ] 门户发短信后，Book `SmsVerification.sendIp` 为 **用户公网 IP**（非 CloudBase 内网/子站出口）

### 5.2 登录限速

- [ ] 同一手机号连续错误密码 8 次 → 429
- [ ] 429 文案：「尝试次数过多，请稍后再试」

### 5.3 SSO 探针

- [ ] 生产 `GET https://ecom.ai-code8.com/api/sso-config-health` → 404
- [ ] 本地 `GET http://localhost:3007/api/sso-config-health` → 200 JSON

### 5.4 访问统计（可选）

- [ ] `/admin/traffic` 可见「其中扫描」KPI 与 IP 类型列
- [ ] 新扫描流量出现后，`probeHitCount` 递增（历史 198 次无 path 明细，不会 retroactive 标扫描）

### 5.5 回归

- [ ] 主站 `/login` 密码登录、验证码登录正常
- [ ] 电商 `/login` → Book autoLogin 链路正常
- [ ] 团队邀请短信 + `/invite/t/...` 正常
