## 1. 需求

在电商工具箱 **微剧故事版** 内，按 [包包.md](./包包.md) 接入 **包包专业版** 全流程：

| 能力 | 说明 |
|------|------|
| 入口 | 新建项目可选「包包专业版」 |
| 七维 | 性别定位（男包/女包/中性）+ 包型品类 + 风格/档次/场景/平台/语言 |
| 卖点 | 手动输入或 AI 自动生成，S01–S0N 分层锁定 |
| 口播 | 6 套差异化文案，用户选 1 套 |
| 分镜 | A–E 五版六镜，每镜绑定卖点 ID + 12.3 验收清单 |
| 运营包 | 标题/封面词/标签/正文等 |
| 成片 | 路径 B：分镜图 → 单镜视频 → 云端合并 |
| 交互 | 右侧分步对话、左侧实时预览（与服装专业版一致） |

同时为 **厨房用品、母婴、3C 数码** 等后续品类预留 **Pro Vertical 插件** 抽象，避免每品类复制一套代码。

## 2. 方案 · Pro Vertical 抽象

### 2.1 架构

- **引擎（共享）**：阶段机、JSON 解析/合并、Markdown 渲染、助手 Chat 分轨、分镜表同步、生图/生视频
- **配置（按品类）**：`VerticalConfig` — 七维枚举、六镜职能文案、A–E 版标题、表格列 label、LLM 规则片段、生图 category

已注册 vertical：

| vertical | schema | 状态 |
|----------|--------|------|
| `fashion_apparel` | `fashion-v4`（legacy）/ `pro-v1` | 现网不变 |
| `bags` | `pro-v1` | 本需求 |

后续：`kitchen_ware` / `baby_maternity` / `digital_3c` 仅增 config + doc。

### 2.2 交付物

- **JSON 真源**：`meta.deliverable`，包包使用 `schemaVersion: "pro-v1"`, `vertical: "bags"`
- **Panel 字段**：统一 `productFocus`（UI 显示「包包展示重点」）；读入兼容 legacy `garmentFocus`
- **Workflow**：包包使用 `proPhase`；服装继续 `fashionPhase`（alias，不迁移存量）

### 2.3 与通用 storyboard 关系

- 无 `vertical` 或非 Pro registry → 仍走 11 参数通用策划流
- Pro 专业版与通用版 **并行**，不互相覆盖
