# 文生试衣 · 产品说明与推荐工作流

> **入口**：电商工具箱 → **模特试衣** → 工作区切换 **文生试衣**  
> **路由**：`/ecom/model-tryon`  
> **技术**：参考图 + Prompt `@图片N` 引用 → Gateway **图片编辑** 模型出图（非 `aitryon-plus` 专用 VTON 链路）  
> **关联**：[`全局资产库.md`](./全局资产库.md) · [`穿搭视频.md`](./穿搭视频.md) §VTON 对比

---

## 1. 能力定位

| 维度 | **文生试衣** | **批量试衣**（同页另一工作流） |
|------|-------------|------------------------------|
| 底层 | 图片编辑 / 多图参考（`wan2.7-image-pro`、`qwen-image-edit*`、`gpt-image-2` 等） | 阿里 **aitryon-plus** 等专用试衣 API |
| 输入 | 多张参考图 + 自然语言 Prompt（可 `@图片1` `@图片2` …） | 模特底图 + 锁定 Look / 服装池 |
| 可控性 | 高：姿态、场景、面料、构图均可写在 Prompt | 中：偏「穿上这件衣服」的成片 |
| 成片归档 | 成功自动写入 **试衣库** + **生成记录** | 手动或批量保存到试衣库 |

**结论（2026-09 实测）**：在「头像 + 服装图 + `@` 引用 Prompt」组合下，**文生试衣模型可直接产出试衣效果良好的全身/大半身时尚大片**，不必先走专用 VTON 再二次修图。适合快速出 lookbook、详情页模特图、穿搭种草静帧。

## 2. 推荐工作流：头像 + 服装 · `@` 引用试衣

这是当前验证效果较好的一种试衣方式（与专用 VTON 并列，非替代关系）。

### 2.1 素材准备

**首次进入文生试衣**时，系统会自动注入 **2 张内置示例参考图**（服装 + 眼镜）并填入默认 Prompt（含 `@图片1` / `@图片2` 内联缩略图），可直接点 **生成试衣图** 体验。点击 **清空编辑区** 后不再自动恢复示例。

1. **模特参考**（可选）：一张 **头像 / 半身** 图（可从 **模特库** 选用，或本地上传）。
2. **服装参考**：一套或多张 **平铺 / 挂拍 / 细节** 服装图（可从 **我的资产**、**服装库** 调入，或上传）。
3. 上传顺序决定 `@图片N` 编号：**先上传的 = `@图片1`**，依此类推。

建议映射（示例）：

| 槽位 | 内容 | Prompt 中写法 |
|------|------|----------------|
| `@图片1` | 模特头像 / 身份参考 | 「模特 `@图片1` …」 |
| `@图片2` | 套装 / 上装+下装 | 「穿上套装 `@图片2` …」 |
| `@图片3`（可选） | 配饰、鞋包、眼镜 | 「佩戴 `@图片3` …」 |

### 2.2 Prompt 写法（精简模板）

**默认 Prompt** 已在句内预埋引用位（带缩略图 badge 展示）：

- 「这套服装」后 → `@图片1`（**第 1 张**参考图，通常为服装）
- 「这副眼镜」后 → `@图片2`（**第 2 张**参考图，通常为眼镜）

在 **参考图 + Prompt** 编辑区，用 `@` 引用上方试衣参考图，例如：

```text
模特身着这套服装@图片1，佩戴这副眼镜@图片2，全身时尚大片…
```

或精简版：

```text
模特 @图片1，穿上套装 @图片2，全身时尚大片，纯白摄影棚背景，
自然光，面料质感清晰，人物占画面四分之三，直视镜头。
```

要点：

- **必须**在 Prompt 里 `@` 引用要用到的参考图；生成时仅把 Prompt 中出现的 `@` 图传给模型（参考图区可上传很多张，不受 9 张 API 上限约束于上传区，但单次生成按模型能力截断引用数）。
- 删除 Prompt 中的 `@图片N` 时，下方 **参考资产条** 会同步移除对应缩略图（**试衣参考图上传区不变**）。
- 可在此基础上扩展：姿态（坐姿 / 站姿）、景别（半身 / 大半身 / 全身）、场景、面料描述、调色等（见系统内置默认 Prompt 范例）。

### 2.3 选模型并生成

1. 点击 **图片模型**，在 `StoryboardModelPickerDialog` 中选择文生试衣白名单内的 **IMAGE** 模型。
2. 推荐优先：`wan2.7-image-pro`（默认）、`qwen-image-edit-max`、`gpt-image-2`（多图参考编辑）。
3. 点击生成 → 结果出现在右侧结果格；**成功即自动进试衣库**。

### 2.4 成片后续

| 动作 | 位置 |
|------|------|
| 预览 / 下载 | 结果格 hover |
| 入库（个人 / 管理员全平台） | hover **保存到库** → 全局资产库弹层（默认 **全身模特** 库） |
| 试衣库统一管理 | 侧栏 **我的资产 → 试衣库** `/library/tryon` |
| 恢复今日未存成片 | 试衣库页 **恢复今日文生试衣** |

## 3. 与穿搭视频链路的关系

[`穿搭视频.md`](./穿搭视频.md) 中经典链路为：

```text
person_vton_img = VTON(模特原图, 服装图)   # aitryon-plus
image_ref = person_vton_img                # 再进分镜 / 生视频
```

**文生试衣**可作为 **VTON 的轻量替代或前置探索**：

- 需要 **强可控的场景 / 姿态 / 光效** 时 → 优先文生试衣 + `@` 引用。
- 需要 **与 aitryon 训练分布一致、批量 Cartesian 试衣** 时 → 仍用批量试衣工作流。
- 穿搭视频 **人物参考图** 可直接使用文生试衣成片（试衣库 / 生成记录中的 OSS URL）。
