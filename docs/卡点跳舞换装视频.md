# 卡点跳舞换装视频

## 1. 产品定位

用户上传**多套服装**，AI 自动生成**音乐卡点、跳舞、逐套换装**的短视频，抖音 / 快手流量种草风格。

## 2. 用户输入（极简表单）

1. **模特**（三选一）：文字创建 / 模特库选择 / 上传模特图
2. **场景**（三选一）：文字自定义 / 场景库选择 / 上传场景图（全程固定不变）
3. **服装**（必填）：用户上传 **2-6 套** 服装平铺图
4. **BGM**：系统内置卡点 BGM（用户可选，不做复杂音乐编辑）

## 3. 技术链路

```
固定模特 + 固定场景（全程统一，保证人脸与背景不跳）
        ↓
循环每一套服装：
  千问Image3.0 / Wan2.7 多图融合
  → 生成「该套服装 + 同一模特 + 同一场景」全身静态图
        ↓
每套静态图独立调用图生视频 → 生成一段跳舞片段
        ↓
后端按BGM节拍时间轴分片拼接全部片段 + 混入BGM音频
→ 输出完整卡点换装成片
```

**关键实现约束**：

- 每套服装**独立一次多图融合**，绝不在单次请求内做多套衣服切换（崩坏概率极高）
- 所有片段共用同一模特、同一场景，仅衣服切换
- 换装效果靠**后端分片拼接**实现，不依赖模型内部换衣

## 4. 视频生成规则

- 画面比例：9:16；时长：跟随 BGM 自动匹配
- 动作：轻微活力跳舞、卡点律动，动作流畅自然
- 约束：全程人脸、场景、光影统一；服装展示清晰

## 5. 提示词（系统默认预填，用户可改）

融合 / 单段视频 / 负面 Prompt 默认预填下方文案，用户可在工作台修改；界面须提示 **「近似卡点」**（动作与 BGM 节拍无法 100% 对齐）。

## 5.1 系统默认提示词

**单套静态融合 Prompt**

```
保留模特五官样貌不变，精准还原当前服装的版型、面料与印花细节，人物全身站立，完美匹配统一场景与光影，高清短视频质感。
```

**单段视频片段 Prompt**

```
9:16竖屏，短视频卡点律动，模特穿着当前服装轻微活力跳舞，动作流畅自然，人物五官不变，场景背景不变，穿搭展示清晰，画面稳定，氛围感强。
```

**负面 Prompt**

```
人脸漂移，肢体畸形，鬼手，大幅度崩坏，画面闪烁，场景变动，五官变动，服装变形，扭曲
```

## 6. 入口与持久化

- **入口**：电商工具箱 → **电商** → **短视频** → **卡点跳舞换装**（`/ecom/video/dance-swap`）。
- **项目 / 生成记录 / 保存作品**：同简易融合短视频统一规范；每套服装独立融合与 i2v 结果均落生成记录。

## 7. 输出结果

- 跟随 BGM 时长的完整卡点跳舞换装视频

## 8. 主要风险与兜底

- 风险：拼接处画面跳变、姿态割裂 → 所有片段固定同一模特同一场景降低跳变
- 风险：跳舞动作肢体畸形 → 动作设定为 "轻微活力跳舞" 而非大幅舞蹈
- 风险：AI 动作与 BGM 节拍无法 100% 精准对齐 → 产品文案明示 "近似卡点"
- 降级：同前，多图融合失败切 VTON 兜底
