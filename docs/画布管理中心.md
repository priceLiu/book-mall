# 画布管理中心

> 权威文档 · 影视专业版 2.0（Pro2）平台管理入口  
> 最后更新：2026-08-20

## 1. 产品需求

### 1.1 背景

Pro2 工业化后，提示词真源从「用户自由片段 + TS 硬编码」收敛为 **JSON-only v13 金标准**（见 [画布提示词.md](./画布提示词.md)）。平台需统一入口管理：

1. **门户工作流**（精选 / 案例 / 社区模板审核）
2. **Pro2 双轨提示词模板**（剧本 LLM + 节点资产 Dock）

### 1.2 角色与权限

| 角色 | 可见入口 | 能力 |
|------|----------|------|
| 普通用户 | 无 | — |
| 平台管理员 | 顶栏 **管理中心** | 工作流管理 + 模板管理 |
| 判定 | `useCanvasAdmin()` | Book `ADMIN`/`SUPER_ADMIN` 或 tools-session `tools_role=admin` |

服务端所有写操作经 book-mall `resolveCanvasApiAdmin` 二次校验。

### 1.3 入口与信息架构

```
顶栏 pill 导航
├── 首页
├── 我的画布
└── 管理中心（admin only）→ /admin

/admin 子导航
├── 工作流管理 → /admin/portal
└── 模板管理   → /admin/templates
```

**与其它「模板管理」的边界**

| 路径 | 应用 | 管理对象 |
|------|------|----------|
| canvas-web `/admin/templates` | 无限画布 | Pro2 剧本 LLM + 节点资产模板 |
| book-mall `/admin/templates` | Book 主站 | QuickReplica / 电商工具箱目录 |
| canvas-web `/settings/providers` · 提示词模板 Tab | 画布设置 | **已退役** · 旧 `CanvasPromptTemplate` 用户片段 |

### 1.4 工作流管理（已有能力迁入）

- 待审核投稿（精选 / 案例 / 社区模板 / 私有模板）
- 已发布精选 / 案例 / 社区模板的预览、下架、禁用、删除
- 详见 [canvas-portal-product-requirements.md](../canvas-web/docs/canvas-portal-product-requirements.md)

### 1.5 模板管理（新建）

模板分 **两条产品线**，共用块 schema，**不得混在同一 Picker**：

#### A. 剧本提示词模板（LLM · `registry=SCRIPT`）

| passKind | 用途 |
|----------|------|
| `OUTLINE` | Hub 大纲 / full_pack 段 |
| `CHARACTER` | 角色视觉辞典段 |
| `SCENE` | 场景 imagePrompt 段 |
| `STORYBOARD` | 分镜 Pass1 导演表段 |

**模板包 `Pro2TemplatePack`**：将四段组合为 preset（如 `default-master`、`gu-feng-tian-chong`），含可编辑的 `categoryDocTitle` / `categoryDocBody`。

#### B. 节点资产模板（Dock 生图 · `registry=ASSET`）

| passKind | 用途 |
|----------|------|
| `CHARACTER_FOUR_VIEW` | 角色四视图构图规范 + variable slots |
| `SCENE_FOUR_PANORAMA` | 场景 2×2 四全景构图规范 |
| `PROP_SIX_VIEW` | 道具六视图构图规范 |

variable slots（用户/剧本数据填充）：名称、描述、服装、特征、氛围等。  
fixed blocks（平台锁定）：构图规范全文。  
`hub_visual_style` 块：运行时从 Hub `visualStylePack` 或大纲解析 `[视觉风格：…]`。

### 1.6 启停规则

- 同一 `registry + passKind` **至多一个** `enabled=true` 模板为运行时默认。
- 管理员切换启用时，service 自动 disable 同 pass 其它模板。
- 模板包 `enabled=false` 时，Hub 新建项目 fallback 到 `default-master`。

## 2. 解决方案

### 2.1 数据模型（book-mall PostgreSQL）

#### `Pro2PromptTemplate`

```prisma
enum Pro2PromptTemplateRegistry { SCRIPT ASSET }
enum Pro2PromptTemplatePassKind {
  OUTLINE CHARACTER SCENE STORYBOARD
  CHARACTER_FOUR_VIEW SCENE_FOUR_PANORAMA PROP_SIX_VIEW
}
```

| 字段 | 说明 |
|------|------|
| `templateKey` | 唯一 slug，如 `script.outline.v13` |
| `blocks` | JSON 数组，见 §2.2 |
| `enabled` | 是否参与运行时解析 |

#### `Pro2TemplatePack`

| 字段 | 说明 |
|------|------|
| `packKey` | `default-master` / `gu-feng-tian-chong` |
| `outlineTemplateId` … `storyboardTemplateId` | FK |
| `categoryDocTitle/Body` | 类别说明 variable 插槽 |

#### 块 schema

```json
{
  "id": "composition_spec",
  "label": "构图规范",
  "source": "fixed",
  "content": "高质量专业角色设定图…",
  "locked": true
}
```

`source` 枚举：`fixed` | `variable` | `hub_visual_style` | `user_override`

渲染：`parseSlots → mergeFixedFromTemplate → appendVisualStyleTag`

### 2.2 API

**Admin（须 platform admin）**

| 方法 | 路径 |
|------|------|
| GET/POST | `/api/canvas/admin/pro2-templates` |
| GET/PATCH/DELETE | `/api/canvas/admin/pro2-templates/[id]` |
| GET/POST/PATCH | `/api/canvas/admin/pro2-template-packs` |
| GET/PATCH/DELETE | `/api/canvas/admin/pro2-template-packs/[id]` |

**Runtime（登录用户）**

| 方法 | 路径 |
|------|------|
| GET | `/api/canvas/pro2-templates/active?packKey=` |

返回：`{ packs, scriptTemplates, assetTemplates }` 启用的模板快照。

### 2.3 前端

| 路径 | 组件 |
|------|------|
| `/admin` | redirect → `/admin/portal` |
| `/admin/layout.tsx` | `AdminSubNav` |
| `/admin/templates` | `TemplatesAdminClient` · Tab：剧本模板包 / 剧本 Pass / 节点资产 |

编辑 `locked` 块须 `doubleConfirm`；禁用 `window.alert/confirm`。

### 2.4 运行时解析

`pro2-template-resolver.ts`（canvas-web + book-mall 镜像）：

1. `fetchActivePro2Templates(base)` — 60s 内存缓存
2. `resolvePro2HubPromptPackFromDb(packKey)` — 优先 DB，fallback `storyPro2HubDefaultPromptPack()`
3. `resolvePro2AssetCompositionSpec(passKind)` — 优先 DB fixed 块，fallback `PRO2_*_COMPOSITION_SPEC`

Hub 字段演进（目标态）：

```json
{
  "templatePackKey": "default-master",
  "promptOutline": "…",
  "…": "运行时由 pack 解析填充，非长期真源"
}
```

### 2.5 Seed

`book-mall/scripts/seed-pro2-prompt-templates.ts` 从 TS 金标准导入：

- 剧本四段 × default + gu-feng 变体
- 资产三构图规范
- 两套 template pack

本地：`pnpm --dir book-mall seed:pro2-templates`

### 2.6 退役计划

| 项 | 状态 |
|----|------|
| `CanvasPromptTemplate` 用户片段 | 文档标注退役；settings Tab 移除 |
| `pro2-script-category-presets.ts` 硬编码 pack | 运行时 DB 优先，TS 作 fallback |
| Hub 存大段 prompt 字符串 | 逐步改为 `templatePackKey` + overrides |
