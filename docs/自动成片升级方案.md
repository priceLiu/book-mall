## 1. 现状与问题

### 已修复：CJK 方框（tofu）

此前 ffmpeg/libass 默认 `FontName=Arial`，中文 glyph 缺失，烧录结果为一排空心方框。已通过以下方式修复：

- `book-mall/lib/media/subtitle-ffmpeg-style.ts`：显式 `FontName` + `fontsdir` + `charenc=UTF-8`
- Docker 镜像安装 `fonts-wqy-microhei`
- macOS 隔离系统字体根目录，避免 libass 扫到 Emoji 字体

### 本次升级：用户可选字体与字号

- **3 种字体**：黑体 / 宋体 / 思源黑体
- **3 档字号**：大（默认，与升级前视觉一致）/ 中 / 小
- **三端统一 UI**：画布、电商合并、AI 空间合成台共用 `SubtitleBurnInFields`
- **协议进 RenderProfile**：为后续轻量剪辑台预留，不另造 JSON

## 2. 统一协议 `RenderProfile.subtitle.style`

仅在 `subtitle.burnIn: true` 时生效；缺省与老 job 等价：

```json
{
  "subtitle": {
    "mode": "script",
    "burnIn": true,
    "style": {
      "fontKey": "heiti",
      "sizeKey": "large"
    }
  }
}
```

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `fontKey` | `heiti` \| `songti` \| `noto` | `heiti` | 烧录字体 |
| `sizeKey` | `large` \| `medium` \| `small` | `large` | ASS FontSize（PlayResY=288） |

### 字号映射

| sizeKey | FontSize | 文案 |
|---------|----------|------|
| `large` | 20 | 大（默认） |
| `medium` | 16 | 中 |
| `small` | 13 | 小 |

### 字体映射与回退

| fontKey | 用户文案 | 优先候选 |
|---------|----------|----------|
| `heiti` | 黑体 | WenQuanYi Micro Hei / Heiti SC |
| `songti` | 宋体 | AR PL UMing / Songti SC |
| `noto` | 思源黑体 | Noto Sans CJK SC / Noto Sans SC |

指定字体不可用时 **fallback → heiti**，打 `[media-render]` 日志，**不失败任务**。Docker 未额外装 `fonts-noto-cjk` 时，`noto` 通常回退黑体。

## 3. 三端接入

| 端 | 入口 | variant |
|----|------|---------|
| 画布 | `canvas-web/components/canvas/jianying-media-render-actions.tsx` | `canvas-dark` |
| 电商 | `e-commerce-toolkit/components/storyboard/storyboard-deliverable-section.tsx` | `ecom-light` |
| AI 空间 | `book-mall/components/ai-space/ai-space-compose-desk.tsx` | `book-account` |

共享包：`@private/media-render-subtitle-style`

- `subtitle-style-options.ts`：枚举、默认值、ASS 字号表
- `subtitle-burn-in-fields.tsx`：烧录开关 +（可选）脚本/ASR + 字体 + 字号

### 电商默认行为

合并分镜视频 **默认不烧录**（与现网一致）；用户在「合并设置」勾选后才传 `burnIn: true` + `style`。
