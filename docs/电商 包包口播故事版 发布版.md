## 1. 能力摘要

| 项 | 说明 |
|----|------|
| 产品入口 | 微剧故事版 → 新建 **电商专业版** → 上传产品图 → 选 **包包** |
| 策划流程 | 七维 → 卖点 → 6 套口播 → A–E 六镜分镜 → 运营包 → 路径 A/B |

| 工作流字段 | `meta.workflow.vertical=bags`，阶段键 `proPhase` |

## 2. 七维参数（dimensionSteps）

| key | label | 类型 |
|-----|-------|------|
| genderCategory | 性别定位 | 男包 / 女包 / 中性 |
| styleCategory | 包型品类 | 托特包、斜挎包…（16 类） |
| styleAttribute | 风格属性 | 共享 enum |
| tier | 档次定位 | 共享 enum |
| customScene | 使用场景 | 自由文本 |
| platform | 发布平台 | 共享 enum |
| outputLanguage | 输出语言 | 共享 enum |

配置代码：`book-mall/lib/ecom/pro-vertical/configs/bags.ts`

## 5. 六镜职能 & A–E 分镜

**六镜**：场景氛围 → 包型轮廓 → 材质细节 → 五金工艺 → 穿搭场景 → 完整种草

**五版**：A 上身携带动感 / B 细节均衡 / C 场景氛围 / D 日常实拍 / E 质感细节

**口播 6 套**：痛点救场 / 场景种草 / 细节种草 / 性价比 / 品质背书 / 搭配指南（见 [包包.md](./包包.md)）

## 6. 对接 API（Book SSO · e-commerce-toolkit BFF）

| 能力 | 路径 |
|------|------|
| 创建项目 | `POST /api/sso/tools/ecom/storyboard/projects` |
| 助手对话 | `POST .../projects/{id}/assistant/chat`（`buildProAssistantSystemPrompt("bags", phase)`） |
| 保存工作流镜像 | `POST .../projects/{id}/save` |
| 资产库 / 复用 | `GET /api/sso/tools/ecom/library` · `POST .../storyboard/projects/reuse` |

Chat route 按 `workflow.vertical` 分流，勿写死 `"bags"` 字符串于新品类。
