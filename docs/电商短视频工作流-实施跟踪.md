## 4. 复刻能力说明（产品对齐）

| 维度 | 机制 | 依赖 |
|------|------|------|
| **运镜 / 动作** | 参考片段 + Kling motion-control（`character_orientation=video`） | OV-120 真实 clip + OV-121.1 |
| **场景 / 背景** | `background_source=input_video` 保留原片环境 | Kling motion-control |
| **光影 / 色调** | 同上 + 合成阶段 Media Render 拼接 | 片段一致时自然连续 |
| **模特 / 服装** | 模特参考图 + 固定 Prompt（服装 ref 百炼路径多图） | 用户绑定 refs |

---

## 5. 本地验收步骤

1. `cd book-mall && pnpm media-render:check-ffmpeg`（必须 OK）
2. 上传 9:16 参考穿搭视频 → **拆解**
3. 确认分镜预览图为视频抽帧，`meta.splitSceneSource=ffmpeg_v1`
4. 绑定模特 + 服装 → 选 **Kling 3.0 动作控制** → 批量生成
5. 合成 → 成片运镜/背景与参考片一致，人物为指定模特
