# 图片编辑功能 · 画布重绘 + AI 修图共用层

> **状态**：实施中（IE-101～IE-111）  
> **管理入口**：Book [`/admin/pending-features`](http://localhost:3000/admin/pending-features) → **待处理**  
> **厂商 API 参考**：[`docs/wen.md`](wen.md) · [`docs/wan 图像局部.md`](wan%20图像局部.md)

画布「重绘」与电商/常用工具「AI 修图」共用 book-mall `runLocalImageEdit` 单一 Gateway 入口；UI 分 LibTV 深色（canvas）与浅色（ecom/common-tools）两套壳层。成功后画布默认在源节点右侧 spawn 新结果节点，源图不变。

---

## 1. 产品决策

| 决策 | 内容 |
|------|------|
| 画布重绘 UX | 源节点进入 inpaint 会话（toolbar + 选区 + dock）；成功后 **右侧 spawn 新结果节点** 并连线 |
| 模型 | Qwen 编辑（`qwen-image-edit*`）+ 万相编辑（`wan2.7-image-pro` 框选 / `wanx-x-painting` 蒙版） |
| 架构 | 逻辑在 **book-mall**；UI 多套 |
| 积分 | Gateway `finalizeRequestLog` → `gateway-credit-settlement`；画布 `CLIENT_SOURCE=CANVAS` + `clientPage: canvas/{projectId}/inpaint` |

## 3. 模型与选区对照

| 模型 | 选区机制 | API 字段 |
|------|----------|----------|
| `qwen-image-edit*` | 笔刷蒙版（可选） | content 第三张 `image` |
| `wanx-x-painting` | 笔刷蒙版（必填） | `mask_image_url` |
| `wan2.7-image-pro` | 框选（最多 2 box/图） | `parameters.bbox_list` |

---

## 4. 架构

```
canvas-web / ecom / common-tools
        ↓
POST /api/platform/v1/image-local-edit
        ↓
runLocalImageEdit() → adapter (qwen / wanx / wan27)
        ↓
GatewayRequestLog → settleSucceededGatewayLog
```
