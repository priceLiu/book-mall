# 图片生种草视频 · 使用说明

> **读者**：运营、短视频策划、带货内容同学。  
> **入口**：电商工具箱 → 营销 → **图片生种草视频** → `/ecom/seed-video`  
> **toolKey**：`ecom-toolkit__seed-video`  
> **工程契约**（助手 JSON / Skill 真源）：`book-mall/doc/种草视频/`（含 `table-format.md`、各 Skill `.md`）

---

## 1. 能做什么

用 **1～9 张商品/穿搭/场景素材图**，配合 **策划 Prompt**（可 `@图片1` 引用），由 **策划助手** 产出 **3 套带口播的脚本**，再选制作方式：

| 方案 | 名称 | 适合 |
|------|------|------|
| **方案①** | 直接连贯生成视频 | 一条 Prompt + 参考图，**单次** 交给视频模型出连贯成片（快） |
| **方案②** | 精细成片 | 分镜执行表 → 正式逐镜脚本 → **镜级图/视频** + **TTS 口播** → **合成成片**（可控） |

默认目标时长 **约 20 秒**（可在 Prompt 里写「时长预计 20s」等；系统会解析）。方案①单次生成受模型上限约束（默认约 **30 秒**，具体以所选视频模型为准）。

---

## 2. 使用前准备

1. 经 Book **SSO 登录** 电商工具箱（`:3007` 或现网域名）。  
2. 账号已关联 **Gateway API Key**（`sk-gw`），否则无法调用策划 LLM / 生视频 / TTS。  
3. 工具 **月费/积分** 按 `ecom-toolkit__seed-video` 扣点；厂商成本走 Gateway（BYOK 或平台代付池）。

---

## 3. 界面布局

| 区域 | 作用 |
|------|------|
| **左侧进度轨** | 素材 → 脚本 → 模式 → 风格 → 成片（点击可滚动到对应区块） |
| **中间工作区** | 上传素材、填写 Prompt、「开始策划」、脚本/镜头表编辑、成片预览与生成按钮 |
| **右侧助手** | 流式对话 + **点选卡片**（选脚本、选方案①/②、选 A/B 风格、确认参数表等） |

**分工（产品固定）**

- **中间**：上传素材、写 Prompt、点开始策划、看成片表与生成结果。  
- **右侧**：所有「选脚本 / 选模式 / 选风格 / 确认同步到工作区」的交互；助手已有待选卡片时 **不要重复点「开始策划」**。

## 4. 新建项目与 Skill

首次进入或点 **新建** 时，先选 **Skill**（决定默认标题、示例 Prompt、脚本卡片文案与 A/B 风格说明）：

| Skill | 适用 |
|-------|------|
| **种草短视频**（`seed-grass`） | 生活方式种草、度假氛围、不费力高级感 |
| **服装爆款带货** | 服装钩子、痛点转化、多场景实穿 |
| **3C 数码带货** | 外观种草、痛点、场景测评 |
| **家居服带货** | 软糯质感、居家舒适、场景穿搭 |

创建后项目标题一般为 Skill 默认名（可改）；`settings.skillKey` 决定助手加载哪份 Skill 文档。

## 5. 推荐操作顺序

### 5.1 素材与策划

1. 上传 **1～9 张**「种草素材」（本地上传或 **我的资产** 挂载；粘贴/上传会打 `firstOrigin`）。  
2. 填写 **Prompt**，用 `@图片1`、`@图片2` 指向已上传顺序；可点 **填入示例 Prompt**。  
3. 点 **开始策划** → 右侧助手输出 **素材解析 + 3 套脚本**，在卡片上 **三选一**。  
4. 依次点选：**制作模式**（方案① / 方案②）→ **成片风格**（A 小红书向 / B 抖音带货向，文案因 Skill 略有不同）。

### 5.2 方案① · 直接连贯生成

1. 助手给出 **成片参数**（镜头序列预览 + 全局视频 Prompt + 完整口播等）。  
2. 在右侧点 **确认成片参数**，同步到中间 **「方案① · 直接连贯生成」**。  
3. 点 **视频生成**（先选 **视频模型** 与 R2V 参数，走 `StoryboardModelPickerDialog`）。  
4. 轮询完成后在中间 **成片视频** 区预览；可 **重新生成**。  
5. 可保存工作流 / 写入视频资产（见 §7）。

### 5.3 方案② · 精细成片

1. 助手输出 **分镜执行表** → 右侧确认或 **修改脚本**（中间可进「正式脚本 · 手动编辑」表格）。  
2. 再输出 **正式逐镜参数表**（含 **AI 视频生成提示词** 列）→ 右侧 **确认逐镜参数表**，同步到中间 **「方案② · 精细成片」** 镜头表。  
3. 推荐顺序（界面文案）：  
   - 勾选镜头 → **逐镜生成视频**（或表内单镜生成）  
   - 勾选含口播镜 → **批量 TTS**  
   - 镜级视频与 TTS 就绪 → **合成成片**（弹层可选 **字幕样式** 后提交）  
4. 首次批量出片前可能弹出 **出片方式**：**逐镜生视频**（一个一个看）或 **自动合成出片**（自动跑完镜级任务再合成）。  
5. 合成进度见 **合成中** 进度条；完成后中间显示 **成片视频**。

## 6. 模型与参数

| 用途 | 说明 |
|------|------|
| **策划对话** | 助手顶栏可选 **对话模型**（默认 DeepSeek 等 Gateway LLM）；须有效 `sk-gw` |
| **生视频** | **StoryboardModelPickerDialog** · `mode=video`；方案①为整片 R2V，方案②为分镜 R2V（默认登记如万相 R2V 等，以 Gateway 列表为准） |
| **画幅** | 项目设置常见 **9:16** / **16:9**（竖屏种草为主） |
| **TTS** | 方案②镜级口播；音色与风格包（A/B）在策划阶段已绑定语气说明 |

---

## 7. 保存、分享与导出

| 操作 | 说明 |
|------|------|
| **保存工作流** | 顶栏保存图标 → 写入 **我的资产 · 工作流草稿**（含聊天、plan、素材引用） |
| **分享链接** | 只读查看交付物/进度（`WorkflowShareLinkDialog`） |
| **导出 ZIP** | 内容区可 **下载项目包**（脚本、参数、资源清单等，见 `export` API） |
| **成片入库** | 合成完成后关联 **视频资产**（`videoOssUrl` / `videoAssetId`） |

**项目恢复**：浏览器 `localStorage` 键 **`ecom-seed-video-active-project`**；刷新后优先打开上次项目，否则列表最近一项。

## 8. 与口播故事版的区别

| | **图片生种草视频** | **电商口播故事版** |
|--|-------------------|-------------------|
| 入口 | `/ecom/seed-video` | `/ecom/storyboard/micro-drama` |
| 输入 | 多图素材 + 短 Prompt | 产品/模特/场景 + 品类七维专业版 |
| 产出 | 20～30s 种草/带货成片 | 口播脚本 + 分镜 sheet + 长片/多镜工作流 |
| 助手协议 | ` ```seed-video ` JSON（见工程 `table-format.md`） | `pro-v1` / 服装 deliverable 等 |

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| 无法「开始策划」 | 至少 **1 张素材** + **非空 Prompt** |
| 助手让选脚本但中间空白 | 正常：先 **右侧点选**；同步后中间才显示表 |
| 方案①「视频生成」灰掉 | 先在右侧 **确认成片参数** 完成同步 |
| 方案②表无法生成 | 先 **确认逐镜参数表**；方案②须先完成 **风格** 点选 |
| 重复点「开始策划」提示已有卡片 | 直接在 **右侧助手** 点选，勿重复策划 |
| 401 / 生视频失败 | 检查 SSO、Gateway Key、模型是否登记 VIDEO/R2V |
| 时长不对 | 在 Prompt 写明秒数；方案①勿超过模型单次上限 |
