## 库与资产 · 概念（2026-10 定稿）

### 一句话

| | **平台资产库**（原「库 / catalog） | **项目资产**（`ProjectAsset`） |
|---|-----------------------------------|--------------------------------|
| **入口文案** | **保存平台资产库** | **保存项目资产** |
| **是什么** | 可反复选用的 **参考条目**（图 / 音 / prompt 等） | 创作产物的 **工作流快照**（节点 data、组布局、脚本包等） |
| **典型用途** | 跨项目当参考、平台中心插入、电商选图 | 在本项目内恢复节点、继续编辑 |
| **含连线 / 组** | 否 | 是（如 `GROUP_BUNDLE`） |
| **存储** | book-mall 各 **catalog 表** + `scope` | `ProjectAsset` + `sourceProjectId` |

### 用户看到的两个「库」

1. **系统平台库**（`scope = platform`）  
   - 平台管理员发布，**全员只读选用**。  
2. **我的平台资产库**（`scope = user`，团队空间可选 `team`）  
   - 用户自行创建、维护，**跨项目、跨画布版**复用；**不是**项目资产表。

**用户需知**：跨项目反复用同一张参考图 → **保存平台资产库**；保留生成参数并在 **当前项目** 清单中恢复 → **保存项目资产**。

### 项目资产范围（目标态）

- 默认绑定 **当前画布项目**（`sourceProjectId`）。  
- 类型与 `/assets` 导航一致（角色、场景、道具、分镜图/视频、音频、风格、提示词、组资产等）。  
- **不**写入系统平台库；团队可见仍用 `TEAM_PUBLIC`，属项目资产域。

> **现网差异（待收敛）**：「保存项目资产」对话框仍可选 **「我的 · 全账号」**；目标态以 **跨项目走平台资产库、项目资产以本项目为主** 为准。

### 管理员

| 能力 | 普通用户 | 平台管理员 |
|------|----------|------------|
| 选用系统平台库 | ✅ | ✅ |
| 保存平台资产库（我的） | ✅ | ✅ |
| 发布为系统平台库（全员） | ❌ | ✅ |

### 平台资产库 · 类型（入库下拉）

与项目资产 **类型命名对齐**（场景、风格等）；当前 catalog 实现还包括姿势、模特头像、全身模特、服装等目录。  
目标扩展：角色、音频、参考图等（见 [`book-mall/doc/product/16-project-assets-unified-design.md`](../book-mall/doc/product/16-project-assets-unified-design.md) 交叉说明）。

### 平台资产中心 · 信息架构（目标）

- **场景** 与 **风格 / 镜头描述 / 数字人** 同级，**不**挂在「模特·素材」下（场景非模特专属）。  
- 「模特·素材」侧重人物、服装、姿势类 catalog。

### 应用范围

| 能力 | 画布三版 | 电商工具箱 |
|------|----------|------------|
| 项目资产 | ✅ | ❌ |
| 我的 / 系统平台资产库 | ✅ | ✅（SSO + catalog API） |

## 原始需求（摘要）

1. **资产类型（11+ 类）**：角色、场景、道具、大纲、分镜脚本、音频、分镜图、分镜视频、数字人、风格、提示词等。  
2. **个人 / 团队**：类型相同；个人仅私有，团队可共享（`AssetVisibility`）。  
3. **节点顶栏**：可入库节点须有 **「保存项目资产」**；平台参考图走 **「保存平台资产库」**。  
4. **组**：分组后可 **保存项目资产**（`GROUP_BUNDLE`）。  
5. **三种画布**：Story-Pro 1.0、影视 2.0、分镜视频 1.0 → 共用一套项目资产 API 与 `/assets` UI。

---

## 方案结论（一句话）

**一套 `ProjectAsset` 表 + 一套 Platform API + 一套 `/assets` 界面**；画布 edition 只决定「从哪种节点导出」；平台参考目录走 **Global Asset Catalog**。

### 节点 data 快照（2026-06 确认）

| 写入 | 不写入 |
| --- | --- |
| `payload.nodeType` + `payload.nodeSnapshot` | 上游/下游连线、组外 id |
| `thumbnailUrl` + `refs[]` | `blobUrl`、runtime 临时字段 |
| 组资产 `GROUP_BUNDLE`：组内结构 | 组外游离边 |

## 界面要点

| 区域 | 设计 |
| --- | --- |
| `/assets` | 左类型导航 + 卡片网格 + 筛选 |
| 画布侧栏 | `ProjectAssetsView`（compact） |
| 保存 | 顶栏 **保存项目资产** → 对话框（名称 · 类型 · 共享范围） |
| 平台参考 | 顶栏 **保存平台资产库** → GALD（名称 · 类型 · 可见范围） |
| 组 | 组顶栏 **保存项目资产** → `GROUP_BUNDLE` |
