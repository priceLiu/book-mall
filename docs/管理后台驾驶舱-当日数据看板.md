# 管理后台 · 平台驾驶舱 · 当日数据看板

> **状态**：Phase 1 设计中 / 首版落地（CST 业务日 · Gateway 真源）  
> **入口**：Book **`/admin`** 长页顶部 **「今日看板」** 区块（`#today`）· `/admin/today` 重定向至 `#today`  
> **SSOT 聚合**：`book-mall/lib/admin/platform-cockpit-daily-dashboard.ts`  
> **关联**：`platform-cockpit-service.ts` · `platform-cockpit-model-usage.ts` · `platform-cockpit-finance-kpis.ts` · `/admin/usage-audit`

---

## 1. 目标

在现有「平台驾驶舱」上增加 **当日（CST 自然日）** 运营看板，一屏回答：

| 问题 | 指标 |
|------|------|
| 今天用了多少积分？ | 积分消耗合计 + 按应用 / 项目 Top |
| 今天生了多少图 / 视频？ | Gateway 成功次数（IMAGE/TRYON vs VIDEO）+ 分应用 / 项目 |
| 今天 Gateway 调用多少？ | 成功 / 失败 / 在飞 + 分应用 |
| 今天平台成本多少？ | 厂商净成本估算（元）+ 积分扣减 + 明细抽样 |

**业务日**：与全站一致，**北京时间 CST** `YYYY-MM-DD`（`cstBusinessDate` / `cstDayStartUtc`）。

## 2. 数据口径

### 2.1 真源优先级

| 域 | 主真源 | 说明 |
|----|--------|------|
| 生图 / 生视频 / Gateway 次数 | `GatewayRequestLog` | `status=SUCCEEDED` 计数；`requestKind` 归类见 `classifyGatewayRequestKind` |
| 积分消耗（平台代扣） | `GatewayRequestLog.creditsCharged` | 成功日志快照；与 `CreditLedger` CONSUME/SETTLE 当日合计可交叉校验 |
| 厂商成本 | `estimateGatewayLogNetCostYuan` | 与 P&L / 驾驶舱财务块同公式；当日扫描上限防拖库 |
| 画布任务（可选对照） | `CanvasGenerationTask` | 仅 IMAGE/TEXT；**不含**全部视频路径（视频以 Gateway VIDEO 为准） |

### 2.2 「应用 / 项目」维度

**应用（appKey）** — 由 `clientSource` + `clientPage` 前缀推断：

| appKey | 规则 |
|--------|------|
| `canvas` | `clientSource=CANVAS` 或 `clientPage` 以 `canvas/` 开头 |
| `ecom` | `E_COMMERCE` 或 `ecom/` |
| `story` | `STORY` 或 `story/` |
| `tool` | `TOOL` |
| `quick-replica` | `QUICK_REPLICA` |
| `other` | 其余 |

**项目（projectKey）** — 可钻取的最小业务单元：

| 应用 | projectKey 提取 |
|------|-----------------|
| canvas | `clientPage` 正则 `^canvas/([^/]+)` → Canvas 项目 id |
| ecom | `ecom/{userId}/{workspaceId}/…` → `workspaceId` |
| story | `storyProjectId` 或 `clientPage` |
| 其他 | `clientPage` 全文或 `—` |

展示名：Canvas 批量查 `CanvasProject.name`；其余暂用 id 截断 + `clientPage` 后缀。

### 2.3 与现有驾驶舱块的关系

| 现有块 | 关系 |
|--------|------|
| `credits.consumedToday` | 来自 `CreditLedger`；当日看板 **另列 Gateway 积分快照合计**， footnote 提示二者可能差异步 |
| `modelUsage` | **当月** 趋势；当日看板补 **当日** 绝对值 + 项目 Top |
| 财务三角（Finance） | **账期** P&L；当日看板为 **日** 成本快照，不替代 `/admin/finance/*` |
| 用量审计 | 应用级对账；当日看板为 **运营日切** 快览 |

## 3. UI 信息架构（Phase 1）

```
当日数据看板 · {businessDateCst}
├── 总览 KPI 行（4～6 卡）
│   ├── 积分消耗（Gateway 快照）
│   ├── 生图成功
│   ├── 生视频成功
│   ├── Gateway 成功 / 失败
│   └── 估算厂商成本（元）
├── Tab 或折叠：按应用
│   └── 表：应用 | 积分 | 生图 | 生视频 | Gateway 成功 | 成本
├── Tab：按项目（Top 20，可切换应用筛选）
│   └── 表：项目名 | 应用 | 积分 | 生图 | 生视频 | Gateway | 成本
└── 当日费用明细（Top 100 成功调用）
    └── 时间 | 应用 | 项目 | 模型 | kind | 积分 | 成本 | 跳转 Gateway 日志
```

**交互**

- 日期：**业务日** `<input type="date">` + 刷新；默认今日（CST）。
- **导出 CSV**：`GET /api/admin/platform-cockpit/daily?date=…&format=csv`（概览 + 应用 + 项目 + 明细）。
- 明细「查看全部」→ Gateway 日志 / finance 对账（带 `submittedAt` 日过滤 query）。
- **积分告警**：Gateway 快照 vs CreditLedger 差异 ≥10 分或 ≥5% 时黄条提示（`creditReconcileAlert`）。

## 5. 性能与限制

| 项 | 值 |
|----|-----|
| 项目 Top N | 20 |
| 费用明细行 | 100 |
| 成本扫描日志上限 | 3000 条/日（超出 `costTruncated=true`） |
| staff 调用 | 默认 **包含**（与财务驾驶舱一致；Phase 2 可开关） |

索引：`GatewayRequestLog(submittedAt)` · 已有 `(actorBookUserId, submittedAt)` 等。
