# Pro2 剧本结构化 v2 · 产品需求

> **状态**：实施中（2026-08）  
> **范围**：影视专业版 2.0 · `story-pro2-script-hub`  
> **技术契约**：[book-mall/doc/product/25-canvas-pro2-script-structured-output.md](../book-mall/doc/product/25-canvas-pro2-script-structured-output.md)  
> **Golden Examples**：[画布提示词.md](./画布提示词.md)

---

## 1. 三阶段流程

| 阶段 | 触发 | 产出 | 禁止 |
|------|------|------|------|
| **Pass 1 · 剧本 LLM** | 脚本 Hub Dock「生成分镜脚本」 | 结构化制作包（导演表） | 不写最终分镜图/分镜视频提示词 |
| **Pass 2 · 提示词 LLM** | 「生成分镜」弹表内用户点「生成提示词」 | 每镜 `frameImagePrompt` + `videoPrompt` | 不改编剧事实 |
| **Pass 3 · 媒体生成** | 用户在组内单元格 Dock 手动发送 | Gateway IMAGE / VIDEO | Hub「创建分镜」不得自动 batch run |

---

## 2. Pass 1 · 导演表字段

### 2.1 分镜表（11 列 · 无 AI 生图/视频列）

| 列 | JSON 字段 | 要求 |
|----|-----------|------|
| 镜号 | `index` | 从 1 连续 |
| 景别 | `shotSize` | 特写/近景/中景/全景/远景… |
| 光影 | `lighting` | 每镜独立，环境+色温+情绪 |
| 运镜 | `cameraMove` | ≥12 字；须含机位状态+运动方向+速度+视觉目的；禁止单/双字 |
| 画面描述 | `sceneDescription` | 【起始】→【结束】，≥30 字 |
| 道具 | `propIds` | 引用 `props[].id` |
| 对白 | `dialogue` | 「角色名（情绪/语气）："台词"」；内心OS/群杂按规范标注；无则「—」 |
| 时长(秒) | `durationSec` | 整数 |
| 音效 | `sfxNote` | 与口型分离 |
| 口型/配音备注 | `audioNote` | BGM dB、同期/OS 等 |

### 2.2 场景 / 角色 / 道具（结构化块）

见 [画布提示词.md](./画布提示词.md)：名称、描述、服装/前背景/特征、**构图规范**、`[视觉风格：…]`。

---

## 3. Pass 2 · 最终提示词

- **分镜图**：单段中文（景别→场景→角色→动作→道具→光影→镜头→氛围→视觉风格）。
- **分镜视频**：中文多段模板（出场角色、背景场景、参考图规则、前一镜、分段描述、输出约束、视觉风格）。
- 全文中文；表头不得再标注「英文」。

---

## 4. 「生成分镜」交互（Hub 工具栏）

1. 按钮文案：**生成分镜**（原「生成分镜组」）。
2. 弹出表格：可编辑 Pass 1 列 + 分镜图/视频提示词列。
3. **生成提示词**：对选中镜调用 Pass 2 LLM（按镜 1 次）。
4. **创建分镜**：写回 Hub → spawn **分镜图组 + 分镜视频组**（已连线）→ 预填 `@` 与 prompt → **不**自动 Gateway。

---

## 5. 验收

1. Pass 1 JSON 无 `imagePrompt` 可通过 v2 校验。
2. 弹表可改表 → 生成提示词 → 手改 → 创建分镜。
3. 创建后两组成对出现，无自动 inflight 任务。
4. 用户 Dock 手动发送才入队 Gateway。
5. **旧版 2.0 剧本项目已停用**：无 `meta.pro2ScriptFormat=json-only-v13` 且画布含 **脚本 Hub**（或关联剧本包）的 Pro2 项目对所有人不可见（API 404）；**纯 starter/生图等未用剧本的项目仍可打开**；新建 v13 项目后使用 JSON-only 剧本链路。
