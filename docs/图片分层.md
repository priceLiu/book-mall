# 图片分层编辑｜产品与技术说明

> **产品定位**：电商工具箱 · **营销**菜单下的独立 Studio——上传成品图 → AI 拆成可编辑图层 → 点选图层做局部 AI 修改 → 拖拽排版 → 导出成品。  
> **AI 能力**：火山方舟 **Doubao Seedream 5.0 Pro**（`doubao-seedream-5-0-pro-260628`），经 Gateway 统一调用。  
> **入口规划**：`/ecom/image-layer` · 侧栏「营销」分组 · `toolKey: ecom-toolkit__image-layer`（沿用电商工具箱月费，不新建 navKey）。

---

## 一、你要做的功能（一句话）

**把一张营销/电商成品图拆成「底图 + 多个透明物体层」，在画布上像设计软件一样选中、移动、改某一层的 AI 内容，最后合并导出。**

与现有模块的区别：

| 模块 | 做什么 |
|------|--------|
| 拆图拆视频 | 反推 prompt / 分镜，不是可编辑图层 |
| 图像处理 | 单图单次修图，无多图层工作流 |
| **图片分层编辑（本功能）** | **结构化图层 + 逐层改 + 合成导出** |

---

## 二、用户流程（MVP）

```
1. 上传一张图片（本地 / 我的资产）
2. 【可选】手动画框：指定要拆出的物体；不画则全自动拆分整张图
3. 点击「AI 图层分离」→ 等待（可能较久，走 BackgroundGenerationDock）
4. 画布展示：底图 + N 个透明 PNG 层（最多 16 层物体 + 1 底图）
5. 点击某一图层 → 右侧编辑面板激活
6. 输入修改描述（如「把包包改成红色」）→「AI 修改本层」
7. 模型按该层 bbox 做交互编辑 → 更新画布（见 §六 更新策略）
8. 可继续改其他层；支持拖拽、缩放、调层级
9. 导出：合并 PNG/JPG（MVP）；PSD 分层（Phase 2）
```

**核心原则**

- **图层拆分只做一次**（除非用户主动「重新拆分」）。
- **改层**走 Seedream Pro **交互编辑**（`<bbox>` / `<point>` + 自然语言），不是独立 Inpaint 服务。
- **导出成品**默认前端合成，不再调 AI。
- **厂商返回 URL 仅保留 24 小时**，拆分/编辑结果必须落 OSS。

## 三、为什么必须用 Seedream 5.0 Pro

据 [图片生成教程](https://www.volcengine.com/docs/82379/1548482) 能力对比表，**图层拆分**与**交互编辑**仅 **Seedream 5.0 Pro** 支持；Lite / 4.5 / 4.0 均不支持。

| 能力 | 5.0 Pro | 5.0 Lite | 4.5 / 4.0 |
|------|---------|----------|-----------|
| 图层拆分 | ✅ | ✗ | ✗ |
| 交互编辑（点/框选改图） | ✅ | ✗ | ✗ |
| 文生组图 / 流式 / 联网搜索 | ✗ | ✅ | 部分 |

Pro 专有能力（官方描述）：

- 坐标、框选、箭头等多种方式指定编辑位置
- 单张图拆分为 **1 张底图 + 最多 16 个独立图层**
- 分辨率档位：**1K、1.5K、2K**（无 3K/4K）
- 生成数量：单图或 **1 底图 + 最多 16 图层**
- 输出格式：`png` / `jpeg`；**图层拆分场景下 `output_format` 仅控制底图，图层始终 PNG**

**本功能固定使用 Pro**，不可降级 Lite。

### 5.1 能力 A：图层拆分

**请求体（推荐默认值）**

```json
{
  "model": "doubao-seedream-5-0-pro-260628",
  "prompt": "将图片进行精确图层分离，需分离的文字坐标为 <bbox>180 64 812 198</bbox>、<bbox>757 210 939 280</bbox>；鹦鹉的坐标为 <bbox>347 305 642 997</bbox>。",
  "image": "https://your-oss-url.png",
  "size": "auto",
  "layer_decomposition": true,
  "output_format": "jpeg",
  "response_format": "url",
  "watermark": false
}
```

**prompt 写法**

| 场景 | 示例 |
|------|------|
| 全自动 | 省略 prompt，或「对图片做完整图层语义分离」 |
| 手动框选 | 官方格式：`将图片进行精确图层分离，需分离的…坐标为 <bbox>x1 y1 x2 y2</bbox>、…` |

**坐标**：`<bbox>x1 y1 x2 y2</bbox>` 为 **0～999 归一化**（交互编辑指南：左上 `0,0`，右下 `999,999`）。  
前端框选 → `round(px / displaySize * 1000)` 再 clamp `[0,999]`。

**`size`（图层拆分专用）**

- **仅支持档位**：`auto`（默认）、`1K`、`1.5K`、`2K`
- **禁止** `2048x2048` 等像素串
- **底图**：分辨率与 `size` 一致，宽高比与原图一致
- **各图层**：分辨率接近 `size`，各层保持原图中宽高比
- **`auto` 规则**（官方）：
  - 原图像素在 `[1280×720, 2048×2048×1.1025]` 即约 921600～4624220 → 按原尺寸
  - 小于 1K → 按 1K 输出
  - 大于 2K → 按 2K 输出

**`output_format`**：仅控制**底图**格式（`png` / `jpeg`）；**物体图层始终 PNG（透明）**。

**输入限制（图层拆分场景）**

| 约束 | 值 |
|------|-----|
| 张数 | **仅 1 张** |
| 格式 | **png、jpeg**（不含 webp 等） |
| 总像素 | `[512×512, 6000×6000]` |
| 宽高比 | `[1/16, 16]` |
| 大小 | ≤ 30 MB |

**响应（逻辑结构，以 POC 为准）**

- `data[]` 含 **1～17 项**（1 底图 + 最多 16 图层）
- 每项：`url`、可选 `size`；图层项另含 `z_index`、`bounding_box`、`name` 等 metadata
- 底图 `z_index: 0`；物体层从 1 递增

**限流（IPM）**：图层拆分每次请求 **预扣 17 IPM**（按最多 1 底图 + 16 图层预留），生成完成后按**实际张数**返还多扣额度。

**计费**：按 **实际输出张数 × 各张像素档位**；`1.5K` 与 `1K` 同价（官方说明）。

### 5.2 能力 B：交互编辑（修改选中图层）

同一 `images/generations`，用 **带坐标标记的 prompt**：

| 场景 | prompt 模板 |
|------|-------------|
| 改框内区域 | `把图 1 <bbox>{x1} {y1} {x2} {y2}</bbox> 区域{用户描述}` |
| 改点附近 | `把图 1 <point>{x} {y}</point> 位置{用户描述}` |

**bbox 来源**：优先 `bounding_box.normalized`（0～999）；否则从 absolute 换算。

**与拆分不同的参数习惯**

| 字段 | 图层拆分 | 交互编辑 |
|------|----------|----------|
| `size` | 默认 `auto`，可选 1K/1.5K/2K | 官方 demo 常用 `2K` |
| `image` | 单张原图 | 合成预览图或原图（POC 定） |
| `output_format` | 控制底图；层恒 PNG | 通常 `png` |

**多主体**（官方使用说明）：bbox 内多物体时须指明目标，例如  
`把图 1 <bbox>120 180 640 760</bbox> 区域内的左侧人物换成机器人`  
或标注保持不变区域：`…区域替换成花园，图 1 <bbox>700 120 920 360</bbox> 区域保持不变`。

**可选**：`optimize_prompt_options.mode` = `standard` | `fast`（Pro 支持；fast 更快但可能略损画质）。

**响应**：**一张编辑后的整图 URL**（非透明单层）。

## 六、改层后如何更新画布（需 POC）

交互编辑返回 **整图**，不是单层 PNG。策略：

| 策略 | 做法 | 说明 |
|------|------|------|
| **A. 重拆** | 编辑后整图再跑图层拆分 | 层结构最一致；多一次计费 |
| **B. 整图替换** | 新整图作底图，清空物体层，提示可重拆 | 省 API |
| **C. 局部贴回** | 从新整图裁 bbox 贴回该层 | 体验最佳；待验证 |

**MVP 默认：策略 A（改层后自动重拆）**——交互编辑返回整图 → OSS → 再调 decompose；层结构一致，接受双倍计费。POC 若证明重拆质量差，可回退策略 B。

## 七、前端画布

| 项 | 建议 |
|----|------|
| 引擎 | 自研 Canvas / DOM 层叠 + `ImageMaskCanvas` 框选；不强制 Fabric.js |
| 坐标 | Client → World（pan/zoom）→ Normalized 0～999（[2582775](https://console.volcengine.com/ark/region:cn-beijing/docs/82379/2582775?lang=zh)） |
| 状态 | `{ id, url, zIndex, bbox, transform, name? }` |

```javascript
function clamp999(n) {
  return Math.max(0, Math.min(999, Math.round(n)));
}
function normalizedBbox(x1_px, y1_px, x2_px, y2_px, w, h) {
  return [
    clamp999((x1_px / w) * 1000),
    clamp999((y1_px / h) * 1000),
    clamp999((x2_px / w) * 1000),
    clamp999((y2_px / h) * 1000),
  ];
}
// 拆分 prompt 片段
function decomposePrompt(bboxes) {
  const tags = bboxes.map((b) => `<bbox>${b.join(" ")}</bbox>`).join("、");
  return `将图片进行精确图层分离，需分离的区域坐标为 ${tags}。`;
}
// 编辑 prompt
function editPrompt(bbox, userText) {
  return `把图 1 <bbox>${bbox.join(" ")}</bbox> 区域${userText}`;
}
```

## 十、风险与限制

1. **仅 Pro**；Lite 不可用。
2. **最多 16 物体层** + 1 底图。
3. **bbox 为矩形**，非轮廓。
4. **改层返回整图**，见 §六。
5. **输入仅 png/jpeg**；webp 上传需转码。
6. **URL 24 小时**失效，必须 OSS。
7. **IPM 预扣 17**：并发/限流需在 UI 提示。
8. **prompt ≤ 300 汉字 / 600 英文词**（官方建议）；多框时注意长度。

## 十一、FAQ

**Q：拆分和改层是同一个 API 吗？**  
A：是，都是 `POST /api/v3/images/generations` + Pro model；靠 **prompt 语义**（拆分描述 vs `<bbox>` 编辑）区分。

**Q：为什么不能用 Seedream Lite？**  
A：官方能力表明确 Lite **不支持**图层拆分与交互编辑。

**Q：和图像处理合并吗？**  
A：不合并；本功能是独立多图层工作流。
