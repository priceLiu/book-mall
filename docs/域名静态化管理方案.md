## 1. 背景与动机

全站采用 **Monorepo + 多 CloudBase 独立服务** 部署：book-mall、canvas-web、quick-replica-web 等十余个子应用各自进程、各自自定义域。域名与 Origin 目前分散在：

| 位置 | 示例 |
|------|------|
| 腾讯云 CloudBase 各服务环境变量 | `NEXTAUTH_URL`、`MAIN_SITE_ORIGIN`、`CANVAS_WEB_ORIGINS` … |
| `deploy/tencent/*.env.example` | 部署模板，与现网可能脱节 |
| 各子应用 `docker-entrypoint.sh` | 启动时 patch 默认值（如 `book.ai-code8.com`） |
| TypeScript 硬编码 fallback | `book-mall/lib/app-web-origins.ts`、`production-origin.ts` 等 |

**痛点**：更换域名需手工改多处，易漏配；env、entrypoint、代码 fallback 三套默认值可能不一致，生产 env 留空时会被 patch 回旧域。

**目标**：建立 **单一真源（Single Source of Truth）** 管理全站 hostname / Origin，换域时改一处、可生成各服务 env 清单，并逐步消除代码与 entrypoint 中的重复硬编码。

## 2. 近期域名变更需求（业务）

以下为主站与部分子站 **计划中的域名调整**（`*.ai-code8.com` 子域体系不变）：

| 应用 | 现网域名（文档/代码默认） | 目标域名 |
|------|---------------------------|----------|
| **book-mall**（主站） | `book.ai-code8.com` | **`mall-ai-code8.com`** |
| **canvas-web** | `canvas.ai-code8.com` | **`cs.ai-code8.com`** |
| **quick-replica-web** | `replica.ai-code8.com`（已废弃） | **`cp.ai-code8.com`**（现网） |

其余子站（tool、story、finance、gateway、ecom 等）**本次不换域**，但主站公网地址变更后，其 env 中凡指向主站的变量须同步改为 `https://mall-ai-code8.com`。

> **说明**：主站目标域为 `mall-ai-code8.com`（非独立根域 `mall-ai-code.com`），仍属 `*.ai-code8.com`，可继续使用 `NEXTAUTH_COOKIE_DOMAIN=.ai-code8.com` 跨子域共享会话。

## 3. 变更影响摘要（登录 / 验证码 / 支付）

### 3.1 注册与登录

| 项 | 影响 |
|----|------|
| `NEXTAUTH_URL` | **必须**改为 `https://mall-ai-code8.com`，与浏览器地址栏一致 |
| `NEXTAUTH_COOKIE_DOMAIN` | 可保持 `.ai-code8.com` |
| 子站 SSO | canvas / 快速复制仍经主站换票；`TOOLS_SSO_*` Secret **不变** |
| 用户侧 | 换域后需 **重新登录** 一次（新 Cookie） |
| finance-web 等同域子站 | Cookie 共享仍可用（同属 `.ai-code8.com`） |

### 3.2 短信验证码

| 项 | 影响 |
|----|------|
| 注册 / 登录 / 绑手机模板 | 仅发验证码，**与域名无关**；`TENCENT_SMS_*` 不用改 |
| 团队邀请短信 | 邀请链接由 `NEXTAUTH_URL` 动态生成 → 随主站域变为 `https://mall-ai-code8.com/invite/t/...` |
| 已发出的旧邀请 | 仍指向旧域，需旧域 301 或重新发邀请 |

### 3.3 微信支付

| 项 | 影响 |
|----|------|
| `WECHAT_PAY_NOTIFY_URL` | 改为 `https://mall-ai-code8.com/api/payments/wechat/notify` |
| 微信商户平台 | 回调 URL **须与 env 一致**（见 `deploy/tencent/wechat-pay-setup.md`） |
| 商户号 / 密钥 | 不因换域而变 |

### 3.4 其它回调

| 项 | 变量 / 配置 |
|----|-------------|
| Story / Canvas KIE 回调 | `STORY_AI_PUBLIC_BASE=https://mall-ai-code8.com` |
| SCF 定时任务 | `BOOK_MALL_HOST=mall-ai-code8.com` |
| Canvas 浏览器 CORS | `CANVAS_WEB_ORIGINS=https://cs.ai-code8.com` |

## 4. 现状问题（为何要静态化）

```text
                    ┌─────────────────────────┐
                    │  CloudBase 各服务 env    │  ← 生产实际生效，但分散、易漏
                    └────────────┬────────────┘
                                 │ 常不一致
         ┌───────────────────────┼───────────────────────┐
         ▼                       ▼                       ▼
 deploy/tencent/*.env.example   docker-entrypoint.sh    TS 硬编码 fallback
 (文档模板)                      (启动 patch 旧域)        (env 空时用旧域)
```

典型风险：

1. **book-mall `docker-entrypoint.sh`**：env 为空或仍为 `*.sh.run.tcloudbase.com` 时，自动写回 `https://book.ai-code8.com` 等旧值。
2. **`book-mall/lib/app-web-origins.ts`**：生产 fallback 仍为 `canvas.ai-code8.com`、`cp.ai-code8.com`（快速复制）。
3. **`book-mall/lib/production-origin.ts`**：`PRODUCTION_MAIN_SITE_ORIGIN` 等常量写死旧主站。
4. **各子应用 `lib/site-origin.ts`**：只读 env，无 env 时行为因应用而异（部分另有硬编码）。
5. **`NEXT_PUBLIC_*`**：Next.js 构建期可能内联，仅改运行时 env 不足以更新全部客户端引用 → 换域后常需 **重建镜像**。

## 5. 方案对比

### 5.1 方案 A：维持现状 — 纯环境变量

各 CloudBase 服务独立配置 env，无仓库内真源。

- **优点**：符合 12-Factor；密钥与域名分离；CloudBase 原生。
- **缺点**：换域改 N 处；与 entrypoint / 代码 fallback 易不同步。**不适合**作为长期方案。

### 5.2 方案 B：单一静态 JSON — 运行时唯一配置

全站只读 `platform-domains.json`，不再依赖 env 中的 hostname。

- **优点**：改域只改一处文件。
- **缺点**：
  - 密钥（DB、SSO、微信）**不能**进 JSON；
  - CloudBase 仍须 per-service env；
  - `NEXT_PUBLIC_*` 对浏览器 bundle 不友好；
  - 各 Docker 镜像须携带或拷贝该文件；
  - 改 JSON 后通常仍要重建、重启。**不能**作为唯一配置源。

### 5.3 方案 C（推荐）：静态清单 + 环境变量 — 混合分层

```text
┌──────────────────────────────────────────┐
│  deploy/platform-domains.json            │  ← Git 真源：hostname / cookieDomain / 端口
│  （不含密钥，可 code review）              │
└──────────────────┬───────────────────────┘
                   │
       ┌───────────┴───────────┐
       │ scripts/sync-platform-  │  （后续实现，本文档阶段不改动代码）
       │ domains.mjs             │
       └───────────┬───────────┘
                   ▼
    ┌──────────────────────────────┐
    │ 生成 / 同步                   │
    │ · 各服务 env 片段（供 CloudBase）│
    │ · TS fallback 常量（可选快照）  │
    │ · entrypoint 默认值（可选）     │
    │ · 架构文档 §2 端口表域名列      │
    └──────────────────────────────┘
                   │
                   ▼
    生产运行时：CloudBase env（**env 优先**）
    代码逻辑：process.env.XXX ?? manifestDefault
    密钥类：仅 env，永不进 JSON
```

**结论**：**方案 C 最优** — 静态文件管「公开、少变的 hostname 表」；env 管「密钥 + 运行时覆盖 + 多环境差异」。

参考本仓库已有模式：`scripts/sync-image-zoom-pan.mjs` 多子应用同步、`docker-shared/` 快照拷贝 federated 组件。

## 6. 静态清单设计（`deploy/platform-domains.json`）

> **本文档阶段**：仅定义 schema 与约定，**不创建该文件、不改代码**。

### 6.1 建议文件路径

```
deploy/platform-domains.json          # 生产 hostname 真源
deploy/platform-domains.schema.json   # （可选）JSON Schema 校验
```

### 6.2 建议内容结构

```json
{
  "$schema": "./platform-domains.schema.json",
  "cookieDomain": ".ai-code8.com",
  "production": {
    "bookMall": {
      "host": "mall-ai-code8.com",
      "port": 3000,
      "cloudbaseService": "book-mall"
    },
    "canvasWeb": {
      "host": "cs.ai-code8.com",
      "port": 3004,
      "cloudbaseService": "canvas-web"
    },
    "quickReplicaWeb": {
      "host": "cp.ai-code8.com",
      "port": 3008,
      "cloudbaseService": "quick-replica-web"
    },
    "toolWeb": { "host": "tool.ai-code8.com", "port": 3001 },
    "financeWeb": { "host": "f.ai-code8.com", "port": 3002 },
    "storyWeb": { "host": "story.ai-code8.com", "port": 3003 },
    "gatewayWeb": { "host": "gateway.ai-code8.com", "port": 3005 },
    "promptOptimizer": { "host": "prompt.ai-code8.com", "port": 3006 },
    "ecommerceToolkit": { "host": "ecom.ai-code8.com", "port": 3007 },
    "directorWeb": { "host": "director.ai-code8.com", "port": 3009 },
    "commonTools": { "host": "common.ai-code8.com", "port": 3010 },
    "publisherWeb": { "host": "publish.ai-code8.com", "port": 3011 }
  },
  "development": {
    "bookMall": { "origin": "http://localhost:3000" },
    "canvasWeb": { "origin": "http://localhost:3004" },
    "quickReplicaWeb": { "origin": "http://localhost:3008" }
  },
  "derived": {
    "wechatPayNotifyPath": "/api/payments/wechat/notify",
    "storyKieCallbackBase": "bookMall"
  }
}
```

约定：

- `host` 不含协议；脚本生成时统一加 `https://`（生产）。
- `derived.wechatPayNotifyPath` 与 `bookMall` 组合 → `WECHAT_PAY_NOTIFY_URL`。
- `derived.storyKieCallbackBase` 指向 `production` 内某 app key → `STORY_AI_PUBLIC_BASE`。

### 6.3 放入静态清单的内容

| 允许 | 禁止 |
|------|------|
| 各子应用 hostname | `NEXTAUTH_SECRET`、`DATABASE_URL` |
| 本地 dev 端口 / origin | `TOOLS_SSO_*`、`GATEWAY_*` 密钥 |
| `cookieDomain` | 微信 / 短信 / OSS 密钥 |
| 容器端口（与架构表一致） | 任何 API Key、证书 PEM |

### 6.4 与现有 env 变量名的映射（生成脚本用）

后续 `sync-platform-domains.mjs` 应维护下表，自 JSON 生成各服务 env 片段：

#### book-mall

| env 变量 | 来源 |
|----------|------|
| `NEXTAUTH_URL` | `production.bookMall` → `https://{host}` |
| `NEXTAUTH_COOKIE_DOMAIN` | `cookieDomain` |
| `BOOK_MALL_ORIGIN` / `STORY_AI_PUBLIC_BASE` | 同 `NEXTAUTH_URL` |
| `NEXT_PUBLIC_CANVAS_WEB_ORIGIN` / `CANVAS_WEB_ORIGINS` | `production.canvasWeb` |
| `NEXT_PUBLIC_QUICK_REPLICA_ORIGIN` / `QUICK_REPLICA_PUBLIC_ORIGIN` | `production.quickReplicaWeb` |
| `NEXT_PUBLIC_*_ORIGIN`（story / tool / finance / …） | 对应 app |
| `WECHAT_PAY_NOTIFY_URL` | `https://{bookMall.host}{derived.wechatPayNotifyPath}` |
| `FEDERATED_TOOLS_LOGOUT_ORIGINS` | 所有已部署子站 origin 逗号拼接 |

#### canvas-web

| env 变量 | 来源 |
|----------|------|
| `MAIN_SITE_ORIGIN` / `BOOK_MALL_URL` / `NEXT_PUBLIC_BOOK_MALL_URL` | `production.bookMall` |
| `NEXT_PUBLIC_CANVAS_WEB_ORIGIN` / `CANVAS_PUBLIC_ORIGIN` | `production.canvasWeb` |

#### quick-replica-web

| env 变量 | 来源 |
|----------|------|
| `MAIN_SITE_ORIGIN` / `BOOK_MALL_URL` / `NEXT_PUBLIC_BOOK_MALL_URL` | `production.bookMall` |
| `QUICK_REPLICA_PUBLIC_ORIGIN` / `NEXT_PUBLIC_QUICK_REPLICA_ORIGIN` | `production.quickReplicaWeb` |

#### 其它子站（tool、story、ecom、finance、gateway …）

| env 变量 | 来源 |
|----------|------|
| `MAIN_SITE_ORIGIN` / `NEXT_PUBLIC_BOOK_MALL_URL` | `production.bookMall` |
| 本子站 `*_PUBLIC_ORIGIN` / `NEXT_PUBLIC_*` | 对应 app |

#### SCF / 外部

| 配置 | 来源 |
|------|------|
| `BOOK_MALL_HOST` | `production.bookMall.host`（无协议） |

完整 env 清单以 `deploy/tencent/book-mall.env.example` 及各子站 `*.env.example` 为准；静态清单只覆盖 **与 hostname 相关的子集**。

## 7. 运行时优先级约定

```
生产 Origin 解析顺序（目标态）：

  1. process.env.{VAR}（CloudBase 显式配置）  ← 最高优先级
  2. platform-domains.json 经构建/启动注入的默认值
  3. （逐步删除）TypeScript / entrypoint 内硬编码旧域
```

特殊开关（保持现有行为）：

- `ALLOW_CLOUDBASE_DEFAULT_ORIGINS=1`：保留 `*.sh.run.tcloudbase.com` 预发域，不 patch 为生产自定义域。

## 8. 实施阶段（后续 PR，本文档不执行）

| 阶段 | 内容 | 产出 |
|------|------|------|
| **P0 文档** | 本文档 + 更新 `全站架构图与配置表.md` §2 目标域名列 | 共识与验收标准 |
| **P1 真源** | 新增 `deploy/platform-domains.json`（填入 §2 目标域） | 可提交的 hostname 表 |
| **P2 脚本** | `scripts/sync-platform-domains.mjs`：`--print-env book-mall` / `--check` | 一键输出 CloudBase 粘贴块 |
| **P3 代码收敛** | 重构 `app-web-origins.ts`、`production-origin.ts`；entrypoint 从 manifest 生成或 **生产 env 缺失则 fail-fast** | 消除三套默认值 |
| **P4 运维** | DNS、CloudBase 绑域、env 更新、旧域 301、微信商户回调 | 现网切换 |
| **P5 文档同步** | `deploy.md`、`deploy/tencent/README.md`、各 `.env.example` | 与 JSON 一致 |

**P3 原则**：

- 生产环境 **禁止** 在 env 未配置时静默 fallback 到旧 `book.ai-code8.com`（改为启动报错或 sync 脚本强制生成）。
- `NEXT_PUBLIC_*` 通过 **构建前** 从 manifest 写入或生成 TS 常量，避免仅改运行时 env 导致客户端仍用旧域。

## 10. 换域标准流程（目标态，P2 完成后）

1. 修改 `deploy/platform-domains.json` 中对应 `host`。
2. 运行 `pnpm platform-domains:sync`（或 `--check` 在 CI 中校验 TS/entrypoint 与 JSON 一致）。
3. 将脚本输出的 env 片段更新到 CloudBase 各服务。
4. 更新 DNS / TLS / 301 / 微信回调 / SCF。
5. 重建并重启受影响服务。
6. 执行 §9.4 验收项。
7. 在同一 PR 或跟进 PR 更新 `docs/全站架构图与配置表.md` §2、§7 变更记录（见 `site-architecture-doc.mdc`）。

---

## 11. 不在本方案范围内

- **密钥轮换**：仍只在 CloudBase / 密钥管理系统操作，与域名清单无关。
- **新子应用上线**：除更新 JSON 外，仍须完成 `site-architecture-doc.mdc` checklist（端口表、dev-all、SSO 登记等）。
- **独立根域**（如未来主站迁出 `ai-code8.com`）：须另评估 `NEXTAUTH_COOKIE_DOMAIN`、finance Cookie 共享、middleware HTTPS 白名单（`isProductionAiCode8Host`）等，**不在本次 `mall-ai-code8.com` 范围内**。
