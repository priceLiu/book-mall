# 平台应用总览（AI 小智知识 · 对外可讲）

> 本文件是「AI 小智」导览助手的权威应用清单，只描述**功能与用途**，不含价格、计费与内部规则。
> 用户问「平台有哪些应用 / 有什么功能 / 某个应用是做什么的」时，以本文为准。

## 平台是什么

这是一个面向个人创作者与小团队的 **AI 创作平台**，把「课程学习 + 多个 AI 创作应用」整合在一起，账号通过统一登录（Book SSO）在各应用间互通，一处登录、全站可用。平台主要包含以下应用：AI 画布、漫剧空间、电商工具箱、工具站、快速复刻、提示词优化器、3D 导演台、常用工具、一键发布，以及主站（课程与个人中心）与 Gateway 控制台。

## 主要应用一览

- **AI 画布**：无限画布式的 AI 设计/影视创作工作台。
- **漫剧空间**：漫剧 / 短剧的分镜与影像创作。
- **电商工具箱**：面向电商卖家的商品图、详情页与带货视频创作。
- **快速复刻**：按示例一键复刻生成图像 / 视频 / 场景。
- **工具站**：AI 试衣、文生图、图生视频等单点工具。
- **提示词优化器**：把粗略想法优化成高质量 AI 提示词。
- **3D 导演台**：3D 场景摆位与机位运镜，产出分镜参考。
- **常用工具**：修图、扩图、抠图、表情包等图像小工具集合。
- **一键发布**：把作品一键分发到多个社交平台。

---

## AI 画布（canvas-web）

**定位**：无限画布 + 节点式工作流的 AI 设计与影视创作工作台，一个人就是一间设计室 / 制作室。

**主要功能**：
- 拖拽「图片节点 / 文本节点 / 生图引擎 / 生视频引擎」等节点，用连线搭建工作流。
- 上传产品图、风格参考图，结合产品参数，让大模型识别分析并生成风格化设计方案。
- 生成海报、设计图，支持生成前后效果对比。
- 影视专业版 2.0（Pro2）：故事大纲 → 分镜脚本 → 三视图 / 分镜图 → 分镜视频的连贯创作。
- 生成时可自选 AI 模型与可调参数；作品可保存为项目资产复用。
- 首页有精选工作流与社区模板，可「用此工作流创建」或复制到我的画布。

**适合**：海报/电商视觉设计、影视分镜与短片、需要可复用工作流的创作者。

## 漫剧空间（story-web）

**定位**：漫剧 / 短剧的创作个人空间，从剧本到分镜影像。

**主要功能**：
- 首页、创作室、影像室与 AI 模型配置。
- 剧本 / 分镜脚本创作，连贯分镜图与分镜视频生成。
- 与画布 Pro2 的影视工作流打通，账号数据互通。

**适合**：漫剧、短剧、连续分镜内容创作者。

## 电商工具箱（e-commerce-toolkit）

**定位**：面向电商卖家的一站式 AI 创作工具箱。

**主要功能**：
- 商品主图、商品详情页、模特图等视觉素材生成。
- 带货视频、宣传短片制作与自动剪辑成片。
- 微剧情分镜故事版、IP 形象 / 海报 / VI 等品牌创意。
- 产品创作：拆为 **电商产品主图创作** 与 **电商产品详情页创作** 两个独立入口，各自建项目；每个项目选 **助手流程（Step by step）** 或 **产品图 + 参考图 + Prompt** 一种制作方式，出图前须在中间工作区确认 **Prompt 计划**（N 条可编辑生图指令）。主图项目的策略层（Step0–3）可一键快照带入详情页项目，无需重填。详见 [产品创作操作指南](../book-mall/doc/product/ecom-product-creation-workflow.md)。

**适合**：电商卖家、店铺运营、带货内容团队。

## 快速复刻（quick-replica-web）

**定位**：按示例「照葫芦画瓢」快速复刻生成。

**主要功能**：
- 浏览分类示例 → 选择模板 → 传入自己的素材 → 一键生成同款图像 / 视频 / 场景。
- 三栏交互（分类示例 / 模板 / 我的作品），新作品优先展示。

**适合**：想快速拿到「同款效果」、不想从零搭流程的用户。

## 工具站（tool-web）

**定位**：与主站 SSO 联通的独立 AI 工具前端，单点即用。

**主要功能**：
- AI 试衣 / 试衣间：人物图 + 服装图生成上身效果。
- 文生图与个人图片库。
- 图生视频、视觉实验室等。
- 智能客服助手，解答工具站使用问题。

**适合**：需要单点快速使用试衣、文生图、图生视频的用户。

## 提示词优化器（prompt-optimizer-platform）

**定位**：把粗略需求打磨成高质量 AI 提示词。

**主要功能**：
- 输入朴素描述，优化为结构化、可复用的提示词。
- 面向文本 / 生图 / 生视频等不同场景的提示词优化。

**适合**：希望提升 AI 生成效果、复用优质提示词的创作者。

## 3D 导演台（director-web）

**定位**：3D 场景摆位与机位运镜，产出分镜参考图。

**主要功能**：
- 在 3D 场景中摆放角色 / 道具、设置机位与运镜。
- 截取画面作为参考图，喂给画布的生图 / 生视频节点。
- 可在 AI 画布中以内嵌方式打开。

**适合**：需要精确构图 / 机位、再交给 AI 出图出片的影视创作者。

## 常用工具（common-tools）

**定位**：AI 图像小工具合集。

**主要功能**：
- 修图、扩图（外扩画面）、背景移除 / 抠图、表情包、海报、局部重绘等图像处理小工具。
- 注册即可体验，全站账号通用。

**适合**：需要零散图像处理的所有用户。

## 一键发布（publisher-web）

**定位**：多平台社交内容一键分发。

**主要功能**：
- 把图文 / 视频作品一键分发到小红书、抖音、微博、B 站、公众号等平台。
- 多账号矩阵管理。

**适合**：需要跨平台分发内容的创作者与运营。

## 主站与账户（book-mall）

**定位**：平台层——课程学习、账号 / 个人中心、登录互通与统一入口。

**主要功能**：
- AI 相关课程学习。
- 个人中心：账号、用量、Gateway 关联等。
- 统一登录（Book SSO），一处登录、各应用互通。

## Gateway 控制台（gateway-web）

**定位**：AI 模型网关控制台（偏进阶 / 管理用途）。

**主要功能**：
- 查看与管理可用 AI 模型、调用记录等。

**适合**：需要管理模型与查看调用情况的进阶用户 / 管理员。
