# AI 运镜穿搭展示视频

## 1. 产品定位

基于「模特 + 服装 + 场景」自动生成**纯运镜穿搭展示视频**：人物几乎不动，靠摄像机推拉、环绕、细节聚焦展示服装版型与面料，成片稳定、电商质感强。适用于服装主图、商品种草短视频。

## 2. 用户输入（极简表单）

1. **模特**（三选一）：文字创建 / 模特库选择 / 上传模特图
2. **场景**（三选一）：文字自定义 / 场景库选择 / 上传场景图
3. **服装平铺图**（必填，用户上传）

无其他参数配置，无时长选择（默认 6 秒）。

## 3. 技术链路

```
确定模特图（三模式之一）
确定场景（三模式之一）
用户上传服装图
        ↓
千问Image3.0 / Wan2.7 多图融合：
模特换装 + 场景光影融合 → 全身静态参考图
        ↓
图生视频接口（非动作迁移）→ 运镜穿搭视频
```

## 4. 视频生成规则（固定，不给用户调）

- 画面比例：9:16；时长：6 秒
- 人物：站立、仅极其轻微姿态变化，**禁止大幅度肢体动作、禁止跳舞**
- 镜头：缓慢推拉、轻微环绕、领口 / 腰线 / 裙摆细节聚焦后拉回全身
- 风格：高清真实、商业电商质感、画面稳定流畅

## 5. 提示词（系统默认预填，用户可改）

工作台提供 **静态融合 / 图生视频 / 负面** 三个输入框，初始值为下方默认文案；用户可编辑，支持「恢复系统默认」。生成时以当前框内内容为准。

## 5.1 系统默认提示词

**静态融合 Prompt**

```
保留模特五官与身形，精准还原服装的版型、面料与印花细节，人物正面全身站立，自然融入目标场景，光影匹配统一，高清商业穿搭摄影，画面干净高级。
```

**视频生成 Prompt**

```
9:16竖屏，商业服装展示视频，模特稳定站立，几乎无肢体动作，画面变化以缓慢摄像机推拉、轻微环绕运镜为主，清晰展示服装整体版型与面料细节，画面稳定流畅，高清真实。
```

**负面 Prompt**

```
肢体畸形，手部崩坏，人脸漂移，大幅度动作，跳舞，跑动，画面闪烁，模糊，曝光异常，多余肢体
```

## 6. 入口与持久化

- **入口**：电商工具箱 → 侧栏 **电商** 分组 → **短视频** → **视频运镜**（`/ecom/video/camera`）。
- **项目**：自动保存表单、参考图与 Prompt；顶栏「保存作品」写入 deliverable 快照，刷新可恢复。
- **生成记录**：融合图、成片写入「生成记录」，含 projectId、实际 prompt、模型 key。

## 7. 输出结果

- 6 秒 9:16 运镜穿搭展示视频（单套服装）

## 8. 主要风险与兜底

- 风险：模型自作主张增加大动作 → 靠固定 Prompt + 负面词强约束
- 风险：细节聚焦时服装纹理丢失 → 静态融合词强调面料细节
- 降级：多图融合连续失败 2 次，提示用户并允许切换传统 VTON 链路
