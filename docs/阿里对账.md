## 2. 对账口径

```
vendorListYuan   = vendorUnits × listUnitYuan     ← CSV「费用信息/目录总价」或 用量×目录价
platformListYuan = platformUnits × listUnitYuan
platformCredits  = Σ creditsCharged
platformRevenue  = Σ(credits × ppcSnap)
usageDiff        = platformUnits − vendorUnits
amountDiff       = platformListYuan − vendorListYuan
```

**Join Key**：`vendor|canonicalKey|tierRaw|unitKind|tokenDirection|month`

**容差**：用量或金额相对差 ≤ **5%** → `OK`；否则按方向标 `OVER_PLATFORM` / `UNDER_PLATFORM`。

**视频用量（对账）**：优先 `resultSummary.usage.duration`（成片秒），否则用户请求秒（封顶 15s）。

## 4. 状态与 UI 颜色

| reconStatus | 含义 | 颜色 |
|-------------|------|------|
| OK | 用量与金额均在容差内 | 绿 `#f6ffed` |
| OVER_PLATFORM | 平台多于厂商 | 橙 `#fff7e6` |
| UNDER_PLATFORM | 平台少于厂商 | 红 `#fff1f0` |
| MISSING_PLATFORM | 厂商有、平台无 | 深红 `#ffccc7` |
| MISSING_VENDOR | 平台有、厂商无 | 蓝灰 `#f0f5ff` |
| PRICE_MISMATCH | 用量 OK、单价不一致 | 紫 `#f9f0ff` |
| UNBOUND | 云账号未绑用户 | 黄 `#fffbe6` |

## 5. 阿里云 Adapter

CSV 列映射（`consumedetailbill_v2`）：

| CSV 列 | 用途 |
|--------|------|
| 账单信息/账单月份 | month |
| 身份信息/资源购买账号ID | CloudAccountBinding |
| 产品信息/选型配置 JSON | model + tier |
| 用量信息/用量 + 用量单位 | vendorUnits + unitKind |
| 定价信息/官网目录价 | listUnitYuan |
| 费用信息/目录总价 | vendorListYuan（挂牌） |
| 费用类型=免费额度 且 用量=0 | 跳过 |

Token 行按「Token类型」拆 `input` / `output` / `cache`。

## 6. API

```
POST /api/admin/finance/reconciliation/run
  multipart: csv 或 bill (File) — 支持 .csv / .tsv / .xls / .xlsx
  form: vendor=aliyun | engine=v2 | priceMode=list | force=1
```

Excel 会先转为 CSV 文本，再走 `consumedetailbill_v2` 表头校验与 AliyunAdapter。

响应：`ReconciliationV2Result`（summary + lines[]，含 `vendorDisplayName` / `modelDisplayName`）

```
POST /api/finance/admin/reconciliation/master/refresh-platform
  JSON: { "month": "202608" } 或 { "months": ["202608","202607"] }

GET /api/finance/admin/reconciliation/master
  ?month=202608&vendor=aliyun&status=UNDER_PLATFORM&take=500
```

对账总表：**平台 Gateway 明细为底**（打开总表或点刷新时调用 refresh-platform）；厂商 CSV/Excel 导入后填入厂商列并按 `joinKey` upsert。

## 8. 对账总表（Master Table）

| 概念 | 说明 |
|------|------|
| **总表** | `BillingReconciliationMasterLine`，全站唯一明细视图 |
| **平台底表** | `refreshPlatformMasterBaseline`：从 Gateway 聚合 platformUnits/挂牌/积分，状态 `MISSING_VENDOR` 直至导入 |
| **joinKey** | `vendor\|modelKey\|tier\|unitKind\|tokenDirection\|month` |
| **导入更新** | 上传阿里云 CSV/Excel → 该 vendor+month 的行 upsert；再上传 KIE → 追加/更新 KIE 行 |
| **账单来源** | 仅当导入过该厂商 CSV 时有值（aliyun / kie / …）；平台底表行为「—」 |
| **厂商列** | `ModelCatalog.vendor` → 展示名（如 阿里云、KIE、MiniMax） |

UI：`/admin/reconciliation` → Tab **对账总表**（默认） / **厂商导入**
