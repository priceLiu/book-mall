## 1. 产品心智（定稿）

### 1.1 每个画布的两个平级入口

| 入口 | 含义 | 列表内容 |
|------|------|----------|
| **我的资产** | 用户 **保存 / 创造** 并入库的 `ProjectAsset` | 仅「保存后」条目 |
| **平台** | **平台供给**，直接选用 | 官方模特 / 风格 / 镜头 / 数字人等 |

**用时**（Dock、插入节点等）：同一套交互里选 **「我的」** 或 **「平台的」**，两者平级。

### 1.2 「我的」共享范围 ≠「平台资产」

用户 **自己创造的资产** 可设置 **可见 / 可用范围**（与平台官方库无关）：

| 范围 | 数据表达（现网） | 在其它项目中的表现 |
|------|------------------|-------------------|
| **仅本项目** | `sourceProjectId = 当前 projectId` · `PRIVATE` | 侧栏「我的资产」不展示；Dock @「我的」不含（除非改范围） |
| **我的 · 全账号** | `sourceProjectId = null` · `PRIVATE` · owner=本人 | 任意画布的 **「我的资产」** 与 Dock @ **「我的」** 可选 |
| **团队** | `TEAM_PUBLIC`（团队租户） | 团队成员在 **「我的资产」**（团队条目）与 Dock @「我的」可见 |

> **「全账号使用（我的）」** = 跨项目复用 **本人资产**，选用侧仍显示 **「我的」**，**不是** 平台 Hub 里的官方资源。  
> **平台资产** = 平台 Hub 供给；除非用户再点「保存为我的资产」，否则不进「我的」列表。
