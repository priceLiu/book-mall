## 1. 产品心智（定稿）

### 1.1 两套库 · 全项目通用

| 库 | 谁维护 | 用户权限 | 在各项目中的入口 |
|----|--------|----------|------------------|
| **平台全局库** | 平台管理员（增删改平台副本） | **仅选用**，不维护平台条目 | 顶栏 / Dock **「平台的」** · **平台资产库** Hub |
| **我的资产** | 用户本人 | 创建、改、删、设共享范围 | 顶栏 **「我的资产」** · Dock @ **「我的」** |

所有子应用 / 画布项目均能看到 **同一套平台全局库**；**我的资产** 则是本人（及下面共享规则下的可见范围）在项目内管理。

### 1.2 「我的」共享范围（含团队 · 无需审批）

用户创造的 `ProjectAsset` 可设 **共享范围**（与平台库无关；**团队共享由用户直接设置，不需要团队管理员或平台管理员同意**）：

| 范围 | 数据表达（现网） | 表现 |
|------|------------------|------|
| **仅本项目** | `sourceProjectId = 当前 projectId` · `PRIVATE` | 其它项目侧栏 / Dock「我的」不可见 |
| **我的 · 全账号** | `sourceProjectId = null` · `PRIVATE` · owner=本人 | 任意画布的「我的资产」与 Dock @「我的」 |
| **团队** | `TEAM_PUBLIC` | 租户内成员在「我的资产」与 Dock @「我的」可见 |

> 以上均属 **「我的」**，角标仍显示「我的 / 团队」，**不会**出现在 **平台资产库** 列表中。

### 1.3 发布到平台 = 复制 · 双份维护

1. 用户从 **我的资产** 发起 **发布到平台**（普通用户：**申请 → 审核通过** 后入库；管理员：**直接**写入平台库 · 待 AM-202 完整流程）。
2. **我的**里原条目 **保留**，用户继续维护自己的那份。
3. 平台库写入 **独立副本**（OSS/元数据可复制），由 **平台管理员** 维护、删除；用户 **不能** 改平台侧副本。
4. 发布后：用户仍可在「我的 · 全账号 / 团队」中看到 **自己的源资产**；全员可在 **平台资产库** 看到 **平台副本**。
5. 入库须带 **来源**（`firstOrigin`、源 `ProjectAsset` / catalog id 等），供管理员按来源运维平台库。

### 1.4 平台 Hub 展示规则

- **模特·素材**：仅 `scope=platform` 的 Global Catalog（`platformOnly` / `audience=platform-hub`），**无**「我的作品」Tab，**无** user/team catalog 混入。
- **风格 / 镜头描述 / 数字人**：平台供给浏览选用（与「我的」分离）。
- 电商 **全局资产库**（工具条）：仍可 **平台素材 + 我的作品** 合并选图，**不**用作画布平台 Hub。

### 1.5 平台分区（将来）

- **官方**：已实现。
- **用户贡献 · 已审核**：与官方并列展示，待 AM-202（仍属平台库，非「我的作品」Tab）。
