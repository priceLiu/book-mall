## 1. 能力摘要

| 项 | 说明 |
|----|------|
| 产品入口 | 微剧故事版 → 新建 **电商专业版** → 上传产品图 → 选 **服装** |

## 2. 七维参数（dimensionSteps）

| key | label | 类型 |
|-----|-------|------|
| genderCategory | 性别品类 | 男装 / 女装 / 裙装 |
| styleCategory | 款式品类 | T恤、衬衫、连衣裙…（25 类） |
| styleAttribute | 风格属性 | 职场办公 / 日常休闲 / 户外机能… |
| tier | 档次定位 | 平价刚需 / 中端质感 / 高端轻奢 |
| customScene | 自定义场景 | 自由文本 |
| platform | 发布平台 | 淘宝 / 抖音 / 小红书… |
| outputLanguage | 输出语言 | 中文 / 英文… |

## 3. 工作流阶段（fashionPhase）

```
product_ref → dimensions → sellpoints → voiceover_pick → storyboard_pick
→ storyboard_confirm → ops_pack → output_mode → produce → done
```

内部 LLM 触发前缀：`fashion-step:{sellpoints|voiceovers|storyboards|ops}-generate`

## 4. 交付 JSON（meta.deliverable）

```typescript
type FashionDeliverableV4 = {
  schemaVersion: "fashion-v4";
  vertical: "fashion_apparel";
  productName: string;
  dimensions: Record<string, string>;
  sellpoints: Array<{ id: string; text: string; layer: "core"|"visual"|"aux"; source: string }>;
  sellpointsLocked: boolean;
  voiceovers: Array<{ id: string; type: string; narrative: string; script: string }>;
  selectedVoiceoverId: string | null;
  storyboardVersions?: Partial<Record<"A"|"B"|"C"|"D"|"E", { title: string; panels: ProPanelRow[] }>>;
```

## 5. 六镜职能 & A–E 分镜

**六镜**：场景氛围 → 服装轮廓 → 面料质感 → 卖点特写 → 穿搭场景 → 完整种草

**五版**：A 上身动效 / B 细节均衡 / C 场景氛围 / D 日常实拍 / E 质感细节

**口播 6 套**：痛点救场 / 场景种草 / 细节种草 / 性价比说服 / 品质背书 / 穿搭指南（见业务 SSOT）
