## 1. 能力摘要

| 项 | 说明 |
|----|------|
| 产品入口 | 微剧故事版 → 新建 **电商专业版** → 上传产品图 → 选 **3C 数码** |
| 策划流程 | 七维（可搜索级联）→ 卖点 → 6 套口播 → A–E 六镜 → 运营包 → 路径 B |
| 交互形态 | 右侧助手 + `ProDimensionSearchSelect` 可搜索下拉 |
| 角色参考图 | **可选**（产品演示为主，不阻断生图） |
| 工作流字段 | `meta.workflow.vertical=digital_3c`，阶段键 `proPhase` |

---

## 2. 七维参数（dimensionSteps）

| key | label | UI | 说明 |
|-----|-------|-----|------|
| productCategory | 产品大类 | searchSelect | 手机、耳机、平板…（19 类） |
| productSubCategory | 产品细项 | searchSelect + 级联 | `parentKey: productCategory`，见 config `subOptionsMap` |
| designLanguage | 设计语言 | chip | 极简科技 / 硬核电竞 / 商务沉稳… |
| tier | 档次定位 | chip | 平价性价比 / 中端均衡 / 高端旗舰 |
| customScene | 使用场景 | freeText | 通勤 / 办公 / 差旅… |
| platform | 发布平台 | chip | 共享 enum |
| outputLanguage | 输出语言 | chip | 共享 enum |

配置代码：`book-mall/lib/ecom/pro-vertical/configs/digital_3c.ts`  
前端搜索组件：`e-commerce-toolkit/components/pro-vertical/pro-dimension-search-select.tsx`

## 5. 六镜职能 & A–E 分镜（3C 专用）

**六镜**：产品亮相 → 工业设计 → 材质工艺 → 功能演示 → 场景植入 → 品牌落版

**五版**：A 开箱惊艳 / B 功能演示 / C 场景沉浸 / D 实测挑战 / E 设计美学

**口播 6 套**：痛点爆破 / 硬核参数 / 场景种草 / 颜值种草 / 性价比说服 / 使用体验

## 6. 对接 API（Book SSO · e-commerce-toolkit BFF）

与包包相同路径；Chat / parse / merge 均传 `workflowVertical`，由 registry 驱动。

额外前端能力：

- `resolveDimensionStepOptions(vertical, step, parentDimensions)` — 细项级联
- `inferFashionChoices` 对 `ui: "searchSelect"` 返回空，由搜索组件接管
