# 智选AI App 应用权限说明

1. 为保障智选AI App 产品功能实现、安全稳定运行，我们需要申请或使用操作系统的相关权限；
2. 为保障您的知情权，我们通过下方列表将产品可能申请、使用的相关操作系统权限进行展示，您可以根据实际需要对相关权限进行管理；
3. 根据产品升级，申请、使用权限的类型与目的可能会有变动，我们将及时调整列表，确保您及时获悉权限的申请与使用情况；
4. 为业务与产品的功能及安全需要，我们可能使用第三方 SDK，这些第三方也可能申请或使用相关操作系统权限，具体以对应 SDK 的隐私说明为准；
5. 所有权限均不会默认开启，只有经您明示授权后才会在实现特定功能时调用，您可以在设备系统设置中随时撤回授权；拒绝某项权限仅会使对应功能不可用，不影响其他功能的正常使用。

## 一、安卓操作系统应用权限列表

| 安卓权限名称 | 权限功能说明 | 使用场景或目的 |
| --- | --- | --- |
| CAMERA   相机 | 拍摄照片和视频 | 通过手机相机拍摄并导入图片、视频、音频等素材，用于后续的内容生成、编辑、制作、保存、发布和/或备份 |
| READ_EXTERNAL_STORAGE   读取外置存储器 | 读取手机存储空间内数据 | 读取存储中的图片、文件等内容，用于发布信息、在本地记录崩溃日志（如有）等功能 |
| READ_MEDIA_IMAGES   读取图片 | 从外部存储读取图片数据 | 读取手机存储中的图片，用于导入素材，进行内容生成、编辑、制作、保存、发布和/或本地备份 |
| READ_MEDIA_VIDEO   读取视频 | 从外部存储读取视频数据 | 读取手机存储中的视频，用于导入素材，进行内容生成、编辑、制作、保存、发布和/或本地备份 |
| RECORD_AUDIO   麦克风 | 录制音频 | 用于音频录制、语音输入，辅助音视频内容编辑、创作、发布 |
| READ_MEDIA_VISUAL_USER_SELECTED   读取用户选取的媒体文件 | 读取用户选取的媒体文件 | 读取您选取的媒体文件，用于导入素材，进行内容生成、编辑、制作、保存、发布和/或本地备份 |
| WRITE_EXTERNAL_STORAGE   写入外置存储器 | 写入外部存储 | 写入/下载/保存/修改/删除图片、文件、崩溃日志等信息 |
| QUERY_ALL_PACKAGES   应用软件列表 | 读取应用软件列表 | 用于预防恶意程序、维护服务正常运行、保障账号安全，并提供更优质的服务体验 |
| GET_ACCOUNTS   获取应用账户 | 获取设备上已安装应用创建的账号（仅获取应用相关信息，无法获取银行账号、密码等个人敏感信息） | 用于第三方账号登录 App |
| POST_NOTIFICATIONS   发送通知 | 通知运行时权限 | 允许向用户发送服务通知、活动通知 |
| READ_PHONE_STATE   获取硬件标识 | 获取设备标识信息用于用户唯一标识 | 便于提供统计分析与账号安全服务 |
