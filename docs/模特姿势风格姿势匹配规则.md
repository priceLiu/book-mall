规则三：冲突强制否决机制（防止不合理组合）
即使优先库和微调公式都对了，AI 在最终输出前还必须执行一次“合理性自检”，以下情况出现任意一条，必须重新抽取该姿势：

动静冲突：用户风格为“优雅/商务”，但抽取的姿势库是 H（沙滩奔跑）或 L（星形跳跃）→ 直接否决重抽。

道具逻辑冲突：

道具是“公文包” → 禁止匹配 H（户外运动）和 L（夸张跳跃）。

道具是“冲浪板/沙滩球” → 禁止匹配 J（商务通勤）和 K（红毯晚宴）。

道具是“高脚酒杯” → 禁止匹配 H（剧烈运动）和 L（大字形）。

道具是“雨伞” → 禁止匹配 D（单膝跪地前倾）和 L（抱头后仰）——会戳到伞面。

躯干与头部不协调：躯干大幅侧转（如45°以上），头部却要求“正视镜头”时，如果描述中出现了“脖子拧成180°”的隐含风险，需微调为“头部回正看向镜头”或“顺势看向侧方”。

手部超载：单手已拎包/拿咖啡，另一手又安排“双手叉腰”或“双手抱头”，导致手脚逻辑打架 → 必须立即修正为单手动作。

🔧 如何将以上规则写入您的 Skill（话术示例）
您不需要把上面三个大表格原封不动全塞进 System Prompt（容易超长）。我建议您按如下精简指令版嵌入 V5.0 的“第五步”位置，保证 AI 精准执行：

第五步（升级版）：风格化抽取与微调规则

生成时，严格遵循以下三层筛选逻辑：

库抽取层：根据“风格 → 优先抽取库对照表”（详见上方规则一），从指定库中优先抽取基础动作，严禁进入“禁止库”。

微调替换层：抽中姿势后，必须按“风格 → 四维微调表”（详见上方规则二）中的动作词，直接替换原姿势描述中的“手部/手臂、腿部/重心、头部/眼神、躯干”四个部分，不得简单叠加形容词。

冲突否决层：输出前执行一次合理性自检，如发现“动静冲突”、“道具逻辑冲突”、“躯干与头部不协调”或“手部超载”，立即丢弃该组合并重新抽取，直至通过自检。

示例：抽取到“B-向前行走，右手拎包”。风格为“酷冷”。应用微调替换后输出：“重心沉稳压在后腿，右腿向前迈出，左手插兜，右手自然垂落拎包，头部微侧平视前方，目光坚定冷峻”。

✅ 为什么这套规则能保证“可靠”？
亲和度规则决定了“抽奖池”是对的，避免了优雅风抽到跳跃动作的“先天错误”。

四维替换公式决定了不是“硬套形容词”，而是直接改写肢体语言，让动作本身传递风格。

否决机制是最后的“安全网”，杜绝了所有不合理的物理组合。

这样一来，无论用户怎么随机组合（模特+场景+道具+风格），AI 产出的 6~8 个姿势都能保证：动作符合风格、肢体协调自然、道具融入合理、且彼此不重复。
