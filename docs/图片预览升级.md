## 1. 目标

全站「点击图片 → 全屏预览」统一为同一套交互，用户在任一子站学会的手势在其它子站同样生效：

| 能力 | 说明 |
|------|------|
| 滚轮缩放 / 拖拽平移 | `useImageZoomPan` + `ImageZoomControls` |
| 多图切换 | 右侧竖列缩略条（≥2 张）；键盘 `↑↓←→` |
| 换图归位 | `resetKey` 变化时缩放回到 1x |
| 单图兼容 | 不传 `items` 时不显示缩略条 |

### 2.1 电商工具箱（规范源）

| 类型 | 路径 |
|------|------|
| Dialog | `e-commerce-toolkit/components/media/ecom-image-preview-dialog.tsx` |
| Hook / Host | `e-commerce-toolkit/components/media/ecom-image-preview-host.tsx` |
| 公共出口 | `e-commerce-toolkit/components/media/index.ts` |
| 类型与工具 | `e-commerce-toolkit/lib/media/ecom-image-preview.ts` |

**推荐用法**（同页多图）：

```tsx
import {
  EcomImagePreviewHost,
  useEcomImagePreview,
  mapPreviewItemsFromEntries,
} from "@/components/media";

const items = useMemo(
  () => mapPreviewItemsFromEntries(list.map((a) => ({ url: a.ossUrl, title: a.title }))),
  [list],
);
const { preview, openPreview, closePreview } = useEcomImagePreview(items);

<EcomImagePreviewHost preview={preview} galleryItems={items} onClose={closePreview} />;
```

**已接入页面**：分镜工作台、Sheet 预览、交付查阅、我的资产库、模板区、模特库、资产 Picker、生成工作区、手伴合成预览等。

## 3. Phase 2 · 待处理（管理后台台账）

以下子应用 **仍使用各自 lightbox 壳层**（`MediaLightbox`、`QrFullscreenImagePreview` 等），尚未直接 import 电商工具箱 `EcomImagePreviewDialog`。后续按本方案统一。

| ID | 应用 | 现状 | 目标 |
|----|------|------|------|
| PV-201 | **canvas-web** | `MediaPreviewLightbox` · `StoryMediaPreviewModal` | 接入 `EcomImagePreviewDialog` + `items`；或 sync dialog/host 至同名路径 |
| PV-202 | **tool-web** | 我的图片库 / 衣柜 / Visual Lab 自有 lightbox | 同上 |
| PV-203 | **story-web** | `MediaLightbox` | 同上 |
| PV-204 | **quick-replica-web** | `QrFullscreenImagePreview`（单图，无缩略条） | 同上；保留 QR 暗色主题时可包一层 variant |

### 3.1 接入步骤（每个子应用）

1. **扩展 sync 脚本**（若选复制方案）：将 `ecom-image-preview-dialog.tsx`、`ecom-image-preview-host.tsx`、`components/media/index.ts` 加入 `FILES`；确认子应用已有 `@/components/ui/dialog`（或改为 fixed 壳层如 book-mall）。
2. **替换调用点**：列表页用 `useEcomImagePreview(items)` + `EcomImagePreviewHost`；单点预览仍可用 `EcomImagePreviewDialog`。
3. **层级**：对照 Rule 弹层层级表，Dialog / fixed 须盖住侧栏。
4. **验收**：单图缩放平移；多图缩略条；`--check` 无 DRIFT。
5. **更新** Rule「已接入」表与本文件 §2 / §3 状态。

### 3.2 不在 Phase 2

- 视频预览（仍走 `EcomVideoPreviewDialog` / 各站 video lightbox）
- 新建 monorepo 共享 npm 包（当前策略：复制 + sync 校验）
