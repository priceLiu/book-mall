3C 数码品类｜AI 短视频生产规则手册 V1.0
一、适用范围
本文档适用于 3C 数码产品 的 AI 电商短视频生成，包括但不限于：
手机 / 平板 / 笔记本电脑
无线耳机 / 智能手表 / 智能手环
充电器 / 充电宝 / 数据线
键盘 / 鼠标 / 支架 / 拓展坞
影音设备 / 游戏设备 / 数码配件
智能家居小硬件
本品类与服装、包包、厨房用品完全独立，禁止混用其他品类的 “上身、背挎、厨具实操” 等展示逻辑。

三、3C 数码卖点双模式体系
1. 卖点获取方式
模式 A：用户手动输入
用户可输入零散卖点，例如：
“充电快”
“续航久”
“降噪强”
“很轻”
“适合办公”
“游戏低延迟”
“多设备切换方便”
AI 需要自动完成：清洗、去重、归类、润色、结构化。

AI 根据以下维度自动生成 5–8 条卖点：

核心功能
外观风格
档次定位
使用场景
目标用户

五、3C 数码六镜分镜体系
总时长 ≤30 秒。
单镜时长：3–7 秒，精度 0.5 秒。
短镜 ≤5.5 秒：单景别固定。
长镜 ≥6 秒：允许平缓推拉、平移、聚焦过渡。
六镜固定职能
镜 1｜场景痛点引入镜
展示用户真实使用场景，并带出痛点。
例如：
出门前电量不足
桌面线材杂乱
通勤噪音大
游戏卡顿延迟
办公设备不够顺手
耳机佩戴不稳
重点：让用户快速代入。
镜 2｜产品整体展示镜
完整展示产品外观、形态、颜色、尺寸比例。
例如：
手机正反面
耳机盒打开状态
手表佩戴状态
电脑开合状态
键盘鼠标桌面摆放
充电器与线材组合
重点：先让用户看清产品长什么样。
镜 3｜细节工艺特写镜
展示材质、做工、接口、按键、灯效、边缘细节。
例如：
金属边框
磨砂质感
接口细节
按键回弹
磁吸结构
灯效变化
表带孔位
线材接头
重点：建立品质感。
镜 4｜核心功能演示镜
3C 品类最重要镜头。
必须展示真实功能动作，禁止纯摆拍。
例如：
插上电源快速充电
耳机开盖连接
手表记录运动
键盘打字输入
鼠标移动点击
手机刷信息流
电脑多窗口办公
耳机降噪前后对比
充电宝给手机补电
桌面收纳整理
重点：把卖点可视化。
镜 5｜真实使用场景镜
展示产品融入生活、办公、娱乐、通勤等场景。
例如：
通勤路上戴耳机
办公室用电脑办公
书桌上键盘鼠标搭配
健身房戴手表记录运动
宿舍桌面游戏
旅行包里收纳充电设备
晚上学习用平板看资料
重点：让用户想象自己正在使用。
镜 6｜收尾定格镜
产品完整定格，强化记忆点。
例如：
产品居中摆放在桌面
手机与耳机手表同框
整洁桌面全貌
充电完成画面
多设备协同画面
产品 slogan 式定格
重点：完成种草闭环。
六、3C 数码五套分镜版本
A 版｜功能演示流量版
主打核心功能，节奏更直接。
适合突出：
快充
降噪
低延迟
长续航
秒连
大容量
结构：痛点 → 产品 → 功能 → 场景 → 定格。
B 版｜细节均衡全能版
外观、材质、功能、场景均衡展示。
适合大多数 3C 产品。
结构：痛点引入 → 全貌展示 → 细节特写 → 功能演示 → 场景使用 → 定格。
C 版｜科技氛围极致版
突出科技感、桌面美学、灯光、环境氛围。
适合：
电竞设备
桌面数码
智能手表
耳机
键盘鼠标
电脑配件
重点：光影、灯效、桌面秩序、未来感。
D 版｜真实生活化实拍版
减少广告感，增强真实使用感。
适合：
通勤耳机
充电宝
充电器
手机
手表
学生党数码
重点：像真实用户随手拍，但画面干净。
E 版｜质感工艺强化版
突出材质、做工、旗舰感、高级感。
适合：
高端耳机
智能手表
笔记本电脑
旗舰手机
高端键鼠
金属配件
重点：微距、慢推、材质高光、细节质感。

十一、3C 数码专属禁令
禁止套用服装、包包、厨房用品逻辑。
禁止用 “上身穿搭、背挎搭配、厨具翻炒” 等不相关展示方式。
禁止全程只摆拍，必须包含功能演示。
禁止卖点空洞，如只写 “好用、好看、高级”。
禁止过度炫光导致产品看不清。
禁止参数堆砌，要把参数转成用户能理解的好处。
禁止一次性输出全部内容，必须按 Skill 流程分步交互。
3C 数码品类｜AI 交互式 Skill 工作流 V1.0
一、界面架构
右侧 AI 交互对话区：负责提问、选择、确认、修改、流程引导。
左侧可视化展示区：负责参数档案、卖点清单、口播、分镜表格、运营素材预览。
核心规则：
提问、选择、确认全部在右侧。
内容、表格、预览全部在左侧。
二、3C 数码专属工作流
步骤 1：选择 3C 产品子类
右侧话术：
「请选择本次 3C 数码产品类型：手机 / 平板 / 笔记本 / 耳机 / 智能手表 / 充电宝 / 充电器 / 数据线 / 键盘 / 鼠标 / 显示器 / 支架 / 拓展坞 / 影音设备 / 游戏设备 / 智能家居 / 其他数码配件」
左侧同步展示：3C 产品参数档案。
步骤 2：分步采集 3C 专属参数
依次采集：
核心功能属性
外观风格属性
档次定位
使用场景
销售平台
输出语言
每次只问一个参数。
全部完成后，左侧展示：
【3C 产品参数档案】
步骤 3：3C 专属卖点确认环节
右侧话术：
「3C 产品参数已采集完成。请输入这款数码产品的核心卖点，例如快充、降噪、续航、低延迟、轻薄、多设备兼容等；也可以回复【AI 自动生成】，系统将根据产品定位自动生成 5–8 条专属卖点清单。」
用户输入后，AI 完成：
清洗
去重
归类
润色
结构化
展示在左侧
用户可增删、修改、确认。
步骤 4：生成 6 套 3C 专属口播文案
左侧展示 6 套口播：
痛点救场型
功能参数型
场景价值型
质感审美型
实用效率型
情绪体验型
右侧引导用户选择一套。
步骤 5：生成 5 套 3C 专属六镜分镜
基于选定口播 + 定稿卖点，生成：
A 版：功能演示流量版
B 版：细节均衡全能版
C 版：科技氛围极致版
D 版：真实生活化实拍版
E 版：质感工艺强化版
左侧展示完整分镜表格。
步骤 6：用户定稿分镜
支持微调：
使用场景
科技色调
功能动作
镜头时长
产品重点
桌面氛围
步骤 7：生成 3C 专属运营素材包
包括：
10 个标题
3 套封面提示词
分层标签
字幕规范
BGM / 音效
发布正文模板
步骤 8：完整交付
交付内容：
3C 产品参数档案
定稿卖点清单
选定口播文案
五套六镜分镜
全套运营素材包

四、Skill 强制执行规则
本 Skill 只适用于 3C 数码品类。
禁止套用服装、包包、厨房用品的展示逻辑。
必须分步交互，禁止一次性输出全部内容。
卖点必须围绕 3C 核心功能，如快充、降噪、续航、低延迟、连接、收纳、便携。
分镜中必须包含功能演示镜头，禁止纯摆拍。
所有内容必须适配产品子类、使用场景和目标用户。
