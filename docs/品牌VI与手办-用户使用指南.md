# 品牌 IP 创作 · 用户使用指南（手办盲盒 + 品牌 VI / 表情包）

> **适用对象**：运营、设计师、自媒体博主、文创创业者、接单同学。
> **工具入口**：电商工具箱（本地默认 `http://localhost:3007`，或 Book 主站 SSO 进入）。
> **本文档范围**：把 [`docs/手办.md`](./手办.md) 与 [`docs/品牌VI与表情包.md`](./品牌VI与表情包.md) 两份设计/PRD 文档，整理成**普通用户可照着用的操作说明**，不含工程实现细节。

---

## 0. 开始前必读（共用前提）

1. **登录**：用 Book 账号 SSO 进入工具箱，未登录会跳转登录。
2. **AI 生图授权**：须已关联 Gateway API Key（`sk-gw`）；页面内通过「选择 AI 模型」卡片选取生图模型。
3. **扣点**：工具按月费 / 积分按 `toolKey` 扣点，厂商成本走 Gateway BYOK 或平台代付池。
4. **一致性核心机制**：两个能力都采用 **「基准形象锁定」** —— 第 1 步生成并确认主形象后，后续所有物料都锁定这张图的脸型、发型、配饰、服装、比例，只改表情 / 动作 / 场景 / 配色，不让角色“跑偏”。

## 1. 两个能力是什么、怎么选

| 能力 | 侧栏位置 | 路由 | 产物风格 | 适合谁 |
|------|----------|------|----------|--------|
| **手办创作** | 电商 · 手办创作 | `/ecom/hand-craft` | 泡泡玛特潮玩 **3D 盲盒**向全案 | 想做盲盒、周边实物、招商授权的人 |
| **品牌 VI · 表情包** | 营销 · 品牌 VI | `/brand/vi` | 偏 **2D 平面 / VI / 表情包** | 想做社媒头像、表情包、品牌规范的人 |

**关系**：两者都从「一张基准图或一段文字 Brief」出发。若有稳定角色，建议先在 **IP 母版**（`/brand/ip`）定基准图 + 结构化模板 → 保存进母版库 → 再「从母版库导入」到手办 / VI，能最大程度避免“前后不像同一个 IP”。

## 2. 手办创作（`/ecom/hand-craft`）—— 线稿转盲盒全案

### 2.1 你要准备什么

- **1～3 张线稿 / 参考图**（手绘线稿、立绘、头像、草图均可）；或纯文字描述角色。
- 上传后系统会先 **1:1 保留线稿造型**，全程不乱改原生结构。

### 2.2 十步流程（进度轨有依赖，前序成图齐了才能拼版）

| 步 | 名称 | 产出要点 | 用户要做的 |
|----|------|----------|------------|
| 1 | 核心主形象 | 定稿 **hero 基准图**（标准站姿、纯白底） | 确认 / 重绘（仅调光影配色，不动线稿轮廓） |
| 2 | 基础规范三件套 | 三视图（正/侧/背）+ 4 表情 + 5 动作 | 确认即批量出 |
| 3 | 6 款盲盒角色卡 | 换穿搭+主题（甜点/森系/居家/田园/假日/冬日），脸型发饰不变 | 选是否出全套 6 张 |
| 4 | 周边样机 | 钥匙扣/亚克力立牌/帆布包/马克杯/贴纸/手机壳/眼罩/笔记本整版 | 确认生成 |
| 5 | 色卡 + 细节拆解 | 主色/辅助色/点缀色卡 + 头部/服装/肢体拆解 | 确认生成规范页 |
| 6 | 盲盒包装 | 包装盒正/背/内卡/腰封（可工厂打样） | 确认渲染 |
| 7 | 九宫格表情包 | 9 款社交商用表情 | 确认扩写 |
| 8 | 小红书长图 | **拼版**：三视图+角色档案+盲盒+周边+色卡集一图 | 确认排版 |
| 9 | 12 页作品集 | **拼版**：固定页序（封面→档案→三视图→表情→色卡→盲盒→单卡→周边→包装→九宫格→长图→版权封底） | 确认生成框架 |
| 10 | 招商授权页 | **拼版**：授权赛道（盲盒联名/文创/快闪/服饰/美妆/表情包商用） | 确认收尾 |

### 2.3 风格与一致性

- 建项目后可在助手选 **视觉风格预设**：潮玩 3D / Q 版 / 扁平 / 国潮 / 赛博 / 自定义。
- **中途换风格会重置 hero 锁**，需从第 1 步重定稿。
- 全程视觉基底：泡泡玛特软胶手办质感、圆润 Q 版、低饱和干净色调、柔和漫反射光影、纯白底。

### 2.4 从 IP 母版导入

中栏参考区点「从母版库导入」→ 选条目与版本 → 基准图写入参考区，生图时自动追加母版约束（刚性锚点等）。

### 2.5 导出与资产

- 步内 / 项目可「保存到资产库」（module `hand-craft`）。
- 项目菜单 / 导出入口支持 **ZIP 打包**（含交付清单）。

## 3. 品牌 VI · 表情包（`/brand/vi`）—— 2D 品牌化 IP

### 3.1 你要准备什么

- **1～3 张参考图**（人物图 / 线稿 / 头像 / Logo 草图）；或纯文字 Brief（品牌名、角色气质、主色、用途）。

### 3.2 创建时先选「产出模式」（单选，决定进度轨可见步骤）

| 模式 | 可见步骤 | 适合 |
|------|----------|------|
| **基础 IP** | 基准 → 三视图 → 九宫格 | 快速要形象+表情 |
| **表情包专项** | 基准 → 九宫格 | 只做社交表情 |
| **VI 专项** | 基准 → Logo → VI 规范页 | 只做品牌识别系统 |
| **文创专项** | 基准 → 周边 → 场景海报 | 只做周边/海报 |
| **完整全案** | 全部 8 步 | 一次性出整套（推荐） |

### 3.3 八步流程

| 步 | 名称 | 类型 | 说明 |
|----|------|------|------|
| 1 | 基准 IP 形象 | 生图 | 定稿 `heroLockedUrl`，后续参考图第一张恒为基准 |
| 2 | 三视图 | 生图 3 槽 | 正/侧/背横向排 |
| 3 | 九宫格表情包 | 生图 9 槽 | 开心/呆萌/害羞/生气/撒娇/加油/犯困/探头/摆手 |
| 4 | Logo | 生图 2 槽 | 从角色头部提炼图形标识（非整身当 Logo） |
| 5 | 周边样机 | 生图 8 槽 | 手机壳/帆布包/亚克力立牌/马克杯/贴纸/眼罩/笔记本/钥匙扣 |
| 6 | 场景海报 | 生图 4 槽 | 科技办公/社媒/四季/节日/品牌主视觉 |
| 7 | VI 规范页 | **拼版** | 依赖 hero、logo、turnaround；主辅点缀色卡+拆解+使用规范 |
| 8 | 作品集长图 | **拼版** | 依赖 hero、emoji、merch；竖版 9:16，用于发布/接单 |

> 注：产品为 **8 步 + 5 种模式**，无独立「招商授权页」「12 页 PDF」（那是手办第 10 步）；透明底 PNG、动态表情包、字体规范为后续迭代。

### 3.4 操作要点

- **无参考图** 仅凭 Brief 也能生成并确认基准形象。
- 第 1 步定稿即锁 hero；助手「进入下一步」只要**下一步硬依赖的槽位已出图**即可（不必当前步全完成）。
- **编辑 Prompt**：槽位与预览统一入口。
- **从 IP 母版导入**：与手办同入口、同约束注入。

## 4. 通用规则（两个能力都遵守）

1. **分步确认制**：每步产出后先确认，再进下一步；不一次性批量生成全部物料。
2. **基准锁死**：基准形象确认后，所有延展物料的脸型 / 五官 / 发型 / 配饰 / 服装 / 比例**不可改动**。
3. **局部重绘**：某步不满意，仅重绘当前步（调光影/配色/构图），不重置已锁定的基准。
4. **输入重置**：上传全新线稿 / 参考图，自动重置全流程，从头开始。
5. **风格切换**：仅重新生成基准形象，确认后再继续后续模块。
6. **纠错**：反馈“不像同一个角色” → 立即回基准图，基于基准重绘当前模块，不动基准本体。

## 6. 常见问题

| 现象 | 排查 |
|------|------|
| 生图报 `url error` / 模型不对 | 确认 Gateway 登记的 IMAGE 模型；Seedream 类走火山分支 |
| 前后步骤脸不像 | 确认第 1 步 hero 已锁定；勿在未换风格时删掉 hero 参考；可先用 IP 母版再导入 |
| VI 第 8 步灰了 | 检查 hero、emoji、merch 是否已有成图（**不要求** 先做第 7 步） |
| 拼版步空白 | 前序依赖步是否出图；VI 拼版后未刷新看快照 merge 是否已修复 |
| 401 / 闪退登录 | SSO token 过期 → 重新从 Book 进入工具箱 |

## 7. 一句话上手

- **想做盲盒/实物周边/招商**：进 `/ecom/hand-craft`，传线稿 → 走 10 步 → 导出 ZIP。
- **想做社媒头像/表情包/品牌规范**：进 `/brand/vi`，选模式 → 走 8 步 → 导出资产。
- **有稳定角色反复用**：先 `/brand/ip` 存母版库，再导入上面两个，省去每次重新定基准。
