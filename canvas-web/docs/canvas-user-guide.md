# ZH 无限画布 · 使用说明

> 产品名称：**ZH 无限画布**（影视专业版 2.0）  
> 最后更新：2026-08-19

## 1. 首页

### 1.1 开始创作

- 点击 **「开始我的创作」** 将直接新建并打开 **影视专业版 2.0** 空白画布，无需再选版本。
- 首页 Hero 下方随机展示 3 条 **精选工作流**（仅 2.0 项目），可复制到你的账户继续编辑。

### 1.2 最近项目

展示你最近更新的画布，**查看全部** 进入「我的画布」。

### 1.3 发现

发现区分为 **全部 / 精选 / 模板 / 案例** 四个 Tab：

| Tab | 内容来源 | 说明 |
|-----|----------|------|
| 全部 | 精选 + 模板 + 案例 | 合并展示 |
| 精选 | 管理员设为首页精选的 2.0 画布 | 他人作品先预览，可复制 |
| 模板 | 用户公开的 2.0 社区模板 | 他人作品先预览，可复制 |
| 案例 | 管理员审核通过的 2.0 案例 | 他人作品先预览，可复制 |

**仅展示影视专业版 2.0 内容**；影视专业版（旧）、分镜视频 1.0 不会出现在发现列表。

**点击行为：**

- **自己的**精选/案例项目 → 直接进入画布编辑。
- **他人的**精选/案例/模板 → 打开预览；右上角 **「复制到我的画布」** 后可编辑使用。
- **自己的**模板 → 复制到画布并打开（模板无独立编辑路由）。

## 2. 分享与投稿

### 2.1 普通用户

| 方式 | 入口 | 是否即时对外 |
|------|------|----------------|
| **社区模板** | 画布工具栏 → **分享到社区** | **是**，立即出现在首页「模板」 |
| **精选** | 我的画布 → 卡片 **投稿** → 选「精选」 | **否**，须管理员审核 |
| **案例** | 我的画布 → 卡片 **投稿** → 选「案例」 | **否**，须管理员审核 |
| **私有模板** | 画布工具栏 → **保存为我的模板** | 仅自己可见 |

投稿说明：精选、案例提交后进入待审核队列；审核通过后展示在发现区对应 Tab。

### 2.2 管理员

- 顶栏 **「我的画布」** 右侧出现 **「管理中心」**（仅管理员可见）。
- **管理中心** 内含 **工作流管理**（门户投稿审核、精选/案例/社区模板）与 **模板管理**（Pro2 剧本 LLM 模板 + 节点资产模板）。
- 详见全站文档 `docs/画布管理中心.md`。
- **我的画布** 卡片上可直接开关 **案例**、**首页（精选）**。
- **投稿 / 发布** 弹层可选全部类型并 **立即生效**。

## 3. 关联剧本包（团队功能）

- 画布顶栏 **「关联剧本包」** 仅对 **团队空间用户** 与 **平台管理员** 显示。
- **个人空间普通用户** 不显示该入口；个人创作无需关联剧本包即可使用 2.0 画布。

团队用户通过关联已发布剧本包，配合公告栏与制作任务协同生产。

## 4. 我的画布

- 新建默认以 **影视专业版 2.0** 为主入口。
- 历史 **影视专业版（旧）**、**分镜视频 1.0** 项目仍可在「我的画布」中管理，但 **不会** 出现在首页发现区。
