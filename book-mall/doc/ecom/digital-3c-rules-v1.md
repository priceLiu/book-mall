# 3C 数码 AI 短视频生产规则手册 V1.0

> **SSOT**：微剧故事版 `digital_3c` 垂类唯一生产规范。  
> 代码配置：[`book-mall/lib/ecom/pro-vertical/configs/digital_3c.ts`](../../lib/ecom/pro-vertical/configs/digital_3c.ts)  
> JSON 交付：[`pro-deliverable-spec-v1.md`](./pro-deliverable-spec-v1.md)

本品类与服装、包包、厨房用品完全独立，禁止混用「上身穿搭、背挎搭配、厨具翻炒」等展示逻辑。

## 一、八维基础参数体系

| # | key | 说明 |
|---|-----|------|
| 1 | `productCategory` | 产品大类（搜索单选） |
| 2 | `productSubCategory` | 产品细项（随大类级联） |
| 3 | `designLanguage` | 设计语言 |
| 4 | `coreFunctionAttributes` | 核心功能属性（主方向，单选） |
| 5 | `tier` | 档次定位 |
| 6 | `customScene` | 使用场景（自由输入） |
| 7 | `platform` | 发布平台 |
| 8 | `outputLanguage` | 输出语言 |

### 1.1 产品大类（25 项）

手机 / 耳机 / 智能手表 / 平板 / 笔记本电脑 / 充电器 / 移动电源 / 数据线 / 手机壳 / 屏幕贴膜 / 支架 / 音箱 / 智能手环 / 相机 / 无人机 / 游戏手柄 / 键盘 / 鼠标 / 散热器 / **显示器 / 拓展坞 / 影音设备 / 游戏设备 / 智能家居小硬件 / 数码配件**

细项 map 见 `DIGITAL_SUBCATEGORIES_BY_CATEGORY`。

### 1.2 设计语言

极简科技 / 硬核电竞 / 商务沉稳 / 潮流时尚 / 户外硬核 / 复古胶片 / 未来感 / 桌面美学 / 智能家居 / 办公效率

### 1.3 核心功能属性（15 项）

快充 / 长续航 / 降噪 / 高清音质 / 轻薄便携 / 大屏护眼 / 高性能 / 低延迟 / 磁吸 / 多设备兼容 / 人体工学 / 桌面收纳 / 智能连接 / 防水防汗 / 耐用抗造

用户选定一项作为主功能方向；更多功能在卖点环节手输或 AI 补充。

### 1.4 档次定位（3C 专用）

平价性价比 / 中端均衡 / 高端旗舰

> 与服装/包包的 `PRO_TIERS`（平价刚需/中端质感/高端轻奢）** intentionally 不同**，更贴合数码消费心智。

### 1.5 输出语言强制规则

选定后，口播、字幕、标题、封面词、标签、运营正文**全部同步**为该语言。

## 二、卖点双模式 + 分层

| 模式 | 说明 |
|------|------|
| 手动输入 | AI 清洗、去重、分层、编号 S01–Sn |
| AI 自动生成 | 结合八维 + `coreFunctionAttributes` 生成 5–8 条 |

| 层级 | 数量 | 落地 |
|------|------|------|
| core | 2–3 | 口播台词 |
| visual | 3–4 | 镜 3/4 特写与功能演示 |
| aux | 其余 | 运营素材 |

**强制**：每镜 `sellpointIds` ≥ 1；`coverageChecklist` 核心+视觉全部 ✅。

---

## 三、口播 6 套（固定结构）

1. 痛点爆破型  
2. 硬核参数型  
3. 场景种草型  
4. 颜值种草型  
5. 性价比说服型  
6. 使用体验型  

---

## 四、六镜职能 + 景别曲线

| 镜 | 职能 | 景别 |
|----|------|------|
| 1 | 场景痛点引入·产品亮相 | 全景/中全景 |
| 2 | 整体外观·工业设计 | 中全景/中景 |
| 3 | 材质工艺·细节特写 | 中近景/近景 |
| 4 | **核心功能·动态演示**（必镜） | 近景/特写 |
| 5 | 场景植入·真实使用 | 中景 |
| 6 | 收尾定格·品牌落版 | 中全景 |

- 总时长 ≤ 30s；单镜 3–7s（0.5 精度）；全片口播 ≤ 100 字  
- 镜 4 必须含真实功能动作，禁止纯摆拍

## 五、五版分镜

| 版 | 名称 | 适用 |
|----|------|------|
| A | 开箱惊艳版 | 新品首发 |
| B | 功能演示版 | 功能型 SKU |
| C | 场景沉浸版 | 通勤/办公/宿舍 |
| D | 实测挑战版 | 续航/防水/延迟信任 |
| E | 设计美学版 | 旗舰/金属工艺 |

C/E 版口播允许 ±15% 微调；A/B/D 版 100% 忠实主干口播。

## 九、专属禁令

1. 禁止套用服装/包包/厨房展示逻辑  
2. 禁止全程纯摆拍（必须含功能演示镜）  
3. 禁止空洞卖点（好用/高级）  
4. 禁止 LLM 输出 Markdown 分镜表（必须 `pro-deliverable` JSON）  
5. 禁止一次性输出全流程（分步 Choice 确认）  
6. 禁止参数堆砌不转用户利益
