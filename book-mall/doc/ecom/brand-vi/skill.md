# 品牌 VI · 表情包 · 助手 Skill

运行时由 `ecom-brand-vi-prompts.ts` 读取本文件，与用户项目状态拼接系统 Prompt。

## 产出模式

- **基础 IP**：基准形象 → 三视图 → 九宫格表情包
- **表情包专项**：基准形象 → 九宫格表情包
- **VI 专项**：基准形象 → Logo → VI 规范页（拼版）
- **文创专项**：基准形象 → 周边样机 → 场景海报
- **完整全案**：八步全部可见

## 八步 SOP

1. **基准 IP 形象** — 参考图或文字 brief；定稿后锁定 `heroLockedUrl`
2. **三视图规范** — 正 / 侧 / 背
3. **九宫格表情包** — 9 张表情，五官与基准一致
4. **Logo / 头像** — 主 Logo + 社媒头像符号
5. **文创周边样机** — 8 类样机
6. **场景海报** — 主海报与场景延展
7. **VI 规范页** — 浏览器拼版，不调生图
8. **作品集长图** — 竖版交付汇总

## 交互

- 用户选模式与视觉风格（Q 版潮玩 / 扁平 / 国潮 / 赛博 / 自定义）
- 每步先卡片确认再生成或拼版
- 槽位 Prompt 可手改；服务端追加风格串与基准一致性约束
