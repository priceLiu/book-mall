## 1. 产品定位

面向女装/服装电商卖家：通过创作助手采集模特、场景与风格，服务端按 **风格 + 场景 tags** 匹配姿势库，编排 6～8 个差异化全身姿势；**道具在姿势计划表填写**；在中栏确认 Prompt 计划后批量生成上身展示图。

## 2. 布局与交互分区

| 区域 | 职责 |
|------|------|
| **右栏助手** | 采集服装/模特/场景/元信息；Choice 点选；流式 Markdown；交互与微剧故事版一致 |
| **中栏工作区** | 参考图（服装/模特/场景）、姿势计划表（场景/道具点选）、确认计划、批量出图 |
| **左缘进度轨** | 采集 → 姿势方案 → 确认 → 出图 |
| **资产库页** | `/ecom/shoot-catalog`：场景 / 道具 / 姿势三 Tab；系统库只读 + 我的库 CRUD |

**禁止**：助手栏出图；中栏重复第二套采集向导。

## 3. 采集流程（V2）

| 步骤 | 内容 | 模式 |
|------|------|------|
| Step0 服装 | 商品实拍/款式锁定 | 上传 / 我的资产（**必填**） |
| Step1 模特 | 人物形象 | 模特库 / 上传 / AI 推荐 / 手写 |
| Step2 场景 | 背景环境（**可选**） | 场景库 / 上传 / 手写 / **跳过** |
| Step3 道具 | **不在此采集** | 助手仅两选项：「不需要道具」「稍后在姿势表填写」 |
| Step4 元信息 | 张数 6～8、平台、风格 1～2 个 | Choice 点选 |
| Step5 姿势方案 | 服务端 pose-picker（**风格 + 场景 tags**）产出 N 条 | 同步至中栏 |
| Step6 确认出图 | `plan.status=confirmed` 后启用 | 中栏操作 |

### 场景三处可设

1. **采集阶段**：上传 / 词库 / 手写 / 跳过
2. **生成姿势时**：参与 `pose-picker` 匹配（需 catalogId 或 tags）
3. **姿势计划表**：可再次从场景库点选或改文字（默认 6～8 条共用项目级场景）

### 道具表内填写

- 生成姿势后，在 **姿势计划表** 的道具列从词库点选或留空
- 支持 **「应用到全部」**
- 不参与 pose-picker 自动否决（生成姿势在填道具之前）

## 4. 资产库（系统 + 我的）

| 类型 | 系统库 | 我的库 |
|------|--------|--------|
| 维护 | Book `/admin/templates?tab=ecom` 管理员 | 用户 `/ecom/shoot-catalog` |
| 可见 | 全员只读 | 仅本人 |
| 编辑 | 管理员 | 未锁定可 CRUD |
| 锁定 | — | 被项目引用且 **确认计划** 或 **任一成图 ready** 后不可编辑/删除 |
| 提示词 | 条目内字段（visualPrompt / visualDescription / baseDescription） | 同左 |

- **姿势自动抽取**：仅 **系统姿势库**（platform scope）
- **用户自建姿势**：供计划表手动替换，不进自动池
- **模特库**：复用现有 `EcomModelLibraryEntry`

## 5. 出图

- 支持参考图的 IMAGE 模型
- 参考图顺序：服装 → 模特 → 场景
- 道具仅 Prompt 文字，不传参考图（MVP）
- 长耗时走 `BackgroundGenerationDock`

## 6. 验收标准

1. 新建项目 → 助手采集（无道具向导）→ 场景可选 → 中栏姿势表填道具 → 确认 → 批量出图
2. 选影棚场景 + 优雅风格 → 姿势无 H/L，偏 A/J/K
3. 选海滨场景 + 活泼风格 → 含 B/H
4. 姿势表场景/道具词库点选 + 应用到全部
5. 用户自建场景（选 archetype）→ 我的库可见；确认计划后锁定
6. 管理后台可维护 platform 场景 tags；助手/picker 即时生效
7. 成图入库 `EcomAsset` module=`model-shot`

## 7. 非范围

- AI 试衣 `aitryon-refiner` 精修
- 与主图创作姿势方案互通导入
- 独立第四张「提示词片段库」表
