# 服装模特图 · 需求文档

- **创建日期**：2026-08-31
- **入口**：`/ecom/model-shot`
- **toolKey**：`ecom-toolkit__model-shot`
- **关联方案**：[solution.md](./solution.md)、[skill.md](./skill.md)

## 1. 产品定位

面向女装/服装电商卖家：通过创作助手采集模特、场景、道具与风格，编排 6～8 个差异化全身姿势，在中栏确认 Prompt 计划后批量生成上身展示图。

## 2. 布局与交互分区

| 区域 | 职责 |
|------|------|
| **右栏助手** | 六步对话采集、Choice 点选、流式 Markdown；交互与微剧故事版一致（折叠 → 右下角悬浮输入） |
| **中栏工作区** | 参考图（服装/模特/场景/道具）、姿势计划表编辑、确认计划、批量出图与结果网格 |
| **左缘进度轨** | 采集 → 姿势方案 → 确认 → 出图 |

**禁止**：助手栏出图；中栏重复第二套采集向导。

## 3. 采集流程

| 步骤 | 内容 | 模式 |
|------|------|------|
| Step0 服装 | 商品实拍/款式锁定 | 上传 / 我的资产（**必填**） |
| Step1 模特 | 人物形象 | 模特库 / 上传 / AI 推荐 / 手写 |
| Step2 场景 | 背景环境 | 场景库推荐 / 上传 / 手写 |
| Step3 道具 | 手持或身配 | 不需要 / 道具库 / 上传 / 手写 |
| Step4 元信息 | 张数 6～8、平台、行业、风格 1～2 个 | Choice 点选 |
| Step5 姿势方案 | 服务端 pose-picker 产出 N 条 | 同步至中栏 |
| Step6 确认出图 | `plan.status=confirmed` 后启用 | 中栏操作 |

## 4. 平台共享库

- **姿势库**、**道具库**、**场景库**：DB 优先 + JSON fallback；管理后台 CRUD；跨模块复用
- **模特库**：复用现有 `EcomModelLibraryEntry`

## 5. 出图（MVP）

- 支持参考图的 IMAGE 模型（`isRefCapableEcomImageModel`）
- 参考图顺序：服装 → 模特 → 场景
- 长耗时走 `BackgroundGenerationDock`；成功 toast

## 6. 验收标准

1. 新建项目 → 六步助手 → 中栏确认 → 批量出图全流程可走通
2. 助手折叠/悬浮与故事版一致
3. 模特可从模特库选择；服装必填
4. 管理后台可增删姿势/道具/场景；助手推荐即时生效
5. 成图入库 `EcomAsset` module=`model-shot`

## 7. 非范围（MVP）

- AI 试衣 `aitryon-refiner` 精修（Phase 2）
- 与主图创作姿势方案互通导入
