# 单积分统一计价 v2

> **状态**：实施中（2026-08）  
> **代码真源**：`book-mall/lib/pricing/unified-credit-formula.ts`、`credit-pricing-formulas.ts`、`model-margin-policy.ts`  
> **财务后台**：finance-web `/admin/credit-pricing` · `UnifiedCreditFormulaPanel`  
> **替代语义**：财务 2.0「通用池 + 视频池」双积分、按档位 `computeTierCredits` 不同扣分

---

## 1. 产品定论

| 原则 | 说明 |
|------|------|
| **一种积分** | 用户只看到一个余额；废除通用/视频双池（存量合并入 `balanceCredits`） |
| **扣分人人相同** | `扣减 = U₀ × units`；`U₀` 来自 `ModelCreditPrice.creditsPerUnit` |
| **用得越多越便宜** | 价差仅在 **ppc = 售价 ÷ 到账积分**（订阅档、轻量包、API 充值） |
| **不能亏本** | `videoMinMarginGuard` 默认 **22%**；SKU 在最贵锚定模型上验算 |
| **月费/月积分** | 保持现网 Pricing 2.0 seed（标准 1000 … 至尊 30000） |

**订阅会员**成本：模型推理 + 应用/工具平台（摊入月费）。  
**API 会员**成本：仅模型推理；充值 ppc 更低，扣分仍相同。

成本 **C** 来自 `ModelCostProfile`：`listCost × (1 − discountRate)`（渠道/合约后净成本）。  
厂商公挂牌与净成本之比用于贵视频 **M 对齐**（示例：Seedance 挂牌 1.4、净 1.0 → M=1.4），**不限定**必须「年框」口径。

---

## 2. 公式（v2）

```
C   = listCost × (1 − discountRate)
M   = resolveModelMarginM(unit, C, listCost)   // 贵视频：max(list÷C, 1.25)
P   = C × M
U₀  = round(P ÷ anchor)                        // anchor 默认 0.04 元/积分
扣减 = U₀ × units                              // 视频秒数封顶 15s
ppc = 售价 ÷ 到账积分
实收 = 扣减 × ppc
毛利 g = 1 − (C × units) ÷ 实收
ppc_max = (C × units) ÷ (扣减 × (1 − m_min))
```

**废弃（仅扣费）**：`credits = round(P_total ÷ ppc)`（`computeTierCredits`）—— 导致各档扣分不同。

## 4. 与双池旧方案对比

| | 双池（已退役） | 单积分 v2 |
|--|----------------|-----------|
| 用户余额 | 通用 + 视频 | **一个数** |
| 视频限制 | 20% 视频池硬隔离 | 同 U₀ + ppc 自然约束 |
| 扣分 | 各档 `computeTierCredits` 不同 | **人人 U₀ 相同** |
| 便宜来源 | 视频专项包 | 高档订阅 / 大轻量包 / API 充值 |
