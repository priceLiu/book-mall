# 电商产品创作 · 用户操作指南

面向卖家与运营，说明「电商产品主图创作」与「电商产品详情页创作」两个工作台怎么用。不涉及内部 API 与代码实现。

## 两个入口

电商工具箱里有两个独立入口，各自建项目、各自出图：

| 入口 | 产出 |
|------|------|
| **电商产品主图创作** | 卖点策略 + 主图分层文案 + 主图 |
| **电商产品详情页创作** | 详情页架构 + 分屏文案 + 详情屏 |

一个项目建好后属于哪个入口就固定了，不能中途改做另一种。你可以只做主图、只做详情页，或先做主图再做详情页。

两个入口的界面结构一样：

| 区域 | 作用 |
|------|------|
| **中间工作区** | 上传参考图、选平台、填产品信息、选制作方式、**Prompt 计划**、点按钮出图、预览与导出 |
| **右侧助手** | 流式输出各步文案；点「下一步 / 修改当前步」推进；不代替中间区出图 |

## 两种制作方式（出图前汇合）

每个项目上传产品图后先选一次：

| 方式 | 说明 |
|------|------|
| **助手流程（Step by step）** | 助手带着你逐步填写策略与文案，再生成 Prompt 草稿 |
| **产品图 + 参考图 + Prompt** | 你写生图意图（参考图可选），系统拆解成 N 条 Prompt |

无论哪种方式，**出图前都必须**在中间工作区完成 **Prompt 计划**：系统展示 N 条可编辑的生图 Prompt，你确认后再出图。走 Prompt 方式时 **不需要**先选张数——张数由拆解出的 Prompt 条数决定。

## 助手流程 · 策略层（Step0–3）

两个入口走助手流程时，**都** 先过策略层，这四步需要你参与：

| 步骤 | 内容 |
|------|------|
| **Step0 信息采集（Brief）** | 产品名称、目标人群、核心痛点、核心优势 |
| **Step1 产品拆解** | 视觉调性、合规红线等 |
| **Step2 营销方案** | 生成 3 个方案，你选 1 个 |
| **Step3 购买理由** | 购买理由矩阵 |

### Step0 由你决定用不用 AI

进入 Step0 时，助手先让你二选一：

- **AI 拆解产品图**：调用一次视觉模型，一次性给出四个字段的候选，你逐一点选确认
- **手动输入**：四个字段依次自己填，**不产生任何模型调用**

系统 **不会** 在你没点之前自动读图。

### 营销方案一经选定即锁定

选中方案后不能换选，但方案 **内容**（切入逻辑 / 击中痛点 / 用户收获）在中间工作区仍可用铅笔修改。方案名称只读。

### 策略层可以带去详情页，不用重填

策略层结果保存在项目里，不依赖聊天记录。跨入口传递有两条路：

**做完主图后。** 主图全部出齐时，中间工作区会出现「主图已出齐，继续做详情页？」的卡片。点「去做详情页」，系统新建一个详情页项目，把 Step0–3、产品图与主图成品（作为详情页风格参考）一起带过去，然后跳转过去。

**直接进详情页入口。** 点顶部「从主图项目导入」（没有项目时在空白页点「从已有主图项目导入」），挑一个已有主图项目，同样把 Step0–3 与图片带过来。可以勾选是否一并带产品图、是否用主图成品当风格参考。

两种方式都是 **拷贝快照**：带过来之后两个项目各自独立，改主图项目不会影响已建好的详情页项目。带过来的策略层内容仍可修改。

导入过策略的详情页项目里，助手会问一次 **「沿用已有策略 / 先去中间区修改策略层」**：

- 沿用 → 直接进 Step7，已选方案、拆解结论、购买理由自动进入模型上下文
- 先去修改 → 在中间工作区改完 Step0–3 再回来点「下一步」

没导入策略的详情页项目，正常从 Step0 走完整流程。

## 助手流程 · 各入口后续步骤

### 产品主图

Step0–3 → **Step4 主图分层文案** → 中间区「主图 · Prompt 计划」点 **从文案生成草稿** → 检查/修改每条 Prompt → **确认计划并开始出图** → **Step5 出主图**。

### 产品详情页

Step0–3 → **Step7 详情架构** → **Step8 分屏文案** → 「详情 · Prompt 计划」→ 确认 → **Step9 出详情图**。

**Step4 是主图专属**，详情页入口不跑这一步。

全部完成后可 **导出交付包（ZIP）** 或 **去做视频**。

### 要点

- 助手只产出 **文案**；生图 Prompt 以中间区 **已确认计划** 为准。
- 未确认计划就点「生成」时，系统会提示先回到 Prompt 计划工作区。

---

## 产品图 + 参考图 + Prompt

两个入口用法一致：选平台 → 填生图意图 Prompt（参考图可选）→ 进入 Prompt 计划点 **识别并拆解** → 确认 → 出图。

- 主图：产品实拍图必传，**main-style 风格参考为可选项**
- 详情页：需要 detail-style 长图参考 **或** 自写 Prompt，两者至少有一个

---

## Prompt 计划工作区说明

1. **产品理解**：产品名、品类、卖点等（拆解结果可改）。
2. **生图 Prompt 列表**：每条含标题 + 完整中文生图指令。
3. **操作**：
   - **识别并拆解 / 从文案生成草稿**：重新生成列表（会回到草稿状态）。
   - **保存修改**：仅保存编辑，未确认前可继续改。
   - **确认计划并开始出图**：按列表创建对应数量的出图槽位。

单张「生成」与「生成全部」均使用列表里 **当前的 Prompt**，不再临时拼接一条 Prompt 重复出多张。

### 你改过的 Prompt 会被保留

手动改过的 Prompt 会打上标记。之后再点 **识别并拆解 / 重新生成草稿** 时，这些条目 **不会被覆盖**，按钮旁会提示将保留几条。想让某条回到系统版本，清空后重新拆解即可。

## 参考图角色

| role | 用途 |
|------|------|
| **product** | 商品实拍，出图须锁定款式/颜色/材质 |
| **main-style** | 主图店铺风格（模特、场景、光线） |
| **detail-style** | 详情页版式/模块节奏参考（常为长图） |

## 常见问题

**为什么要先确认 Prompt？**  
避免「一条笼统描述 × N 张图」导致画面雷同或偏离参考；每条 Prompt 对应一张图的职责与构图。

**如何增减张数？**  
在 Prompt 列表底部 **增加一张** 或删除某条，再 **确认计划**（若已出过图，增删后需重新确认）。

**导出与预览**  
- 点击主图/详情缩略图可 **画廊预览**（右侧缩略图切换）。  
- **导出交付包** 下载 ZIP（文案 + 主图 + 详情 + 参考图分类）。

**助手栏能直接出图吗？**  
不能。助手引导你到中间区确认 Prompt 计划后再点生成。

**必须先做主图才能做详情页吗？**  
不必。两个入口相互独立，可以只做详情页。若两个都做，策略层（Step0–3）只需在主图项目填一次，再带到详情页项目。

**主图项目改了策略，已建好的详情页项目会跟着变吗？**  
不会。导入是一次性拷贝，两个项目之后各改各的。需要同步就在详情页项目里手动改。

**一个项目能同时做主图和详情页吗？**  
不能。一个项目只属于一个入口。同一款产品要做两样，就在两个入口各建一个项目，用导入把策略层带过去。

**导入策略会扣费吗？**  
不会。导入是纯数据拷贝，零模型调用。

**哪些操作会调用 AI？**  
Step0 的「AI 拆解产品图」、各步文案生成、Prompt 拆解、出图。选「手动输入」的 Step0 不产生调用。
