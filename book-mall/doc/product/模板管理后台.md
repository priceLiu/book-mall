- **创建日期**：2026-08-14  
- **状态**：Phase 1–3 已落地（Book `/admin/templates`；电商走 Prisma；QR 内嵌 admin 已拆除）  
- **关联产品**：[quick-replica-platform.md](./quick-replica-platform.md)、[e-commerce-toolkit.md](./e-commerce-toolkit.md)  
- **关联逻辑**：[admin-access.md](../logic/admin-access.md)

## 1. 背景与目标

运营需要在 **Book 管理后台** 统一管理两套平台预置模板 catalog：

1. **快速复制（QuickReplica）** — 视频 / 图像 / 角色 / 场景 / 音频等官方示例模板  
2. **电商工具箱** — 模板区（按品类）与模特库

迁后现状：

| 能力 | QuickReplica | 电商工具箱 |
|------|--------------|------------|
| 完整管理 UI | Book `/admin/templates?tab=quick-replica` | Book `/admin/templates?tab=ecom`（模板区 / 模特库） |
| 旧入口 | `/admin/quick-replica/templates` 仅 redirect；QR 侧栏外链 Book | 电商「导入 HTML」仍为快捷入口，写入同一 Prisma |
| 数据 | `QrTemplate`（Prisma）+ builtin JSON | `EcomTemplateCatalogEntry` / `EcomModelLibraryEntry`；JSON 仅种子 |

**目标**：将 QuickReplica 的完整管理能力 **迁入 Book 管理后台**，与电商模板/模特管理 **合并为同一入口「模板管理」**，运营只登录 Book 即可维护两套 catalog。

**零遗留原则（已确认）**：迁移完成后 **不保留** QuickReplica 应用内 admin、不保留 Book 旧简化页、不保留 Platform 写接口双轨；仅保留 Book 单一管理入口与 Book Session 写 API。详见 §4.5、§8。

**不在本需求首期范围**（另立需求）：电商模板区用户侧「同款」三栏工作流（左菜单 / 中工作区 / 右结果）。本需求聚焦 **运营侧 catalog CRUD**。

## 2. 产品决策（已确认）

| 决策 | 结论 |
|------|------|
| 管理入口位置 | **Book 管理后台**（`/admin/*`），非 QuickReplica 应用内、非电商侧栏一级菜单 |
| 页面名称 | **模板管理** |
| 一级 Tab | **快速复制** \| **电商工具箱** |
| 是否在 QR 应用内继续维护 catalog | **否**；QR 仅提供跳转 Book 的链接，**无**内嵌 admin |
| **零遗留** | **是**；不长期保留双 admin UI、双写 API；见 §4.5 |
| 权限 | 与现 QR admin 一致：`canViewFinanceCost` / `requireFinanceAdminApi` |

## 4. Tab：快速复制（迁移要求）

### 4.1 能力对齐参照

以 `quick-replica-web/components/quick-replica/qr-admin-panel.tsx` 为 **功能基准**，迁入 Book 后交互对齐、视觉遵循 Book admin（`site-home.css`），**不**整页复制 QuickReplica MiniMax 皮肤。

### 4.2 编辑表单字段（与 QR 一致）

| 字段 | 说明 |
|------|------|
| `category` / `kind` / `toolKey` | QR 分类与子类 |
| `title` | 标题 |
| `thumbnailUrl` | 封面（列表卡片） |
| `targetImageUrl` | 目标/主图 |
| `sceneImageUrls[]` | 参考图，最多 9 张 |
| `referenceVideoUrl` / `outputUrl` / `mediaUrl` | 视频/输出媒体 |
| `promptText` | 提示词（必填） |
| `modelKey` + 音频等 `params` | 默认生成模型与参数 |
| `sortOrder` | 排序 |
| builtin 覆盖 | `catalogBuiltinId`；支持「恢复内置」 |

### 4.3 后端（Book Session 为唯一写入口）

| 用途 | 路由（Book Session） | 服务 |
|------|----------------------|------|
| 列表 / 创建 / 更新 | `/api/admin/quick-replica/templates` | `qr-template-admin-service` |
| 单条 / 删除 | `/api/admin/quick-replica/templates/[id]` | 同上 |
| 资源上传 | `/api/admin/quick-replica/assets/upload` | `qr-asset-upload` |
| 用户作品审核 | `/api/admin/quick-replica/user-templates`（新建，或扩展现有 admin 路由） | 同上 / 专用 handler |
| 分类示例 featured | `/api/admin/quick-replica/kinds/[kind]/featured`（新建，自 Platform 迁入） | `QrKindFeatured` 相关服务 |
| 音频 prompt 模板 | `/api/admin/quick-replica/audio-prompt-templates`（新建，自 Platform 迁入） | 现 Platform handler 逻辑下沉 |
| 表单解析 | — | `qr-admin-template-form.ts` |

Book 页 **只调用** 上述 `/api/admin/*`，**不**经 QuickReplica BFF + Platform Bearer。

**Platform 写 API（迁移完成后删除，不保留兼容）**：

- `DELETE` 整个目录 `book-mall/app/api/platform/v1/quick-replica/admin/**`
- 含：`templates`、`templates/[id]`、`user-templates`、`audio-prompt-templates`、`kinds/[kind]/featured`

### 4.4 QuickReplica 应用内 admin 拆除（Phase 1 收尾，必做）

| 动作 | 路径 / 说明 |
|------|-------------|
| 删除内嵌 admin | `quick-replica-web/components/quick-replica/qr-admin-panel.tsx` 及 **仅 admin 引用** 的组件（或迁至 book-mall 后 QR 零引用） |

| 文档 | 更新 `quick-replica-platform.md` § 管理后台入口 |

### 4.5 零遗留迁移顺序（禁止边迁边长期双轨）

1. **Book 新建** `/admin/templates`，快速复制 Tab 能力 **≥** 现 `QrAdminPanel`（含用户作品、featured、音频 prompt）。  
2. **Book 扩展** `/api/admin/quick-replica/*`，覆盖原 Platform admin 全部写能力。  
3. **验收** finance-admin 在 Book 可完成原 QR admin 全部操作。  
4. **QR 改造**：admin 改外链；删除 `QrAdminPanel` 与预览内写操作。  
5. **删除** Platform admin 路由 + Book 旧简化页；旧 URL 仅 redirect。  
6. **全仓校验**（应为 0 命中，文档除外）：
   - `QrAdminPanel`
   - `platform/v1/quick-replica/admin`
   - `navMode === "admin"`（QR 内）

**禁止**：在 Book 能力未齐前删除 QR admin（会导致运营能力倒退）。

## 5. Tab：电商工具箱

### 5.1 模板区 — 字段（对齐 QR 概念，电商语义）

| 字段 | QR 对应 | 说明 |
|------|---------|------|
| `id` | — | 稳定 ID，如 `accessories-001-xxx` |
| `category` | `category` | `womens` \| `mens` \| `kids` \| `home-textile` \| `bags` \| `shoes` \| `accessories` |
| `mediaKind` | `mediaType` | `image` \| `video` |
| `title` | `title` | 展示标题 |
| `hot` | badges.hot | 爆款标记 |
| `coverUrl` / `thumbUrl` | `thumbnailUrl` | 列表封面（预生成 `-thumb.webp`） |
| `mainImageUrl` | `targetImage` / `output` | 主图（预览/同款主素材） |
| `referenceImages[]` | `sceneImages` | 多张参考图 `{ url, label? }` |
| `promptText` | `reference.prompt.text` | 提示词（可选 negative） |
| `defaultModelKey` + `defaultParams` | `reference.model` | 同款默认模型（Gateway IMAGE/VIDEO） |
| `ossUrl` | 主媒体 | 原图或视频 URL（现有字段，可与 main 合并或保留兼容） |
| `posterUrl` | — | 视频封面（可选） |
| `sortOrder` | `sortOrder` | 排序 |

**存量数据**：当前 `catalog.json` 仅含 `ossUrl/thumbUrl/title/hot`；上线 rich schema 后需 **补录或分批迁移** prompt/参考图。

### 5.2 模板区 — 管理操作

- 列表：分类 + 图/视频筛选 + 搜索（title/id）
- 新建：表单 + OSS 上传（封面、主图、参考图、视频）
- 编辑：同上；支持替换媒体
- 删除：**二次确认**；若删除 OSS 对象，第二次确认须写明云端存储（见 `destructive-delete-confirmation.mdc`）
- 批量：保留现有 HTML 导入能力，导入结果可在本页补全 prompt/参考图；导入队列逻辑仍在电商工具箱前端，写入 catalog 经 book-mall API

### 5.3 模特库 — 字段与操作

| 字段 | 说明 |
|------|------|
| `id` | 如 `female-123`、`plus_female-247` |
| `name` | 展示名 |
| `gender` | `female` \| `male` \| `plus_female` |
| `age` | `adult` \| `child` |
| `ossUrl` | 原图 OSS |

操作：列表、上传、编辑名称/分类、删除（二次确认 + OSS）。

### 5.4 持久化（待实施时拍板，推荐 DB）

| 方案 | 说明 |
|------|------|
| **推荐** | 新增 Prisma 表（如 `EcomTemplateCatalogEntry`、`EcomModelLibraryEntry`），运行时 API 读 DB；JSON/脚本作种子与迁移 |
| 过渡 | 继续写 `catalog.json`（多环境运维差，仅适合短期） |

OSS 路径保持现 convention：

- 模板：`ecom/template-gallery/{category}/{id}.{ext}`，缩略图 `{id}-thumb.webp`
- 模特：`ecom/model-library/{id}.{ext}`

服务层扩展：`book-mall/lib/ecom/ecom-template-gallery-service.ts`；模特库需新建对称 service + admin API。

### 5.5 电商 admin API（待新建）

## 6. 权限与安全

- 所有 `/api/admin/ecom/*` 与 QR admin 路由统一 **`requireFinanceAdminApi()`**
- 禁止在电商工具箱前端对普通用户展示写操作；现 `tools_role === admin` 的「导入 HTML」可逐步收敛到 Book 模板管理，或保留为运营快捷入口（仍服务端 admin 校验）
- OSS 删除须 UI 二次确认；API 不替代人工确认

## 7. 与「资源库（图/视频）」的区别

| 入口 | 对象 |
|------|------|
| `/admin/tool-libraries` | 用户生成资产（按用户） |
| **本需求 `/admin/templates`** | **平台预置** catalog（QR 模板 + 电商模板/模特） |

## 10. 验收标准

### 功能

1. Finance 管理员登录 Book，在 **工具与应用 → 模板管理** 可见两个 Tab（电商 Tab 未就绪时可占位）。  
2. **快速复制** Tab 可完成与 **迁前** `QrAdminPanel` **等价**的全部操作：创建/编辑/删除、参考图、prompt、封面、builtin 覆盖、用户作品审核、featured、音频 prompt 模板。  
3. **电商工具箱 → 模板区** 可单条增删改（Phase 2）。  
4. **电商工具箱 → 模特库** 可增删改（Phase 3）。  
5. 普通用户 **无法** 调用 admin 写 API。  
6. 删除破坏性操作符合二次确认规范（含 OSS 文案）。  
7. 旧 `/admin/quick-replica/templates` 访问后 **重定向** 至新页，无独立 CRUD 页。

### 零遗留（Phase 1 发布必验）

8. QuickReplica 应用内 **无** `QrAdminPanel`、**无** admin 全屏模式。  
9. QuickReplica 模板预览 **无**「设为分类示例」等写按钮。  
10. 仓库内 **无** 对 `platform/v1/quick-replica/admin` 的运行时代码引用（文档除外）。  
11. finance 角色在 QR 侧栏可见「模板管理」链接，点击直达 Book `/admin/templates?tab=quick-replica`。
