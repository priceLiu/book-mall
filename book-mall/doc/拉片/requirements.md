## 1. 一句话说明

上传一条 ≤90s 视频，AI 逐镜拉片分析；再用**新模特图 + 新产品图**按原片镜头语言复刻成片。流程与拆图拆视频**壳层一致**（上传 → 分析 → 一键复刻 → 素材 → 制作 → 合成），但制作表用**拉片自己的分镜结构**，不叫「精细成片」。画布侧同一结构写入专业版制作包（`analysis`），不再压缩成 8 字段。

## 2. 和拆图拆视频的区别

| | 拆图拆视频 | 专业拉片 |
|--|-----------|----------|
| 用户 | 电商小白 | 专业/进阶 |
| 分析结果 | 15 列简表 | **25 维**逐镜表（只读） |
| 制作表 | 种草 seed-video 7 列 | **拉片制作脚本表**（画布/光影/运镜 + 生图/生视频 Prompt） |
| 成片区名称 | 方案② · 精细成片 | **制作成片** |

## 3. 用户流程（6 步）

### 步骤 1 · 拉片

- 上传视频（≤90s）
- 点「拉片」或开发环境 Mock 拉片
- **拉片结果只读**：25 维分镜表 + 叙事/卡点/拍摄脚本三块
- 可保存项目、导出交付包

### 步骤 2 · 一键复刻 + 素材

- 拉片完成后，结果区或底栏点 **「一键复刻」**
- 上传 **模特图**（可多张）、**产品图**（可多张）
- 填写或 **AI 识产品** 产品描述

### 步骤 3 · 参考图匹配

- 系统 **自动** 为每一镜匹配要用哪些模特图、产品图（@图片1、@图片2…）
- 用户在 **匹配表** 里可改任意镜的 ref 组合
- 点 **「确认参考图匹配」** 进入下一步

### 步骤 4 · 制作脚本

- 系统按拉片结构 **组装制作脚本**（画布描述、光影、运镜、生图 Prompt、生视频 Prompt 等）
- 用户在表里 **可改**，点 **「确认制作脚本」**

### 步骤 5 · 制作成片

- 进入 **制作成片** 工作区（不是 seed-video 那套表）
- 每一镜可以：
  - **只生视频**（参考图 + 生视频 Prompt → R2V）
  - **先生图再生视频**（可选）
  - **改 Prompt 再生成**（可多次）
- 支持勾选多镜批量生图/生视频

### 步骤 6 · 合成

- 各镜都有分镜视频后，点 **「合成成片」**
- 预览整条视频，保存/导出

## 4. 页面布局（与拆图拆视频对齐）

- **顶栏**：新建、项目列表、我的资产、保存、导出
- **主区自上而下**：视频上传 → 拉片指令 → 拉片结果 →（复刻后）素材采集 → 参考图匹配 → 制作脚本 → 制作成片
- **底栏**：阶段引导 + 「一键复刻」等主按钮（脚本确认后底栏收起）

## 5. 验收标准

1. 上传视频 → Mock/正式拉片 → 只读 25 列结果
2. 一键复刻 → 上传模特/产品 → 自动匹配表 → 改某镜产品 ref → 确认
3. 生成制作脚本 → 改生视频 Prompt → 确认
4. 制作成片：A 镜只生视频；B 镜先生图再生视频；可重复生成
5. 全部镜有视频 → 合成 → 预览/导出
6. 管理后台 `/admin/pending-features` 可见 FP-101～118 待处理项

## 6. 非目标（V2 仍不做）

- \>90s 分段拉片
- QuickReplica
- 制作阶段修改镜数或时间轴（时间继承拉片结果，不可改）
- 专业拉片走 seed-video「精细成片」表（已废弃）
